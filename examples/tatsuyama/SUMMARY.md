# 要約 — ハバード模型に対する CRM シャドウ

> 詳細は [README.md](README.md)(全実験の記録、1,549行)、[ROADMAP.md](ROADMAP.md)(確立した主張と未解決問題)、[CRM_RESEARCH_NOTES.md](CRM_RESEARCH_NOTES.md)(論文化用ノート)、[paper/](paper/)(論文4本)。**この文書はそれらへの入口**である。

## 一行でいうと

**古典計算で作った近似状態(prior)をランダム測定に組み合わせると測定分散が減る。その削減率は prior の「良さ」全般では決まらず、測りたい観測量ごとの局所的な近さだけで決まる** — だから prior のグローバル忠実度が系サイズとともに指数的に崩壊しても、局所観測量の利得は生き残る。

## 中心にある式

```math
G = \frac{(3^{\lvert A\rvert}-1)\langle P\rangle^2 + v_s}{(3^{\lvert A\rvert}-1)\Delta^2 + v_s},
\qquad v_s = \frac{3^{\lvert A\rvert}(1-\langle P\rangle^2)}{n_m},
\qquad \Delta = \langle P\rangle_\rho - \langle P\rangle_\sigma
```

$P$ は局所Pauli列、 $A$ はその台、 $\rho$ は実験状態、 $\sigma$ は prior、 $n_m$ は1設定あたりのショット数、 $G=\mathrm{Var}[\text{標準}]/\mathrm{Var}[\text{CRM}]$。

この式から読めることが3つあり、それが研究全体の骨格になっている。

1. **prior のグローバル忠実度が式に現れない。** 効くのは観測量ごとの局所誤差 $\Delta$ だけ。
2. **$v_s$ は分子・分母の両方に同じ形で入る**ので消せない床であり、 $\Delta\to0$ でも $G$ は $G_{\max}=1+(3^{\lvert A\rvert}-1)\langle P\rangle^2/v_s$ で頭打ちになる。
3. **$G<1$(損)が起こりうる。** $\langle P\rangle=0$ が対称性から厳密な観測量では打ち消すべき揺らぎが最初からゼロなのに、対称性を破った prior が $\Delta\neq0$ を作るため。

## 主要な結論

| # | 主張 | 最も強い数字 |
|---|---|---|
| 1 | **利得法則は約5.9桁で成り立つ** | $G=1.8\times10^{-3}$〜 $1.3\times10^{3}$(§1、8量子ビットED + マスタープロット218点) |
| 2 | **グローバル忠実度が崩壊しても局所利得は保たれる** | $L=8\to128$ で $F$ が120分の1に崩壊する間、利得を決める相対誤差 $\varepsilon$ は3.8倍・ $G$ は1.2分の1にしか動かない(§2b) |
| 3 | **利得は鎖のどこでも生き残る** | $L=128$(256量子ビット)全サイト、17,210点。 $\chi_p\ge4$ なら損はゼロ(§2b) |
| 4 | **MPS を作らない平均場 prior が MPS prior に匹敵する** | $W=6$ シリンダー(96量子ビット)、 $U=8$ onsite $ZZ$: UHF $G=157$ 対 $\chi=32$ MPS $G=96$(§8) |
| 5 | **CRM は制御変量法に一般化でき、「損をしない」形にできる** | 係数をデータから推定すると $G\ge1$ が保証され、損をしていた全ケースが修復(§6) |
| 6 | **prior が破った対称性は、群平均でタダで回復できる** | 測定コストゼロ。SU(2) では $\langle S^z\rangle$ が $-6\times10^{-17}$ に、並進では $\chi_p=4$ +平均が完全な prior と一致(§2i, §2j) |
| 7 | **利得は測定なしで予測できる — 台に縮約したトレース距離ひとつから** | 半充填では $\lvert\Delta\rvert=2D_A$ が恒等式。破れる条件まで閉形式 $\min(1,2/(1+4r))$, $r=\lvert\Delta(S^z)\rvert/\lvert\Delta_P\rvert$ で、 $r$ が10桁にわたる24点で最大誤差 0.0022(§2m) |

## 実験の一覧

| 節 | 問い | 答え |
|---|---|---|
| 1 | 利得法則は本当に成り立つか | 約5.9桁で一致。損のケースも予言どおり |
| 2 | 系を大きくすると手法は無意味になるか | ならない。 $F$ は指数的に死ぬが $\varepsilon$ はほぼ $L$ 非依存 |
| 2b | 利得は鎖の「どこでも」出るか | 出る。ただし場所によって5〜17倍ばらつく |
| 2c | なぜボンド量の利得が1本おきに振動するのか | 開放端が作る Friedel 振動。PBC にすると完全に消える |
| 2d | 損の領域は直せるか | 直せる。ただし素朴なプラグイン $\hat\beta$ は $\mathrm{Var}(Y)\to0$ で発散するので解析式が要る |
| 2e | 局所性はどこまで成り立つか | 必要ボンド次元 $\chi^\ast$ が、ギャップのある系では飽和(16)、gapless では $L$ とともに増加 |
| 2f | 独立に構成した prior(HF)でも成り立つか | 成り立つが、素の UHF は3〜4割のサイトで損。対称性回復で完全にゼロ |
| 2g | 参照状態を厳密対角化にしても変わらないか | 変わらない($L\le14$、OBC で全2,688点が厳密に一致) |
| 2h | 切断が本当に効く状況(PBC)でも変わらないか | 変わらない。差は $G$ の統計誤差の 1/123 |
| 2i | Z型以外の観測量では何が見えるか | 横スピン相関で UHF の SU(2) 破れが露呈(縦横比 7.14、真値 1.000)。既存の対称性回復が球面平均でなかったことも判明 |
| 2j | prior の対称性は設計軸になるか | なる。群平均は測定コストゼロで、並進版は最悪サイトの損を消し、 $\chi_p=4$ +平均が完全な prior に一致 |
| 0.5b | $n_u$ と $n_m$ はいくつにすべきか | $n_u$ は $G$ に無関係。 $n_m$ は境目 $n_m^\ast$ に対して決める(粗い prior ほど小さく) |
| 3 | どの物理領域で・どの観測量に効くか | 弱結合は運動項、強結合は密度・スピン。天井の高さは $\langle P\rangle$ が決める |
| 4 | 2D でタダの平均場は MPS に代われるか | オンサイト量・運動項では代われる。サイト間スピン相関は対称性回復が必要 |
| 4b | 安価な prior はどこで破綻するか | ドープ系の電荷テクスチャ。誤差は列 $x$ にのみ依存する縞構造を示す |
| 5 | matchgate シャドウと組み合わせると二重に得か | ならない。JW弦は解けるが、Gauss測定は自己平均的で CRM の効く余地が小さい |
| 6 | 損をしない推定器は作れるか | 作れる。単一Pauli列では最適β利得は **prior 非依存** |
| 7 | 既存手法(derandomization)に勝てるか | 固定リストには derand が強い。CRM は測定後に観測量を選べる点と最悪誤差の半減で相補的 |
| 8 | 幅を増やすとどうなるか | MPS だけが指数的に苦しくなる($\chi\sim e^{cW}$)。平均場は $O(N^3)$ のまま |
| 9 | 安い prior の相図の境界はどこか | 電荷テクスチャで平均場が破綻。スピンセクターは対称性回復で救える |

## 撤回・訂正の記録

自分の主張を後から潰した箇所を残してある。**論文化のとき、査読者に先回りして書くべき部分**でもある。

| 何を | どう間違っていたか | 現在 |
|---|---|---|
| ショット配分の指針 | 「設定を減らしショットを増やせ」— $G$ は最大化するが、**総予算固定なら誤差は $n_m$ に単調増加**する | 閾値 $n_m^\ast=3^{\lvert A\rvert}(1-\langle P\rangle^2)/[(3^{\lvert A\rvert}-1)\Delta^2]$ を提示 |
| $U=8$ の「異常」 | $\chi=8$ だけのアーティファクト($\lvert\Delta\rvert$ 比が $\chi$ で 0.43, **7.31**, 0.21, 0.55) | 撤回。**単一の $\chi$ での比較は信用しない**という方法論に |
| 局所性の機構 | 「 $\Delta$ が $L$ 非依存だから」— 実際は $\chi_p=2$(飽和)でしか成り立たない | 正しくは「 $G_{\max}$ に貼り付いている(ショットノイズ律速)から」 |
| §2b/§2c のサイト依存性 | 帰無検定をしていなかった | PBC にすると $\langle P\rangle$ の依存性が完全に消えることを確認(変動係数 0.25→0.0015) |

| 対称性回復の効果 | 「オンサイト量には影響しない」— **全体**と**項ごと**を混同 | 項ごとには変わり、多項観測量の $G$ は変わりうる |
| §2g の「厳密ゼロ」 | 一般的主張としては強すぎた | PBC・別シードでは差が出る(ただし統計誤差の 1/123) |
| プラケットを二量体化する理由 | 「一様だと基底状態が非一意」— **Lieb の定理により $U>0$ では一意**。縮退するのは $U=0$ だけ | 一様 $t=1$ を本編にし、弱化版は対照に降格 |
| 「分散を最大80分の1」 | 出典不明。本スクリプトの最大は 2.0倍 | 「旧実装は36点中18点で標準に負ける」に差し替え |
| §2m の最初の結論(「部分系の忠実度でも決まらない」) | (i) 台より大きい窓を使い、(ii) prior を横断して相関を取っていた | 両方直すと上界は**飽和**し、仮説は支持される |

## わかっている限界

- **擬似実験である。** 参照状態 $\rho$ は DMRG(または ED)で作ったもので、実機のノイズ・読み出し誤差は入っていない。
- **ED による直接確認は $L\le14$(28量子ビット)まで。** §2 は $L=32$、§2b は $L=128$ を扱うので、そこは $\chi$ 収束チェックでの代替になる。
- **2D は $W=4,6$ のシリンダーのみ。** 本物の2次元極限は取れていない。
- **境界条件に依存する結論が1つある。** $\chi_p=2$ は OBC では損ゼロだが PBC では約8%のサイトで損をする。実務上の下限は $\chi_p\ge4$。
- **CRM が効かない領域がある。** matchgate(Gauss)測定では $G\approx0.5$– $1.9$ にとどまる。決定論的な測定計画(derandomization)には原理的に適用できない。

## 実務上の指針(この研究から出る処方箋)

1. **測りたいのが局所観測量なら、系の大きさを理由に諦める必要はない。** 見るべきは忠実度ではなく $\Delta/\langle P\rangle$。
2. **prior は $\chi_p\ge4$ を下限に。** それ以下は境界条件次第で損をする。
3. **prior 側は絶対に標本推定しない。** ここが先行実装の敗因であり、本研究の出発点。
4. **$n_m$ は prior の質に合わせる。** 境目は $n_m^\ast=(1-\langle P\rangle^2)/\Delta^2$ で、基底切替が1回ショット $c$ 個ぶんのコストなら最適は $n_m^{\rm opt}=\sqrt{cn_m^\ast}$。**粗い prior ($\chi_p=2$)ほど $n_m$ を小さく** — 実測では $n_m=100$ は最適の20倍以上で、誤差で約11倍損をしている。一方 $n_u$ は利得 $G$ に一切影響しない(比で約分される)。詳細は README §0.5b。
5. **$G$ を引用するときは必ず $n_m$ を併記する。** 総ショット数 $B$ を固定して配分だけを振ると、**CRM 側の誤差はほぼ不変で標準シャドウだけが20倍悪化する** — $G$ が 1.45 から 568 へ伸びるのはその効果である(実測、README §0.5b)。最適配分( $n_m=1$ )での上限は prior の質によらず $G\le 1/(1-\langle P\rangle^2)$ で、実測 1.55 対 上限 1.559。
6. **prior を信頼できるなら $\beta=1$、不確かなら最適β。** ただし $\beta^\ast$ の推定には $O(1/\sqrt{n_u})$ のノイズが残るので、 $\beta^\ast\approx1$ が分かっているなら決め打ちが有利。
7. **prior は古典後処理なので観測量ごとに使い分けてよい**(追加測定ゼロ)。二重占有は共線UHF、スピン相関は対称性回復UHF、というように。
8. **幅の広い2D系ほどタダの平均場 prior が相対的に有利になる。** MPS は $\chi\sim e^{cW}$、UHF は $O(N^3)$。
