## 一行でいうと

**古典計算で作った近似状態(prior)をランダム測定に組み合わせると測定分散が減る。その削減率は prior の「良さ」全般では決まらず、測りたい観測量ごとの局所的な近さだけで決まる** — だから prior のグローバル忠実度が系サイズとともに指数的に崩壊しても、局所観測量の利得は生き残る。

かみくだくと次のようになる。

- 量子コンピュータで量を測るとき、測定結果は毎回ばらつくので、何度も測って平均する。その回数を減らしたい。
- 測りたい状態を古典計算でおおまかに真似た状態(prior)があれば、その「真似」が出すはずの値を測定結果から引くことで、ばらつきの大部分を打ち消せる。
- どれだけ打ち消せるかは、prior が状態**全体**としてどれだけ正確か(忠実度)では決まらない。**測りたい量の値を prior がどれだけ正しく言い当てているか**だけで決まる。
- 系を大きくすると、全体としての正確さ(忠実度)は急速に 0 に近づく。各部分のわずかな違いが掛け算で積み重なるからである。しかし1サイトや隣どうしのような狭い範囲の量(局所観測量)については、prior の正確さは系の大きさによらない。だから大きな系でもこの方法は使える。

## 中心にある式

```math
G = \frac{(3^{\lvert A\rvert}-1)\langle P\rangle^2 + v_s}{(3^{\lvert A\rvert}-1)\Delta^2 + v_s},
\qquad v_s = \frac{3^{\lvert A\rvert}(1-\langle P\rangle^2)}{n_m},
\qquad \Delta = \langle P\rangle_\rho - \langle P\rangle_\sigma
```

$P$ は局所Pauli列、 $A$ はその台、 $\rho$ は実験状態、 $\sigma$ は prior、 $n_m$ は1設定あたりのショット数、 $G=\mathrm{Var}[\text{標準}]/\mathrm{Var}[\text{CRM}]$。

記号をもう少し丁寧に言うと、

- $\langle P\rangle$ は、測りたい状態 $\rho$ での観測量 $P$ の期待値(知りたい値)。 $-1$ から $+1$ の間の数である。
- $\Delta$ は、知りたい値と、prior $\sigma$ が予言する値との差。prior の**外れ**と呼ぶ。
- $3^{\lvert A\rvert}$ は、ランダムに選んだ基底が台の上ですべて当たる確率 $3^{-\lvert A\rvert}$ の逆数である。

分子が標準の方法の分散、分母が CRM の分散で、どちらも2つの部分の和になっている。

- **第1項(くじの揺らぎ)**: どの基底を引いたかによるばらつき。標準の方法では $\langle P\rangle^2$ に比例し、CRM では $\Delta^2$ に比例する。CRM が減らすのはここである。
- **第2項 $v_s$ (ショットの揺らぎ)**: 基底を固定した中での測定値のばらつき。分子と分母で同じで、CRM では減らせない。

式の導出は [README_basics.md](README_basics.md) の3〜4章に、数値の例つきで書いてある。

この式から読めることが3つあり、それが研究全体の骨格になっている。

1. **prior のグローバル忠実度が式に現れない。** 効くのは観測量ごとの局所誤差 $\Delta$ だけ。
2. **$v_s$ は分子・分母の両方に同じ形で入る**ので消せない床であり、 $\Delta\to0$ でも $G$ は $G_{\max}=1+(3^{\lvert A\rvert}-1)\langle P\rangle^2/v_s$ で頭打ちになる。
3. **$G<1$(損)が起こりうる。** $\langle P\rangle=0$ が対称性から厳密な観測量では打ち消すべき揺らぎが最初からゼロなのに、対称性を破った prior が $\Delta\neq0$ を作るため。

3番目の点の例を挙げる。half-filling の Hubbard 模型の基底状態では、スピンは上向きにも下向きにも偏っていない。したがって「あるサイトのスピンが上か下か」を表す量の期待値は厳密に 0 である。ところが平均場の一種である UHF は、スピンを上下交互に並べた状態を作るので、この量を 0 でない値と予言する。標準の方法にはもともとくじの揺らぎがない( $\langle P\rangle=0$ なので第1項が 0)のに、CRM は外れ $\Delta$ の分だけくじの揺らぎを新しく作ってしまう。これが損である。

## 主要な結論

> 表の $G$ は、断りがなければ1設定あたり $n_m=100$ ショットでの値で、「**測定の設定(回路)の数**を何分の1にできるか」を表す。1基底1ショット( $n_m=1$ )では、どんな prior でも天井は約 $1/(1-\langle P\rangle^2)$ まで下がる(指針5)。

### 各主張をかみくだくと

表の各行を、専門用語を減らして言い直す。番号は表の # に対応する。

1. **利得の式は正しく実装されている。** 上の式で計算した利得と、測定を計算機の中で模擬して数えた利得が、損をする場合( $G\approx0.002$ )から大きく得をする場合( $G\approx1300$ )まで一致した。ED は厳密対角化(小さい系を近似なしで解く方法)のことである。式そのものは元論文にすでにあるので、これは新発見ではなく、計算の道具が正しいことの確認である。
2. **系を大きくしても利得は保たれる。** 鎖の長さを 8 サイトから 128 サイトにすると、prior の忠実度 $F$ は 120 分の1になる。しかし利得を決める相対的な外れ $\varepsilon=\lvert\Delta\rvert/\lvert\langle P\rangle\rvert$ は 3.8 倍にしかならず、利得は 1.2 分の1にしかならない。
3. **鎖のどのサイトでも得をする。** 端のある鎖では、端に近いサイトと中央のサイトで観測量の値が違う。256 量子ビットの鎖のすべてのサイトで利得を調べ、結合次元 4 以上の MPS を prior にすれば、1次元では損をするサイトが1つもないことを確かめた。ただし2次元などではこの下限は上がる。
4. **安い平均場が、高価な MPS と同じくらい効くことがある。** 幅 6 のシリンダー(筒に丸めた2次元格子)では、MPS で良い prior を作るには大きな結合次元が要る。一方、平均場(UHF)は計算がごく軽い。サイト上の電荷の量(オンサイト ZZ)では、UHF の利得 148 が天井 149.6 にほぼ届き、結合次元 32 の MPS(103)を上回った。ただしこの比較には、参照状態が十分に収束していないという留保がある。
5. **損をしない形に直せる。** prior の値をそのまま引く代わりに、係数を掛けてから引き、その係数をデータから決める(最適係数)。こうすると、prior が悪いときは係数が自動的に小さくなり、標準の方法より悪くなることがなくなる。統計でいう制御変量法と同じものである。
6. **prior が勝手に選んだ向きは、平均すれば消せる。** UHF は「スピンの上向き」という特定の向きを選んでしまうが、本当の基底状態に特別な向きはない(スピン回転の対称性、SU(2))。UHF をあらゆる向きに回して平均すれば、向きは消える。これは古典計算の中だけの操作で、測定を増やす必要がない。格子をずらす操作(並進)についての平均も同じように効く。
7. **「台の上のトレース距離」が外れ $\Delta$ をちょうど与える場合がある。** トレース距離 $D_A$ は、台 $A$ の上だけを見たときに2つの状態がどれだけ区別できるかを表す数で、一般に $\lvert\Delta\rvert\le2D_A$ が成り立つ。オンサイト ZZ では、この不等式が等号になる。ただし $D_A$ を計算するには測りたい状態そのものの情報が要るので、「測る前に利得を予測する道具」にはならない。
8. **prior が「はっきりした値」を予言するのは良い兆候とは限らない。** 観測量の固有状態とは、その量を測ると必ず同じ値( $+1$ か $-1$ )が出る状態である。平均場や小さい結合次元の MPS は、本当の状態より固有状態に近い、つまり値を $\pm1$ 寄りに大きく予言する傾向がある(過信)。得をする条件は「prior の値が、本当の値の 0 倍から 2 倍の間にあること」なので、2倍を超えて過信すると損になる。
9. **和で書ける量では、項ごとの外れが効く。** 二重占有(1つのサイトに電子が2個いる確率)は、4つのパウリ文字列の和で書ける。UHF は和としての値はよく当てるが、個々の項(上向きの電子の数、下向きの電子の数)は大きく外す。分散には項ごとの外れが入るので、利得は 1.8 にとどまる。向きを平均した UHF(UHF-sym)なら項ごとにも合い、124 になる。
10. **向きを消す別の方法(射影)の効果は系が大きいと薄まり、小さい MPS は作り方で得意が逆になる。** スピン射影 HF(PHF)は、UHF から全体のスピンが 0 の成分を取り出す方法である。それで加わる量子的な相関は、系の長さ $L$ に反比例して薄まる。また結合次元 4 の MPS は、正確な状態を切り詰めて作るとスピンの量が合って電荷の量が外れ、エネルギーを最小にして作ると逆になる。

## 撤回・訂正の記録

自分の主張を後から潰した箇所を残してある。**論文化のとき、査読者に先回りして書くべき部分**でもある。

初めて読むときは飛ばしてよい。表の中の言葉の補足:

- **帰無検定**: 「この効果は端のせいだ」という説明を確かめるために、端をなくした系(周期境界)で効果が消えることを見る、というように、原因を取り除いて結果が消えるかを調べること。
- **アーティファクト**: 物理ではなく、計算の設定のせいで出た見かけの結果。
- **恒等成分 $c_0$**: 観測量をパウリ文字列の和に書いたときの定数項。例えば二重占有 $(1-Z_\uparrow-Z_\downarrow+Z_\uparrow Z_\downarrow)/4$ の $1/4$ 。定数は測らなくてもわかるので、ばらつきに寄与しない。
- **RDM**: 縮約密度行列。系の一部分だけを見たときの状態。
- **フラストレーション**: 「隣どうしは逆向き」という要請を、格子の形のせいですべての結合で同時には満たせないこと。三角形や、奇数個のサイトの環で起こる。
- **二部格子**: 隣が必ず別の組になるようにサイトを2組に分けられる格子。フラストレーションがない。

## わかっている限界

結論が確かめられていない範囲を挙げる。「損」は $G<1$ 、つまり CRM を使うと標準の方法より悪くなることを指す。

- **擬似実験である。** 参照状態 $\rho$ は DMRG(または ED)で作ったもので、実機のノイズ・読み出し誤差は入っていない。読み出し誤差だけは式で見積もった。台の大きい観測量では、誤差モデルを prior に掛けないと標準の方法より悪くなりうる([README_readout_noise.md](README_readout_noise.md))。
- **ED による直接確認は $L\le14$(28量子ビット)まで。** §2 は $L=32$、§2b は $L=128$ を扱うので、そこは $\chi$ 収束チェックでの代替になる。
- **2D は $W=4,6$ のシリンダーのみ。** 本物の2次元極限は取れていない。
- **粗い prior の損は、境界条件・系の大きさ・次元・結合の強さで変わる。** $\chi_p=2$ は1次元開放端でも半充填の $L\ge64$ で損が出( $L=128$ で 5.7%)、ドープ系では $L=8$ から出る。周期境界では $L\le14$ でも約8%で損をする。 $\chi_p=4,8$ は1次元開放端( $U=4$ )では損ゼロだが、2次元・周期境界・弱結合( $U=2,4$ )では損をする系がある(厳密な80系で $\chi_p=4$ が160点中8点、 $\chi_p=8$ が3点。 $\chi_p\ge16$ は0点)。
- **CRM が効かない領域がある。** matchgate(Gauss)測定では $G\approx0.5$– $1.9$ にとどまる。決定論的な測定計画(derandomization)には原理的に適用できない。

## 実務上の指針(この研究から出る処方箋)

指針 4 と 5 に出てくる $n_m^\ast$ の意味を先に説明する。CRM の分散は「くじの揺らぎ $(3^{\lvert A\rvert}-1)\Delta^2$ 」と「ショットの揺らぎ $v_s=3^{\lvert A\rvert}(1-\langle P\rangle^2)/n_m$ 」の和である。 $n_m$ を増やすと後者だけが減る。2つが等しくなる $n_m$ が $n_m^\ast$ で、これを超えてショットを増やしても、減らない方(くじの揺らぎ)が残るので得にならない。prior が粗い( $\Delta$ が大きい)ほど $n_m^\ast$ は小さい。つまり粗い prior では、同じ設定で何度も測るより、設定を変える方に回数を使うべきである。

1. **測りたいのが局所観測量なら、系の大きさを理由に諦める必要はない。** 見るべきは忠実度ではなく $\Delta/\langle P\rangle$。
2. **prior の $\chi_p$ の下限は系によって違う。** 1次元開放端( $U=4$ )なら $\chi_p\ge4$ で損はない。2次元・周期境界・弱結合では $\chi_p=4,8$ でも損をする系があり、厳密な80系で損が1点もなかったのは $\chi_p\ge16$ である。 $\chi_p=2$ は大きな系やドープ系で損をする(限界の節)。
3. **prior 側は絶対に標本推定しない。** ここが先行実装の敗因であり、本研究の出発点。
4. **$n_m$ は prior の質に合わせる。** 境目は $n_m^\ast=(1-\langle P\rangle^2)/\Delta^2$ で、基底切替が1回ショット $c$ 個ぶんのコストなら最適は $n_m^{\rm opt}=\sqrt{cn_m^\ast}$。**粗い prior ($\chi_p=2$)ほど $n_m$ を小さく** — 実測では $n_m=100$ は最適の20倍以上で、分散で約11倍(標準偏差で約3.3倍)損をしている。一方 $n_u$ は利得 $G$ に一切影響しない(比で約分される)。詳細は README §0.5b。
5. **$G$ を引用するときは必ず $n_m$ を併記する。** 総ショット数 $B$ を固定して配分だけを振ると、**CRM 側の誤差はほぼ不変で標準シャドウだけが20倍悪化する** — $G$ が 1.45 から 568 へ伸びるのはその効果である(実測、README §0.5b)。最適配分( $n_m=1$ )では、prior が完全でも天井は $(1-\langle P\rangle^2/3^{\lvert A\rvert})/(1-\langle P\rangle^2)$ (おおよそ $1/(1-\langle P\rangle^2)$ )で、この例(ZZ onsite、 $\langle P\rangle=-0.599$ )では 1.50 である。実測 1.55 は統計誤差の範囲でこれを超えた値。
6. **prior を信頼できるなら $\beta=1$、不確かなら最適β。** ただし $\beta^\ast$ の推定には $O(1/\sqrt{n_u})$ のノイズが残るので、 $\beta^\ast\approx1$ が分かっているなら決め打ちが有利。
7. **prior は古典後処理なので観測量ごとに使い分けてよい**(追加測定ゼロ)。二重占有は共線UHF、スピン相関は対称性回復UHF、というように。**ただし「二重占有は共線UHF」は参照状態自体が対称性を破っていた §4 の2次元実験での結論で、参照状態が対称な場合は和として測る二重占有にも対称性回復UHFを使う**(共線 UHF 1.8 対 124、[README_observables.md](README_observables.md) 5.2・6)。
8. **幅の広い2D系ほどタダの平均場 prior が相対的に有利になる。** MPS は $\chi\sim e^{cW}$、UHF は $O(N^3)$。
