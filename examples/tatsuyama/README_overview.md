# これまでの研究のまとめ — Hubbard 模型に対する CRM シャドウ

[README.md](README.md) に戻る / より詳しい入口: [SUMMARY.md](SUMMARY.md)

久しぶりに読み返すときのための、研究全体の見取り図である(2026年10月時点)。数値はすべて各文書からの再掲で、出典は5章の文書の地図にまとめた。

---

## 0. 一言でいうと

**量子コンピュータで測った結果から、古典計算で作った近似状態(prior)が同じ測定で出すはずの値を引き、prior の値そのものを足し戻すと、推定の偏りを生まずにばらつきだけが減る(CRM シャドウ)。** この研究は Hubbard 模型を題材に、「**どんな prior が、どの観測量で、なぜ効くのか**」を系統的に調べ、物理的に説明してきた。

## 1. 道具立て

### 1.1 古典シャドウ

$N$ 量子ビットの状態 $\rho$ の各量子ビットを、 $X,Y,Z$ のどれかの基底で独立にランダムに選んで測る。基底の組を1つ選ぶことを「設定」と呼び、設定を $n_u$ 個選び、それぞれで $n_m$ 回測る。台 $A$ ( $\lvert A\rvert$ 個の量子ビット)のパウリ文字列 $P$ は、基底が台の上で全部当たったとき(確率 $3^{-\lvert A\rvert}$ )だけ、測定値の積を $3^{\lvert A\rvert}$ 倍した値で推定され、外れたときは 0 と推定される。当たり外れの確率を補正する $3^{\lvert A\rvert}$ 倍のおかげで推定は偏らないが、当たり外れによる揺らぎが大きく、分散は $3^{\lvert A\rvert}$ に比例して増える。

### 1.2 CRM シャドウ

元論文: Vermersch ら, *PRX Quantum* **5**, 010352 (2024)。解説は [README_crm_paper.md](README_crm_paper.md)。

- prior $\sigma$ (古典計算で作った $\rho$ の近似)について、「同じ設定で $\sigma$ を測ったときの推定値の期待値」を古典計算で厳密に求め、実験の推定値から引き、 $\sigma$ での真の値 $y=\langle P\rangle_\sigma$ を足し戻す。
- 設定について平均すると、引いた量の期待値は $y$ で、足し戻した $y$ と打ち消し合う。したがって **prior が何であっても推定は偏らない**。この議論に $\sigma$ の性質は使わないので、prior は混合状態でも、どの状態の期待値でもない数値でもよい。
- 当たり外れの揺らぎは、引いた量も同じように揺らぐので打ち消し合う。打ち消し残りは prior の外れ $\Delta=x-y$ ( $x=\langle P\rangle_\rho$ )に比例する。prior が良いほどばらつきが減る。

### 1.3 利得の式

同じ設定数・同じショット数で、標準のシャドウの分散を CRM の分散で割ったものを利得 $G$ と呼ぶ。単一のパウリ文字列では

```math
G=\frac{(3^{\lvert A\rvert}-1)x^2+v_s}{(3^{\lvert A\rvert}-1)\Delta^2+v_s},\qquad v_s=\frac{3^{\lvert A\rvert}(1-x^2)}{n_m}
```

である。

- **これは元論文の付録にある厳密な分散の式の比そのもの**で、新しい法則ではない(arXiv 版の付録 B.1 の式(25)、PRX Quantum 版の付録 C.1 の式(C7))。
- 分子・分母の第1項は「どの基底が当たるかのくじ」の揺らぎで、CRM はその $x^2$ を $\Delta^2$ に置き換える。第2項 $v_s$ は1つの設定の中のショットの揺らぎで、prior では消せない。
- **損得の境目は $\lvert\Delta\rvert=\lvert x\rvert$ である**(元論文 II.C 節)。式で分子と分母が等しくなる条件そのものである。
- **天井がある。** prior が完全( $\Delta=0$ )でも $v_s$ が残るので、 $G$ は $G_{\max}=1+n_m(3^{\lvert A\rvert}-1)x^2/[3^{\lvert A\rvert}(1-x^2)]$ を超えない。
- 設定の数 $n_u$ は分子と分母に同じように掛かるので、比では消える。**$G$ は「同じ精度に必要な設定(回路)の数を何分の1にできるか」を表す。** 見出しの値は1設定あたり $n_m=100$ ショットでのもので、1設定1ショットなら天井は約 $1/(1-x^2)$ (オンサイト ZZ で約 6.5)まで下がる。
- 二重占有のように複数のパウリ項の和で書かれる観測量では、合計の外れではなく**項ごとの外れ**が分散に入る。その厳密な式もこの研究で書き下した([README_experiments.md](README_experiments.md) §3、[crm_exact_gain.jl](crm_exact_gain.jl))。

### 1.4 主な prior

| prior | 中身 | 厳密な状態が要るか |
|---|---|---|
| UHF | 平均場。各サイトのスピンを副格子ごとに上下どちらかに傾ける(スピン回転の対称性を破る) | 要らない |
| UHF-sym | UHF をあらゆるスピンの向きに回して平均した混合状態 | 要らない |
| PHF | UHF を全スピン 0 に射影したもの | 要らない |
| 切断 MPS | 厳密な状態を結合次元 $\chi$ に切り詰めたもの | 要る |
| 変分 MPS | 結合次元を $\chi$ に制限した DMRG の基底状態 | 要らない |
| 変分 MPS-sym | 変分 MPS をスピンの向きについて平均した混合状態 | 要らない |

## 2. 主な発見

### A. 利得を決めるのは大域的な忠実度ではなく、観測量ごとの外れ $\Delta$

- 1.3 節の式には prior の大域的な忠実度が現れない。外れ $\Delta=\mathrm{Tr}[P(\rho-\sigma)]$ は、観測量の台に縮約した密度行列だけで決まる局所的な量である。
- 実際、系を $L=8\to128$ に広げると prior の大域的な忠実度は 120 分の1に落ちるが、利得はほとんど変わらない。1次元 $L=8,16,32$ の鎖では、オンサイト ZZ の利得が 50.9、50.6、50.7 と天井 50.7 で一定だった(厳密な値)。
- 大域的な忠実度 0.078 の UHF が、忠実度 0.83 の MPS に勝つ例がある。
- 台に縮約した量で prior の良さを測るなら、トレース距離が $\lvert\Delta\rvert$ の最良の上界で、半充填のオンサイト量では等号 $\lvert\Delta\rvert=2D_A$ が成り立つ([README_distance_vs_fidelity.md](README_distance_vs_fidelity.md))。
- 元論文が忠実度を使うのは「多コピー観測量と純粋な prior」の場合で、この結果と矛盾しない。

### B. 「観測量の固有状態に近い prior ほど良い」は成り立たない

- 損得の境目 $\lvert\Delta\rvert\le\lvert x\rvert$ は、 $y/x$ で言えば $0<y/x<2$ である。prior の値が真の値の2倍を超えるか、符号が逆なら損をする。これは元論文の条件の言い換えで、この研究の寄与は、それが固有状態に近い prior でどう効くかを調べたことにある。
- 固有状態に近い prior は観測量の値を $\pm1$ に近く予言しがちで、真の値が小さい観測量では2倍を超えやすい。例えば UHF は単一サイトの $Z_\uparrow$ を $\pm2m$ (真の値は 0)と予言し、 $G=0.016$ (大損)になる。

### C. 観測量によって平均場の得意・不得意が逆になる

$U=12$ 、厳密な参照状態を持つ 80 系のうち 20 系の中央値( $n_m=100$ ):

| 観測量 | UHF | UHF-sym | PHF | 切断 $\chi=4$ | 変分 $\chi=16$ | 変分 $\chi=8$ -sym | 天井 |
|---|---|---|---|---|---|---|---|
| オンサイト ZZ(電荷) | **465** | 465 | 513 | 151 | 555 | 555 | 555 |
| 隣接 $Z_\uparrow Z_\uparrow$ (スピン) | 1.2 | 7.0 | 14.2 | **29.2** | 28.8 | 19.8 | 31.6 |
| 単一サイト $Z_\uparrow$ | **0.02** | 1.00 | 1.00 | 1.00 | 0.46 | 1.00 | 1 |
| 二重占有(4項の和) | 1.8 | **123** | 127 | 78 | 53 | 129 | — |

- **電荷の量では、強結合で平均場の誤差が $(t/U)^2$ で消える。** 二重占有率 $d$ は「隣の結合がどれだけ一重項を組んでいるか」に比例し、UHF はそれを古典的な Néel 配置(半分だけ一重項)として持つ。そのため $d$ そのものの相対誤差は 28% で止まる。しかしオンサイト ZZ $=4d-1$ に対する相対誤差は、分母が $-1$ に張り付くので $4d\times0.28\approx3.1(t/U)^2$ で消える。
- **スピンの量では UHF が損をする。** 理由は2つある。
  - スピンの向きを選んでしまう → UHF-sym(向きについての平均)で直る。隣接 $Z_\uparrow Z_\uparrow$ で損をする系が 17/80 から 0/80 になる。
  - 量子的な一重項の相関が足りない → UHF-sym では直らない。 $S^zS^z$ の相対誤差は 1次元で 0.69 に止まり、2次元では損になる(損得の境目は $\lvert\langle\mathbf S\cdot\mathbf S\rangle\rvert=3/8$ で、1次元の 0.443 は得、2次元の正方格子の約 0.335 は損)。
- **PHF の効果は $1/L$ で消える。** 射影は2つの副格子の大きなスピンを1つの回転子として組み直すだけで、1つの結合に配られる量子相関は $1/L$ に薄まる。 $L=64$ では真の値との差の 11% しか埋まらない。予測 $L\,\Delta\langle\mathbf S\cdot\mathbf S\rangle=-2m$ は実測と合った。
- **2種類の MPS は性質が逆である。** 切断 $\chi=4$ はスピンが正確な代わりに電荷のゆらぎを捨て、変分 $\chi=4$ は電荷が正確な代わりにスピンの向きを選ぶ。中央の結合の Schmidt 分解で、少ない状態の使い方の違いとして確かめた。
- **変分 MPS を回転平均すると、電荷とスピンの両方で損をしない。** $\chi\ge8$ では 80 系 × 4 観測量のすべてで損がなく、厳密な状態を使わない prior の中で最も良い([README_varsym.md](README_varsym.md))。

### D. 和の観測量では、項ごとの誤差が効く

二重占有を $\frac14(1-Z_\uparrow-Z_\downarrow+Z_\uparrow Z_\downarrow)$ の和として測ると、共線 UHF の利得は 1.8 に落ち、UHF-sym なら 123 である。UHF の $\langle Z_\uparrow\rangle=\pm2m$ と $\langle Z_\downarrow\rangle=\mp2m$ の外れは合計では打ち消し合うが、分散には項ごとの外れの積として入り、打ち消されない。

### E. 回転平均は偽の長距離秩序を消さない

スピンの向きを選んだ prior の $\langle\mathbf S_i\cdot\mathbf S_j\rangle$ には、距離によらない $\langle\mathbf S_i\rangle\cdot\langle\mathbf S_j\rangle=\pm m^2$ が含まれる。 $\mathbf S_i\cdot\mathbf S_j$ は回転で変わらないので、回転平均してもこの部分は残る。そのため UHF-sym は距離 $r\ge4$ の対ではすべて損をする( $U\ge4$ )。全距離で得をするのは、対称性を保つ量子的な prior だけだった([README_varsym_distance.md](README_varsym_distance.md))。

### F. 対称性の役割

- 半充填の二部格子では、粒子正孔対称性により電子数がサイトごとに厳密に 1 になる。開放端の影響は電荷には出られず、結合の強弱の交替に回る。電荷の量が境界条件に鈍いのはこのためである([README_particle_hole.md](README_particle_hole.md))。
- 二部格子でない 4×3 トーラスでは UHF の電荷が 6.5% 偏っていた。これが以前の「既知の異常点」の原因の一部だった。

### G. 2次元とドープ系

- half-filling の2次元シリンダーでは、オンサイトの量とホッピングで UHF が $\chi=64$ 〜 $128$ の MPS に並ぶ( $W=6$ 、 $U=8$ のオンサイト ZZ で 148、天井 149.6)。MPS の必要な結合次元は幅について指数的に増えるが、UHF の計算量は $O(N^3)$ のままである。
- 1/8 ドープの系では、平均場は電荷の模様(ストライプ)で破綻する。破綻はストライプの壁の上と電荷の量に局在し、ドメインの中のスピンの量は UHF-sym で救える([README_experiments.md](README_experiments.md) §8–§9)。

## 4. 次の候補

1. **誤差に強い prior**: 対称なビット反転の読み出し誤差は [README_readout_noise.md](README_readout_noise.md) で調べた。残りは非対称な読み出し誤差(混同行列)と、状態の用意の誤差(論文にするなら必須)
2. **基底の選び方を prior で偏らせる方法との組み合わせ**: 1設定1ショットでの天井 $\approx1/(1-x^2)$ を破れるかどうか
3. **データから prior を作る**: データを2つに分けて、偏りなく prior を合わせ込む
4. **ドープ系(ストライプ)の prior**: 電荷の分布を合わせた平均場など、平均場より先の prior
5. **2次元での回転平均と遠い相関**: 2次元では真の状態自体が長距離秩序に近づくので、[README_varsym_distance.md](README_varsym_distance.md) の結論が変わるかどうか

(以前の候補のうち「文書の修正」と「変分 MPS をスピンの向きについて平均する」は実行済み。)
