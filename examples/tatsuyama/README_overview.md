## 0. 一言でいうと

**量子コンピュータで測った結果から、古典計算で作った近似状態(prior)が同じ測定で出すはずの値を引き、prior の値そのものを足し戻すと、推定の偏りを生まずにばらつきだけが減る(CRM シャドウ)。** この研究は Hubbard 模型を題材に、「**どんな prior が、どの観測量で、なぜ効くのか**」を系統的に調べ、物理的に説明してきた。

言葉を補う。

- **偏り**とは、測定を無限に繰り返しても残る、推定値と正しい値のずれである。**ばらつき**とは、有限の回数しか測らないために推定値が毎回違う値になることで、その大きさを分散で表す。測定の回数を減らしたいなら、偏りを作らずにばらつきを減らせばよい。
- **Hubbard 模型**は、格子の上を電子が飛び移り、同じサイトに2個入るとエネルギーが $U$ だけ上がる、という模型である。固体の中の電子の磁性や絶縁体を表す最も単純な模型で、量子コンピュータで調べたい対象の代表である。
- **観測量**は、測って期待値を知りたい量である。この研究では、サイトに電子が2個いる確率や、隣り合うスピンの並び方などを扱う。

## 1. 道具立て

### 1.1 古典シャドウ

量子ビットは、1回の測定では $X$ 、 $Y$ 、 $Z$ の3種類の測り方(基底)のうち1つでしか測れない。測ると $+1$ か $-1$ が出る。古典シャドウは、どの基底で測るかをランダムに決めてしまい、後からいろいろな量の期待値を計算できるようにする方法である。

$N$ 量子ビットの状態 $\rho$ の各量子ビットを、 $X,Y,Z$ のどれかの基底で独立にランダムに選んで測る。基底の組を1つ選ぶことを「設定」と呼び、設定を $n_u$ 個選び、それぞれで $n_m$ 回測る。台 $A$ ( $\lvert A\rvert$ 個の量子ビット)のパウリ文字列 $P$ は、基底が台の上で全部当たったとき(確率 $3^{-\lvert A\rvert}$ )だけ、測定値の積を $3^{\lvert A\rvert}$ 倍した値で推定され、外れたときは 0 と推定される。当たり外れの確率を補正する $3^{\lvert A\rvert}$ 倍のおかげで推定は偏らないが、当たり外れによる揺らぎが大きく、分散は $3^{\lvert A\rvert}$ に比例して増える。

言葉を補う。

- **パウリ文字列**は、いくつかの量子ビットの $X$ 、 $Y$ 、 $Z$ の積である。例えば $Z_1Z_2$ は、1番と2番を $Z$ 基底で測った値の積で、2つの量子ビットの値がそろっているかどうかを表す。
- **台**は、パウリ文字列が実際に触る量子ビットの集まりである。 $Z_1Z_2$ なら1番と2番で、台の大きさは $\lvert A\rvert=2$ 。
- **当たり**は、ランダムに選んだ基底が、台の上のすべての量子ビットで、パウリ文字列の文字と一致することである。1量子ビットにつき確率 $1/3$ なので、全部当たる確率は $3^{-\lvert A\rvert}$ になる。外れた設定からは、その量の情報が得られない。
- $3^{\lvert A\rvert}$ 倍するのは、当たる確率が $3^{-\lvert A\rvert}$ しかないことを補うためである。 $\lvert A\rvert=2$ なら、9回に1回だけ当たり、当たったときは9倍する。平均すれば正しい値になるが、「たいてい 0 で、たまに大きな値」という荒れた推定になる。

1量子ビットでの数値の例は [README_basics.md](README_basics.md) の 3.2 節にある。

### 1.2 CRM シャドウ

元論文: Vermersch ら, *PRX Quantum* **5**, 010352 (2024)。解説は [README_crm_paper.md](README_crm_paper.md)。

- prior $\sigma$ (古典計算で作った $\rho$ の近似)について、「同じ設定で $\sigma$ を測ったときの推定値の期待値」を古典計算で厳密に求め、実験の推定値から引き、 $\sigma$ での真の値 $y=\langle P\rangle_\sigma$ を足し戻す。
- 設定について平均すると、引いた量の期待値は $y$ で、足し戻した $y$ と打ち消し合う。したがって **prior が何であっても推定は偏らない**。この議論に $\sigma$ の性質は使わないので、prior は混合状態でも、どの状態の期待値でもない数値でもよい。
- 当たり外れの揺らぎは、引いた量も同じように揺らぐので打ち消し合う。打ち消し残りは prior の外れ $\Delta=x-y$ ( $x=\langle P\rangle_\rho$ )に比例する。prior が良いほどばらつきが減る。

身近なたとえで言うと、こうなる。300 人の今年のテストの平均点を、くじで選んだ 10 人の採点だけで見積もりたい。去年の点が全員分わかっているなら、「選んだ 10 人の今年の平均 − 同じ 10 人の去年の平均 + 全員の去年の平均」を計算する。たまたま点の高い人が多く選ばれた、という偶然は、今年の点にも去年の点にも同じように現れるので、引き算で打ち消される。去年の点が今年の点をよく予想しているほど、残るばらつきは小さい。くじで選ぶ人が「設定」、去年の点が「prior」に当たる。

### 1.3 利得の式

同じ設定数・同じショット数で、標準のシャドウの分散を CRM の分散で割ったものを利得 $G$ と呼ぶ。分散が $1/G$ になれば、同じ精度に必要な測定の回数も $1/G$ になる。 $G>1$ なら得、 $G<1$ なら損である。単一のパウリ文字列では

```math
G=\frac{(3^{\lvert A\rvert}-1)x^2+v_s}{(3^{\lvert A\rvert}-1)\Delta^2+v_s},\qquad v_s=\frac{3^{\lvert A\rvert}(1-x^2)}{n_m}
```

である。 $x=\langle P\rangle_\rho$ は知りたい値( $-1$ から $+1$ の間)、 $\Delta=x-y$ は prior の外れ、 $n_m$ は1設定あたりのショットの数である。導出は [README_basics.md](README_basics.md) の 3.4 節と 4.3 節に、途中を省かずに書いてある。

**数値の例。** オンサイト ZZ( $\lvert A\rvert=2$ )で $x=-0.93$ 、 $n_m=100$ とする。 $v_s=9\times(1-0.93^2)/100=0.0122$ 、分子は $8\times0.93^2+0.0122=6.93$ である。

| prior の値 $y$ | 外れ $\Delta$ | 分母 | 利得 $G$ |
|---|---|---|---|
| $-0.93$ (完全) | 0 | 0.0122 | 570(天井) |
| $-0.95$ | 0.02 | 0.0154 | 451 |
| $-0.80$ | $-0.13$ | 0.147 | 47 |
| $0$ (何も引かない) | $-0.93$ | 6.93 | 1 |
| $+0.5$ (符号が逆) | $-1.43$ | 16.4 | 0.42 |

外れが 0.02 でも天井の8割、0.13 あると天井の 12 分の1になる。天井が高い観測量ほど、小さな外れに敏感である。

- **これは元論文の付録にある厳密な分散の式の比そのもの**で、新しい法則ではない(arXiv 版の付録 B.1 の式(25)、PRX Quantum 版の付録 C.1 の式(C7))。
- 分子・分母の第1項は「どの基底が当たるかのくじ」の揺らぎで、CRM はその $x^2$ を $\Delta^2$ に置き換える。第2項 $v_s$ は1つの設定の中のショットの揺らぎで、prior では消せない。
- **損得の境目は $\lvert\Delta\rvert=\lvert x\rvert$ である**(元論文 II.C 節)。式で分子と分母が等しくなる条件そのものである。
- **天井がある。** prior が完全( $\Delta=0$ )でも $v_s$ が残るので、 $G$ は $G_{\max}=1+n_m(3^{\lvert A\rvert}-1)x^2/[3^{\lvert A\rvert}(1-x^2)]$ を超えない。
- 設定の数 $n_u$ は分子と分母に同じように掛かるので、比では消える。**$G$ は「同じ精度に必要な設定(回路)の数を何分の1にできるか」を表す。** 見出しの値は1設定あたり $n_m=100$ ショットでのもので、1設定1ショットなら天井は約 $1/(1-x^2)$ (オンサイト ZZ で約 6.5)まで下がる。
- 二重占有のように複数のパウリ項の和で書かれる観測量では、合計の外れではなく**項ごとの外れ**が分散に入る。その厳密な式もこの研究で書き下した([README_experiments.md](README_experiments.md) §3、[crm_exact_gain.jl](crm_exact_gain.jl))。

### 1.4 主な prior

prior を作る古典計算の方法は、大きく2つある。

- **平均場(Hartree–Fock)**: 各電子が、ほかの電子の平均的な影響の中を独立に動くと近似する。計算はごく軽い(量子ビットの数 $N$ に対して $N^3$ 程度)。電子どうしが互いを避け合う効果(相関)は入らない。
- **MPS(行列積状態)**: 量子状態を小さな行列の積で表す。行列の大きさ(**結合次元** $\chi$ )を大きくするほど正確になり、計算は重くなる。MPS の中でエネルギーの最も低い状態を探す計算法が **DMRG** である。1次元では少ない $\chi$ で正確だが、2次元では必要な $\chi$ が幅とともに急速に増える。

| prior | 中身 | 厳密な状態が要るか |
|---|---|---|
| UHF | 平均場。各サイトのスピンを副格子ごとに上下どちらかに傾ける(スピン回転の対称性を破る) | 要らない |
| UHF-sym | UHF をあらゆるスピンの向きに回して平均した混合状態 | 要らない |
| PHF | UHF を全スピン 0 に射影したもの | 要らない |
| 切断 MPS | 厳密な状態を結合次元 $\chi$ に切り詰めたもの | 要る |
| 変分 MPS | 結合次元を $\chi$ に制限した DMRG の基底状態 | 要らない |
| 変分 MPS-sym | 変分 MPS をスピンの向きについて平均した混合状態 | 要らない |

表の言葉を補う。

- 「**スピン回転の対称性を破る**」とは次のことである。Hubbard 模型には「上向き」という特別な向きはなく、本当の基底状態(half-filling、有限の系)ではスピンはどの向きにも偏っていない。UHF は、エネルギーを下げるために、スピンを上下交互に並べた状態を作る。つまり、特定の向きを勝手に選んでしまう。
- 「**混合状態**」は、いくつかの状態を確率的に混ぜたものである。UHF-sym は「上下」の軸をあらゆる向きに取った UHF の状態を、等しい確率で混ぜたもので、特定の向きを持たない。
- 「**射影**」は、状態の中から特定の性質(ここでは全体のスピンが 0)を持つ成分だけを取り出すことである。
- 「**厳密な状態が要る**」prior は、測りたい状態そのものが先に手に入っていないと作れない。現実の実験では使えないので、「同じ結合次元でどこまで良くなりうるか」の目安として使う。

prior どうしの比較(どの prior がどの観測量で効くか、図と選び方の手順つき)は [README_prior_comparison.md](README_prior_comparison.md) にまとめた。

## 2. 主な発見

### A. 利得を決めるのは大域的な忠実度ではなく、観測量ごとの外れ $\Delta$

**大域的な忠実度**とは、2つの状態が系全体としてどれだけ重なっているかを表す数(一致すれば 1)である。系が大きくなると、各部分のわずかな違いが掛け算で積み重なって、急速に 0 に近づく。「忠実度が低い prior は使えない」と考えるのが自然に思えるが、そうではない、というのがこの項である。

- 1.3 節の式には prior の大域的な忠実度が現れない。外れ $\Delta=\mathrm{Tr}[P(\rho-\sigma)]$ は、観測量の台に縮約した密度行列だけで決まる局所的な量である(台に縮約した密度行列とは、台の外の量子ビットを見なかったことにして得られる、台の上だけの状態のこと。 $\lvert A\rvert=2$ なら $4\times4$ の行列で、系全体の大きさによらない)。
- 実際、系を $L=8\to128$ に広げると prior の大域的な忠実度は 120 分の1に落ちるが、利得はほとんど変わらない。1次元 $L=8,16,32$ の鎖では、オンサイト ZZ の利得が 50.9、50.6、50.7 と天井 50.7 で一定だった(厳密な値)。
- 大域的な忠実度 0.078 の UHF が、忠実度 0.83 の MPS に勝つ例がある。
- **トレース距離**は、2つの状態がどれだけ区別できるかを表す数(一致すれば 0)で、期待値のずれの上限を直接与える。台に縮約した量で prior の良さを測るなら、トレース距離が $\lvert\Delta\rvert$ の最良の上界で、半充填のオンサイト量では等号 $\lvert\Delta\rvert=2D_A$ が成り立つ([README_distance_vs_fidelity.md](README_distance_vs_fidelity.md))。
- 元論文が忠実度を使うのは「多コピー観測量と純粋な prior」の場合で、この結果と矛盾しない。

### B. 「観測量の固有状態に近い prior ほど良い」は成り立たない

観測量 $P$ の**固有状態**とは、 $P$ を測ると必ず同じ値( $+1$ か $-1$ )が出る状態である。そこでは $\langle P\rangle=\pm1$ になる。「prior が $P$ の固有状態に近い」とは、prior が $P$ の値を $\pm1$ の近くに、はっきりと予言していることを意味する。はっきりした予言は良い prior の印に見えるが、そうとは限らない。

- 損得の境目 $\lvert\Delta\rvert\le\lvert x\rvert$ は、 $y/x$ で言えば $0<y/x<2$ である。prior の値が真の値の2倍を超えるか、符号が逆なら損をする。これは元論文の条件の言い換えで、この研究の寄与は、それが固有状態に近い prior でどう効くかを調べたことにある。
- 固有状態に近い prior は観測量の値を $\pm1$ に近く予言しがちで、真の値が小さい観測量では2倍を超えやすい。例えば UHF は単一サイトの $Z_\uparrow$ を $\pm2m$ (真の値は 0)と予言し、 $G=0.016$ (大損)になる。ここで $Z_\uparrow$ は「そのサイトに上向きの電子がいなければ $+1$ 、いれば $-1$ 」を返す量で、 $m$ は UHF が持つ磁化( $\langle S^z_i\rangle=\pm m$ )である。本当の状態では上向きの電子は確率 $1/2$ でいるので期待値は 0 だが、UHF では副格子によって確率が $\tfrac12\pm m$ に偏るので $\mp2m$ になる。 $G=0.016$ は、CRM を使うと必要な測定が約 60 倍に増えることを意味する。

### C. 観測量によって平均場の得意・不得意が逆になる

表の読み方を先に述べる。

- 行は観測量、列は prior、数は利得 $G$ である。右端の「天井」は完全な prior での利得で、その行で到達できる上限である。
- **オンサイト ZZ** は、同じサイトの上向きと下向きの席の $Z$ の積で、「そのサイトに電子が2個いる確率(二重占有率 $d$ )」と同じ情報を持つ(half-filling で期待値は $4d-1$ )。電子の数で決まる量なので**電荷の量**と呼ぶ。
- **隣接 $Z_\uparrow Z_\uparrow$** は、隣り合うサイトの上向きの席の $Z$ の積で、隣どうしのスピンがそろっているか逆かを表す。**スピンの量**の代表である。
- **二重占有(4項の和)** は、二重占有率を $\tfrac14(1-Z_\uparrow-Z_\downarrow+Z_\uparrow Z_\downarrow)$ と4つの項に分けて、項ごとに測る場合である。
- 「厳密な参照状態を持つ 80 系」は、格子の形と大きさ 20 通り × $U=2,4,8,12$ の、近似なしで基底状態を求められる小さな系である。**中央値**は、利得を大きさの順に並べたときの真ん中の値である。

$U=12$ 、厳密な参照状態を持つ 80 系のうち 20 系の中央値( $n_m=100$ ):

| 観測量 | UHF | UHF-sym | PHF | 切断 $\chi=4$ | 変分 $\chi=16$ | 変分 $\chi=8$ -sym | 天井 |
|---|---|---|---|---|---|---|---|
| オンサイト ZZ(電荷) | **465** | 465 | 513 | 151 | 555 | 555 | 555 |
| 隣接 $Z_\uparrow Z_\uparrow$ (スピン) | 1.2 | 7.0 | 14.2 | **29.2** | 28.8 | 19.8 | 31.6 |
| 単一サイト $Z_\uparrow$ | **0.02** | 1.00 | 1.00 | 1.00 | 0.46 | 1.00 | 1 |
| 二重占有(4項の和) | 1.8 | **123** | 127 | 78 | 53 | 129 | — |

以下の説明に出てくる言葉を補う。

- **強結合**は $U/t$ が大きい場合である。half-filling では電子が各サイトに1個ずつ収まり、ほとんど動けなくなる。それでも隣へ一瞬飛んで戻る「寄り道」は起こり、その途中で二重占有ができる。そのため二重占有率は $(t/U)^2$ に比例する小さな値として残る。寄り道は隣のスピンが逆向きのときだけできるので、隣のスピンは逆向きになりたがる(反強磁性)。
- **Néel 配置**は、スピンが「上、下、上、下」と向きの決まった形で交互に並んだ古典的な配置である。
- **一重項**は、2つのスピンが「どちらが上かは決まっていないが必ず逆向き」という量子的な重ね合わせになった状態である。スピン相関 $\langle\mathbf S_i\cdot\mathbf S_j\rangle$ は、Néel 配置で $-1/4$ 、一重項で $-3/4$ で、一重項の方が3倍強く逆向きである。本当の基底状態の値はこの2つの間にある(1次元で $-0.443$ )。
- **Schmidt 分解**は、系を左右に切って、状態を「左の状態 × 右の状態」の組の和で書くことである。結合次元 $\chi$ の MPS は、この和を $\chi$ 項までしか持てない。

- **電荷の量では、強結合で平均場の誤差が $(t/U)^2$ で消える。** 二重占有率 $d$ は「隣の結合がどれだけ一重項を組んでいるか」に比例し、UHF はそれを古典的な Néel 配置(半分だけ一重項)として持つ。そのため $d$ そのものの相対誤差は 28% で止まる。しかしオンサイト ZZ $=4d-1$ に対する相対誤差は、分母が $-1$ に張り付くので $4d\times0.28\approx3.1(t/U)^2$ で消える。数で言うと、 $U=12$ で $d\approx0.018$ のとき、UHF の $d$ は 28% 小さい 0.013 程度である。オンサイト ZZ にすると本当の値が $4\times0.018-1=-0.93$ 、UHF の値が $-0.95$ で、ずれは 0.02、相対的には 2% にすぎない。 $d$ を 28% も外しているのに、 $-1$ に近い量に直すと外れが目立たなくなる。
- **スピンの量では UHF が損をする。** 理由は2つある。
  - スピンの向きを選んでしまう → UHF-sym(向きについての平均)で直る。隣接 $Z_\uparrow Z_\uparrow$ で損をする系が 17/80 から 0/80 になる。
  - 量子的な一重項の相関が足りない → UHF-sym では直らない。 $S^zS^z$ の相対誤差は 1次元で 0.69 に止まり、2次元では損になる(損得の境目は $\lvert\langle\mathbf S\cdot\mathbf S\rangle\rvert=3/8$ で、1次元の 0.443 は得、2次元の正方格子の約 0.335 は損)。
- **PHF の効果は $1/L$ で消える。** 副格子とは、二部格子を「隣は必ず別の組」になるよう2組に分けたときの各組で、UHF では一方の組のスピンが上、他方が下を向く。射影は2つの副格子の大きなスピンを1つの回転子として組み直すだけで、1つの結合に配られる量子相関は $1/L$ に薄まる。 $L=64$ では真の値との差の 11% しか埋まらない。予測 $L\Delta\langle\mathbf S\cdot\mathbf S\rangle=-2m$ は実測と合った。
- **2種類の MPS は性質が逆である。** 切断 $\chi=4$ はスピンが正確な代わりに電荷のゆらぎを捨て、変分 $\chi=4$ は電荷が正確な代わりにスピンの向きを選ぶ。中央の結合の Schmidt 分解で、少ない状態の使い方の違いとして確かめた。
- **変分 MPS を回転平均すると、電荷とスピンの両方で損をしない。** $\chi\ge8$ では 80 系 × 4 観測量のすべてで損がなく、厳密な状態を使わない prior の中で最も良い([README_varsym.md](README_varsym.md))。

### D. 和の観測量では、項ごとの誤差が効く

二重占有 $n_\uparrow n_\downarrow$ は、 $n=(1-Z)/2$ を代入すると $\frac14(1-Z_\uparrow-Z_\downarrow+Z_\uparrow Z_\downarrow)$ になる。定数と、 $Z_\uparrow$ 、 $Z_\downarrow$ 、 $Z_\uparrow Z_\downarrow$ の3つのパウリ文字列の和である。3つは別々の設定で当たるので、それぞれのくじの揺らぎは打ち消し合わない。二重占有をこの和として測ると、共線 UHF の利得は 1.8 に落ち、UHF-sym なら 123 である。UHF の $\langle Z_\uparrow\rangle=\pm2m$ と $\langle Z_\downarrow\rangle=\mp2m$ の外れは合計では打ち消し合うが、分散には項ごとの外れの積として入り、打ち消されない。

### E. 回転平均は偽の長距離秩序を消さない

**長距離秩序**とは、遠く離れた2つのスピンの向きにも決まった関係があることである。UHF では、すべてのスピンが「副格子 A は上、B は下」とそろっているので、どれだけ離れた2サイトでもスピン相関が $\pm m^2$ のまま減らない。本当の基底状態(1次元)では、スピン相関は距離とともに小さくなる。UHF のこの性質は実際にはないものなので、「偽の」長距離秩序と呼ぶ。

スピンの向きを選んだ prior の $\langle\mathbf S_i\cdot\mathbf S_j\rangle$ には、距離によらない $\langle\mathbf S_i\rangle\cdot\langle\mathbf S_j\rangle=\pm m^2$ が含まれる。 $\mathbf S_i\cdot\mathbf S_j$ は回転で変わらないので、回転平均してもこの部分は残る。遠い対では本当の値 $x$ が小さいのに、prior は $\pm m^2/3$ 程度の値を予言し続けるので、外れが本当の値より大きくなり( $\lvert\Delta\rvert>\lvert x\rvert$ )、損得の境目を越える。そのため UHF-sym は距離 $r\ge4$ の対ではすべて損をする( $U\ge4$ )。全距離で得をするのは、対称性を保つ量子的な prior だけだった([README_varsym_distance.md](README_varsym_distance.md))。

### F. 対称性の役割

- **粒子正孔対称性**は、「電子がいる」と「電子がいない」を入れ替えても模型が変わらない、という性質である。half-filling(半充填。電子の数がサイトの数と等しい場合)の二部格子で成り立つ。半充填の二部格子では、粒子正孔対称性により電子数がサイトごとに厳密に 1 になる。開放端の影響は電荷には出られず、結合の強弱の交替に回る。電荷の量が境界条件に鈍いのはこのためである([README_particle_hole.md](README_particle_hole.md))。
- トーラスは、縦横の両方向を環につないだ格子である。3サイトの環は「上、下、上」と並べると最初と最後が同じ向きで隣り合ってしまうので、二部格子ではない。二部格子でない 4×3 トーラスでは UHF の電荷が 6.5% 偏っていた。これが以前の「既知の異常点」の原因の一部だった。

### G. 2次元とドープ系

- シリンダーは、正方格子を一方向だけ環につないで筒にしたもので、幅 $W$ は筒の周のサイトの数である。half-filling の2次元シリンダーでは、オンサイトの量とホッピングで UHF が $\chi=64$ 〜 $128$ の MPS に並ぶ( $W=6$ 、 $U=8$ のオンサイト ZZ で 148、天井 149.6)。MPS の必要な結合次元は幅について指数的に増えるが、UHF の計算量は $O(N^3)$ のままである。
- ドープとは、half-filling から電子を抜くことである。1/8 ドープでは8サイトにつき1個抜く。抜けた跡(正孔)は一様には広がらず、線状に集まって縞模様を作る。これをストライプと呼ぶ。1/8 ドープの系では、平均場は電荷の模様(ストライプ)で破綻する。破綻はストライプの壁の上と電荷の量に局在し、ドメインの中のスピンの量は UHF-sym で救える([README_experiments.md](README_experiments.md) §8–§9)。

## 3. 最近の確認でわかった注意点

結論をどこまで信用してよいかに関わる点をまとめた。表の言葉を補う。

- **モンテカルロ(模擬)の値**は、測定を乱数で模擬し、推定を何十回も繰り返して分散を数えた値である。繰り返しの数が有限なので誤差を持つ。**厳密な値**は、1.3 節の式に $x$ と $y$ を代入して計算した値で、誤差がない。
- **読み出し誤差**は、測定の最後に $+1$ と $-1$ を読み間違える装置の誤りである。台の量子ビットのどれか1つでも読み間違えると積の符号が変わるので、台が大きいほど影響が大きい。
- $P_{16}$ は、16 個の量子ビットにまたがる $Z$ の積(電子の数の偶奇を表す量)である。
- $\chi_p$ は prior に使う MPS の結合次元である。
