## 1. 確立した主張(このまま論文に書けるもの)

### 1.1 利得法則 — 5桁にわたる定量的な検証

局所Pauli観測量に対するCRMの分散削減率は閉形式

$$G = \frac{(3^{|A|}-1)\langle P\rangle^2 + v_s}{(3^{|A|}-1)\Delta^2 + v_s},\qquad v_s=\frac{3^{|A|}(1-\langle P\rangle^2)}{n_m}$$

**記号の定義**

| 記号 | 定義 |
|---|---|
| $P$ | 推定したい局所Pauli演算子(Pauli列)。例: $Z_1Z_2$ |
| $A$ | $P$ の**台** — 恒等演算子でないPauliが載る量子ビットの集合。$\lvert A\rvert$ はその個数 |
| $\rho$ | 実験状態(本研究では擬似実験としてDMRGで作った参照状態) |
| $\sigma$ | **prior** — 古典計算で作った $\rho$ の近似(切断MPS、UHF平均場など) |
| $\langle P\rangle$ | 実験状態での期待値 $\langle P\rangle_\rho=\mathrm{Tr}[P\rho]$。添字を省いたものは常に $\rho$ 側 |
| $\langle P\rangle_\sigma$ | prior での期待値 $\mathrm{Tr}[P\sigma]$ |
| $\Delta$ | **priorの局所誤差** $\langle P\rangle_\rho-\langle P\rangle_\sigma$ — その観測量について prior がどれだけ外しているか |
| $n_m$ | 1つの測定設定あたりのショット数 |
| $n_u$ | 測定設定(ランダム基底の選び方)の数。標準・CRM双方の分散が $1/n_u$ に比例するので、比である $G$ には現れない |
| $v_s$ | **ショットノイズ床** — 有限ショットに由来し、priorでは打ち消せない分散 |
| $3^{\lvert A\rvert}$ | 逆測定チャネルの増幅率。基底が $A$ 上で全一致する確率が $3^{-\lvert A\rvert}$、一致時の推定値が $3^{\lvert A\rvert}(\pm1)$ |
| $G$ | **利得** $=\mathrm{Var}[\text{標準シャドウ}]/\mathrm{Var}[\text{CRM}]$。$G>1$ で得、$G<1$ で損 |

**式の読み方**: 分子の $(3^{\lvert A\rvert}-1)\langle P\rangle^2$ は「ランダムに選んだ基底が当たるか外れるか」による**設定間の揺らぎ**で、CRMが打ち消す対象である。分母ではこれが $\Delta^2$ に置き換わる — priorが当たっていれば($\Delta\to0$)この揺らぎは消える。$v_s$ は分子・分母の**両方に同じ形で入る**ので決して打ち消せない床であり、$\Delta\to0$ でも $G$ は $1+(3^{\lvert A\rvert}-1)\langle P\rangle^2/v_s$ で頭打ちになる。

この法則は $G\approx0.005$ から $\approx1000$ まで経験値と一致する。**priorのグローバル忠実度は式に現れない**。

**2つの律速レジーム**: $\varepsilon=\Delta/\langle P\rangle$、$g=(3^{|A|}-1)\langle P\rangle^2/v_s$ とすると $G=(g+1)/(\varepsilon^2 g+1)$。$G\approx G_{\max}=1+g$ ならショットノイズ律速($n_m$ を増やすべき)、$G\ll G_{\max}$ なら $\Delta$ 律速(prior改善の余地)。

### 1.2 局所性 — 256量子ビット鎖の全サイトで検証済み

$\chi_p\ge4$ の prior なら、忠実度が $10^{-17}$ まで崩壊しても**損をするサイトは一つもない**(L=8–128、半充填とδ=1/8ドープ、17,210点)。$\Delta(i)$ は**サイトにほとんど依存しない**。

**機構(訂正済み)**: 「$\Delta$ が L にも依存しない」は誤りで、$\chi_p=2$ で飽和しているから平坦に見えるだけである(Δ の L128/L8 比は χ_p=2,4,8,16,32 で 1.02, 4.97, 0.99, 12.4, **184**)。利得が L に平坦な本当の理由は**ショットノイズ律速に留まっている**ことである:

| χ_p | G(L=8) | G(L=128) | ε(L=128) | G/G_max | レジーム |
|---|---|---|---|---|---|
| 2 | 2.27 | 2.18 | 0.67 | 0.043 | Δ律速・飽和 |
| **4** | **40.5** | **9.84** | 0.29 | 0.194 | **Δ律速・遷移** |
| 8 | 50.5 | 50.9 | 2.8e-3 | 1.000 | ショットノイズ律速 |
| 32 | 50.4 | 50.8 | 4.5e-4 | 1.000 | ショットノイズ律速 |

χ_p≥8 では $\varepsilon$ がショットノイズ床のはるか下にあるので $G=G_{\max}$ に貼り付き、**L にも prior 品質にも一切依存しない**(忠実度 $10^{-17}$ が無関係な理由)。**χ_p=4 の遷移領域だけ利得が4倍劣化する**。正しい主張は「ショットノイズ律速でいられる限り利得は L に依存しない」である。

### 1.3 CRMは常に得ではない — そして直せる

$\chi_p=2$ の粗い prior では**ドープ鎖の2〜3割のサイトで有意に損**をする(最悪 G=0.037)。設定数 $n_u\ge200$ で係数をプラグイン推定すれば **445点すべてで損が消える**。

### 1.4 2Dでの安価なprior

$O(N^3)$ のUHF平均場priorがオンサイト観測量で $\chi=32$–$64$ のMPS prior に匹敵する。弱点(サイト間スピン相関)は**スピン回転平均による対称性回復**(混合状態prior)で修復される。W=6(96量子ビット)ではUHFの優位がさらに広がる。

### 1.5 効果範囲の切り分け

- **matchgateシャドウ**: JW弦問題を解消し2Dの全エネルギーを測れるようにするが、Gauss回転アンサンブルは自己平均的でCRMはほとんど効かない。
- **derandomization**: 既知の固定観測量リストには貪欲derandが最強。CRMはシャドウの事後選択の柔軟性を保ったまま差をほぼ埋める。
- 三者は**同じ問題の異なるボトルネックへの相補的な道具**である。

## 2. 今回の一連の実験で新たに分かったこと

### 2.1 利得は鎖に沿って一様ではない(§2b–2c)

端の数サイトで1.3–3.6倍高く、ボンド観測量では隣り合うボンドで最大17倍違う。原因は**prior品質ではなく観測量自身の $\langle P\rangle(i)$** で、開放端が誘起する周期2のFriedel振動が天井 $G_{\max}$ を上下させている。振幅は $A(x)\propto x^{-1/2}$($A(x)\sqrt x$ が4%以内で一定)で、gapless スピン鎖の既知の指数と一致する。

$\langle P\rangle$ の2.5倍差が $G$ の17倍差になるのは $G_{\max}\propto\langle P\rangle^2/(1-\langle P\rangle^2)$ が $|\langle P\rangle|\to1$ で発散するため。

**帰無検定で確認済み**: 周期境界にすると振動は完全に消える($\langle P\rangle$ の変動係数 0.25→0.0015、$G_{\max}$ の最大/最小比 16.1→1.01、L=32)。PBC のバルク値 $-0.514$ は OBC の交替値のちょうど中間で、「バルク値のまわりの定在波」という描像と整合する。**周期境界の系ではサイト分解に意味がなく、中央1点で十分**。

**実務的含意**: 測定計画は「どの観測量か」だけでなく**系のどこか**まで含めて $\langle P\rangle$ を見積もる必要がある(ただし開放端など並進対称性が破れている場合に限る)。

### 2.2 分散比という指標の落とし穴(§2d)

$G$ は分散比なので**バイアスを見ない**。プラグイン $\hat\beta$ は同一データで係数を推定するため原理的にバイアスを持ち、分散比だけで比較すると不当に有利に評価される。MSE比とバイアス/標準偏差を併記すると推奨が変わる:

| 推定量 | 損@n_u=50 | MSE比(χ_p=4) | max\|bias\|/sd |
|---|---|---|---|
| CRM(β=1) | 134/445 | 4.32 | 0.13 |
| プラグインβ | 16/445 | **17.46** | 0.59 |
| 標本分割 | 66/445 | 16.69 | 0.14 |
| 厳密Var(Y) | **0/445** | 5.94 | 0.78 |
| 分割×厳密Var | 8/445 | 4.60 | **0.12** |

### 2.3 「prior側は標本推定に頼らない」原則の再適用(§2d)

プラグイン $\hat\beta$ は prior がある項をゼロと予言するとき($\chi_p=2$ の二重占有など)$\mathrm{Var}(Y)=0$ の $0/0$ で発散する。しかし **$\mathrm{Var}(Y)$ は prior だけから閉形式で計算できる**(基底分布が既知なので $\Pr[t]=3^{-|A_t|}$、$\Pr[t\wedge t']=3^{-|A_t\cup A_{t'}|}$)。これは研究の出発点だった推定器のバグ修正とまったく同じ原理であり、**同じ設計原則が推定量の複数箇所で繰り返し効く**。

### 2.4 prior フリー性の定量化と限界(§2d)

単一Pauli列では $\hat\beta(\bar Y-\mathrm{Tr}[O\sigma])$ の中で $\langle P\rangle_\sigma$ が約分され、$G_\beta$ が $\chi_p$ に対し小数点2桁まで不変になる。忠実度 $10^{-17}$ の prior でもZZ系は**天井の94–95%**に到達する。すなわち「粗いpriorでも最適βなら効く」の実体は**priorを捨てた推定量への切り替わり**である。多項観測量(二重占有・SzSz)では prior 依存が残り、prior の価値はそちらに集約される。

限界も明確で、$\mathrm{Var}(Y)=0$(priorがその量を厳密にゼロと予言)なら制御変量が原理的に存在せず、$\beta=0$ に落ちて標準シャドウに戻る(損も得もなし)。

### 2.5 局所性の適用条件 — ギャップのある系でのみ成立(§2e)

**仮説**: gapless なセクターがあると、固定 χ の prior が捉える割合が L とともに落ちる。

**第1版は失敗した**。固定 $\chi_p$ での $\varepsilon$ の L 依存を測ったが χ_p に対して頑健でなく(U=4 半充填で 1.08, 1.20, 1.03, 9.18)、χ で平均すると区別が消えた。原因は $|\Delta|(\chi)$ が**非単調**(偶然の打ち消しでくぼむ)なこと。

**再設計版は成功した**。指標を「目標精度 $\varepsilon<10^{-2}$ に必要な χ」$\chi^*(L)$ に変えると、定義上単調になり:

| 配置 | χ*(16) | χ*(128) | 指数 p | c(独立測定) |
|---|---|---|---|---|
| U=4 half(gapped) | 10.0 | **15.1** | 0.200 | 0.92 |
| U=8 half(gapped) | 8.9 | **15.1** | 0.255 | 0.91 |
| U=2 half | 13.9 | 24.8 | 0.278 | 0.99 |
| U=1 half | 16.4 | 35.5 | 0.372 | 1.53 |
| U=4 δ=1/8(gapless) | 13.5 | **30.9** | 0.400 | 1.64 |
| U=8 δ=1/8(gapless) | 12.4 | **32.8** | 0.467 | 1.66 |

1. **ギャップのある系は飽和**(U=4 半充填は L=32 以降 χ*=16 のまま、観測量5種すべて)
2. **gapless では $\chi^*\propto L^p$ で増加**($p\approx0.40$–$0.47$)
3. **$p$ と中心電荷 $c$ の相関 = +0.95**。$c$ はエントロピーから独立に測った量なので、仮説の直接確認になる

$\chi\sim e^S=L^{c/6}$ が期待されるが実測 $p$ は $c/6$ の平均1.55倍 — 観測量を固定精度で当てるのはエントロピー再現より厳しい要求なので向きは自然(係数の由来は未解明)。

**結論**: 局所性は**ギャップのある系で厳密**、gapless では $L^{c/6}$ 程度で緩やかに破れる(L を8倍にして χ* は2〜3倍。指数的破綻ではない)。

**実験設計上の教訓**: 第1版と再設計版は同じ物理・同じデータ生成過程を測っており、違うのは指標だけである。非単調な量の比を取ると結論が消え、単調に定義し直すと corr=0.95 が現れる。**指標が単調で well-defined かを先に確認すべき**。

## 3. 未解決の問題(優先度順)

### 3.1 【一部解決・一部撤回】prior誤差と切断の関係

**問題**: U=4 と U=8 の半充填はどちらも c≈0.9、U=8 の方がエントロピーも捨てる重みも小さいのに、χ_p=8 の prior 誤差(相対誤差 ε)は U=8 が4倍大きい。

**確定していること**: U=8/U=4 の比を分解すると、絶対誤差 |Δ| が7.3倍大きいのは**二重占有(とその一次関数である onsite ZZ)だけ**である(L=128, χ_p=8, 半充填):

| 観測量 | \|⟨P⟩\| 比 | \|Δ\| 比 | ε 比 |
|---|---|---|---|
| **二重占有** | 0.366 | **7.31** | 20.0 |
| ZZ onsite (= −1+4D) | 1.425 | **7.31** | 5.13 |
| SzSz r=1 | 1.236 | 0.876 | 0.73 |
| ZZ up-up r=1 | 1.097 | 1.176 | 1.09 |

サイト間スピン相関はむしろ U=8 の方が良い。したがって「U=8 では prior が悪い」のではなく「**二重占有という特定の量が壊れる**」。ここまでは確定。

**撤回した説明**: 当初「捨てた重み w のうち ⟨D⟩ に効く割合が U=4 で1.0%、U=8 で41.5%」と書いたが、これは誤りだった。χ を掃引する実験([crm_sensitivity.jl](crm_sensitivity.jl))で **|Δ|(χ) が単調でない**ことが判明した — U=4 半充填(L=64)では χ=8 で 7.8×10⁻⁵、χ=16 で 5.6×10⁻⁴ と**増える**。χ=8 で偶然の打ち消しが起きており、私はそのくぼみを拾って比を作っていた。

**代わりに分かったこと**: |Δ| ≈ s·w^α のフィットは α ≈ 0.63–1.16(多くは0.8–1.0)で概ね成立し、**感度 s は観測量ごとに一桁以上違う**:

| 観測量 | s (U=2 half) | s (U=4 half) | s (U=8 half) |
|---|---|---|---|
| n | 0.000 | 0.000 | 0.000 |
| SzSz r=1 | 0.159 | 0.031 | 0.118 |
| 二重占有 | 0.158 | 0.128 | 0.192 |
| ZZ onsite | 0.631 | 0.510 | 0.767 |

**同じ捨てる重みでも、観測量によって生じる誤差が一桁以上違う**という主張は残る(これは中心主張の拡張として有効)。しかし**同一観測量の s は U によって1.5倍しか変わらない**ので、これでは |Δ| の7.3倍差は説明できない。

**この問題自体が解消した**: §2.5 の再設計(χ* 指標)で、U=8 半充填の「異常」が χ=8 のみのアーティファクトだったことが確定した。χ* で測れば U=8 半充填は U=4 と同様に飽和する(χ*=15.1 で一致)。残るのは「感度 s が観測量ごとに一桁違う」という事実で、これは中心主張の拡張として有効である。

**教訓(重要)**: 単一の χ での比較は信用できない。|Δ|(χ) は偶然の打ち消しで桁で上下する。**χ を掃引してフィットするか、複数の χ の中央値を使うこと**。

### 3.2 損の事前予測(真値を知らずに $\varepsilon>1$ を検知する)

損の条件は $\varepsilon=\Delta/\langle P\rangle>1$ だが $\Delta$ は真値を要する。候補は2つある。

**(a) 2つのpriorの差**: $|\langle P\rangle_{\chi_2}-\langle P\rangle_{\chi_4}|$ を代理にすると、半充填では log-log 相関 0.975–0.992 と桁の予測はほぼ完璧だが、**半分以上の場合で過小評価する**ため安全側の上界にならない。3つの $\chi$ でのRichardson外挿か安全係数の導入を検討する。

**(b) prior 自身が予言する物理量**(§3.3 で判明): 2DではUHFの誤差が局所ホール密度と corr 0.83–0.98 で相関し、UHF自身の予言密度でも 0.29–0.69 の相関が残る。**prior が予言する「難しさの指標」を使う**というのは (a) より安価で、prior 側だけで完結する。ただし対象はオンサイト量に限られ、スピン相関では相関が負になる。(a) と (b) を組み合わせるのが自然な次の一手。

### 3.3 【実施済み】サイト分解の2D版 → README §4b

W=4×8 シリンダー(64量子ビット)、U ∈ {4,8}、半充填とドープで実施した。結果:

1. **安いprior(UHF)だけが空間的に大きく不均一**。半充填では変動 1.4–3.0倍だが、ドープすると 9.9–52.9倍に跳ね上がる。誤差は列 x にのみ依存する縞構造を示す(電荷変調が x 方向にのみ立つため)。切断MPS priorの誤差はまだら模様で系統的構造を持たない。
2. **UHF の誤差は局所ホール密度で予測できる**: corr(lnε, |n−1|) = **+0.83〜+0.98**(オンサイト量、ドープ系)。§9 の定性的示唆が定量的に確認された。
3. **ただし自己診断は限定的**。実務で使えるのは UHF が自分で予言する密度だが、それを使うと相関は 0.29–0.69 に落ちる。**UHF の密度プロファイル自体が真の値と corr 0.42–0.55 でしか一致しない**ためで、「安いpriorが最も間違える量」が「どこで間違えるかを教えてくれる量」でもあるという circular な状況になっている。

4. **対称性回復UHFはオンサイト量を一切変えない(数学的事実)**。大域スピン回転 $\theta$ について、サイトの相関行列ブロックは $C'_{aa}=c^2n_u+s^2n_d$, $C'_{bb}=s^2n_u+c^2n_d$, $C'_{ab}=cs(n_d-n_u)$ となり、
   $$C'_{aa}C'_{bb}-C'^2_{ab} = (c^4+s^4+2c^2s^2)\,n_u n_d = n_u n_d$$
   と\emph{厳密に不変}である($n_u+n_d$ も不変)。したがって $\ev{Z_uZ_d}$、二重占有、$n$ はすべて回転平均で変わらない。**対称性回復が効きうるのはサイト間量だけ**であり、これは §4 で観測された挙動の数学的な理由になっている。
5. **対称性回復が効くかは参照状態が対称性を破っているかに依存する**。Lx=4 では DMRG 自身が対称性を破り(m_stag=−0.28)、対称性回復UHFはむしろ不利になった(SzSz の誤差 0.501→0.471 とほぼ不変)。Lx=8 では m_stag≈0 なので状況が変わるはずで、実行中(ジョブ1880/1881)。

**残る課題**: x方向ボンド($2^{2W+1}=512$ 次元のRDM、W=4なら実行可能)を含めた完全な地図。

### 3.4 prior-informed derandomization

priorを測定計画の設計そのものに使う。§2c で「どのボンドを測るかで必要ショット数が一桁変わる」ことが分かったので、priorから $\langle P\rangle(i)$ を見積もって測定設定を最適化する枠組みは自然な発展になる。

### 3.5 測定予算の最適配分

$G_{\max}$ を経験的に測る手法(§2b)が確立したので、観測量集合が与えられたとき「prior改善に計算資源を割く」か「$n_m$ を増やす」かを定量的に決められる。$G/G_{\max}$ が1に近い観測量が多ければ後者が有利。

## 4. 方法論上の教訓(繰り返し効いたもの)

この研究で同じ原則が3回別々の場所で効いた。記録しておく価値がある。

1. **prior側は標本推定に頼らず解析的に計算する**
   - 出発点: CRM推定器のバグ(prior側を有限ショットでサンプルしていた)→ 厳密計算で修正
   - 2Dのprior: MPS表現を経由せず Wick の定理で閉形式 → コストが $O(N^3)$
   - 最適β: $\mathrm{Var}(Y)$ を標本推定すると $0/0$ で発散 → 閉形式で解消

2. **グローバルな尺度は使えない。観測量ごとの局所的な量を見る**
   - グローバル忠実度 → 局所prior誤差 $\Delta$
   - $|\langle P\rangle|$ の大きさ → 相対誤差 $\varepsilon=\Delta/\langle P\rangle$
   - 切断で捨てる重み → 観測量ごとの感度 s(§3.1。同じ w でも観測量により誤差が一桁違う)

3. **単一の切断・単一の χ での比較を信用しない**
   - $|\Delta|(\chi)$ は偶然の打ち消しで桁で上下する(U=4, L=64 では χ=8 が χ=16 より7倍良い)
   - χ を掃引してフィットするか、複数 χ の中央値を使う
   - この落とし穴で一度誤った結論を出した(§3.1)

4. **指標が何を見ていないかを常に確認する**
   - 分散比 $G$ はバイアスを見ない → MSE を併記
   - 絶対誤差 $|\Delta|$ は基準値がゼロに近い場合に無意味 → 相対誤差を使う
   - 中央値は最悪ケースを隠す → 最小値と「損なサイト数」を併記

## 5. 計算資源のメモ

| 実験 | 規模 | 時間 |
|---|---|---|
| サイト分解(L=8–128、17,210点) | 256量子ビット | 45分(8コア) |
| 最適β(6推定量、L=16/64) | 128量子ビット | 50分(8コア) |
| gapped/gapless(7配置×5サイズ) | 256量子ビット | 2時間(8コア、30スイープ) |

**窓RDMサンプリング**により局所観測量のシャドウ実験はボンド次元に依存しなくなった(逐次MPSサンプリングの約250秒/サイト → 約1秒/サイト)。これが L=128 を可能にした最大の要因。

**DMRG収束の注意**: U=8 では16スイープでは収束せず、中央エントロピーが L=64→128 で減少するという異常が出た。30スイープで解消(χ=512 にしても変わらないのでスイープ数が原因)。強結合では必ず収束確認をすること。
