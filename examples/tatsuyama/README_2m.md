## 2m. 利得は「部分系の忠実度」で決まるか

スクリプト: [crm_support_fidelity.jl](crm_support_fidelity.jl) / [.pbs](crm_support_fidelity.pbs) / データ: [crm_support_fidelity_results.tsv](crm_support_fidelity_results.tsv) / 最初の(欠陥のある)版: [crm_window_fidelity.jl](crm_window_fidelity.jl)

### 問い

§2 の主張は「**大域**忠実度 $F=\lvert\langle\sigma\vert\rho\rangle\rvert^2$ は利得を決めない、観測量ごとの局所誤差 $\Delta$ が決める」だった。この2つは粒度が両極端である。

| | 粒度 | 長所 | 短所 |
|---|---|---|---|
| 大域忠実度 $F$ | 系全体で1つの数 | 観測量を決めなくても計算できる | 全サイトの誤差の積なので $L$ とともに指数的に死に、利得と無関係になる |
| 局所誤差 $\Delta$ | 観測量1つに1つの数 | 利得を厳密に決める | 観測量を決めないと計算できない |

その中間に自然な候補がある。**観測量が触る量子ビットだけに縮約した密度行列どうしの近さ**である。これなら系全体ではないので指数的には死なず、しかも(その部分系を見る限り)観測量に依存しない1つの数になる。

**これで $\Delta$ が決まるなら実務上とても有用である。** prior を1つ作ったら、部分系の距離を1回計算するだけで「どの観測量にどれだけ効くか」が分かることになる。観測量ごとに $\Delta$ を計算し直す必要がなくなる。

### この節には別々の2つの問いが入っている

以下は長いので、先に構成を示す。**この節は性格の違う2つの問いを扱っており、混同すると誤る。**

| | 段階1(科学) | 段階2(実用) |
|---|---|---|
| 問い | 利得は部分系のトレース距離・忠実度に**依存するのか** | それを prior の**選定に使えるのか** |
| 目的 | 機構の解明 | 道具としての評価 |
| $\rho_A$ を知ってよいか | **よい**(古典参照 = ED や高 $\chi$ DMRG を使う) | **いけない**(未知。有限データから推定する) |
| 評価軸 | 関係が成り立つか、いつ厳密になるか | 正しい prior を選べるか、いくら測定が要るか |
| 該当箇所 | 準備1–5、結果1–5、段階1のまとめ | 準備4e、準備4f、段階2 |

準備4b–4d(トレース距離と忠実度の性質の比較、元論文の指標、混合状態)は両方の土台である。

> **混同すると何が起きるか。** 段階1で得た関係(飽和 $\lvert\Delta\rvert=2D_A$ 、閉形式 $\min(1,2/(1+4r))$ )を、そのまま段階2の処方として書いてしまう。実際に一度そう書いて準備4e で訂正した。段階1の関係は $\rho_A$ を持っている前提で導いたもので、**そのままでは選定の道具にならない。**

### 準備1: 縮約密度行列(部分系だけを見る)

系全体の状態を $\rho$ とする。着目する量子ビットの集合を $A$、それ以外を $B$ とすると、**$A$ の縮約密度行列**は

```math
\rho_A = \mathrm{Tr}_B[\rho]
```

で定義される。 $\mathrm{Tr}_B$ は「 $B$ の自由度を足し上げる(積分し尽くす)」操作で、**部分トレース**という。成分で書くと、 $\lvert a\rangle$ を $A$ の基底、 $\lvert b\rangle$ を $B$ の基底として

```math
(\rho_A)_{a a'} = \sum_b \langle a\,b\rvert\rho\lvert a'\,b\rangle
```

つまり $B$ の添字を対角で潰す。 $A$ が $\lvert A\rvert$ 量子ビットなら $\rho_A$ は $2^{\lvert A\rvert}\times2^{\lvert A\rvert}$ の行列で、系全体の $2^N\times2^N$ よりはるかに小さい。

**重要な性質**: 観測量 $P$ が $A$ の上にしか作用しないなら、その期待値は $\rho_A$ だけで決まる。

```math
\langle P\rangle_\rho = \mathrm{Tr}[P\,\rho] = \mathrm{Tr}_A[P\,\rho_A]
```

**$A$ の外の情報は $\langle P\rangle$ に一切入らない。** だから「観測量が触る量子ビット(=台)」に絞った縮約密度行列こそが、その観測量にとっての「状態のすべて」である。

### 準備2: トレース距離

行列 $M$ の**トレースノルム**を

```math
\lVert M\rVert_1 = \mathrm{Tr}\sqrt{M^\dagger M} = \sum_i \lvert\lambda_i\rvert
\qquad(\lambda_i \text{ は } M \text{ の固有値、} M \text{ がエルミートのとき})
```

と定義する。これを使って2状態の**トレース距離**は

```math
D_{\rm tr}(\rho_A,\sigma_A) = \tfrac12\lVert\rho_A-\sigma_A\rVert_1
```

である。 $0\le D_{\rm tr}\le1$ で、 $0$ は完全一致、 $1$ は台が直交(完全に区別できる)を意味する。

**この量が本質的なのは、次の変分表示があるからである:**

```math
D_{\rm tr}(\rho_A,\sigma_A) = \max_{0\le M\le I}\ \mathrm{Tr}\bigl[M(\rho_A-\sigma_A)\bigr]
```

右辺は「あらゆる測定 $M$ にわたって、期待値の差を最大にしたもの」である。つまり **トレース距離は「2つの状態を最も見分けやすい測定で見分けたときの差」** であり、 $\tfrac12$ が付いているのはこの最大値と一致させるためである。

### 準備3: なぜ $\lvert\Delta\rvert\le 2D_{\rm tr}$ なのか

Pauli 列 $P$ は固有値が $\pm1$ なので、 $+1$ 固有空間への射影を $\Pi$ として $P = 2\Pi - I$ と書ける。 $\rho_A$ と $\sigma_A$ はどちらもトレース1なので $\mathrm{Tr}[\rho_A-\sigma_A]=0$ であり、

```math
\Delta = \mathrm{Tr}[P(\rho_A-\sigma_A)]
= 2\,\mathrm{Tr}[\Pi(\rho_A-\sigma_A)] - \underbrace{\mathrm{Tr}[\rho_A-\sigma_A]}_{=0}
= 2\,\mathrm{Tr}[\Pi(\rho_A-\sigma_A)]
```

となる。 $\Pi$ は $0\le\Pi\le I$ を満たす測定の一種なので、上の変分表示から $\lvert\mathrm{Tr}[\Pi(\rho_A-\sigma_A)]\rvert\le D_{\rm tr}$ 。したがって

```math
\lvert\Delta\rvert \;\le\; 2D_{\rm tr}
```

**係数 2 は「Pauli 列の固有値が $\pm1$ の幅2を持つ」ことから来る。** そして等号が成り立つのは、 $\Pi$ が最大を達成する測定と一致するとき、すなわち **$P$ の固有値の符号パターンが $\rho_A-\sigma_A$ の固有値の符号パターンとちょうど揃うとき**である。後で見るように、半充填ではこれが自動的に起きる。

### 準備4: 忠実度

**Uhlmann 忠実度**は

```math
F(\rho_A,\sigma_A) = \Bigl(\mathrm{Tr}\sqrt{\sqrt{\rho_A}\,\sigma_A\sqrt{\rho_A}}\Bigr)^2
```

で定義される。 $0\le F\le1$ で、 $1$ が完全一致(トレース距離と逆向き)。特別な場合には簡単になる:

- **純粋状態どうし**: $F=\lvert\langle\psi\vert\phi\rangle\rvert^2$ (よく使う「重なりの2乗」)
- **可換な状態どうし**(同時対角化できる、確率分布 $p,q$ とみなせる場合): $F=\bigl(\sum_i\sqrt{p_i q_i}\bigr)^2$ (Bhattacharyya 係数の2乗)

本節で扱う RDM は占有基底で対角なので、2番目の形が使える。

忠実度は距離ではない(三角不等式を満たさない)が、トレース距離と **Fuchs–van de Graaf の不等式**

```math
1-\sqrt{F} \;\le\; D_{\rm tr} \;\le\; \sqrt{1-F}
```

で結ばれている。右側から $\lvert\Delta\rvert\le2D_{\rm tr}\le2\sqrt{1-F}$ が出るので、**忠実度からも上界は作れるが、必ずトレース距離版より緩い**。

### 準備4b: なぜ忠実度ではなくトレース距離を使うのか

準備3で $\lvert\Delta\rvert\le 2D_{\rm tr}$ を出したが、「忠実度でも同じことができるのでは」というのは自然な疑問である。**できない。しかもそれは好みの問題ではなく、量の種類が違うことによる。**

> **先に断っておく。** 元論文(Vermersch *et al.*)は忠実度を prior の品質判定に実際に使っており、**その設定では正しい**。本節が否定するのは「混合 prior のもとで局所観測量の利得を定量予測する」という本研究の設定での使用である。元論文が何を指標にしているかは**準備4c**で原典を引いて整理した。

以下は行列ノルムや双対性の言葉を使うが、**本節に出てくる行列はすべて対角**なので、実質は4成分のベクトルの話に落ちる。まず記号を全部定義し、実データから取った具体例を1つ用意して、それを使って説明する。

#### 記号一覧

| 記号 | 読み | 意味 |
|---|---|---|
| $\mathrm{Tr}[A]$ | トレース | 対角成分の和 $\sum_i A_{ii}$ |
| $\lVert X\rVert_\infty$ | 作用素ノルム | 固有値の絶対値の**最大値** |
| $\lVert X\rVert_1$ | トレースノルム | 固有値の絶対値の**総和** |
| $\sup$ / $\max$ | 上限 / 最大 | 取りうる値の一番大きいもの |
| $0\le M\le I$ | 作用素の不等号 | $M$ はエルミートで固有値が全て $[0,1]$ に入る |
| $I$ | 恒等行列 | 対角成分が全部 $1$ |
| $\Pi$ | 射影子 | $\Pi^2=\Pi$ 、固有値は $0$ か $1$ のみ |
| $O(\varepsilon^n)$ | ランダウの記号 | $\varepsilon\to0$ で $\varepsilon^n$ と同じ速さで消える |
| $\lvert\psi\rangle$ の purification | 純粋化 | 混合状態を、環境を足した大きい系の純粋状態として書き直したもの |

#### 具体例(実データ、L=16、 $U=8$ 半充填、site 2、prior $\chi_p=4$ )

サイト1つは「上向きモード」と「下向きモード」の2量子ビットなので、状態空間は4次元である。基底を $\lvert 0\rangle$ (空)、 $\lvert\uparrow\rangle$ 、 $\lvert\downarrow\rangle$ 、 $\lvert\uparrow\downarrow\rangle$ (二重占有)と取る。半充填で $\langle S^z\rangle=0$ なら、RDM はこの基底で**対角**になり、しかも二重占有 $d=\langle n_\uparrow n_\downarrow\rangle$ ひとつで決まる(準備5で確かめる):

```math
\rho_A=\mathrm{diag}\bigl(d,\ \tfrac12-d,\ \tfrac12-d,\ d\bigr)
```

実データの数値は

| | $d$ | 対角成分 |
|---|---|---|
| 真の状態 $\rho_A$ (ED) | 0.09924590 | $(0.099246,\ 0.400754,\ 0.400754,\ 0.099246)$ |
| prior $\sigma_A$ ( $\chi_p=4$ ) | 0.09023233 | $(0.090232,\ 0.409768,\ 0.409768,\ 0.090232)$ |

差を $X\equiv\rho_A-\sigma_A$ と書く。 $u\equiv d_\rho-d_\sigma=9.0136\times10^{-3}$ とおくと

```math
X=\mathrm{diag}(u,\,-u,\,-u,\,u)
```

測りたい観測量はオンサイトの $ZZ$ 、つまり $P=Z\otimes Z$ で、この基底での対角成分は

```math
P=\mathrm{diag}(+1,\,-1,\,-1,\,+1)
```

である( $\lvert0\rangle$ と $\lvert\uparrow\downarrow\rangle$ が $+1$ 、片方だけ占有が $-1$ )。**以降すべて、この2本の4成分ベクトルの話である。**

#### 理由1: $\Delta$ は線形汎関数であり、その双対ノルムがトレース距離である

##### $\Delta$ は差 $X$ の「線形」な関数である

推定したい量は

```math
\Delta=\mathrm{Tr}\bigl[P(\rho_A-\sigma_A)\bigr]=\mathrm{Tr}[PX]=\sum_{i=1}^{4}P_i X_i
```

対角なので単なる**内積**である。具体例では

```math
\Delta=(+1)(u)+(-1)(-u)+(-1)(-u)+(+1)(u)=4u=3.6054\times10^{-2}
```

実データの $\Delta(ZZ)=3.60543\times10^{-2}$ と一致する(比 0.9999996)。

ここで「線形」とは $X$ について1次、つまり $X\to2X$ なら $\Delta\to2\Delta$ 、という意味である。**この性質が以下すべての鍵になる。**

##### 2つのノルム

行列の「大きさ」の測り方は一通りではない。エルミート行列 $X$ の固有値を $x_1,\dots,x_n$ とすると、本節で使うのは次の2つである:

```math
\lVert X\rVert_\infty=\max_i\lvert x_i\rvert
\qquad\text{(作用素ノルム: 絶対値の最大)}
```

```math
\lVert X\rVert_1=\sum_i\lvert x_i\rvert=\mathrm{Tr}\lvert X\rvert
\qquad\text{(トレースノルム: 絶対値の和)}
```

対角行列なら固有値は対角成分そのものなので、具体例では

- $\lVert X\rVert_1=\lvert u\rvert+\lvert-u\rvert+\lvert-u\rvert+\lvert u\rvert=4\lvert u\rvert=3.6054\times10^{-2}$
- $\lVert P\rVert_\infty=\max(1,1,1,1)=1$

トレース距離はトレースノルムの半分である(準備2):

```math
D_{\rm tr}(\rho_A,\sigma_A)=\tfrac12\lVert\rho_A-\sigma_A\rVert_1=2\lvert u\rvert=1.80271\times10^{-2}
```

実データの $D_{\text{台}}=1.802714\times10^{-2}$ と一致する。

##### Hölder の不等式 — 中身は当たり前のこと

ベクトルの形で書けば、これは1行で示せる:

```math
\Bigl\lvert\sum_i a_ib_i\Bigr\rvert\le\sum_i\lvert a_i\rvert\lvert b_i\rvert
\le\Bigl(\max_i\lvert a_i\rvert\Bigr)\sum_i\lvert b_i\rvert
```

1つ目は三角不等式、2つ目は各 $\lvert a_i\rvert$ を最大値で置き換えただけである。行列版はこれを固有値について適用したもので、

```math
\lvert\mathrm{Tr}[PX]\rvert\le\lVert P\rVert_\infty\,\lVert X\rVert_1
```

**Pauli 列は固有値が $\pm1$ しかないので $\lVert P\rVert_\infty=1$ ちょうど**である。よって

```math
\lvert\Delta\rvert\le\lVert X\rVert_1=2D_{\rm tr}
```

これが準備3の上界の正体である。

##### 双対ノルム — 「最良定数」とはどういう意味か

上の不等式で $\lVert P\rVert_\infty$ の係数が $1$ でよいのは分かった。問題は「**$2D_{\rm tr}$ という上界自体、もっと小さくできないのか**」である。できない。理由も初等的である:

```math
\sum_i\lvert x_i\rvert=\max_{\lvert a_i\rvert\le1}\ \sum_i a_i x_i
\qquad(\text{最大は }a_i=\mathrm{sign}(x_i)\text{ で達成})
```

つまり**トレースノルムとは、「固有値が $[-1,1]$ に収まる観測量が達成できる内積の最大値」そのもの**である。行列の言葉では

```math
\lVert X\rVert_1=\sup_{\lVert O\rVert_\infty\le1}\mathrm{Tr}[OX]
```

これを「 $\lVert\cdot\rVert_\infty$ の**双対ノルム**が $\lVert\cdot\rVert_1$ である」という。だから「 $P$ は固有値 $\pm1$ の観測量である」という情報**だけ**を使う限り、 $2D_{\rm tr}$ より良い上界は原理的に存在しない。

##### 等号成立条件 = 符号パターンの一致 — 飽和の正体

上の $\max$ が $a_i=\mathrm{sign}(x_i)$ で達成される、ということは:

> **等号 $\lvert\Delta\rvert=2D_{\rm tr}$ が成り立つのは、 $P$ の符号パターンが $X$ の符号パターンと(全体の符号を除いて)一致するときである。**

具体例で確かめる。 $X=(u,-u,-u,u)$ の符号パターンは $(+,-,-,+)$ 、 $P=Z\otimes Z$ の符号パターンも $(+,-,-,+)$ で**完全に一致する**。だから飽和する(実測 $\lvert\Delta\rvert/2D=1.00000000$ )。これが結果1の飽和の正体であり、「半充填のオンサイト RDM は $ZZ$ と同じ符号構造しか持てない」と言っても同じである。

結果5の閉形式もここから直ちに出る。prior が $S^z$ 対称性を破ると差は2パラメータになり

```math
X=\mathrm{diag}(u,\,-u+s,\,-u-s,\,u)
```

となる( $s$ が $S^z$ 方向のずれ)。 $u>0,s>0$ として

- $s<u$ なら $-u+s<0$ で符号は $(+,-,-,+)$ 、 $ZZ$ と**一致 → 飽和**
- $s>u$ なら $-u+s>0$ で符号は $(+,+,-,+)$ 、 $ZZ$ と**不一致 → 飽和しない**

この基底で $S^z$ の対角成分は $(0,+\tfrac12,-\tfrac12,0)$ なので $\Delta(S^z)=\tfrac12(-u+s)-\tfrac12(-u-s)=s$ 、また $\Delta_{ZZ}=4u$ である。したがって境目 $s=u$ は

```math
r\equiv\frac{\lvert\Delta(S^z)\rvert}{\lvert\Delta_{ZZ}\rvert}=\frac{s}{4u}=\frac14
```

**結果5で数値的に見つけた閾値 $r\le1/4$ は、符号パターンが一致するかどうか、というだけの話だった。**

##### 忠実度にはこの構造がない

忠実度 $F(\rho_A,\sigma_A)$ は $\rho_A$ と $\sigma_A$ に別々に依存し、**差 $X$ の関数として書けない**。 $\rho_A\to\rho_A+X$ 、 $\sigma_A\to\sigma_A+X$ と両方を同じだけずらせば $\Delta$ も $D_{\rm tr}$ も変わらないが、 $F$ は変わる。ノルムでもない(斉次性 $\lVert cX\rVert=\lvert c\rvert\lVert X\rVert$ を満たさない)。したがって**「最良定数」という概念自体が立たない**。

#### 理由2: 変分表示が推定量と同じ土俵にある

##### $0\le M\le I$ の意味

作用素の不等号 $A\le B$ は「 $B-A$ が半正定値(固有値が全て $\ge0$ )」の意味である。したがって $0\le M\le I$ は「 $M$ はエルミートで、固有値が全て $0$ 以上 $1$ 以下」を意味する。これは**測定で『はい』と答える確率を与える作用素**(POVM 要素)の条件そのもので、 $\mathrm{Tr}[M\rho]$ が『はい』の確率になる。

##### Helstrom の変分表示

トレース距離には次の表示がある:

```math
D_{\rm tr}(\rho_A,\sigma_A)=\max_{0\le M\le I}\ \mathrm{Tr}\bigl[M(\rho_A-\sigma_A)\bigr]
```

右辺は「 $\rho_A$ のときの『はい』の確率」 $-$ 「 $\sigma_A$ のときの『はい』の確率」の最大値、つまり

> **部分系 $A$ だけを測る測定で、2つの状態を見分けられる最大の確率差**

である(これは上の双対ノルムの表示を $O=2M-I$ で書き直したものにすぎない)。

##### 観測量そのものが実行可能集合の中にいる

Pauli 列 $P$ は固有値 $\pm1$ なので、 $\Pi\equiv(I+P)/2$ とおくと $\Pi$ の固有値は $1$ か $0$ 、つまり**射影子**であり $0\le\Pi\le I$ を満たす。逆に解けば

```math
P=2\Pi-I
```

つまり**測りたい観測量が、アフィン変換( $2$ 倍して $I$ を引く)を除いて、そのまま最大化の実行可能集合の中にいる**。だから「いつ等号になるか」が意味のある問いになり、実際に答えが出た(上の符号パターン一致、 $r\le1/4$ )。具体例では $\Pi=\mathrm{diag}(1,0,0,1)$ で、これは「二重占有か空か」を判定する射影子である。

##### 忠実度の変分表示は別の土俵にある

まず **purification(純粋化)** を定義する。混合状態 $\rho_A$ に対し、環境 $E$ を足した大きい系の**純粋**状態 $\lvert\psi\rangle_{AE}$ で

```math
\mathrm{Tr}_E\bigl[\lvert\psi\rangle\langle\psi\rvert\bigr]=\rho_A
```

を満たすものを purification という。必ず存在し、しかも $E$ 上のユニタリ変換の分だけ**無数にある**。Uhlmann の定理はこの自由度についての最大化を与える:

```math
F(\rho_A,\sigma_A)=\max_{\lvert\psi\rangle,\lvert\phi\rangle}\bigl\lvert\langle\psi\vert\phi\rangle\bigr\rvert^2
```

( $\lvert\psi\rangle$ は $\rho_A$ の、 $\lvert\phi\rangle$ は $\sigma_A$ の purification を動く。)

つまり**環境側の自由度を使って最適化している**。しかし CRM の推定量が触るのは $\rho_A$ 上の Pauli 期待値だけで、環境の自由度は一切使わない。**使わない自由度で最適化した量が、使う自由度の誤差を鋭く抑える理由はない。**

#### 理由3: 次数が違う — 1次の量を2次の量から予測することはできない

これが実務上いちばん効く。

##### 「次数」とは

$\rho_A=\sigma_A+\varepsilon X$ と微小パラメータ $\varepsilon$ で書いたとき、ある量が $\varepsilon\to0$ でどれくらいの速さで消えるかを次数という。 $O(\varepsilon)$ なら $\varepsilon$ に比例(1次)、 $O(\varepsilon^2)$ なら $\varepsilon^2$ に比例(2次)である。 $\varepsilon=0.01$ なら1次の量は $10^{-2}$ 、2次の量は $10^{-4}$ 程度になる。

| 量 | 式 | 次数 |
|---|---|---|
| $\Delta$ | $\varepsilon\mathrm{Tr}[PX]$ | **1次** |
| $D_{\rm tr}$ | $\varepsilon\lVert X\rVert_1/2$ | **1次** |
| $1-F$ | $\varepsilon^2\times(\cdots)$ | **2次** |

$\Delta$ と $D_{\rm tr}$ が1次なのは、どちらも $X$ について線形(あるいは1次斉次)だからである。一方 $F$ は $\rho_A=\sigma_A$ で最大値 $1$ を取る滑らかな関数なので、**極大点まわりの展開は1次の項が消えて必ず2次から始まる**(1変数関数が極大点で $f(x_0+\delta)=f(x_0)-c\delta^2+\cdots$ となるのと同じ)。

具体例で確認する。 $D=1.80\times10^{-2}$ に対し $1-F=5.29\times10^{-4}$ で、たしかに $D^2=3.25\times10^{-4}$ と同じオーダーである( $1-F$ が $D$ と同じ $10^{-2}$ ではない)。

実測でも正確にそうなっている(1D、台に縮約した 4103 点、両対数プロットの傾き):

| 縦軸 | vs $\log D_A$ の傾き | 理論 |
|---|---|---|
| $\log(1-F_{\text{台}})$ | **2.006** | 2 |
| $\log\lvert\Delta\rvert$ | **1.023** | 1 |

##### 帰結: 較正係数が存在しない

**1次の量を2次の量から予測する変換は存在しない。** 実際、非忠実度をそのまま使うと

```math
\frac{\lvert\Delta\rvert}{2\,(1-F_A)}:\quad \text{中央値 } 25.0,\quad \text{範囲 } 0.01\sim1.3\times10^{6}
```

と**4桁以上ばらつき、定数にならない**。つまり「この係数を掛ければよい」という較正が存在しない。平方根を取れば1次に戻せるが、それが次の Fuchs–van de Graaf であり、等式にはならない。

#### 理由4: Fuchs–van de Graaf は不等式のままで、利得の予測が桁で不定になる

```math
1-\sqrt{F}\;\le\;D_{\rm tr}\;\le\;\sqrt{1-F}
```

両端が同時に達成されることはない(左は純粋状態、右は直交する極限で別々に鋭くなる)。

##### 具体例で帯の広さを見る

上の実データ( $\chi_p=4$ 、 $F_A=0.99947081$ )に当てはめると:

| | 値 |
|---|---|
| 下限 $1-\sqrt{F}$ | $2.65\times10^{-4}$ |
| **実際の $D_{\rm tr}$** | $1.80\times10^{-2}$ |
| 上限 $\sqrt{1-F}$ | $2.30\times10^{-2}$ |

**忠実度だけからでは $D$ が 87倍の幅でしか決まらない。** トレース距離を直接計算すれば1つの数が出るのと対照的である。

##### 上界としての鋭さ(全データ)

ZZ onsite、単一 Pauli 列・半充填の 588 点:

| 上界 | $\lvert\Delta\rvert/(\text{上界})$ 中央値 | 最大 | 達成するか |
|---|---|---|---|
| $2D_A$ | **1.0000** | 1.0000 | **する(恒等式)** |
| $2\sqrt{1-F_A}$ | 0.7287 | 0.9875 | **しない** |

##### 利得に翻訳するとどうなるか

FvdG 区間の両端を利得法則に入れる( $n_m=100$ 、ZZ onsite):

| prior | $F_{\text{台}}$ | $D$ 下限 | $D$ 実際 | $D$ 上限 | $G$ 下限 | $G$ 上限 | 不定性 |
|---|---|---|---|---|---|---|---|
| χ_p=2 | 0.77509 | 1.2e−01 | 2.3e−01 | 4.7e−01 | 0.34 | 4.77 | **14倍** |
| χ_p=4 | 0.99157 | 4.2e−03 | 7.1e−02 | 9.2e−02 | 7.47 | 39.23 | **5倍** |

| χ_p=32 | 1.00000 | 1.3e−09 | 3.9e−05 | 5.2e−05 | 39.59 | 39.59 | 1倍 |

**忠実度が使い物になるのは prior がほぼ完全で利得が天井に張り付いたとき、つまり答えを知る必要がなくなったときだけである。** prior が粗く利得を見積もりたい場面(χ_p=2, 4)でちょうど不定性が最大になる。これは偶然ではなく理由3の2次性の帰結で、 $F$ が $1$ に近いほど $1-F$ が持つ相対的な情報量が落ちる。

#### 理由5: テンソル積での振る舞いが逆向き

**乗法的**とは、系を独立な部分に分けたとき全体の値が各部分の積になることをいう。忠実度はこれを満たす:

```math
F\Bigl(\bigotimes_i\rho_i,\ \bigotimes_i\sigma_i\Bigr)=\prod_i F(\rho_i,\sigma_i)
```

各サイトで $F_i=0.999$ 程度でも、 $L=128$ サイトなら $0.999^{128}\simeq0.88$ 、 $F_i=0.99$ なら $0.28$ と、**サイト数について指数的に落ちる**。§2 で見た「大域忠実度の崩壊」はこの性質そのものであって、prior の質が物理的に崩壊しているわけではない。

トレース距離は乗法的ではなく**劣加法的**( $D(\rho_1\otimes\rho_2,\sigma_1\otimes\sigma_2)\le D_1+D_2$ )なので、この人工的な指数崩壊を起こさない。

より本質的には、必要なのは「 $A$ に閉じた量」である。 $D_A$ には「 $A$ だけを測る測定で識別できる最大バイアス」という $A$ に閉じた作用素的意味がある(理由2)。 $F_A$ にはその読みがない。忠実度は「2つの状態は同じか」という**大域的な yes/no** に答えるための量であり、こちらの問い「ある1つの有界観測量の期待値がどれだけずれるか」とは別の問いである。

#### 古典的にはよく知られた話である

本節の RDM は占有基底で対角なので、確率分布 $p,q$ の比較に帰着する。そこでは

| 量子 | 古典の対応物 | 定義 |
|---|---|---|
| $D_{\rm tr}$ | **全変動距離** $\mathrm{TV}$ | $\tfrac12\sum_i\lvert p_i-q_i\rvert$ |
| $F$ | **Bhattacharyya 係数** の2乗 | $\bigl(\sum_i\sqrt{p_iq_i}\bigr)^2$ |
| $1-\sqrt{F}$ 近辺 | **Hellinger 距離** | $\tfrac12\sum_i(\sqrt{p_i}-\sqrt{q_i})^2$ |

具体例で確かめると、 $p=(0.099246,0.400754,0.400754,0.099246)$ 、 $q=(0.090232,0.409768,0.409768,0.090232)$ から Bhattacharyya を手計算して $F=0.99947081$ 、データの $F_{\text{台}}=0.99947081$ と一致する。

有界関数 $f$ の期待値の差を抑えるのは全変動距離である:

```math
\bigl\lvert E_p[f]-E_q[f]\bigr\rvert=\Bigl\lvert\sum_i f_i(p_i-q_i)\Bigr\rvert\le2\lVert f\rVert_\infty\,\mathrm{TV}
```

これは理由1の Hölder の古典版そのものである。一方 Bhattacharyya/Hellinger は仮説検定の誤り指数や尤度比を制御する量であって、線形汎関数の誤差を制御する量ではない。**つまりこれは量子特有の事情ではなく、「有界な観測量の期待値差を見るなら $L^1$ 」という古典統計の常識の言い換えにすぎない。**

#### 公平に: 忠実度が正しい道具である場面

トレース距離が万能という話ではない。忠実度が適切なのは:

- **純粋状態どうしの重なり** — $F=\lvert\langle\psi\vert\phi\rangle\rvert^2$ でそのまま物理的意味を持つ
- **乗法性が本質の問い** — 積状態・独立コピー・漸近論。理由5の乗法性がここでは長所になる
- **計量情報** — 量子 Fisher 情報は忠実度の**Hesse 行列**(パラメータについての2階微分の行列)で与えられ、Cramér–Rao 型の推定精度限界を与える。理由3で「欠点」とした2次性が、ここでは計量そのものになる
- **「アルゴリズムは正しい状態に収束したか」** という大域的判定 — DMRG の収束判定など

これらはすべて「**状態そのものの近さ**」を問うている。本節の問いは「**ある1つの有界観測量の期待値がどれだけずれるか**」なので、そもそも量が違う。§2 の一貫した主張(「prior の良さ全般ではなく観測量ごとの局所誤差が効く」)は、この量の取り違えを正す話でもある。

#### まとめ

| 論点 | トレース距離 | 忠実度 |
|---|---|---|
| 差 $\rho_A-\sigma_A$ の関数か | **はい(ノルム)** | いいえ |
| $\lvert\Delta\rvert$ の上界として最良か | **はい(双対ノルム)** | いいえ(必ず緩い) |
| 変分表示 | $A$ 上の測定(推定量と同じ土俵) | purification(使わない自由度) |
| 微小差での次数 | **1次**( $\Delta$ と同じ) | 2次( $\sqrt{\ }$ が要る) |
| 等号は成り立つか | **成り立つ**(符号パターン一致、条件は $r\le1/4$ ) | 成り立たない(実測 最大 0.9875) |
| $G$ の予測 | 5%以内 | 5〜14倍の不定性 |
| 系サイズ | 指数崩壊しない | 乗法的に指数崩壊 |

### 準備4c: 元論文は何を指標にしているか(一次資料で確認)

準備4b は「忠実度ではなくトレース距離」という書き方をしたが、**元論文は忠実度を prior の品質指標として実際に使っている**。ただし本研究とは設定が違い、その設定では正しい。混同しないように、元論文の記述を原典で確認して整理する。

対象: B. Vermersch, A. Rath, B. Sundar, C. Branciard, J. Preskill, A. Elben, *Enhanced Estimation of Quantum Properties with Common Randomized Measurements*, PRX Quantum **5**, 010352 (2024) / [arXiv:2304.12292](https://arxiv.org/abs/2304.12292)

#### 分散保証に使われている量

**式(4) — 単一コピーの Pauli 観測量:**

```math
\mathbb{V}[\hat O]\ \le\ \frac{3^{N_A}}{N_U}\left(\mathrm{Tr}\bigl[O(\rho-\sigma)\bigr]^2+\frac{1}{N_M}\right)
```

指標は $\mathrm{Tr}[O(\rho-\sigma)]$ 、**本研究の $\Delta$ そのもの**である。さらに本文は「標準シャドウより分散が小さくなるのは $\lvert\mathrm{Tr}[O(\rho-\sigma)]\rvert\le\lvert\mathrm{Tr}(O\rho)\rvert$ のとき」と明記しており、これは本研究の $\varepsilon=\Delta/\langle P\rangle\le1$ と同じ条件である。**§2 の利得法則はこの式(4)から出ている。**

**式(6) — 多コピー観測量(MCO):**

```math
\mathbb{V}[\hat O]\ \le\ \frac{n^2\lVert O^{(1)}_A\rVert_2^2}{N_U}\left(3^{N_A}\lVert\rho_A-\sigma_A\rVert_2^2+\frac{2^{N_A}}{N_M}\right)+\mathcal{O}\!\left(\frac{1}{N_U^2}\right)
```

こちらは**観測量の台 $A$ に縮約した距離**だが、トレース距離ではなく **Hilbert–Schmidt ノルム**( $\lVert X\rVert_2=\sqrt{\mathrm{Tr}[X^2]}$ 、シャッテン2ノルム)である。つまり「台に縮約した距離で prior の質を測る」という発想は元論文に既にある。

**「trace distance」という語は本文に一度も出てこない**(全文検索して0件)。

#### 忠実度はどこに出てくるか

忠実度は17箇所に現れ、**すべて Example 2(フィデリティ推定)**である。役割は2つある。

**役割(a): 推定対象そのもの。** 「 $F_\psi=\langle\psi\vert\rho\vert\psi\rangle$ を推定する。すなわち $O=\lvert\psi\rangle\langle\psi\rvert$ という射影子を取る」と書かれている。つまりここでの忠実度は**射影子の期待値、すなわち単一コピー観測量**である。 $\lVert O\rVert_\infty=1$ なので、準備4b の議論が $P\to\lvert\psi\rangle\langle\psi\rvert$ とそのまま適用できる。**「状態間の距離の指標」として使われているのではない。**

**役割(b): prior の良し悪しの判定基準。** ここが本題である。本文は「フィデリティ推定は適切な CRM prior $\sigma$ を見つけるのにも使える」と述べ、反復手順を与えている:

> $F_\phi$ が閾値 $F\ge1/2$ を下回れば新しい prior を定義して繰り返す。十分高い $F_\phi$ を持つ prior $\sigma=\lvert\phi\rangle\langle\phi\rvert$ が見つかれば、任意の MCO $O$ について強化推定を行える。**性能保証は、測定した $F_\phi$ の値を用いて式(6)で与えられる。**

**確かに忠実度を prior の品質指標として使っている。** ユーザの記憶は正しい。

#### なぜ元論文の設定ではそれが正しいのか — prior が純粋だから

決め手は $\sigma=\lvert\phi\rangle\langle\phi\rvert$ が**純粋状態**であることである。このとき $\mathrm{Tr}[\sigma^2]=1$ かつ $\mathrm{Tr}[\rho\sigma]=F_\phi$ なので

```math
\lVert\rho-\sigma\rVert_2^2=\mathrm{Tr}[\rho^2]-2\,\mathrm{Tr}[\rho\sigma]+\mathrm{Tr}[\sigma^2]
=\mathrm{Tr}[\rho^2]-2F_\phi+1\ \le\ 2\,(1-F_\phi)
```

( $\mathrm{Tr}[\rho^2]\le1$ を使った。)つまり**純粋 prior では、忠実度が式(6)の距離を直接押さえる**。「測った $F_\phi$ で式(6)の保証が付く」は厳密に正しい。

準備4b の理由3(忠実度は2次、 $\Delta$ は1次)がここで問題にならないのは、**式(6)の指標が距離の2乗** $\lVert\rho_A-\sigma_A\rVert_2^2$ **だから**である。2次の量を2次の量で押さえているので次数が合っている。準備4b が問題にしたのは1次の量 $\Delta$ を2次の量で予測しようとする場合である。

#### なぜ本研究の設定には移せないのか

| | 元論文 Example 2 | 本研究(§2m) |
|---|---|---|
| prior $\sigma$ | **純粋**( $\lvert\phi\rangle\langle\phi\rvert$ 、MPS) | **混合**(MPS/UHF を台に縮約した RDM) |
| 見る領域 | 系全体( $N=30$ ) | 観測量の台(2〜4量子ビット) |
| 推定対象 | 忠実度・MCO | 局所 Pauli 観測量 |
| 問い | この prior を**使えるか**(go/no-go) | 利得が**何倍になるか**(定量予測) |

3点とも効く:

1. **prior が混合になると等式が壊れる。** 台に縮約した $\sigma_A$ は混合状態で $\mathrm{Tr}[\sigma_A^2]<1$ なので、上の $\lVert\rho-\sigma\rVert_2^2\le2(1-F)$ が使えない。準備4b の理由3・理由4がそのまま効いてくる。
2. **大域忠実度は局所観測量では判定に使えない。** 元論文の $F_\phi$ は $N=30$ 量子ビット全体の忠実度で、 $\chi$ を上げれば上がる測定可能な量である。本研究の $L=128$ (256量子ビット)では $F$ が $10^{-17}$ まで落ちるが局所利得は無傷である(§2b)。**閾値 $F\ge1/2$ をそのまま持ち込むと、実際には有効な prior を全部棄却してしまう。**
3. **go/no-go と定量予測は別の要求である。** 閾値判定なら緩い上界でも足りるが、利得の倍率を予測するには等号が要る。

**元論文が間違っているのではなく、適用範囲が違う。** 本研究の寄与は、局所観測量・混合 prior の領域では忠実度による判定が働かないことを示し(§2, §2b)、代わりに使える量として台のトレース距離を与えたこと(§2m)である。

#### 2ノルムと1ノルムはどう違うか(単一 Pauli 列の場合)

元論文の式(6)は2ノルムなので、単一 Pauli 列に対して2ノルム版の上界を作るとどうなるかを見ておく。Cauchy–Schwarz(2ノルムでの Hölder)から

```math
\lvert\Delta\rvert\le\lVert P\rVert_2\lVert X\rVert_2=2\lVert X\rVert_2
\qquad(\text{2量子ビットの Pauli 列は }\lVert P\rVert_2=\sqrt{\mathrm{Tr}[P^2]}=2)
```

準備4b と同じ $X=\mathrm{diag}(u,-u+s,-u-s,u)$ を入れると $\lVert X\rVert_2=\sqrt{4u^2+2s^2}$ なので

```math
\frac{\lvert\Delta\rvert}{\lVert P\rVert_2\lVert X\rVert_2}=\frac{1}{\sqrt{1+8r^2}}
\qquad\text{対}\qquad
\frac{\lvert\Delta\rvert}{2D_A}=\min\left(1,\frac{2}{1+4r}\right)
```

4×4 の実データで両方を確認する(どちらも閉形式と一致する):

| 幾何 | prior | $r$ | 1ノルム 実測 | 1ノルム 式 | 2ノルム 実測 | 2ノルム 式 |
|---|---|---|---|---|---|---|
| シリンダー | χ_p=128 | 0.000 | **1.0000** | 1.0000 | **1.0000** | 1.0000 |
| シリンダー | χ=1024 | 0.018 | **1.0000** | 1.0000 | 0.9987 | 0.9987 |
| トーラス | χ_p=8 | 0.192 | **1.0000** | 1.0000 | 0.8783 | 0.8783 |
| トーラス | χ_p=32 | 0.374 | 0.7900 | 0.8017 | 0.6872 | 0.6872 |
| トーラス | χ_p=128 | 0.806 | 0.4757 | 0.4735 | 0.4017 | 0.4017 |
| トーラス | UHF | 30.43 | 0.0163 | 0.0163 | 0.0116 | 0.0116 |

$r=0$ では両方とも飽和する( $X\propto P$ なので Cauchy–Schwarz も等号)。 $r>0$ では**常に1ノルム版のほうが鋭い**。準備4b の理由1のとおり、単一 Pauli 列という「 $\lVert P\rVert_\infty=1$ の線形汎関数」に対しては1ノルムが双対ノルムであり、これが最良だからである。

**ただしこれは優劣の話ではない。** 元論文の式(6)は MCO( $\rho$ について $n$ 次)の分散に対する保証で、そこでは推定量が2次形式になるため2ノルムが自然に現れる。線形汎関数に1ノルム、2次形式に2ノルム、というだけのことである。

### 準備4d: 縮約するとなぜ混合状態になるのか、なぜそれで忠実度が使えなくなるのか

準備4c で「元論文の prior は純粋、本研究の prior は混合」が分かれ目だと述べた。ここを詳しく説明する。**要点を先に言うと、混合になるのは prior が粗いからではなく、台に縮約したからである。** そして混合になると、純粋 prior のときに揃っていた3つの条件が同時に壊れる。

#### 純粋状態と混合状態

状態は密度行列 $\rho$ (エルミート、半正定値、 $\mathrm{Tr}\rho=1$ )で表す。

- **純粋状態**: ある状態ベクトル $\lvert\psi\rangle$ で $\rho=\lvert\psi\rangle\langle\psi\rvert$ と書ける。固有値は $(1,0,\dots,0)$ 。
- **混合状態**: そう書けない。複数の固有値が非ゼロ。

判定には**純粋度** $\mathrm{Tr}[\rho^2]$ を使う。固有値を $\lambda_k$ とすれば $\mathrm{Tr}[\rho^2]=\sum_k\lambda_k^2$ で、

```math
\mathrm{Tr}[\rho^2]=1\iff\text{純粋},\qquad
\mathrm{Tr}[\rho^2]=\frac1{d}\iff\text{最大混合}\ (\rho=I/d)
```

本節の台は2量子ビット( $d=4$ )なので、純粋なら $1$ 、最大混合なら $0.25$ である。

#### 部分トレース(縮約)とは何か

系を $A$ (見る部分)と $\bar A$ (見ない部分)に分ける。 $A$ だけを見たときの状態が**縮約密度行列**で、

```math
(\rho_A)_{a a'}=\sum_{b}\rho_{(a,b),(a',b)}
```

つまり $\bar A$ の添字について対角和を取る。これは「 $\bar A$ については一切測らない」という操作に対応し、 $A$ 上のどんな測定の結果も $\rho_A$ だけで決まる。

#### なぜ縮約すると混合になるのか — Schmidt 分解が答え

全体が純粋状態 $\lvert\psi\rangle$ でも、 $A$ と $\bar A$ の間にエンタングルメントがあれば $\rho_A$ は必ず混合になる。**Schmidt 分解**を使うと一目で分かる。任意の2分割について

```math
\lvert\psi\rangle=\sum_k\sqrt{\lambda_k}\,\lvert a_k\rangle_A\otimes\lvert b_k\rangle_{\bar A},
\qquad \lambda_k\ge0,\ \sum_k\lambda_k=1
```

と書ける( $\lvert a_k\rangle$ 、 $\lvert b_k\rangle$ はそれぞれ正規直交)。これを縮約すると $\langle b_k\vert b_{k'}\rangle=\delta_{kk'}$ より

```math
\rho_A=\mathrm{Tr}_{\bar A}\bigl[\lvert\psi\rangle\langle\psi\rvert\bigr]=\sum_k\lambda_k\,\lvert a_k\rangle\langle a_k\rvert
```

**すなわち $\rho_A$ の固有値は Schmidt 係数 $\lambda_k$ そのもの**である。したがって

```math
\mathrm{Tr}[\rho_A^2]=\sum_k\lambda_k^2
```

- $\lambda$ が1つだけ( $\lambda_1=1$ ) $\iff$ $\lvert\psi\rangle=\lvert a_1\rangle\otimes\lvert b_1\rangle$ は**積状態** $\iff$ $\rho_A$ は純粋
- $\lambda$ が2つ以上 $\iff$ **エンタングルしている** $\iff$ $\rho_A$ は混合

**エンタングルメントがある限り、縮約は必ず混合状態を作る。** これは近似の粗さとは無関係な、operation そのものの性質である。(実際、エンタングルメントエントロピーは $S=-\sum_k\lambda_k\log\lambda_k$ 、Rényi-2 なら $S_2=-\log\mathrm{Tr}[\rho_A^2]$ で、まさに純粋度で測られる。)

#### 重要: 本研究の prior は大域的には純粋である

ここを誤解しやすい。 $\chi_p$ で切断した MPS $\lvert\psi_{\chi_p}\rangle$ も、UHF の Slater 行列式も、**大域的には純粋状態**である。それでも台に縮約した $\sigma_A$ は混合になる。理由は上のとおりで、prior 状態自身がサイトと環境の間にエンタングルメントを持つからである。

```math
\underbrace{\lvert\psi_{\chi_p}\rangle\langle\psi_{\chi_p}\rvert}_{\text{純粋}}
\ \xrightarrow{\ \mathrm{Tr}_{\bar A}\ }\
\underbrace{\sigma_A}_{\text{混合}}
```

**つまり「混合だから」は prior の質の話ではなく、台に絞るという本研究の方針そのものの帰結である。** 元論文は系全体で比較するので $\sigma$ は純粋のままでいられた。§2m は観測量の台に絞る(それが結果1の飽和の前提でもある)ので、必然的に混合になる。**これが設定の違いの核心である。**

#### 純粋 prior のときに揃っていた3条件

元論文で忠実度が prior 判定に使えたのは、 $\sigma=\lvert\phi\rangle\langle\phi\rvert$ が純粋なおかげで次の3つが同時に成り立つからである。

**(1) 忠実度が「観測量」になる。** 片方が純粋なら Uhlmann 忠実度は退化して

```math
F(\rho,\lvert\phi\rangle\langle\phi\rvert)=\langle\phi\vert\rho\vert\phi\rangle=\mathrm{Tr}\bigl[\lvert\phi\rangle\langle\phi\rvert\,\rho\bigr]
```

となる。これは**射影子という有界観測量( $\lVert O\rVert_\infty=1$ )の期待値**、つまり $\rho$ の**線形**汎関数である。だからシャドウから不偏推定でき、元論文の「同じ1回分のデータで $F_\phi$ を測って prior を選び直す」という反復手順が成立する。

**(2) 1次である。** 線形なので $\rho=\sigma+\varepsilon X$ に対し $1-F$ は $\varepsilon$ の**1次**。数値で確認すると:

| $\varepsilon$ | $1-F$ (純粋 prior) | 傾き |
|---|---|---|
| $10^{-2}$ | $1.000\times10^{-2}$ | — |
| $10^{-3}$ | $1.000\times10^{-3}$ | **1.0000** |
| $10^{-4}$ | $1.000\times10^{-4}$ | **1.0000** |

準備4b の理由3(忠実度は2次だから使えない)が元論文に当てはまらないのはこのためである。

**(3) 距離を直接押さえる。** $\mathrm{Tr}[\sigma^2]=1$ と $\mathrm{Tr}[\rho\sigma]=F$ から

```math
\lVert\rho-\sigma\rVert_2^2=\mathrm{Tr}[\rho^2]-2\underbrace{\mathrm{Tr}[\rho\sigma]}_{=F}+\underbrace{\mathrm{Tr}[\sigma^2]}_{=1}
=\mathrm{Tr}[\rho^2]-2F+1\ \le\ 2(1-F)
```

#### 混合になると3つとも同時に壊れる

**(1') 忠実度が観測量でなくなる。** 一般の混合 $\sigma_A$ に対する Uhlmann 忠実度は

```math
F(\rho_A,\sigma_A)=\Bigl(\mathrm{Tr}\sqrt{\sqrt{\rho_A}\,\sigma_A\sqrt{\rho_A}}\Bigr)^2
```

で、 $\sqrt{\rho_A}$ を含む。これは $\rho_A$ の**線形汎関数でも多項式でもない**。シャドウが不偏推定できるのは $\rho$ の線形汎関数(多コピーを使えば多項式)なので、**忠実度そのものは有限コピーから不偏推定できない**。元論文の「測って判定する」ループが原理的に成立しない。

> これは実務上いちばん重い。純粋 prior なら $F_\phi$ は測れる量だが、混合 $\sigma_A$ の忠実度は「古典計算で $\rho_A$ を知っていれば計算できる」量にすぎない。 $\rho_A$ を知っているなら最初から $\Delta$ を計算すればよいので、判定基準としての存在意義が消える。

**(2') 2次になる。** $\rho_A=\sigma_A$ は状態空間の内点なので $F$ の勾配が消え、 $1-F$ は2次から始まる。数値で確認する(混合 $\sigma_A=\mathrm{diag}(0.09,0.41,0.41,0.09)$ を $ZZ$ 方向に $\varepsilon$ ずらす):

| $\varepsilon$ | $1-F$ (混合 prior) | 傾き |
|---|---|---|
| $10^{-2}$ | $6.500\times10^{-4}$ | — |
| $10^{-3}$ | $6.746\times10^{-6}$ | 1.9839 |
| $10^{-4}$ | $6.772\times10^{-8}$ | 1.9983 |
| $10^{-5}$ | $6.775\times10^{-10}$ | **1.9998** |

**同じ忠実度という量が、prior が純粋か混合かで次数を変える。** 純粋なら1次、混合なら2次である。

**(3') 不等式の鎖が2箇所で切れる。** 実データ(L=16, site 2, χ_p=4)で確かめる:

| 量 | 実際の値 | 純粋 $\sigma$ なら |
|---|---|---|
| Uhlmann $F(\rho_A,\sigma_A)$ | 0.99947076 | — |
| 重なり $\mathrm{Tr}[\rho_A\sigma_A]$ | **0.34634266** | $=F$ のはず(0.653 ずれる) |
| $\mathrm{Tr}[\sigma_A^2]$ | **0.35210326** | $=1$ のはず |
| $\mathrm{Tr}[\rho_A^2]$ | 0.34090707 | — |
| $\lVert\rho_A-\sigma_A\rVert_2^2$ | $3.2501\times10^{-4}$ | — |
| $2(1-F)$ | $1.0585\times10^{-3}$ | 上界(ここでは 3.26倍の緩み) |

**忠実度と重なりが別物になる**( $0.9995$ 対 $0.3463$ )のが決定的である。純粋 $\sigma$ では両者が一致するので $F$ が距離の式に直接入れたが、混合ではそもそも違う量なので入れられない。 $\mathrm{Tr}[\sigma_A^2]=1$ も使えない。

##### 表の $\varepsilon$ とは何か

```math
\varepsilon \equiv \frac{\lvert\Delta\rvert}{\lvert\langle P\rangle\rvert}
= \frac{\text{prior がその観測量で外している量}}{\text{その観測量の期待値そのものの大きさ}}
```

**prior の誤差を、観測量のスケールで割った相対誤差**である。 $\Delta$ そのままでは観測量ごとに比べられない — 例えば二重占有( $\langle P\rangle=0.099$ )の $\Delta=0.009$ と ZZ onsite( $\langle P\rangle=-0.603$ )の $\Delta=0.036$ は、絶対値では後者が大きいが、相対誤差では前者(9.1%)の方が後者(6.0%)より悪い。

$\varepsilon$ を使う理由は、**利得法則が $\varepsilon$ だけで書き直せる**からである。利得法則の分子・分母を $\langle P\rangle^2$ で割ると

```math
G=\frac{(3^{\lvert A\rvert}-1)+w}{(3^{\lvert A\rvert}-1)\,\varepsilon^2+w},
\qquad w\equiv\frac{v_s}{\langle P\rangle^2}
```

となり、 $\langle P\rangle$ の絶対的な大きさは消えて $\varepsilon$ だけが残る。逆数を取るともっと見やすい:

```math
\frac{1}{G}=\varepsilon^2\Bigl(1-\frac{1}{G_{\max}}\Bigr)+\frac{1}{G_{\max}}
\qquad\simeq\qquad
\underbrace{\varepsilon^2}_{\text{prior のせい}}+\underbrace{\frac{1}{G_{\max}}}_{\text{ショットノイズのせい}}
```

**「損失の逆数」が2つの独立な原因の和になる。** したがって:

| $\varepsilon$ | 意味 | 利得 |
|---|---|---|
| $\varepsilon\ll1$ | prior が観測量のスケールに比べて十分正確 | 天井 $G_{\max}$ に張り付く(ショットノイズ律速) |
| $\varepsilon\approx0.1$ | 10%外している | $G\approx100$ か天井の小さい方 |
| $\varepsilon=1$ | 外し方が期待値と同じ大きさ | $G=1$ (**得も損もない**) |
| $\varepsilon>1$ | 期待値より大きく外している | $G<1$ (**CRM が損をする**) |

**$\varepsilon=1$ が損益分岐点**であり、これは元論文 式(4)の「CRM が標準シャドウより良くなる条件 $\lvert\mathrm{Tr}[O(\rho-\sigma)]\rvert\le\lvert\mathrm{Tr}(O\rho)\rvert$ 」と同じものである(準備4c)。

| χ_p=2 | 0.80151 | **2.25** | **2.34** | **1.00** | **1.00** |
| χ_p=4 | 0.99947 | **43.83** | **26.88** | **1.00** | **1.00** |
| χ_p=8 | 1.00000 | **51.76** | **28.40** | **1.00** | **1.00** |

**同じ忠実度の値が、1.00 から 51.76 までの利得に対応している。** これは統計誤差でも近似の粗さでもなく、**定義から出る構造的な限界**である:

> **$F_{\text{台}}$ と $D_A$ は「台ごとに1つ」の量だが、 $G$ は「観測量ごと」の量である。** 2量子ビットの台には恒等演算子でない Pauli 列が15個載り、それぞれ別の $G$ を持つ。台ごとに1つしかない数が、15個の別々の値を言い当てられるはずがない。

準備4b 理由1の言い方をすれば、 $D_A$ は15方向すべてを1つの数に潰したノルムであり、 $\Delta_P$ はそのうち1方向への射影である。**忠実度も距離も、台を決めた時点で観測量の区別を失っている。** できるのは全観測量に共通の上界(最悪値)を与えることだけで、これは段階1で述べた $D_A$ の役割そのものである。

### 準備4e: トレース距離はいつでも簡単に計算できるのか

結論を先に言う。**行列の計算としては局所観測量なら常に一瞬である。しかし「 $\rho_A$ が要る」という一点で、これは測定の近道にはならない。** 準備4d で忠実度に対して立てた反論は、そのままトレース距離にも当たる。ここを曖昧にしたまま「実務上の使い方」を書いていたので、訂正も含めて整理する。

#### 行列演算としてのコスト — 局所なら無視できる

台が $\lvert A\rvert$ 量子ビットなら $\rho_A-\sigma_A$ は $2^{\lvert A\rvert}\times2^{\lvert A\rvert}$ のエルミート行列で、固有値分解は $\mathcal{O}(2^{3\lvert A\rvert})$ である。実測(NumPy、乱数エルミート行列):

| $\lvert A\rvert$ | 行列サイズ | 必要な Pauli 期待値 $4^{\lvert A\rvert}$ | 固有値分解の時間 |
|---|---|---|---|
| 2 | $4\times4$ | 16 | 0.01 ms |
| 4 | $16\times16$ | 256 | 0.02 ms |
| 6 | $64\times64$ | 4.1e3 | 0.23 ms |
| 8 | $256\times256$ | 6.6e4 | 3.3 ms |
| 10 | $1024\times1024$ | 1.0e6 | 66 ms |
| 12 | $4096\times4096$ | 1.7e7 | 3.3 s |

**局所観測量では $\lvert A\rvert$ は定義上小さい**(本研究では2〜4)ので、コストは完全に無視できる。半充填のオンサイトなら準備4b のとおり閉形式で、固有値分解すら要らない。

一方 $\lvert A\rvert$ について**指数的**なので、大域のトレース距離( $\lvert A\rvert=N$ )は計算できない。これは忠実度も同じで、両者に差はない。

#### 本当の制約は $\rho_A$ をどこから持ってくるか

$D_{\rm tr}(\rho_A,\sigma_A)$ を計算するには $\sigma_A$ (prior、古典的に計算できる)だけでなく **$\rho_A$ 、すなわち真の状態の縮約が要る**。これは実験で知りたい当のものである。

**準備4d で忠実度に対して書いた反論は、そのままトレース距離に当たる。** すなわち「 $\rho_A$ を知っているなら最初から $\Delta=\mathrm{Tr}[P(\rho_A-\sigma_A)]$ を計算すればよい」。これを認めた上で、では何が残るのかを正確に述べる。

#### 3つの量の必要コストを並べる

| 量 | $\rho$ 側に必要なもの | 線形か | シャドウから不偏推定できるか |
|---|---|---|---|
| $\Delta$ | **Pauli 期待値ひとつ** $\langle P\rangle_\rho$ | **線形** | **できる** |
| $D_{\rm tr}(\rho_A,\sigma_A)$ | RDM 全体( $4^{\lvert A\rvert}$ 成分) | 非線形(固有値の絶対値) | できない(再構成して計算) |
| $F(\rho_A,\sigma_A)$ | RDM 全体( $4^{\lvert A\rvert}$ 成分) | 非線形( $\sqrt{\rho_A}$ ) | できない(再構成して計算) |

**$\Delta$ が3つの中でいちばん安い。** 単一の Pauli 期待値で、線形なので不偏推定でき、RDM の再構成すら要らない。**トレース距離は $\Delta$ の近道ではなく、むしろ遠回りである。**

> **準備4d の (1') は言い過ぎだった。** そこでは「忠実度は不偏推定できない」ことを混合 prior の欠点として挙げたが、トレース距離も同じく非線形で不偏推定できない。この軸では両者に差はない。忠実度に対する反論として生き残るのは (2') 次数が2次であること、(3') 元論文の不等式の鎖が切れること、および実測での順序逆転(UHF が χ_p=2 より低い忠実度で24倍の利得)である。

さらに言えば、**CRM 推定量を走らせるのに $\Delta$ も $D$ も $F$ も要らない**。推定量は prior の質によらず不偏だからである。これらが要るのは「測定を使う前に、CRM が得かどうかを予測する」設計段階だけである。そして設計段階では $\rho$ を持っていない — **3つとも同じ問題を抱えている。**

#### では §2m の結果は何の役に立つのか

$\rho_A$ が要るという制約を認めた上で、残る価値は次の3つである。**どれも「測定を減らす近道」ではなく、「設計を導く理解」である。**

**(1) 1つの数が台の上の全観測量を同時に押さえる。** 双対ノルムの表示(準備4b 理由1)から

```math
2D_A=\max_{\lVert O\rVert_\infty\le1}\bigl\lvert\mathrm{Tr}[O(\rho_A-\sigma_A)]\bigr\rvert
\ \ge\ \max_{P\,\in\,\text{台 }A\text{ の Pauli 列}}\lvert\Delta_P\rvert
```

つまり $D_A$ は**台 $A$ 上のあらゆる観測量に対する $\lvert\Delta\rvert$ の最悪値**である。 $4^{\lvert A\rvert}-1$ 個の観測量を個別に調べる代わりに1つの数で保証できる。しかも半充填では**最悪値が実際に達成される**(結果1の飽和)ので、この保証は保守的すぎない。

**(2) prior の「クラス」を測定前に判定できる。** これが実際に使える形である。 $r=\lvert\Delta(S^z)\rvert/\lvert\Delta_P\rvert$ の**分子は prior 側だけで計算できる**: $\rho$ が $S^z$ 対称性を持つことは物理から分かっているので $\Delta(S^z)=-\langle S^z\rangle_\sigma$ であり、測定も $\rho$ の知識も要らない。分母には $\rho$ が要るが、**小さい系での厳密計算(ED や高 $\chi$ の DMRG)で1回較正すれば、同じ prior クラスを大きい系に持ち込むときの指針になる**。本研究自体がこの使い方である。

**(3) 説明としての価値。** 閉形式 $\min(1,2/(1+4r))$ は、UHF とトーラス上の MPS prior を**同一の軸に乗せた**(結果5)。これは何かを速く計算するための道具ではなく、「なぜこの prior は効いてこの prior は効かないのか」に答えるものである。 $\chi_p$ を上げるほど $r$ が上がって予測が壊れる、という反直感的な事実も、この形があって初めて見える。

#### 訂正: 結論部の「実務上の使い方」

§2m の結論に次のように書いていた:

> 2. 測りたい観測量の**台だけ**に縮約した $\rho_A,\sigma_A$ を作る
> 3. $D_{\rm tr}(\rho_A,\sigma_A)$ を1回計算すれば、単一Pauli列なら $\lvert\Delta\rvert=2D_{\rm tr}$ が(半充填では)厳密に得られる
>
> これで**観測量ごとに $\Delta$ を計算し直す必要がなくなる**

**手順2が $\rho_A$ を要求している点を明示していなかった。** 実験でこれから測ろうとしている状態の RDM を持っている前提になっており、そのまま読むと循環している。正しくは:

> **前提**: $\rho_A$ が得られる場合に限る。古典参照(小さい系の ED、高 $\chi$ の DMRG、QMC)でもよいし、**台が小さければ同じ測定データからの後処理でもよい**(準備4f — 当初ここに「実験対象そのものには使えない」と書いたのは誤りだった)。
>
> 1. prior が $\rho$ の対称性を尊重しているか確認する。破っていれば群平均を当てる(§2j、測定コストゼロ)。**この段階は $\rho$ を要しない。**
> 2. 較正用の小さい系で $\rho_A,\sigma_A$ を作り、 $D_{\rm tr}$ と $r$ を求める
> 3. $r\le1/4$ なら $\lvert\Delta\rvert=2D_{\rm tr}$ が厳密に成り立ち、台の上の全観測量の利得が1つの数で決まる
> 4. その $r$ を指標に、同じ prior クラスを大きい系へ持ち込むかを判断する
>
> **実験対象について $\Delta$ を直接知りたいなら、トレース距離を経由してはいけない。** $\langle P\rangle_\rho$ を測るのが最も安く、しかも不偏である。

### 準備4f: トレース距離そのものを CRM で測れるか

準備4e で「 $D_{\rm tr}$ には $\rho_A$ が要るが、それは未知である」と書いた。しかし**元論文はまさにその問題を測定で解いている** — $\rho$ が未知でも、 $\sigma$ を prior にした CRM で忠実度 $F_\phi=\langle\phi\vert\rho\vert\phi\rangle$ を推定していた。同じことがトレース距離にもできるのか。

**結論: できる。そして CRM は分散だけでなく偏りも減らす。ただしそれでも $D$ は $\Delta$ の近道にはならない。** 準備4e の「実験対象そのものには使えない」は強すぎたので、あわせて訂正する。

#### なぜ元論文では測れたのか — 忠実度が「良い量」だからではない

準備4d で見たとおり、 $\sigma=\lvert\phi\rangle\langle\phi\rvert$ が純粋なら

```math
F=\mathrm{Tr}\bigl[\lvert\phi\rangle\langle\phi\rvert\,\rho\bigr]
```

は $\rho$ の**線形**汎関数、すなわち有界観測量の期待値である。だから不偏推定できた。**忠実度という量が本質的に扱いやすいのではなく、「純粋状態と組にすると線形になる」というだけである。** 実際、混合 $\sigma$ に対する Uhlmann 忠実度は $\sqrt{\rho}$ を含み、この性質を失う(準備4d の (1'))。

トレース距離 $D_{\rm tr}=\tfrac12\sum_i\lvert\lambda_i(\rho_A-\sigma_A)\rvert$ も固有値の絶対値なので非線形である。したがって直接の不偏推定量は存在しない。しかし**間接的な経路が2つある**。

#### 経路B(理論上は可能だが、この領域では死んでいる): 多項式近似 + 多コピー観測量

$X\equiv\rho_A-\sigma_A$ として $\lVert X\rVert_1=\mathrm{Tr}\lvert X\rvert=\mathrm{Tr}[f(X)]$ 、 $f(x)=\lvert x\rvert$ である。 $f$ を $k$ 次多項式で近似すれば $\mathrm{Tr}[X^n]$ ( $n\le k$ )の推定に帰着する。 $X^n$ を展開すると各項は $\rho_A$ について高々 $n$ 次なので、**バッチシャドウによる $n$ コピー観測量の推定**でよく、元論文の式(6)の CRM 分散保証がそのまま効く。

**これは元論文 Example 1(フォン・ノイマンエントロピーの多項式近似)の機械そのものである。** 原理的には同じ道具で書ける。

**しかし $\lvert x\rvert$ は原点で微分できない。** Bernstein の定理により、 $[-1,1]$ 上での $\lvert x\rvert$ の最良 $k$ 次一様近似の誤差は $\approx0.2801/k$ で、**精度 $\epsilon$ に次数 $k\sim0.28/\epsilon$ が必要**である(滑らかな関数の指数収束と対照的)。本研究では $X$ の固有値が $10^{-2}$ のオーダー、つまり**まさに折れ点のすぐ近くを見にいく**ので $k\sim10^2$ – $10^3$ 、すなわち100〜1000コピー観測量が必要になる。現実的でない。

> エントロピーの場合に $n_{\max}=3,5,7$ で足りたのは、そこで扱う $\rho$ の固有値が $[0,1]$ に広がっていて折れ点に集中していないからである。**差 $X$ の固有値は必ず $0$ の近くに集まる**(prior が良いほどそうなる)ので、この経路は本質的に不利である。

#### 経路A(実用的): 台の RDM をトモグラフィで再構成する

台が小さければ、 $\rho_A$ の $4^{\lvert A\rvert}$ 個の Pauli 期待値を**同じランダム測定データから**推定できる。各成分は線形なので不偏推定でき、**しかもそれぞれに CRM の分散低減が効く**。再構成した $\hat\rho_A$ から $\hat D=\tfrac12\lVert\hat\rho_A-\sigma_A\rVert_1$ を計算する。非線形な後処理なので不偏ではないが、一致推定量である。

$\lvert A\rvert=2$ なら16成分、 $4\times4$ 行列の固有値分解1回(0.01 ms、準備4e)である。

#### 数値実験

実データの $\rho_A,\sigma_A$ (L=16, $U=8$ 半充填, site 2, prior $\chi_p=4$ 、真値 $D_A=1.8027\times10^{-2}$ 、 $\Delta_{ZZ}=3.6054\times10^{-2}$ )で、局所 Pauli 測定を Monte Carlo で模擬した(60回反復、 $N_M=100$ 固定):

| $N_U$ | 方式 | $\hat D$ 平均 | 偏り( $\hat D/D$ ) | $\hat D$ 相対誤差 | $\hat\Delta$ 相対誤差 | $\Delta$ の利得 |
|---|---|---|---|---|---|---|
| 100 | 標準 | $8.75\times10^{-2}$ | **4.9倍** | 265% | 490% | — |
| 100 | **CRM** | $4.47\times10^{-2}$ | **2.5倍** | 50.5% | 77.2% | 40.3 |
| 1000 | 標準 | $3.40\times10^{-2}$ | 1.9倍 | 87.7% | 153.5% | — |
| 1000 | **CRM** | $2.16\times10^{-2}$ | 1.2倍 | 21.3% | 23.3% | 43.6 |

| 10000 | **CRM** | $1.827\times10^{-2}$ | 1.0倍 | **6.5%** | 6.7% | 53.4 |

読み取れることが4つある。

**(1) 測れる。** $N_U=10^4$ 、 $N_M=100$ の CRM で $\hat D=1.827\times10^{-2}$ (真値 $1.803\times10^{-2}$ )、相対誤差 6.5%。**元論文が忠実度でやったことは、トレース距離でもできる。**

**(2) CRM が効く。** 同じ予算で標準の 45.1% に対し CRM は 6.5% — 誤差で7倍、分散で約48倍である。 $\Delta$ 単体の利得 53.4 とほぼ一致しており、**トレース距離の推定精度も利得法則にそのまま従う**。

**(3) 偏りは正で、標本が少ないと支配的になる。** $N_U=100$ では標準シャドウが真値の **4.9倍**を返す。原因は明快で、 $\lVert\cdot\rVert_1$ はノルムなので推定ノイズ $N$ が乗ると $\mathbb{E}\lVert X+N\rVert_1>\lVert X\rVert_1$ となる。真の $X$ は $ZZ$ 方向の1成分しか持たないのに、推定した $\hat\rho_A$ は残り14成分にもノイズを持ち、それが全部トレースノルムに足し込まれる。**prior が良い(= $D$ が小さい)ほどこの偏りは深刻になる** — ちょうど知りたい領域で悪化する。

**(4) CRM は偏りも減らす。** $N_U=100$ で 4.9倍 → 2.5倍。偏りの原因がノイズの大きさそのものなので、分散低減がそのまま偏りの低減になる。**これは分散低減の副産物として得られる、報告されていない利点である。**

#### もっと安い経路: 飽和を使って Pauli 期待値ひとつで済ませる

結果1の飽和( $r\le1/4$ で $\lvert\Delta_{ZZ}\rvert=2D_A$ )を**逆向きに使う**と、16成分のトモグラフィは要らない:

```math
\hat D_A=\frac{\lvert\hat\Delta_{ZZ}\rvert}{2}
\qquad(\text{半充填、}r\le1/4)
```

上表の最終行で、この経路の相対誤差は **6.7%** と16成分トモグラフィの 6.5% と同等である( $ZZ$ 成分が $D$ を支配しているので当然)。**測定データは同じでも、使う成分が1つで済む。** さらに妥当性条件 $r\le1/4$ の分子 $\Delta(S^z)$ は、 $\rho$ の $S^z$ 対称性が物理から分かっていれば prior 側だけで計算できる(準備4e)。

> **Pauli 期待値2つ($ZZ$ と、必要なら $S^z$)で、 $D_A$ とその妥当性判定が揃う。**

#### 訂正: 準備4e の「実験対象そのものには使えない」は強すぎた

準備4e で「 $\rho_A$ が古典的に得られる場合に限る。実験対象そのものについては使えない」と書いた。**これは訂正する。** 上のとおり、台が小さければ $\hat\rho_A$ は同じデータセットから後処理で得られる。元論文の反復手順(prior を取り替えながら1回分のデータで判定する)と同じ形が、トレース距離でも成立する。

**ただし準備4e の本質は変わらない。** $D$ は $\Delta$ の近道ではない:

- 経路A で16成分を得たなら、その時点で台の上の**全ての** $\Delta_P$ が手に入っている。 $D$ を別途計算する必要はない。
- 飽和を使う経路では、 $D$ を $\Delta_{ZZ}$ **から**得ている。因果が逆で、 $D$ が $\Delta$ を与えているのではない。

したがって $D$ の価値は準備4e に挙げた3点(台上の全観測量に対する最悪値の証明書、prior クラスの事前判定、説明)のままである。**新たに加わったのは「その最悪値の証明書は、古典参照がなくても実験データから作れる」という点である。**

#### 難しさの序列

| 量 | 何が必要か | 難しさ |
|---|---|---|
| $\Delta_P$ | Pauli 期待値ひとつ(線形・不偏) | **最も易しい** |
| $F$ (純粋 $\sigma$ ) | 射影子の期待値(線形・不偏) | 同上 ← **元論文** |
| $D_{\rm tr}$ (小さい台) | $4^{\lvert A\rvert}$ 成分 + 非線形後処理 | 可能。正の偏りあり、CRM が両方を改善 |
| $F$ (混合 $\sigma$ 、小さい台) | 同上、さらに $\sqrt{\rho_A}$ | 同程度かそれ以上に悪い |
| $D_{\rm tr}$ または $F$ (大域) | $4^N$ 成分 | 不可能 |
| $D_{\rm tr}$ (多項式近似経路) | $k\sim0.28/\epsilon$ コピー観測量 | 原理的には可能、実際には不可 |

### 準備5: 具体例で確かめる

以上を数値で追ってみる。 $U=4$ 半充填のサイト内2量子ビット $(q_\uparrow,q_\downarrow)$ を考える。後で示すように、この RDM は占有基底 $\lvert n_\uparrow n_\downarrow\rangle$ で対角で、二重占有 $D$ ただ1つで決まる:

```math
\rho_A = \mathrm{diag}(D,\ \tfrac12-D,\ \tfrac12-D,\ D)
```

実測値 $D_\rho=0.10$ とし、prior が $D_\sigma=0.11$ とわずかに外したとする。

```math
\rho_A = \mathrm{diag}(0.10,\,0.40,\,0.40,\,0.10), \qquad
\sigma_A = \mathrm{diag}(0.11,\,0.39,\,0.39,\,0.11)
```

**トレース距離**:

```math
M=\rho_A-\sigma_A = \mathrm{diag}(-0.01,\,+0.01,\,+0.01,\,-0.01),\quad
\lVert M\rVert_1 = 0.04,\quad D_{\rm tr}=0.02
```

**局所誤差** ( $Z_\uparrow Z_\downarrow$ の固有値は $(+1,-1,-1,+1)$ ):

```math
\Delta = \mathrm{Tr}[Z_\uparrow Z_\downarrow M] = (-0.01)-(+0.01)-(+0.01)+(-0.01) = -0.04
```

したがって $\lvert\Delta\rvert = 0.04 = 2D_{\rm tr}$ で、**上界がちょうど等号**になっている。 $M$ の符号パターン $(-,+,+,-)$ が $Z_\uparrow Z_\downarrow$ の符号パターン $(+,-,-,+)$ と(全体の符号を除いて)一致するためである。

**忠実度**(可換なので Bhattacharyya):

```math
F = \bigl(2\sqrt{0.10\cdot0.11}+2\sqrt{0.40\cdot0.39}\bigr)^2 = (0.20976+0.78994)^2 = 0.99940
```

```math
1-F = 6.0\times10^{-4},\qquad \sqrt{1-F}=0.0245,\qquad
\frac{\lvert\Delta\rvert}{2\sqrt{1-F}} = \frac{0.04}{0.049} = 0.816
```

**忠実度版の上界は等号にならない**(0.816)。後で示す一般式 $2/\sqrt{\tfrac12(1/D+1/(\tfrac12-D))}$ に $D=0.1$ を入れると $2/\sqrt{6.25}=0.80$ で、この数値と合う。

**この2つの違い — 距離版は状態によらず等号、忠実度版は $D$ に依存する係数が付く — が、本節の技術的な結論である。**

### 最初の測り方は間違っていた

最初は次のように測り、「上界は10〜20倍緩い ⇒ 部分系の忠実度では決まらない」と結論した。**これは誤りで、原因は2つとも私の設計にあった。**

**欠陥1: 部分系を観測量の台より大きく取っていた。**

全観測量に対して**同じ4量子ビットの窓**(サイト $i,i{+}1$ の up/dn)を使っていた。しかし実際の台は観測量ごとに違う:

| 観測量 | 台 $A$ | 大きさ |
|---|---|---|
| $S^z_i$ | $q_\uparrow(i), q_\downarrow(i)$ | 2 |
| ZZ onsite | $q_\uparrow(i), q_\downarrow(i)$ | 2 |
| ZZ up-up r=1 | $q_\uparrow(i), q_\uparrow(i{+}1)$ | 2 |
| SzSz r=1 | 4量子ビット全部 | 4 |

**台に含まれない量子ビットは $\Delta$ に一切寄与しない**(上の $`\mathrm{Tr}_A`$ の式)。ところが $D_{\rm tr}$ には寄与する。つまり「 $\Delta$ に効かない誤差」を距離に混ぜて、それで $\Delta$ を予測しようとしていた。緩くなって当然である。

**欠陥2: 相関を prior 横断で計算していた。**

$\chi_p=2$ から $\chi_p=32$ まで並べると、 $D_{\rm tr}$ も $\lvert\Delta\rvert$ も3桁動く。その全体で相関を取れば 0.9 は出るが、それは「**粗い prior は何に対しても悪く、細かい prior は何に対しても良い**」という当たり前のことを見ているだけで、「距離が $\Delta$ を決める」証拠にはならない。

仮説を検証するには **prior を1つ固定して、サイト間で** 見なければならない。同じ prior でもサイトによって距離は変わるので、「距離が大きいサイトほど $\Delta$ も大きいか」を問える。

**両方を直して測り直した。** データは同じ 4,116 点(  $L=16,32$ 、半充填とδ=1/8、サイト $2$〜 $L-2$ 、7観測量、7 prior)で、Monte Carlo を使わない厳密計算なので統計誤差はない。平均場 prior の RDM は台の中の全 Pauli 列の期待値から $\sigma_A = 2^{-\lvert A\rvert}\sum_P\langle P\rangle_\sigma P$ と再構成した(§2i の一般Wickが要る)。

### 結果1: 台に絞ると、上界は緩いどころか厳密に飽和する

| 観測量 | 台 | 4量子ビット窓での $\lvert\Delta\rvert/(2D)$ | **台での** $\lvert\Delta\rvert/(2D)$ |
|---|---|---|---|
| ZZ onsite | 2 | 0.126 | **1.0000** |
| ZZ up-up r=1 | 2 | 0.293 | **1.0000** |
| 二重占有 | 2 | 0.031 | 0.2500 |
| hop up r=1 | 3 | 0.258 | 0.4515 |
| SzSz r=1 | 4 | 0.060 | 0.060(台=窓なので不変) |

**単一Pauli列では比が 1.0000、つまり不等式が等号で成立する。**

#### なぜ飽和するのか(準備5の具体例が一般に成り立つ理由)

サイト $i$ の2量子ビット $(q_\uparrow, q_\downarrow)$ の RDM は $4\times4$ で、占有基底 $\lvert n_\uparrow n_\downarrow\rangle$ で対角である(粒子数が保存するので異なる占有どうしの非対角要素が立たない)。対角成分を $p_{00},p_{01},p_{10},p_{11}$ と書くと

```math
\langle n\rangle = p_{01}+p_{10}+2p_{11}, \qquad
\langle S^z\rangle = \tfrac12(p_{10}-p_{01}), \qquad
\langle D\rangle = p_{11}
```

である。ここで**半充填**( $\langle n\rangle=1$ )かつ**スピン対称**( $\langle S^z\rangle=0$ )を課すと、規格化 $\sum p=1$ と合わせて自由度が1つだけ残る:

```math
p_{01}=p_{10}=\tfrac12-D, \qquad p_{00}=p_{11}=D
```

つまり **RDM 全体が二重占有 $D$ ただ1つで決まる。**(ついでに $\langle Z_\uparrow Z_\downarrow\rangle = p_{00}-p_{01}-p_{10}+p_{11} = 4D-1$ となり、§0.3b で述べた関係が出る。)

切断MPS prior は $\rho$ から作るので $\langle n\rangle$ と $\langle S^z\rangle$ を(数値誤差の範囲で)受け継ぐ。したがって差 $M=\rho_A-\sigma_A$ は $\delta \equiv D_\rho-D_\sigma$ ひとつで書けて

```math
M = \mathrm{diag}(\delta,\,-\delta,\,-\delta,\,\delta)
```

となる。ここから

```math
\lVert M\rVert_1 = 4\lvert\delta\rvert \;\Rightarrow\; D_{\rm tr}=2\lvert\delta\rvert,
\qquad
\Delta(ZZ) = \mathrm{Tr}[Z_\uparrow Z_\downarrow M] = \delta+\delta+\delta+\delta = 4\delta
```

( $Z_\uparrow Z_\downarrow$ の固有値が $(+1,-1,-1,+1)$ なので符号がちょうど揃う)。よって

```math
\lvert\Delta(ZZ)\rvert = 4\lvert\delta\rvert = 2D_{\rm tr}
```

**が恒等式として成り立つ。** 差が「二重占有の方向」しか持たず、それが $Z_\uparrow Z_\downarrow$ の固有値符号と完全に一致するためである。二重占有の比が $0.25$ なのは $D=(1-Z_\uparrow-Z_\downarrow+Z_\uparrow Z_\downarrow)/4$ の $ZZ$ 係数が $1/4$ だからで、これも整合する。

#### 飽和は半充填に固有である

ドープすると $\langle n\rangle$ も prior とずれうるので、差の自由度が $D$ と $n$ の2つになり、上の議論が崩れる。実際:

| 観測量 | 半充填で飽和( $>0.99$ )する割合 | δ=1/8 |
|---|---|---|
| ZZ onsite | **86%** | 52% |
| ZZ up-up r=1 | **86%** | 40% |

### 結果2: prior を固定すると、仮説は支持される

corr( $\log\lvert\Delta\rvert$, $\log D_{\text{台}}$ ) を prior ごとに、サイト間で測る:

| 観測量 | χ_p=2 | χ_p=4 | χ_p=8 | χ_p=16 | χ_p=32 | **UHF** | UHF-sym |
|---|---|---|---|---|---|---|---|
| ZZ onsite | 0.999 | 0.910 | **0.996** | 0.736 | 0.903 | **−0.669** | 0.962 |
| ZZ up-up r=1 | 0.962 | 0.892 | **0.983** | 0.932 | **0.989** | 0.102 | 0.692 |
| 二重占有 | −0.790 | 0.822 | 0.952 | 0.655 | 0.959 | **−0.553** | 0.964 |
| SzSz r=1 | 0.398 | 0.528 | 0.491 | 0.633 | 0.842 | 0.665 | 0.689 |
| hop up r=1 | 0.729 | 0.830 | **0.990** | 0.967 | 0.939 | **−0.646** | 0.440 |

**切断MPS prior では 0.74–0.999。** 同じ prior の中でも、台の忠実度が悪いサイトほど $\Delta$ が大きい。**仮説は支持される。**

**ところが UHF では相関が負になる**(−0.55 〜 −0.67)。距離が大きいサイトほど $\Delta$ が**小さい**という逆転が起きている。

### 結果3: 負の相関の正体 — 距離が「観測量と直交する方向」を測っている

上と同じ $4\times4$ の枠組みで説明がつく。UHF は共線 Néel 解なので **$\langle S^z\rangle\ne0$**、つまり $p_{10}\ne p_{01}$ になる。差 $M$ が**スピンの方向だけ**を持つ場合を書くと

```math
M = \mathrm{diag}(0,\,-s,\,+s,\,0)
```

このとき

```math
D_{\rm tr} = \tfrac12(\lvert{-s}\rvert+\lvert s\rvert) = \lvert s\rvert,
\qquad
\Delta(S^z) = \tfrac12\bigl(s-(-s)\bigr) = s,
\qquad
\Delta(ZZ) = 0-(-s)-(+s)+0 = 0
```

**距離は $S^z$ の誤差そのものになり、 $ZZ$ に対しては厳密にゼロを与える。** 距離が $ZZ$ と直交する方向を向いているのである。

実測がこの通りになっている(半充填、全サイト中央値):

| prior | $D_{\text{台}}$ | $\lvert\Delta(S^z)\rvert$ | $\lvert\Delta(ZZ)\rvert$ | $D_{\text{台}}/\lvert\Delta(ZZ)\rvert$ |
|---|---|---|---|---|
| χ_p=8 | 7.73e−4 | 5.8e−10 | 1.55e−3 | **0.50** |
| χ_p=32 | 6.86e−6 | 1.5e−10 | 1.37e−5 | **0.50** |
| **UHF** | **3.86e−1** | **3.85e−1** | 7.77e−3 | **49.7** |
| UHF-sym | 3.89e−3 | 1.2e−9 | 7.77e−3 | **0.50** |

- **切断MPS**: $\lvert\Delta(S^z)\rvert\sim10^{-10}$ で、スピン対称性を $\rho$ から受け継いでいる。距離は**二重占有の方向だけ**でできており、それはまさに `ZZ onsite` が測る方向。だから比が厳密に $0.50$ (= 飽和)で、相関が 0.996 になる
- **UHF**: $D_{\text{台}}=0.386$ に対し $\lvert\Delta(S^z)\rvert=0.385$。**距離のほぼ全部が対称性破れである。** 予測すべき $\lvert\Delta(ZZ)\rvert=0.0078$ は距離の50分の1しかなく、サイト間ではむしろ逆相関する
- **UHF-sym**: 群平均で対称性破れが消えると $D_{\text{台}}$ が **100分の1**(0.386 → 0.0039)に落ち、比が $0.50$ に戻る。**このとき $\lvert\Delta(ZZ)\rvert$ は 0.0078 のまま動かない**

最後の行が示唆的である。**群平均は prior を「良くして」いるのではない。距離のうち、どの観測量にも効かない成分を取り除いているだけである。** §2j で「群平均は損を消すが、得を増やすとは限らない」と書いたことの、幾何学的な言い換えになっている。

### 結果4: 忠実度で測るとどうなるか — 同じ相関、緩い上界

解析: [crm_fidelity_vs_delta.jl](crm_fidelity_vs_delta.jl) / [.pbs](crm_fidelity_vs_delta.pbs)

ここまではトレース距離で測った。**忠実度 $F_A$ (準備4)でも同じことが言えるのか**を確かめる。Fuchs–van de Graaf の不等式 $D_{\rm tr}\le\sqrt{1-F}$ を挟むと

```math
\lvert\Delta\rvert \;\le\; 2D_{\rm tr} \;\le\; 2\sqrt{1-F_A}
```

なので、**忠実度版の上界は必ずトレース距離版より緩い**。どれだけ緩いかは予測できる。半充填のサイト内2量子ビットでは差が $e=(\delta,-\delta,-\delta,\delta)$ 、確率が $p=(D,\tfrac12-D,\tfrac12-D,D)$ なので、可換な状態の忠実度の展開 $1-F\simeq\tfrac14\sum_i e_i^2/p_i$ から

```math
1-F \simeq \frac{\delta^2}{2}\Bigl(\frac1D+\frac1{\tfrac12-D}\Bigr)
\qquad\Longrightarrow\qquad
\frac{\lvert\Delta\rvert}{2\sqrt{1-F}} = \frac{2}{\sqrt{\tfrac12\bigl(\tfrac1D+\tfrac1{\tfrac12-D}\bigr)}}
```

**係数が二重占有 $D$ に依存する。** トレース距離版が $D$ によらず厳密に 1 だったのと対照的である。

#### 上界のタイトさ

| 観測量 | 台 | $\lvert\Delta\rvert/(2D_A)$ | $\lvert\Delta\rvert/(2\sqrt{1-F_A})$ |
|---|---|---|---|
| ZZ onsite | 2 | **1.0000** | 0.7978 |
| ZZ up-up r=1 | 2 | **1.0000** | 0.8523 |
| 二重占有 | 2 | 0.2500 | 0.1994 |
| hop up r=1 | 3 | 0.4593 | 0.3403 |

#### 係数の $D$ 依存が予測どおりに出る

$U=4$ 半充填の実測二重占有は $D=0.1002$ ( $\langle ZZ\rangle=4D-1$ から復元)。予測される係数は $0.8007$ :

| prior | 予測 | 実測(忠実度版) | 実測(距離版) |
|---|---|---|---|
| χ_p=8 | 0.8007 | **0.8003** | 1.0000 |
| χ_p=32 | 0.8007 | **0.8007** | 1.0000 |
| UHF-sym | 0.8007 | 0.8036 | 1.0000 |
| χ_p=4 | 0.8007 | 0.7336 | 1.0000 |
| χ_p=2 | 0.8007 | 0.4477 | 1.0000 |

**$\chi_p\ge8$ では予測と実測が小数点以下4桁で一致する。** $\chi_p=2,4$ でずれるのは展開の前提( $\delta$ が小さい)が崩れるためで、実際 $\chi_p=2$ では $\lvert\Delta\rvert=0.40$ と $D=0.10$ に匹敵する大きさである。

#### 相関はほぼ同じ

prior を固定したときの corr( $\log\lvert\Delta\rvert$, $\log(1-F_A)$ ) は、距離版とほぼ変わらない:

| 観測量 | χ_p=8(忠実度 / 距離) | χ_p=32(忠実度 / 距離) | UHF(忠実度 / 距離) |
|---|---|---|---|
| ZZ onsite | 0.990 / 0.996 | 0.904 / 0.903 | **−0.790 / −0.669** |
| ZZ up-up r=1 | 0.979 / 0.983 | 0.989 / 0.989 | −0.199 / 0.102 |
| 二重占有 | 0.968 / 0.952 | 0.972 / 0.959 | **−0.689 / −0.553** |
| hop up r=1 | 0.976 / 0.990 | 0.906 / 0.939 | **−0.603 / −0.646** |

理由は単純で、両者が対数で線形に結びついているからである。実測すると

```math
\log_{10}(1-F_A) = 2.038\,\log_{10} D_A + \text{const}, \qquad \text{相関 } 0.9985
```

**傾きがほぼ 2**、すなわち $1-F_A\propto D_A^2$ 。相関係数はアフィン変換で不変なので、どちらを使っても相関は同じ値になる。**UHF で負になることも共通で、対称性破れの話は道具の選び方によらない。**

#### この問題ではトレース距離が「正しい道具」である

| | トレース距離 | 忠実度 |
|---|---|---|
| 上界 | $\lvert\Delta\rvert\le 2D_A$ | $\lvert\Delta\rvert\le 2\sqrt{1-F_A}$(必ず緩い) |
| 単一Pauli列での飽和 | **恒等式** $\lvert\Delta\rvert=2D_A$ | 係数 $2/\sqrt{\tfrac12(1/D+1/(\tfrac12-D))}$ が付く |
| 係数の状態依存 | **なし** | **二重占有 $D$ に依存** |
| $\Delta$ との相関 | 同じ | 同じ |

**「距離が大きいか小さいか」を見るだけなら両者は等価だが、 $\Delta$ を数値として読み取りたいならトレース距離を使うべきである。** トレース距離の定義が「あらゆる測定にわたる期待値差の最大」であり、Pauli 列の期待値差と同じ土俵に乗っているためで、忠実度は $\sqrt{\cdot}$ を挟むぶん系のパラメータが混入する。

### 結果5: 2次元でも成り立つか — そして利得を測定なしで予測できるか

スクリプト: [crm_2d_support.jl](crm_2d_support.jl) / [.pbs](crm_2d_support.pbs) / データ: [crm_2d_supp_W4L3_U8p0.tsv](crm_2d_supp_W4L3_U8p0.tsv), [crm_2d_supp_W4L4_U8p0.tsv](crm_2d_supp_W4L4_U8p0.tsv)

ここまでは1次元鎖だった。4×3 シリンダー/トーラス(12サイト、24量子ビット、**参照は厳密対角化**、 $U=8$ 半充填)で同じ解析を行う。§2k と同じ ED 参照なので、参照状態が MPS であることによる交絡がない。

#### 飽和は次元にも幾何にもよらない

結果1の飽和の導出は「半充填 + $\langle S^z\rangle=0$ + 規格化 ⇒ サイト内2量子ビットの RDM は二重占有ひとつで決まる」という代数だけで、**格子の形が一切入っていない**。予想どおり2次元でも成り立つ:

| 幾何 | 観測量 | 台 | $\lvert\Delta\rvert/(2D_A)$ 中央値 | 飽和( $>0.99$ ) |
|---|---|---|---|---|
| シリンダー | ZZ onsite | 2 | **1.0000** | 86% |
| シリンダー | ZZ up-up nb | 2 | **1.0000** | 86% |
| トーラス | ZZ onsite | 2 | **1.0000** | 76% |
| トーラス | ZZ up-up nb | 2 | **1.0000** | 83% |
| (参考)二重占有 | | 2 | 0.2500 | — |

#### 利得を測定なしで予測できる

飽和が成り立つなら、利得法則に $\lvert\Delta\rvert=2D_A$ を代入して

```math
G_{\rm pred} = \frac{(3^{\lvert A\rvert}-1)\langle P\rangle^2 + v_s}{(3^{\lvert A\rvert}-1)\,(2D_A)^2 + v_s}
```

と、**部分系のトレース距離ひとつから利得が計算できる**はずである。実測した $G$ と突き合わせる( $n_u=240$, $n_m=100$, ZZ onsite):

| 幾何 | prior | $G$(実測) | $G_{\rm pred}$( $D_A$ から) | 比 |
|---|---|---|---|---|
| シリンダー | χ_p=4 | 32.09 | 31.40 | **0.98** |
| シリンダー | χ_p=8 | 38.07 | 38.98 | **1.02** |
| シリンダー | χ_p=32 | 156.4 | 164.6 | **1.05** |
| シリンダー | UHF-sym | 158.2 | 170.6 | **1.08** |
| シリンダー | **UHF** | **158.2** | **0.79** | **0.005** |
| トーラス | χ_p=8 | 37.31 | 37.07 | **0.99** |
| トーラス | χ_p=32 | 127.7 | 121.8 | **0.95** |
| トーラス | UHF-sym | 138.7 | 125.8 | 0.91 |
| トーラス | **UHF** | **138.7** | **0.74** | **0.005** |

**対称性を尊重する prior なら、測定を一切せずに利得が5%以内で当たる。** ( $n_u=240$, n_repeat=200 の統計誤差が約10%なので、ずれは誤差の範囲である。)

**UHF だけが200倍外れる。** $D_A=0.463$ と距離は大きいのに、実際の $\lvert\Delta(ZZ)\rvert=0.019$ は小さい — 距離が対称性破れに食われているためである。 $\Delta$ から直接計算すれば 170.6 と正しい値が出るので、**壊れているのは「距離から $\Delta$ を読む」段階だけ**である。

#### 飽和が破れる条件は閉じた式で書ける(4×4、32量子ビット)

データ: [crm_2d_supp_W4L4_U8p0.tsv](crm_2d_supp_W4L4_U8p0.tsv)

§2k で「4×4 トーラスでは $\chi=1024$ の DMRG が自発的にスタッガード磁化 0.019 を立てる」ことが分かった。 $\chi_p$ 切断 prior はその状態から作るので破れを受け継ぐ。すると §2m の機構から、**トーラスでは MPS prior が UHF のように振る舞う**はずである。4×4(16サイト、32量子ビット、ED 参照、シリンダーもトーラスも**二部格子**)で検証する。

**予想は当たり、しかも厳密な形で当たった。** 飽和が破れるかどうかは、**対称性破れと観測量の誤差の比**ひとつで決まる:

```math
r \equiv \frac{\lvert\Delta(S^z)\rvert}{\lvert\Delta_{ZZ}\rvert},
\qquad
\frac{\lvert\Delta_{ZZ}\rvert}{2D_A} = \min\left(1,\ \frac{2}{1+4r}\right)
```

導出は結果1と同じ代数を1パラメータ広げるだけである。半充填の粒子正孔対称性からサイト内 RDM の差は対角で $\delta=(u,-u+s,-u-s,u)$ の**2**パラメータになる( $s$ が $S^z$ 方向)。すると $\Delta_{ZZ}=4u$、 $D_A=\lvert u\rvert+\max(\lvert u\rvert,\lvert s\rvert)$ なので、

- $\lvert s\rvert\le\lvert u\rvert$ すなわち $r\le 1/4$ のとき $D_A=2\lvert u\rvert$ で**飽和する**
- $r>1/4$ のとき距離は $S^z$ 方向に食われ、比は $2/(1+4r)$ に落ちる

$r$ が $10^{-9}$ から 30 まで10桁にわたる**24通り(2系 × 2幾何 × 6 prior)すべてで最大誤差 0.0022**:

#### 訂正: 4×3 トーラスの「幾何が prior を変える」という読みは誤りだった

先に 4×3 トーラスで、台=4量子ビットの SzSz nb の corr( $\log\lvert\Delta\rvert$, $\log D_A$ )がシリンダーの $+0.81/+0.89/+0.94$ に対し $-0.07/-0.37/-0.33/-0.81$ と符号が反転することを、上の対称性破れの機構の現れとして報告した。**これは誤りである。**

**4×3 トーラスは二部格子ではない。** $L_x=3$ が奇数なので $x$ 方向に長さ3の奇環ができ、反強磁性がフラストレートする。スクリプトの自動判定([crm_2d_support.jl](crm_2d_support.jl) 414行目)は正しく `二部格子: いいえ(奇環あり)` と警告を出していたが、私がそれを読まずに結果を解釈した。§2k で一度捕まえた交絡と同じものを、同じ形で再び入れたことになる。

二部格子である 4×4 トーラスで測り直すと、SzSz nb の相関は **+0.963 / +0.835 / +0.985 / +0.993**(χ_p=4/8/32/128)と**すべて正**で、シリンダー(+0.802/+0.898/+0.987/+0.991)と区別がつかない:

| 系 | 幾何 | 二部格子 | SzSz nb の corr( $\log\lvert\Delta\rvert$, $\log D_A$ ) |
|---|---|---|---|
| 4×3 | シリンダー | はい | +0.810 / +0.889 / +0.938 / +0.806 |
| 4×3 | トーラス | **いいえ** | −0.067 / −0.369 / −0.327 / −0.812 ← フラストレーションの影響 |
| 4×4 | シリンダー | はい | +0.802 / +0.898 / +0.987 / +0.991 |
| 4×4 | トーラス | はい | **+0.963 / +0.835 / +0.985 / +0.993** |

つまり**符号反転を起こしていたのは対称性破れではなくフラストレーション**であり、周期境界そのものではない。対称性破れの効果は相関の符号ではなく、**上の飽和比 $\lvert\Delta\rvert/(2D_A)$ に現れる** — そちらは閉形式で完全に記述できる。

### 段階1のまとめ: 距離が $\Delta$ を決めるのはどの観測量か

結果1–5 はすべて **ZZ onsite**(単一 Pauli 列、台=2量子ビット)で議論した。ここで全観測量に広げ、**段階1の主張がどこまで成り立つかの境界**を確定させる。

まず論理を整理する。利得法則(元論文 式(4))は $G$ を $\Delta$ で決めており、**距離は法則に登場しない**。したがって「利得は部分系の距離に依存するか」は

> **部分系の距離は $\Delta$ を決めるか**

という問いに完全に帰着する。結果1–5 はこれに答えていた。全観測量で測る(L=16/32 全サイト、対称性を尊重する prior のみ):

| 観測量 | 型 | 台 | $\lvert\Delta\rvert/(2D_A)$ 中央 | 飽和率 | $\lvert\Delta\rvert/(2\sqrt{1-F_A})$ 中央 |
|---|---|---|---|---|---|
| ZZ onsite | **単一 Pauli 列** | 2 | **1.0000** | 79% | 0.7761 |
| ZZ up-up $r=1$ | **単一 Pauli 列** | 2 | **1.0000** | 73% | 0.7831 |
| hop up $r=1$ | 2項の和 | 3 | 0.4972 | 0% | 0.3782 |
| 二重占有 | 4項の和 | 2 | 0.2500 | 0% | 0.1979 |
| SzSz $r=1$ | 4項の和 | 4 | 0.0611 | 0% | 0.0380 |
| $n$ | 3項の和 | 2 | 0.0118 | 0% | 0.0105 |
| $S^z$ | 2項の和 | 2 | 0.0000 | 0% | 0.0000 |

**飽和するのは単一 Pauli 列だけである。** 和の観測量では上界が 2倍から 85倍緩む。理由は準備4b の符号パターン一致で説明できる: 和 $O=\sum_ic_iP_i$ では各項の寄与が打ち消し合うので、 $O$ の「符号パターン」が $X$ のそれと揃いようがない。

いくつかは閉じた形で分かる:

- **二重占有がちょうど $1/4$ になる理由**: $n_\uparrow n_\downarrow=(I-Z_a-Z_b+Z_aZ_b)/4$ で、半充填では $\langle Z_a\rangle=\langle Z_b\rangle=0$ が $\rho$ でも $\sigma$ でも成り立つので $\Delta(\text{二重占有})=\Delta_{ZZ}/4$ 。 $D_A=\lvert\Delta_{ZZ}\rvert/2$ と合わせて比はちょうど $1/4$ 。
- **$S^z$ がちょうど $0$ になる理由**: 対称性を尊重する prior では $\Delta(S^z)=0$ が厳密(§2g)。距離は有限なので比は $0$ 。

**これは枠組みの境界と一致している。** 利得法則そのものが単一 Pauli 列でのみ厳密なので(和の観測量では交差項が残る)、距離が $\Delta$ を決めるのも同じ範囲に限られる。

#### 段階1の結論

**利得は部分系のトレース距離に依存する。ただし正確には次の形である。**

```math
G=G(\Delta),\qquad
\lvert\Delta\rvert\le 2D_A\ \text{(常に)},\qquad
\lvert\Delta\rvert=2D_A\ \text{(単一 Pauli 列 + 半充填 + }r\le1/4)
```

- **常に成り立つこと**: $D_A$ は台の上の全観測量に対する $\lvert\Delta\rvert$ の**上界**(準備4b 理由1、双対ノルム)
- **厳密になる条件**: 単一 Pauli 列、半充填、 $r=\lvert\Delta(S^z)\rvert/\lvert\Delta_P\rvert\le1/4$ 。外れると $\min(1,2/(1+4r))$ で連続的に緩む(結果5、24点で最大誤差 0.0022)
- **忠実度は同じ役割を果たせない**: 上界としても緩く(0.78 対 1.0000)、次数が違う(2次 対 1次、準備4b 理由3)

### 段階2: 有限のデータで prior を選べるか(数値実験)

### 誤りが起こる理由 — 「大きさ」だけでは「向き」が分からない

段階2で「距離と忠実度は、データを無限に増やしても順位相関 0.786 で頭打ちになる」という結果が出た。ここまで「距離が対称性の破れに食われる」と書いてきたが、これは説明として粗い。**具体的な数で書き下すと、理由は一行で終わる。** そして新しい失敗様式を予言し、それが当たる。

#### まず、日常のたとえ

「駅から5 km 歩いた」と言われたとき、**北にどれだけ進んだか**は分かるだろうか。分からない。真北に歩けば 5 km、真東に歩けば 0 km で、その間のどこでもありうる。**「5 km」は距離であって、向きの情報を含んでいない。**

本節の2つの量はちょうどこの関係にある:

| | たとえ | 本節 |
|---|---|---|
| 分かっているもの | 歩いた距離 5 km | トレース距離 $D_A$ |
| 知りたいもの | 北に何 km 進んだか | 観測量の誤差 $\Delta_P$ |
| 言えること | $0$ 〜 $5$ km のどこか | $0\le\lvert\Delta_P\rvert\le2D_A$ |

上界 $\lvert\Delta_P\rvert\le2D_A$ (準備3)は「北に進んだ距離は総移動距離を超えない」と言っているだけである。**距離が向きを教えてくれないのは、当たり前のことだった。**

#### 準備: サイト1つの状態は「4つの数」で表せる

抽象的な話にしないために、具体的な数で見ていく。まずその「4つの数」が何なのかを説明する。

**(a) サイト1つに起こりうることは4通りしかない。** Hubbard 模型の1サイトには上向き電子と下向き電子が入りうるが、Pauli の排他律により**同じスピンは1個まで**である。したがって起こりうる配置は:

| 配置 | 記号 | 電子数 |
|---|---|---|
| 空 | $\lvert0\rangle$ | 0 |
| 上向き1個 | $\lvert\uparrow\rangle$ | 1 |
| 下向き1個 | $\lvert\downarrow\rangle$ | 1 |
| 二重占有 | $\lvert\uparrow\downarrow\rangle$ | 2 |

の**4通り**である。

**(b) そのサイトだけを見るとき、言えるのは各配置の確率である。** 鎖の残りを見ないことにする(= 縮約する、準備4d)と、このサイトについて言えるのは「空である確率」「↑ である確率」…の4つだけになる。合計は当然 1 である。これが縮約密度行列 $\rho_A$ の対角成分である。

> **なぜ確率4つだけで済むのか(対角になる理由)。** 一般には異なる配置の「重ね合わせ」を表す非対角成分もありうる。しかし全体の電子数と $S^z$ が確定している状態では、たとえば $\lvert0\rangle$ と $\lvert\uparrow\rangle$ の重ね合わせは残らない。このサイトの電子が1個増えれば鎖の残りが1個減るので、環境側が「どちらだったか」を覚えており、干渉が消えるからである。本節で扱う状態はすべてこれに当てはまるので、4つの確率で完全に決まる。

**(c) 実データ。** L=16、 $U=8$ 半充填、site 2 の真の状態(厳密対角化):

| | 空 | ↑ | ↓ | 二重占有 |
|---|---|---|---|---|
| $\rho_A$ | 0.099246 | 0.400754 | 0.400754 | 0.099246 |

物理的に読める。 $U=8$ は強い斥力なので**二重占有は損**で、確率は 0.099 しかない。ほとんど(0.400754 + 0.400754 = 0.80)は1個だけ入った状態で、↑ と ↓ が完全に対等である(これがスピン対称性)。空も 0.099 で、二重占有と同じ値である(これが半充填の粒子正孔対称性)。**Mott 絶縁体の姿がそのまま出ている。**

#### 誤差 $X$ とは何か、なぜ合計が 0 になるのか

prior $\sigma_A$ も同じ4つの数で表せる。その差を誤差と呼ぶ:

```math
X=\rho_A-\sigma_A\qquad(\text{4つの数})
```

$\chi_p=4$ の MPS prior で実際に引き算すると:

| | 空 | ↑ | ↓ | 二重占有 | 合計 |
|---|---|---|---|---|---|
| $\rho_A$ (真) | 0.099246 | 0.400754 | 0.400754 | 0.099246 | 1 |
| $\sigma_A$ (prior) | 0.090232 | 0.409768 | 0.409768 | 0.090232 | 1 |
| **$X$ (誤差)** | **+0.009014** | **−0.009014** | **−0.009014** | **+0.009014** | **0** |

**合計が 0 になるのは、どちらも確率で合計が 1 だからである**( $1-1=0$ )。物理的には確率の保存で、**prior が二重占有を少なめに見積もったなら、その分をどこか別の配置に置いているはずだ**という当たり前のことである。実際この prior は二重占有と空を 0.009 少なく、その分を ↑ と ↓ に 0.009 ずつ多く置いている。

**誤差は必ず「どこかから、どこかへ」という形をしている。** この見方が後で決定的になる。

#### 観測量とは「4つの配置に数を割り当てるもの」

次に観測量の側を用意する。**観測量とは、4つの配置それぞれに数を割り当てる規則**である。そして期待値は、その数を確率で重みづけした平均である:

```math
\langle O\rangle=\sum_{i\in\{空,\uparrow,\downarrow,二重\}} O_i\,\rho_i
```

本節に出てくる観測量を並べる:

| 観測量 | 空 | ↑ | ↓ | 二重占有 | $\langle O\rangle_\rho$ |
|---|---|---|---|---|---|
| 二重占有 $n_\uparrow n_\downarrow$ | 0 | 0 | 0 | **1** | 0.099246 |
| 電子数 $n$ | 0 | 1 | 1 | **2** | 1.000000 |
| $S^z$ | 0 | $+\tfrac12$ | $-\tfrac12$ | 0 | 0.000000 |
| **$Z\otimes Z$** | **+1** | **−1** | **−1** | **+1** | **−0.603016** |

たとえば二重占有の期待値は $0\cdot0.099+0\cdot0.401+0\cdot0.401+1\cdot0.099=0.099246$ で、素直に「二重占有である確率」になる。 $\langle n\rangle=1$ はちょうど半充填、 $\langle S^z\rangle=0$ は ↑ と ↓ が対等であることを表している。

#### $Z\otimes Z$ の符号 $(+,-,-,+)$ はどこから来るのか

これが分かりにくいところなので丁寧に述べる。ランダム測定の枠組みは量子ビットで書かれているので、**電子のモード1つを量子ビット1つに対応させる**(Jordan–Wigner 変換、§0)。サイト1つには上向きモードと下向きモードがあるので**量子ビット2つ**になり、それぞれ

```math
\lvert0\rangle_{\text{qubit}}=\text{そのモードは空き},\qquad
\lvert1\rangle_{\text{qubit}}=\text{そのモードは占有}
```

と読む。Pauli 行列 $Z$ は $Z\lvert0\rangle=+\lvert0\rangle$ 、 $Z\lvert1\rangle=-\lvert1\rangle$ なので、**空きなら $+1$ 、占有なら $-1$** を返す。そこで4つの配置について $Z_a$ (上向きモード)と $Z_b$ (下向きモード)の値を書き出すと:

| 配置 | 上向きモード | $Z_a$ | 下向きモード | $Z_b$ | $Z_a Z_b$ |
|---|---|---|---|---|---|
| 空 | 空き | $+1$ | 空き | $+1$ | **$+1$** |
| ↑ | 占有 | $-1$ | 空き | $+1$ | **$-1$** |
| ↓ | 空き | $+1$ | 占有 | $-1$ | **$-1$** |
| 二重占有 | 占有 | $-1$ | 占有 | $-1$ | **$+1$** |

**これが $(+1,-1,-1,+1)$ の出どころである。** 意味も読める: $Z_aZ_b$ は**2つのモードの状態が一致しているか**を測っている( $+1$ = 両方空きか両方占有、 $-1$ = 片方だけ占有)。

さらに $Z_a=1-2n_\uparrow$ 、 $Z_b=1-2n_\downarrow$ を掛け合わせると

```math
Z_aZ_b=1-2n+4\,n_\uparrow n_\downarrow
```

半充填では $\langle n\rangle=1$ なので $\langle Z_aZ_b\rangle=4\langle n_\uparrow n_\downarrow\rangle-1$ 、実データで検算すると $4\times0.099246-1=-0.603016$ で表の値と一致する。**つまり $ZZ$ は二重占有の言い換えにすぎない。** 「 $ZZ$ を測る」とは「二重占有を測る」ことであり、これが本節を通じて $ZZ$ を主役に据えている理由である。

#### 作り方の違い(1): $\Delta$ は「符号つきで足す」

$\Delta$ は、同じ加重平均を $\rho$ と $\sigma$ でとった差である:

```math
\Delta_{ZZ}=\langle ZZ\rangle_\rho-\langle ZZ\rangle_\sigma
=\sum_i (ZZ)_i\,\rho_i-\sum_i (ZZ)_i\,\sigma_i
=\sum_i (ZZ)_i\,X_i
```

つまり**誤差 $X$ に $ZZ$ の符号を掛けて足す**。 $\chi_p=4$ で1項ずつ書くと:

```math
\Delta_{ZZ}=\underbrace{(+1)(+0.009014)}_{空}
+\underbrace{(-1)(-0.009014)}_{\uparrow}
+\underbrace{(-1)(-0.009014)}_{\downarrow}
+\underbrace{(+1)(+0.009014)}_{二重}
=+0.036056
```

この prior では4項すべてが $+$ で揃っている。**誤差の符号 $(+,-,-,+)$ が $ZZ$ の符号 $(+,-,-,+)$ とぴったり同じだからである。**

#### 作り方の違い(2): $D_A$ は「動かすべき確率の量」

トレース距離は絶対値で足して半分にする:

```math
D_A=\tfrac12\sum_i\lvert X_i\rvert
```

**なぜ絶対値なのか。** トレース距離が答えたい問いは「2つの状態はどれくらい見分けられるか」(準備2、準備4b 理由2)である。どの配置での食い違いも、向きに関係なく見分けやすさに寄与するので、すべて正で数える。

**なぜ $\tfrac12$ なのか。** $X$ の合計は 0 なので、**正の部分の総和と負の部分の総和は必ず等しい**。したがって $\sum_i\lvert X_i\rvert$ は同じ量を2回数えている(出ていく分と入ってくる分)。半分にすると

> $D_A$ = **prior の確率分布を真の分布に直すために、動かさなければならない確率の量**

という意味になる。 $\chi_p=4$ では、空と二重占有に $+0.009014$ ずつ($+$ 側で合計 $0.018028$)、↑ と ↓ に $-0.009014$ ずつ($-$ 側で合計 $-0.018028$)なので、**0.018028 だけ確率を動かせばよい**。実際 $D_A=\tfrac12(0.009014\times4)=0.018028$ である。

#### 決定的な違い: $ZZ$ は ↑ と ↓ を区別しない

ここが本題である。 $ZZ$ の割り当てをもう一度見る:

| 配置 | 空 | ↑ | ↓ | 二重占有 |
|---|---|---|---|---|
| $ZZ$ の値 | $+1$ | **$-1$** | **$-1$** | $+1$ |

**↑ と ↓ に同じ $-1$ が割り当てられている。** これは当然で、 $ZZ$ が測っているのは二重占有(= 電子が2個か0個か1個か)であって、1個のときにそれが上向きか下向きかには何の関心もないからである。

したがって:

> **↑ と ↓ の間で確率を移すだけの誤差は、 $ZZ$ にはまったく見えない。**

なぜなら移した分は $(-1)\times(-t)+(-1)\times(+t)=0$ と厳密に打ち消し合うからである。ところが $D_A$ は絶対値で足すので、この移動を**丸ごと数えてしまう**。

**これが「片方は打ち消し合いを許し、片方は許さない」の意味である。**

#### UHF の誤差を2つに分ける

UHF はまさにこの状況にいる。同じ site の UHF prior:

| | 空 | ↑ | ↓ | 二重占有 |
|---|---|---|---|---|
| $\sigma_A$ (UHF) | 0.104691 | **0.776464** | **0.014154** | 0.104691 |
| **$X$ (誤差)** | −0.005445 | **−0.375710** | **+0.386600** | −0.005445 |

UHF は「このサイトのスピンは上向きだ」と決めつけている(↑ が 0.776、↓ が 0.014)。真の状態は上下対等(どちらも 0.401)なので、誤差の大半は **↓ から ↑ へ確率を 0.38 も動かしてしまった分**である。

そこで誤差を「↑↔↓ の移動」と「残り」に厳密に分解する:

| | 空 | ↑ | ↓ | 二重占有 | $ZZ$ の誤差 | 大きさ $\tfrac12\sum\lvert\cdot\rvert$ |
|---|---|---|---|---|---|---|
| **↑↔↓ の移動** | 0 | −0.381155 | +0.381155 | 0 | **0.000000** | **0.381155** |
| **残り** | −0.005445 | +0.005445 | +0.005445 | −0.005445 | **−0.021780** | 0.010890 |
| 合計( $=X$ ) | −0.005445 | −0.375710 | +0.386600 | −0.005445 | −0.021780 | 0.386600 |

**移動部分の $ZZ$ 誤差は厳密にゼロである。** $ZZ$ から見れば、UHF がスピンの向きをどれだけ間違えていても関係ない。 $\Delta_{ZZ}=-0.021780$ は全部「残り」から来ている。

一方 $D_A$ から見ると:

```math
D_A=0.386600\ \text{のうち}\ \mathbf{0.381155\ (98.6\%)}\ \text{が}\ ZZ\ \text{には見えない成分}
```

**距離の 98.6% が、測りたい観測量とは無関係な誤差である。** これが $D_A$ が $\Delta$ の35倍を主張し、利得を 48.57 対 0.61 と80倍も過小評価する理由である。

> **一言でまとめると。** UHF が間違えているのは「**スピンが上か下か**」で、 $ZZ$ が測っているのは「**電子が何個いるか**」である。別の量なので $ZZ$ は間違いに気づかない。ところがトレース距離は「どんな食い違いも食い違い」として数えるので、両方を等しく計上してしまう。**距離には「どの観測量を測りたいのか」という情報が入っていない**からである。

#### 同じ距離でも $\Delta$ は自由に動く

念のため、 $D_A$ を $0.100$ に固定したまま $\Delta$ が動くことを見ておく:

| $X=($ 空, ↑, ↓, 二重 $)$ | $D_A$ | $\Delta_{ZZ}$ | 比 |
|---|---|---|---|
| $(+0.050,\ -0.050,\ -0.050,\ +0.050)$ | 0.100 | 0.200 | **1.000** |
| $(+0.025,\ +0.050,\ -0.100,\ +0.025)$ | 0.100 | 0.100 | 0.500 |
| $(\ \ 0.000,\ +0.100,\ -0.100,\ \ \ 0.000)$ | 0.100 | **0.000** | **0.000** |

**距離が同じ 0.100 でも、 $\Delta$ は 0.200 から 0 まで何でもありうる。** 最後の行は「スピンの向きだけを間違えていて、二重占有は完全に正しい」prior で、 $ZZ$ の誤差はゼロなのに距離は 0.100 ある。UHF はこれに近い状況にいる。

#### では結果1ではなぜ一致したのか

飽和は**距離の性質ではなかった**。半充填では次の3つの拘束がかかる:

1. 確率の合計が 1 → $X$ の合計は 0
2. スピン対称( $\langle S^z\rangle=0$ )→ ↑ と ↓ の値が等しい
3. 粒子正孔対称(半充填)→ 空 と 二重占有 の値が等しい

これで4つの数のうち**自由なのは1つだけ**になり、 $X$ は必ず $(u,-u,-u,u)$ の形をとる。これは $ZZ$ の符号 $(+,-,-,+)$ とぴったり同じ向きなので、打ち消し合いようがない。

> **つまり「誤差の向きが1通りしかない」ように拘束されていたから一致していた。** 拘束が外れれば向きは自由になり、一致は失われる。UHF は拘束2を破り、次に見るようにドーピングは拘束3を破る。

#### 角度で言い直す

「向きが揃っているか」は角度で測れる。2つのベクトルの向きの近さを表す量が

```math
\cos\theta=\frac{\text{2つのベクトルの内積}}{\text{それぞれの長さの積}}
```

で、 $\cos\theta=1$ なら**同じ向き**、 $\cos\theta=0$ なら**直角(全く別の方向)**である。誤差 $X$ と観測量 $ZZ$ の間で測ると:

| prior | $\cos\theta$ | 角度 $\theta$ | $\lvert\Delta\rvert/(2D_A)$ | 真の $G$ | $D_A$ からの予測 |
|---|---|---|---|---|---|
| χ_p=2 〜 χ_p=32 | **1.0000** | **0.00°** | 1.0000 | — | 正しい |
| UHF-sym | **1.0000** | **0.00°** | 1.0000 | 48.57 | 48.57 |
| **UHF** | **0.0202** | **88.84°** | 0.0282 | **48.57** | **0.61** |

**UHF の誤差は、測りたい観測量からほぼ直角の方向を向いている。** 距離は角度を見ないので、この「関係ない方向の誤差」を「観測量の誤差」として数え上げてしまう。80倍の過小評価はここから出ている。

#### 汚染される向きは2つある — まとめの式

4つの数のうち自由なのは3つ(合計が0という拘束が1つ)なので、誤差の向きは3方向に分けられる:

| 方向 | 意味 | いつ開くか |
|---|---|---|
| $ZZ$ 方向 | 二重占有のずれ = **知りたい誤差** | — |
| **スピン方向** | ↑ と ↓ の非対称 | prior が**スピン対称性を破る**とき(UHF) |
| **粒子数方向** | 空 と 二重占有 の非対称 | **ドープ**したとき(粒子正孔対称性が破れる) |

汚染の強さを、知りたい誤差との比で測る:

```math
\sigma=\frac{4\lvert\Delta(S^z)\rvert}{\lvert\Delta_{ZZ}\rvert}\ \ (\text{スピン方向}),
\qquad
m=\frac{2\lvert\Delta(n)\rvert}{\lvert\Delta_{ZZ}\rvert}\ \ (\text{粒子数方向})
```

すると比は完全に決まる:

```math
\boxed{\ \frac{\lvert\Delta_{ZZ}\rvert}{2D_A}=\frac{2}{\max(1,m)+\max(1,\sigma)}\ }
```

$\max(1,\cdot)$ の意味は素直である。**汚染が知りたい誤差より小さいうちは何も起きず( $1$ のまま)、追い越して初めて効き始める。** 両方とも小さければ $2/(1+1)=1$ 、つまり飽和する。結果5で見つけた $\min(1,2/(1+4r))$ は、この式の $m=0$ の場合である。

全588点(2ドーピング × 7 prior × 全サイト)で検定する:

| ドープ | prior | $m$ | $\sigma$ | 実測 | 式の予測 | 誤差 |
|---|---|---|---|---|---|---|
| 0 | χ_p=4 | 0.000 | 0.000 | 1.0000 | 1.0000 | 3.1e−15 |
| 0 | **UHF** | 0.000 | **197.9** | **0.0101** | **0.0101** | 7.6e−17 |
| 0 | UHF-sym | 0.000 | 0.000 | 1.0000 | 1.0000 | 6.0e−14 |
| 1/8 | χ_p=8 | 0.649 | 0.297 | 1.0000 | 1.0000 | 5.6e−12 |
| 1/8 | **χ_p=16** | **1.097** | 0.893 | **0.8509** | **0.8509** | 3.1e−08 |
| 1/8 | **χ_p=32** | **1.395** | 0.674 | **0.7794** | **0.7794** | 9.9e−10 |

**全588点で最大誤差 $3.1\times10^{-8}$ 、中央値は機械精度である。**

#### 予言と検証: ドープすれば、対称性を破らなくても壊れる

この見方は**対称性の破れとは無関係な失敗**を予言する。半充填では粒子正孔対称性が「空 と 二重占有 の確率が等しい」を強制するので $m=0$ だった。**ドープすると電子の数が変わるのでこれが崩れ、 $m$ が開く。** したがって**スピン対称性をきちんと保っている MPS prior でも、ドープすれば飽和が壊れるはず**である。

| ドーピング | prior | $\lvert\Delta\rvert/(2D_A)$ 中央 | 飽和率 |
|---|---|---|---|
| 0(半充填) | χ_p=4 〜 χ_p=32 | 1.0000 | **100%** |
| **1/8** | χ_p=4 | 1.0000 | 67% |
| **1/8** | χ_p=8 | 1.0000 | 81% |
| **1/8** | χ_p=16 | **0.8509** | **36%** |
| **1/8** | χ_p=32 | **0.7794** | **31%** |

機構も直接見える。粒子数方向の誤差は半充填では**厳密にゼロ**なのに、ドープで開く:

| ドーピング | prior | $\lvert\Delta(n)\rvert$ | $\lvert\Delta(ZZ)\rvert$ |
|---|---|---|---|
| 0 | χ_p=4 | $3.7\times10^{-10}$ | $1.5\times10^{-1}$ |
| 1/8 | χ_p=4 | $1.2\times10^{-2}$ | $8.6\times10^{-2}$ |

**予言が当たった。** 対称性の破れとは別の機構なので、「距離は関係ない方向の誤差まで数える」という見方が正しいことの**独立な確認**になっている。

#### なぜ「prior を良くするほど予測が悪くなる」のか

$m$ と $\sigma$ の**分母が $\lvert\Delta_{ZZ}\rvert$ である**ことが効く。 $\chi_p$ を上げると知りたい方向の誤差 $\lvert\Delta_{ZZ}\rvert$ は小さくなるが、粒子数方向・スピン方向の誤差は同じ速さでは減らない。**分子が残ったまま分母だけ小さくなるので、比は上がる:**

```
ドープ δ=1/8:   χ_p=8 → m=0.649     χ_p=16 → m=1.097     χ_p=32 → m=1.395
```

結果5でトーラス上の MPS prior に見たのと同じ現象で、そこでは $\sigma$ が、ここでは $m$ が上がっている。**prior を精密にするほど、残った誤差は「観測量に対して斜め」になっていく。**

#### なぜ選定という文脈で致命的になるのか

3つ重なる。

**(1) 系統的である。** $m$ と $\sigma$ は prior の性質であって、測定データの量とは無関係である。だから測定を増やしても順位相関は 0.786 で止まる(段階2)。

**(2) 最も安い prior を狙い撃ちにする。** これが偶然でないことが重要である。**平均場が対称性を破るのは、それが局所的な物理を正しく捉えるための手段だからである** — Slater 行列式(平均場の波動関数)は「各サイトに局所モーメントがあるが全体としては一重項」という状態を表せない。そこで UHF はスピン対称性を破ることで局所的な正しさを買う。つまり**「安くて局所観測量に効く prior」と「対称性を破る prior」は同じものを指しており、距離ベースの判定はそこを狙い撃ちで棄却する。**

**(3) 中央値が隠す。** 選定は $\arg\max$ 、つまり**裾に敏感な操作**である。ところが誤差の中央値で評価すると、7つのうち6つが当たっているので 1.2% に見えてしまう。**平均的な精度で評価している限り、この失敗は見えない。** 段階2で決定問題として測るまで気づかなかったのはこのためである。

#### 対処できるか

- **スピン方向( $\sigma$ )は消せる。** 群平均(§2j)を当てれば $\Delta(S^z)\to0$ になり、コストは0である。表のとおり UHF-sym は正しい予測を与える。**距離ベースの診断を使うなら、群平均は前処理として必須である。**
- **粒子数方向( $m$ )は消せない。** 粒子数は物理量であって、平均を取って消すべき「破れ」ではない。**ドープ系では距離ベースの診断は原理的に使えない。**
- したがって結局、**選定には $\Delta$ を直接測るのが正しい**。 $\Delta$ は「知りたい1方向への成分」そのものなので、そもそも角度の問題が生じない。

#### 段階2の結論

**prior の選定には $\Delta$ を直接推定する。距離や忠実度を経由してはいけない。**

理由は3つあり、いずれも準備4e・4f で見た通りである:

1. **$\hat\Delta$ が最も安い** — Pauli 期待値ひとつ、線形、不偏(準備4e)
2. **$\hat D_A$ 、 $\hat F_A$ は正に偏る** — ノルムなのでノイズが足し込まれ、prior が良いほど相対的に悪化(準備4f)
3. **そして本質的に、両者は系統的に誤る** — 対称性を破る安い prior を、それが実際に働くときに棄却する(上の結果1)

**では段階1の結果に実用上の意味はないのか。** ある。ただし選定の道具としてではない:

- **最悪値の証明書**: $D_A$ は台の上の**全観測量**に対する $\lvert\Delta\rvert$ の上界である。個別の観測量では $\Delta$ に負けるが、「この台のどんな観測量でも利得は $X$ 以上」という保証は $D_A$ にしか作れない
- **prior クラスの事前判定**: $r\le1/4$ の分子 $\Delta(S^z)$ は prior 側だけで計算でき、測定が要らない。**破れているなら群平均を当てる**(§2j、コスト0)という処方は、距離を測らずに実行できる
- **説明**: なぜ UHF が効いて χ_p=2 が効かないのかを、 $r$ という1つの変数で説明する(結果5)

### 結論

**仮説「局所観測量には部分系の忠実度が効く」は正しい。ただし2つの条件が付く。**

| 条件 | 満たすとき | 満たさないとき |
|---|---|---|
| **部分系を観測量の台そのものにする** | 単一Pauli列で上界が飽和(半充填の86%) | 台より大きく取ると10〜20倍緩く見える |
| **prior が $\rho$ の対称性を尊重する**、定量的には $r=\lvert\Delta(S^z)\rvert/\lvert\Delta_P\rvert\le 1/4$ | 相関 0.74–0.999、 $D_{\text{台}}=\lvert\Delta\rvert/2$ が恒等式 | 距離が対称性破れに食われ、比は $\min(1,2/(1+4r))$ に落ちる(24点で最大誤差 0.0022) |

> **最初の報告(「部分系の忠実度でも決まらない」)は誤りだった。** 決まらないように見えたのは私の測り方のせいで、(i) 台より大きい部分系を使い、(ii) prior を横断して相関を取った、の2点である。両方を直すと仮説は支持される。
>
> **§2 の主張は損なわれない。** 「 $\Delta$ が利得を決める」ことは変わらない。新しく分かったのは「**その $\Delta$ は、対称性を尊重する prior に限れば、台のトレース距離から読める**」という追加の構造である。大域忠実度が使えないのは変わらず、使えるのは**台まで絞ったとき**だけである。
>
> **実務上の使い方**(手順2が $\rho_A$ を要求する点について、前提と限界を**準備4e**で訂正した。実験対象そのものには使えない):
> 1. prior が $\rho$ の対称性を尊重しているか確認する。破っていれば先に群平均を当てる(§2j、測定コストゼロ)
> 2. 測りたい観測量の**台だけ**に縮約した $\rho_A,\sigma_A$ を作る
> 3. $D_{\rm tr}(\rho_A,\sigma_A)$ を1回計算すれば、単一Pauli列なら $\lvert\Delta\rvert=2D_{\rm tr}$ が(半充填では)厳密に得られる
>
> これで**観測量ごとに $\Delta$ を計算し直す必要がなくなる** — ただし台が同じ観測量に限る。
