## 2m. 利得は「部分系の忠実度」で決まるか

スクリプト: [crm_support_fidelity.jl](crm_support_fidelity.jl) / [.pbs](crm_support_fidelity.pbs) / データ: [crm_support_fidelity_results.tsv](crm_support_fidelity_results.tsv) / 最初の(欠陥のある)版: [crm_window_fidelity.jl](crm_window_fidelity.jl)

### 問い

§2 の主張は「**大域**忠実度 $F=\lvert\langle\sigma\vert\rho\rangle\rvert^2$ は利得を決めない、観測量ごとの局所誤差 $\Delta$ が決める」だった。この2つは粒度が両極端である。

| | 粒度 | 長所 | 短所 |
|---|---|---|---|
| 大域忠実度 $F$ | 系全体で1つの数 | 観測量を決めなくても計算できる | 全サイトの誤差の積なので $L$ とともに指数的に死に、利得と無関係になる |
| 局所誤差 $\Delta$ | 観測量1つに1つの数 | 利得を厳密に決める | 観測量を決めないと計算できない |

その中間に自然な候補がある。**観測量が触る量子ビットだけに縮約した密度行列どうしの近さ**である。これなら系全体ではないので指数的には死なず、しかも(その部分系を見る限り)観測量に依存しない1つの数になる。

**これで $\Delta$ が決まるなら実務上とても有用である。** prior を1つ作ったら、部分系の距離を1回計算するだけで「どの観測量にどれだけ効くか」が分かることになる。観測量ごとに $\Delta$ を計算し直す必要がなくなる。

### 準備1: 縮約密度行列(部分系だけを見る)

系全体の状態を $\rho$ とする。着目する量子ビットの集合を $A$、それ以外を $B$ とすると、**$A$ の縮約密度行列**は

```math
\rho_A = \mathrm{Tr}_B[\rho]
```

で定義される。 $\mathrm{Tr}_B$ は「 $B$ の自由度を足し上げる(積分し尽くす)」操作で、**部分トレース**という。成分で書くと、 $\lvert a\rangle$ を $A$ の基底、 $\lvert b\rangle$ を $B$ の基底として

```math
(\rho_A)_{a a'} = \sum_b \langle a\,b\rvert\rho\lvert a'\,b\rangle
```

つまり $B$ の添字を対角で潰す。 $A$ が $\lvert A\rvert$ 量子ビットなら $\rho_A$ は $2^{\lvert A\rvert}\times2^{\lvert A\rvert}$ の行列で、系全体の $2^N\times2^N$ よりはるかに小さい。

**重要な性質**: 観測量 $P$ が $A$ の上にしか作用しないなら、その期待値は $\rho_A$ だけで決まる。

```math
\langle P\rangle_\rho = \mathrm{Tr}[P\,\rho] = \mathrm{Tr}_A[P\,\rho_A]
```

**$A$ の外の情報は $\langle P\rangle$ に一切入らない。** だから「観測量が触る量子ビット(=台)」に絞った縮約密度行列こそが、その観測量にとっての「状態のすべて」である。

### 準備2: トレース距離

行列 $M$ の**トレースノルム**を

```math
\lVert M\rVert_1 = \mathrm{Tr}\sqrt{M^\dagger M} = \sum_i \lvert\lambda_i\rvert
\qquad(\lambda_i \text{ は } M \text{ の固有値、} M \text{ がエルミートのとき})
```

と定義する。これを使って2状態の**トレース距離**は

```math
D_{\rm tr}(\rho_A,\sigma_A) = \tfrac12\lVert\rho_A-\sigma_A\rVert_1
```

である。 $0\le D_{\rm tr}\le1$ で、 $0$ は完全一致、 $1$ は台が直交(完全に区別できる)を意味する。

**この量が本質的なのは、次の変分表示があるからである:**

```math
D_{\rm tr}(\rho_A,\sigma_A) = \max_{0\le M\le I}\ \mathrm{Tr}\bigl[M(\rho_A-\sigma_A)\bigr]
```

右辺は「あらゆる測定 $M$ にわたって、期待値の差を最大にしたもの」である。つまり **トレース距離は「2つの状態を最も見分けやすい測定で見分けたときの差」** であり、 $\tfrac12$ が付いているのはこの最大値と一致させるためである。

### 準備3: なぜ $\lvert\Delta\rvert\le 2D_{\rm tr}$ なのか

Pauli 列 $P$ は固有値が $\pm1$ なので、 $+1$ 固有空間への射影を $\Pi$ として $P = 2\Pi - I$ と書ける。 $\rho_A$ と $\sigma_A$ はどちらもトレース1なので $\mathrm{Tr}[\rho_A-\sigma_A]=0$ であり、

```math
\Delta = \mathrm{Tr}[P(\rho_A-\sigma_A)]
= 2\,\mathrm{Tr}[\Pi(\rho_A-\sigma_A)] - \underbrace{\mathrm{Tr}[\rho_A-\sigma_A]}_{=0}
= 2\,\mathrm{Tr}[\Pi(\rho_A-\sigma_A)]
```

となる。 $\Pi$ は $0\le\Pi\le I$ を満たす測定の一種なので、上の変分表示から $\lvert\mathrm{Tr}[\Pi(\rho_A-\sigma_A)]\rvert\le D_{\rm tr}$ 。したがって

```math
\lvert\Delta\rvert \;\le\; 2D_{\rm tr}
```

**係数 2 は「Pauli 列の固有値が $\pm1$ の幅2を持つ」ことから来る。** そして等号が成り立つのは、 $\Pi$ が最大を達成する測定と一致するとき、すなわち **$P$ の固有値の符号パターンが $\rho_A-\sigma_A$ の固有値の符号パターンとちょうど揃うとき**である。後で見るように、半充填ではこれが自動的に起きる。

### 準備4: 忠実度

**Uhlmann 忠実度**は

```math
F(\rho_A,\sigma_A) = \Bigl(\mathrm{Tr}\sqrt{\sqrt{\rho_A}\,\sigma_A\sqrt{\rho_A}}\Bigr)^2
```

で定義される。 $0\le F\le1$ で、 $1$ が完全一致(トレース距離と逆向き)。特別な場合には簡単になる:

- **純粋状態どうし**: $F=\lvert\langle\psi\vert\phi\rangle\rvert^2$ (よく使う「重なりの2乗」)
- **可換な状態どうし**(同時対角化できる、確率分布 $p,q$ とみなせる場合): $F=\bigl(\sum_i\sqrt{p_i q_i}\bigr)^2$ (Bhattacharyya 係数の2乗)

本節で扱う RDM は占有基底で対角なので、2番目の形が使える。

忠実度は距離ではない(三角不等式を満たさない)が、トレース距離と **Fuchs–van de Graaf の不等式**

```math
1-\sqrt{F} \;\le\; D_{\rm tr} \;\le\; \sqrt{1-F}
```

で結ばれている。右側から $\lvert\Delta\rvert\le2D_{\rm tr}\le2\sqrt{1-F}$ が出るので、**忠実度からも上界は作れるが、必ずトレース距離版より緩い**。

### 準備4b〜4f: なぜ忠実度ではなくトレース距離なのか → **[README_distance_vs_fidelity.md](README_distance_vs_fidelity.md)**

「どの量が局所観測量の推定誤差を測るのに正しいのか」を詰めた理論部は、分量が大きいので別ファイルにした(GitHub の数式描画上限に迫ったため)。

要点: **$\Delta$ は線形汎関数で、その双対ノルムがトレース距離である** — 「 $P$ は固有値 $\pm1$ の観測量」という情報だけを使う限り $2D_{\rm tr}$ より良い上界は存在しない。忠実度は差 $\rho_A-\sigma_A$ の関数ですらない。 / **元論文は $\Delta$ と Hilbert–Schmidt ノルムで分散保証を書いており**、忠実度は推定対象および**純粋 prior に限った**品質判定として使っている。 / **台に縮約すると prior が混合になり**、純粋 prior で成り立っていた3条件(忠実度が観測量になる・1次である・距離を押さえる)が同時に壊れる。 / **トレース距離は $\Delta$ の近道ではない** — $\Delta$ は Pauli 期待値ひとつで不偏推定できるのに対し、距離は RDM 全体が要る。

→ **[README_distance_vs_fidelity.md](README_distance_vs_fidelity.md) を参照**


### 準備5: 具体例で確かめる

以上を数値で追ってみる。 $U=4$ 半充填のサイト内2量子ビット $(q_\uparrow,q_\downarrow)$ を考える。後で示すように、この RDM は占有基底 $\lvert n_\uparrow n_\downarrow\rangle$ で対角で、二重占有 $D$ ただ1つで決まる:

```math
\rho_A = \mathrm{diag}(D,\ \tfrac12-D,\ \tfrac12-D,\ D)
```

実測値 $D_\rho=0.10$ とし、prior が $D_\sigma=0.11$ とわずかに外したとする。

```math
\rho_A = \mathrm{diag}(0.10,\,0.40,\,0.40,\,0.10), \qquad
\sigma_A = \mathrm{diag}(0.11,\,0.39,\,0.39,\,0.11)
```

**トレース距離**:

```math
M=\rho_A-\sigma_A = \mathrm{diag}(-0.01,\,+0.01,\,+0.01,\,-0.01),\quad
\lVert M\rVert_1 = 0.04,\quad D_{\rm tr}=0.02
```

**局所誤差** ( $Z_\uparrow Z_\downarrow$ の固有値は $(+1,-1,-1,+1)$ ):

```math
\Delta = \mathrm{Tr}[Z_\uparrow Z_\downarrow M] = (-0.01)-(+0.01)-(+0.01)+(-0.01) = -0.04
```

したがって $\lvert\Delta\rvert = 0.04 = 2D_{\rm tr}$ で、**上界がちょうど等号**になっている。 $M$ の符号パターン $(-,+,+,-)$ が $Z_\uparrow Z_\downarrow$ の符号パターン $(+,-,-,+)$ と(全体の符号を除いて)一致するためである。

**忠実度**(可換なので Bhattacharyya):

```math
F = \bigl(2\sqrt{0.10\cdot0.11}+2\sqrt{0.40\cdot0.39}\bigr)^2 = (0.20976+0.78994)^2 = 0.99940
```

```math
1-F = 6.0\times10^{-4},\qquad \sqrt{1-F}=0.0245,\qquad
\frac{\lvert\Delta\rvert}{2\sqrt{1-F}} = \frac{0.04}{0.049} = 0.816
```

**忠実度版の上界は等号にならない**(0.816)。後で示す一般式 $2/\sqrt{\tfrac12(1/D+1/(\tfrac12-D))}$ に $D=0.1$ を入れると $2/\sqrt{6.25}=0.80$ で、この数値と合う。

**この2つの違い — 距離版は状態によらず等号、忠実度版は $D$ に依存する係数が付く — が、本節の技術的な結論である。**

### 最初の測り方は間違っていた

最初は次のように測り、「上界は10〜20倍緩い ⇒ 部分系の忠実度では決まらない」と結論した。**これは誤りで、原因は2つとも私の設計にあった。**

**欠陥1: 部分系を観測量の台より大きく取っていた。**

全観測量に対して**同じ4量子ビットの窓**(サイト $i,i{+}1$ の up/dn)を使っていた。しかし実際の台は観測量ごとに違う:

| 観測量 | 台 $A$ | 大きさ |
|---|---|---|
| $S^z_i$ | $q_\uparrow(i), q_\downarrow(i)$ | 2 |
| ZZ onsite | $q_\uparrow(i), q_\downarrow(i)$ | 2 |
| ZZ up-up r=1 | $q_\uparrow(i), q_\uparrow(i{+}1)$ | 2 |
| SzSz r=1 | 4量子ビット全部 | 4 |

**台に含まれない量子ビットは $\Delta$ に一切寄与しない**(上の $`\mathrm{Tr}_A`$ の式)。ところが $D_{\rm tr}$ には寄与する。つまり「 $\Delta$ に効かない誤差」を距離に混ぜて、それで $\Delta$ を予測しようとしていた。緩くなって当然である。

**欠陥2: 相関を prior 横断で計算していた。**

$\chi_p=2$ から $\chi_p=32$ まで並べると、 $D_{\rm tr}$ も $\lvert\Delta\rvert$ も3桁動く。その全体で相関を取れば 0.9 は出るが、それは「**粗い prior は何に対しても悪く、細かい prior は何に対しても良い**」という当たり前のことを見ているだけで、「距離が $\Delta$ を決める」証拠にはならない。

仮説を検証するには **prior を1つ固定して、サイト間で** 見なければならない。同じ prior でもサイトによって距離は変わるので、「距離が大きいサイトほど $\Delta$ も大きいか」を問える。

**両方を直して測り直した。** データは同じ 4,116 点(  $L=16,32$ 、半充填とδ=1/8、サイト $2$〜 $L-2$ 、7観測量、7 prior)で、Monte Carlo を使わない厳密計算なので統計誤差はない。平均場 prior の RDM は台の中の全 Pauli 列の期待値から $\sigma_A = 2^{-\lvert A\rvert}\sum_P\langle P\rangle_\sigma P$ と再構成した(§2i の一般Wickが要る)。

### 結果1: 台に絞ると、上界は緩いどころか厳密に飽和する

| 観測量 | 台 | 4量子ビット窓での $\lvert\Delta\rvert/(2D)$ | **台での** $\lvert\Delta\rvert/(2D)$ |
|---|---|---|---|
| ZZ onsite | 2 | 0.126 | **1.0000** |
| ZZ up-up r=1 | 2 | 0.293 | **1.0000** |
| 二重占有 | 2 | 0.031 | 0.2500 |
| hop up r=1 | 3 | 0.258 | 0.4515 |
| SzSz r=1 | 4 | 0.060 | 0.060(台=窓なので不変) |

**単一Pauli列では比が 1.0000、つまり不等式が等号で成立する。**

#### なぜ飽和するのか(準備5の具体例が一般に成り立つ理由)

サイト $i$ の2量子ビット $(q_\uparrow, q_\downarrow)$ の RDM は $4\times4$ で、占有基底 $\lvert n_\uparrow n_\downarrow\rangle$ で対角である(粒子数が保存するので異なる占有どうしの非対角要素が立たない)。対角成分を $p_{00},p_{01},p_{10},p_{11}$ と書くと

```math
\langle n\rangle = p_{01}+p_{10}+2p_{11}, \qquad
\langle S^z\rangle = \tfrac12(p_{10}-p_{01}), \qquad
\langle D\rangle = p_{11}
```

である。ここで**半充填**( $\langle n\rangle=1$ )かつ**スピン対称**( $\langle S^z\rangle=0$ )を課すと、規格化 $\sum p=1$ と合わせて自由度が1つだけ残る:

```math
p_{01}=p_{10}=\tfrac12-D, \qquad p_{00}=p_{11}=D
```

つまり **RDM 全体が二重占有 $D$ ただ1つで決まる。**(ついでに $\langle Z_\uparrow Z_\downarrow\rangle = p_{00}-p_{01}-p_{10}+p_{11} = 4D-1$ となり、§0.3b で述べた関係が出る。)

切断MPS prior は $\rho$ から作るので $\langle n\rangle$ と $\langle S^z\rangle$ を(数値誤差の範囲で)受け継ぐ。したがって差 $M=\rho_A-\sigma_A$ は $\delta \equiv D_\rho-D_\sigma$ ひとつで書けて

```math
M = \mathrm{diag}(\delta,\,-\delta,\,-\delta,\,\delta)
```

となる。ここから

```math
\lVert M\rVert_1 = 4\lvert\delta\rvert \;\Rightarrow\; D_{\rm tr}=2\lvert\delta\rvert,
\qquad
\Delta(ZZ) = \mathrm{Tr}[Z_\uparrow Z_\downarrow M] = \delta+\delta+\delta+\delta = 4\delta
```

( $Z_\uparrow Z_\downarrow$ の固有値が $(+1,-1,-1,+1)$ なので符号がちょうど揃う)。よって

```math
\lvert\Delta(ZZ)\rvert = 4\lvert\delta\rvert = 2D_{\rm tr}
```

**が恒等式として成り立つ。** 差が「二重占有の方向」しか持たず、それが $Z_\uparrow Z_\downarrow$ の固有値符号と完全に一致するためである。二重占有の比が $0.25$ なのは $D=(1-Z_\uparrow-Z_\downarrow+Z_\uparrow Z_\downarrow)/4$ の $ZZ$ 係数が $1/4$ だからで、これも整合する。

#### 飽和は半充填に固有である

ドープすると $\langle n\rangle$ も prior とずれうるので、差の自由度が $D$ と $n$ の2つになり、上の議論が崩れる。実際:

| 観測量 | 半充填で飽和( $>0.99$ )する割合 | δ=1/8 |
|---|---|---|
| ZZ onsite | **86%** | 52% |
| ZZ up-up r=1 | **86%** | 40% |

### 結果2: prior を固定すると、仮説は支持される

corr( $\log\lvert\Delta\rvert$, $\log D_{\text{台}}$ ) を prior ごとに、サイト間で測る:

| 観測量 | χ_p=2 | χ_p=4 | χ_p=8 | χ_p=16 | χ_p=32 | **UHF** | UHF-sym |
|---|---|---|---|---|---|---|---|
| ZZ onsite | 0.999 | 0.910 | **0.996** | 0.736 | 0.903 | **−0.669** | 0.962 |
| ZZ up-up r=1 | 0.962 | 0.892 | **0.983** | 0.932 | **0.989** | 0.102 | 0.692 |
| 二重占有 | −0.790 | 0.822 | 0.952 | 0.655 | 0.959 | **−0.553** | 0.964 |
| SzSz r=1 | 0.398 | 0.528 | 0.491 | 0.633 | 0.842 | 0.665 | 0.689 |
| hop up r=1 | 0.729 | 0.830 | **0.990** | 0.967 | 0.939 | **−0.646** | 0.440 |

**切断MPS prior では 0.74–0.999。** 同じ prior の中でも、台の忠実度が悪いサイトほど $\Delta$ が大きい。**仮説は支持される。**

**ところが UHF では相関が負になる**(−0.55 〜 −0.67)。距離が大きいサイトほど $\Delta$ が**小さい**という逆転が起きている。

### 結果3: 負の相関の正体 — 距離が「観測量と直交する方向」を測っている

上と同じ $4\times4$ の枠組みで説明がつく。UHF は共線 Néel 解なので **$\langle S^z\rangle\ne0$**、つまり $p_{10}\ne p_{01}$ になる。差 $M$ が**スピンの方向だけ**を持つ場合を書くと

```math
M = \mathrm{diag}(0,\,-s,\,+s,\,0)
```

このとき

```math
D_{\rm tr} = \tfrac12(\lvert{-s}\rvert+\lvert s\rvert) = \lvert s\rvert,
\qquad
\Delta(S^z) = \tfrac12\bigl(s-(-s)\bigr) = s,
\qquad
\Delta(ZZ) = 0-(-s)-(+s)+0 = 0
```

**距離は $S^z$ の誤差そのものになり、 $ZZ$ に対しては厳密にゼロを与える。** 距離が $ZZ$ と直交する方向を向いているのである。

実測がこの通りになっている(半充填、全サイト中央値):

| prior | $D_{\text{台}}$ | $\lvert\Delta(S^z)\rvert$ | $\lvert\Delta(ZZ)\rvert$ | $D_{\text{台}}/\lvert\Delta(ZZ)\rvert$ |
|---|---|---|---|---|
| χ_p=8 | 7.73e−4 | 5.8e−10 | 1.55e−3 | **0.50** |
| χ_p=32 | 6.86e−6 | 1.5e−10 | 1.37e−5 | **0.50** |
| **UHF** | **3.86e−1** | **3.85e−1** | 7.77e−3 | **49.7** |
| UHF-sym | 3.89e−3 | 1.2e−9 | 7.77e−3 | **0.50** |

- **切断MPS**: $\lvert\Delta(S^z)\rvert\sim10^{-10}$ で、スピン対称性を $\rho$ から受け継いでいる。距離は**二重占有の方向だけ**でできており、それはまさに `ZZ onsite` が測る方向。だから比が厳密に $0.50$ (= 飽和)で、相関が 0.996 になる
- **UHF**: $D_{\text{台}}=0.386$ に対し $\lvert\Delta(S^z)\rvert=0.385$。**距離のほぼ全部が対称性破れである。** 予測すべき $\lvert\Delta(ZZ)\rvert=0.0078$ は距離の50分の1しかなく、サイト間ではむしろ逆相関する
- **UHF-sym**: 群平均で対称性破れが消えると $D_{\text{台}}$ が **100分の1**(0.386 → 0.0039)に落ち、比が $0.50$ に戻る。**このとき $\lvert\Delta(ZZ)\rvert$ は 0.0078 のまま動かない**

最後の行が示唆的である。**群平均は prior を「良くして」いるのではない。距離のうち、どの観測量にも効かない成分を取り除いているだけである。** §2j で「群平均は損を消すが、得を増やすとは限らない」と書いたことの、幾何学的な言い換えになっている。

### 結果4: 忠実度で測るとどうなるか — 同じ相関、緩い上界

解析: [crm_fidelity_vs_delta.jl](crm_fidelity_vs_delta.jl) / [.pbs](crm_fidelity_vs_delta.pbs)

ここまではトレース距離で測った。**忠実度 $F_A$ (準備4)でも同じことが言えるのか**を確かめる。Fuchs–van de Graaf の不等式 $D_{\rm tr}\le\sqrt{1-F}$ を挟むと

```math
\lvert\Delta\rvert \;\le\; 2D_{\rm tr} \;\le\; 2\sqrt{1-F_A}
```

なので、**忠実度版の上界は必ずトレース距離版より緩い**。どれだけ緩いかは予測できる。半充填のサイト内2量子ビットでは差が $e=(\delta,-\delta,-\delta,\delta)$ 、確率が $p=(D,\tfrac12-D,\tfrac12-D,D)$ なので、可換な状態の忠実度の展開 $1-F\simeq\tfrac14\sum_i e_i^2/p_i$ から

```math
1-F \simeq \frac{\delta^2}{2}\Bigl(\frac1D+\frac1{\tfrac12-D}\Bigr)
\qquad\Longrightarrow\qquad
\frac{\lvert\Delta\rvert}{2\sqrt{1-F}} = \frac{2}{\sqrt{\tfrac12\bigl(\tfrac1D+\tfrac1{\tfrac12-D}\bigr)}}
```

**係数が二重占有 $D$ に依存する。** トレース距離版が $D$ によらず厳密に 1 だったのと対照的である。

#### 上界のタイトさ

| 観測量 | 台 | $\lvert\Delta\rvert/(2D_A)$ | $\lvert\Delta\rvert/(2\sqrt{1-F_A})$ |
|---|---|---|---|
| ZZ onsite | 2 | **1.0000** | 0.7978 |
| ZZ up-up r=1 | 2 | **1.0000** | 0.8523 |
| 二重占有 | 2 | 0.2500 | 0.1994 |
| hop up r=1 | 3 | 0.4593 | 0.3403 |

#### 係数の $D$ 依存が予測どおりに出る

$U=4$ 半充填の実測二重占有は $D=0.1002$ ( $\langle ZZ\rangle=4D-1$ から復元)。予測される係数は $0.8007$ :

| prior | 予測 | 実測(忠実度版) | 実測(距離版) |
|---|---|---|---|
| χ_p=8 | 0.8007 | **0.8003** | 1.0000 |
| χ_p=32 | 0.8007 | **0.8007** | 1.0000 |
| UHF-sym | 0.8007 | 0.8036 | 1.0000 |
| χ_p=4 | 0.8007 | 0.7336 | 1.0000 |
| χ_p=2 | 0.8007 | 0.4477 | 1.0000 |

**$\chi_p\ge8$ では予測と実測が小数点以下4桁で一致する。** $\chi_p=2,4$ でずれるのは展開の前提( $\delta$ が小さい)が崩れるためで、実際 $\chi_p=2$ では $\lvert\Delta\rvert=0.40$ と $D=0.10$ に匹敵する大きさである。

#### 相関はほぼ同じ

prior を固定したときの corr( $\log\lvert\Delta\rvert$, $\log(1-F_A)$ ) は、距離版とほぼ変わらない:

| 観測量 | χ_p=8(忠実度 / 距離) | χ_p=32(忠実度 / 距離) | UHF(忠実度 / 距離) |
|---|---|---|---|
| ZZ onsite | 0.990 / 0.996 | 0.904 / 0.903 | **−0.790 / −0.669** |
| ZZ up-up r=1 | 0.979 / 0.983 | 0.989 / 0.989 | −0.199 / 0.102 |
| 二重占有 | 0.968 / 0.952 | 0.972 / 0.959 | **−0.689 / −0.553** |
| hop up r=1 | 0.976 / 0.990 | 0.906 / 0.939 | **−0.603 / −0.646** |

理由は単純で、両者が対数で線形に結びついているからである。実測すると

```math
\log_{10}(1-F_A) = 2.038\,\log_{10} D_A + \text{const}, \qquad \text{相関 } 0.9985
```

**傾きがほぼ 2**、すなわち $1-F_A\propto D_A^2$ 。相関係数はアフィン変換で不変なので、どちらを使っても相関は同じ値になる。**UHF で負になることも共通で、対称性破れの話は道具の選び方によらない。**

#### この問題ではトレース距離が「正しい道具」である

| | トレース距離 | 忠実度 |
|---|---|---|
| 上界 | $\lvert\Delta\rvert\le 2D_A$ | $\lvert\Delta\rvert\le 2\sqrt{1-F_A}$(必ず緩い) |
| 単一Pauli列での飽和 | **恒等式** $\lvert\Delta\rvert=2D_A$ | 係数 $2/\sqrt{\tfrac12(1/D+1/(\tfrac12-D))}$ が付く |
| 係数の状態依存 | **なし** | **二重占有 $D$ に依存** |
| $\Delta$ との相関 | 同じ | 同じ |

**「距離が大きいか小さいか」を見るだけなら両者は等価だが、 $\Delta$ を数値として読み取りたいならトレース距離を使うべきである。** トレース距離の定義が「あらゆる測定にわたる期待値差の最大」であり、Pauli 列の期待値差と同じ土俵に乗っているためで、忠実度は $\sqrt{\cdot}$ を挟むぶん系のパラメータが混入する。

### 結果5: 2次元でも成り立つか — そして利得を測定なしで予測できるか

スクリプト: [crm_2d_support.jl](crm_2d_support.jl) / [.pbs](crm_2d_support.pbs) / データ: [crm_2d_supp_W4L3_U8p0.tsv](crm_2d_supp_W4L3_U8p0.tsv), [crm_2d_supp_W4L4_U8p0.tsv](crm_2d_supp_W4L4_U8p0.tsv)

ここまでは1次元鎖だった。4×3 シリンダー/トーラス(12サイト、24量子ビット、**参照は厳密対角化**、 $U=8$ 半充填)で同じ解析を行う。§2k と同じ ED 参照なので、参照状態が MPS であることによる交絡がない。

#### 飽和は次元にも幾何にもよらない

結果1の飽和の導出は「半充填 + $\langle S^z\rangle=0$ + 規格化 ⇒ サイト内2量子ビットの RDM は二重占有ひとつで決まる」という代数だけで、**格子の形が一切入っていない**。予想どおり2次元でも成り立つ:

| 幾何 | 観測量 | 台 | $\lvert\Delta\rvert/(2D_A)$ 中央値 | 飽和( $>0.99$ ) |
|---|---|---|---|---|
| シリンダー | ZZ onsite | 2 | **1.0000** | 86% |
| シリンダー | ZZ up-up nb | 2 | **1.0000** | 86% |
| トーラス | ZZ onsite | 2 | **1.0000** | 76% |
| トーラス | ZZ up-up nb | 2 | **1.0000** | 83% |
| (参考)二重占有 | | 2 | 0.2500 | — |

#### 利得を測定なしで予測できる

飽和が成り立つなら、利得法則に $\lvert\Delta\rvert=2D_A$ を代入して

```math
G_{\rm pred} = \frac{(3^{\lvert A\rvert}-1)\langle P\rangle^2 + v_s}{(3^{\lvert A\rvert}-1)\,(2D_A)^2 + v_s}
```

と、**部分系のトレース距離ひとつから利得が計算できる**はずである。実測した $G$ と突き合わせる( $n_u=240$, $n_m=100$, ZZ onsite):

| 幾何 | prior | $G$(実測) | $G_{\rm pred}$( $D_A$ から) | 比 |
|---|---|---|---|---|
| シリンダー | χ_p=4 | 32.09 | 31.40 | **0.98** |
| シリンダー | χ_p=8 | 38.07 | 38.98 | **1.02** |
| シリンダー | χ_p=32 | 156.4 | 164.6 | **1.05** |
| シリンダー | UHF-sym | 158.2 | 170.6 | **1.08** |
| シリンダー | **UHF** | **158.2** | **0.79** | **0.005** |
| トーラス | χ_p=8 | 37.31 | 37.07 | **0.99** |
| トーラス | χ_p=32 | 127.7 | 121.8 | **0.95** |
| トーラス | UHF-sym | 138.7 | 125.8 | 0.91 |
| トーラス | **UHF** | **138.7** | **0.74** | **0.005** |

**対称性を尊重する prior なら、測定を一切せずに利得が5%以内で当たる。** ( $n_u=240$, n_repeat=200 の統計誤差が約10%なので、ずれは誤差の範囲である。)

**UHF だけが200倍外れる。** $D_A=0.463$ と距離は大きいのに、実際の $\lvert\Delta(ZZ)\rvert=0.019$ は小さい — 距離が対称性破れに食われているためである。 $\Delta$ から直接計算すれば 170.6 と正しい値が出るので、**壊れているのは「距離から $\Delta$ を読む」段階だけ**である。

#### 飽和が破れる条件は閉じた式で書ける(4×4、32量子ビット)

データ: [crm_2d_supp_W4L4_U8p0.tsv](crm_2d_supp_W4L4_U8p0.tsv)

§2k で「4×4 トーラスでは $\chi=1024$ の DMRG が自発的にスタッガード磁化 0.019 を立てる」ことが分かった。 $\chi_p$ 切断 prior はその状態から作るので破れを受け継ぐ。すると §2m の機構から、**トーラスでは MPS prior が UHF のように振る舞う**はずである。4×4(16サイト、32量子ビット、ED 参照、シリンダーもトーラスも**二部格子**)で検証する。

**予想は当たり、しかも厳密な形で当たった。** 飽和が破れるかどうかは、**対称性破れと観測量の誤差の比**ひとつで決まる:

```math
r \equiv \frac{\lvert\Delta(S^z)\rvert}{\lvert\Delta_{ZZ}\rvert},
\qquad
\frac{\lvert\Delta_{ZZ}\rvert}{2D_A} = \min\left(1,\ \frac{2}{1+4r}\right)
```

導出は結果1と同じ代数を1パラメータ広げるだけである。半充填の粒子正孔対称性からサイト内 RDM の差は対角で $\delta=(u,-u+s,-u-s,u)$ の**2**パラメータになる( $s$ が $S^z$ 方向)。すると $\Delta_{ZZ}=4u$、 $D_A=\lvert u\rvert+\max(\lvert u\rvert,\lvert s\rvert)$ なので、

- $\lvert s\rvert\le\lvert u\rvert$ すなわち $r\le 1/4$ のとき $D_A=2\lvert u\rvert$ で**飽和する**
- $r>1/4$ のとき距離は $S^z$ 方向に食われ、比は $2/(1+4r)$ に落ちる

$r$ が $10^{-9}$ から 30 まで10桁にわたる**24通り(2系 × 2幾何 × 6 prior)すべてで最大誤差 0.0022**:

| 系 | 幾何 | prior | $r$ | $\lvert\Delta\rvert/(2D_A)$ 実測 | 閉形式の予測 |
|---|---|---|---|---|---|
| 4×4 | シリンダー | χ_p=8 | 0.000 | 1.0000 | 1.0000 |
| 4×4 | シリンダー | χ_p=128 | 0.000 | 1.0000 | 1.0000 |
| 4×4 | シリンダー | UHF-sym | 0.000 | 1.0000 | 1.0000 |
| 4×4 | **トーラス** | χ_p=8 | 0.192 | **1.0000** | **1.0000** |
| 4×4 | **トーラス** | χ_p=32 | 0.374 | **0.8018** | **0.8017** |
| 4×4 | **トーラス** | χ_p=128 | 0.806 | **0.4757** | **0.4735** |
| 4×4 | **トーラス** | χ=1024 | 3.730 | **0.1248** | **0.1256** |
| 4×4 | シリンダー | **UHF** | 25.63 | 0.0193 | 0.0193 |
| 4×4 | トーラス | **UHF** | 30.43 | 0.0163 | 0.0163 |

**遷移点まで当たっている。** 同じトーラス上で χ_p=8 は $r=0.192<1/4$ なので飽和し、χ_p=32 は $r=0.374>1/4$ なので破れる。 $\chi_p$ を上げるほど $\lvert\Delta_{ZZ}\rvert$ が小さくなる一方、受け継いだ破れ $\lvert\Delta(S^z)\rvert\simeq 0.02$ は下がらないので、**prior を良くするほど $r$ が上がって飽和が壊れる**。 $\chi=1024$ の「厳密」prior が $r=3.73$ で最悪になるのはそのためである。

これで **UHF とトーラス上の MPS prior が同一の軸に乗った**。両者は別種の失敗ではなく、 $r$ という一本の変数の大小にすぎない。UHF は $r\simeq 26$ という極端な場所にいるだけである。

利得予測も $r$ に従って劣化する(ZZ onsite, $n_m=100$):

| 系 | 幾何 | prior | $r$ | $G$(実測) | $G_{\rm pred}$( $D_A$ ) | 比 | $G$( $\Delta$ から) | 比 |
|---|---|---|---|---|---|---|---|---|
| 4×4 | シリンダー | χ_p=8 | 0.000 | 36.88 | 36.09 | **0.98** | 36.09 | 0.98 |

**距離から予測した列だけが $r$ とともに壊れ、 $\Delta$ から計算した列は全て 0.97–1.04 で無事である。** 壊れているのは距離→ $\Delta$ の一段だけ、という結果5の診断が定量的に確認された。

#### 訂正: 4×3 トーラスの「幾何が prior を変える」という読みは誤りだった

先に 4×3 トーラスで、台=4量子ビットの SzSz nb の corr( $\log\lvert\Delta\rvert$, $\log D_A$ )がシリンダーの $+0.81/+0.89/+0.94$ に対し $-0.07/-0.37/-0.33/-0.81$ と符号が反転することを、上の対称性破れの機構の現れとして報告した。**これは誤りである。**

**4×3 トーラスは二部格子ではない。** $L_x=3$ が奇数なので $x$ 方向に長さ3の奇環ができ、反強磁性がフラストレートする。スクリプトの自動判定([crm_2d_support.jl](crm_2d_support.jl) 414行目)は正しく `二部格子: いいえ(奇環あり)` と警告を出していたが、私がそれを読まずに結果を解釈した。§2k で一度捕まえた交絡と同じものを、同じ形で再び入れたことになる。

二部格子である 4×4 トーラスで測り直すと、SzSz nb の相関は **+0.963 / +0.835 / +0.985 / +0.993**(χ_p=4/8/32/128)と**すべて正**で、シリンダー(+0.802/+0.898/+0.987/+0.991)と区別がつかない:

| 系 | 幾何 | 二部格子 | SzSz nb の corr( $\log\lvert\Delta\rvert$, $\log D_A$ ) |
|---|---|---|---|
| 4×3 | シリンダー | はい | +0.810 / +0.889 / +0.938 / +0.806 |
| 4×3 | トーラス | **いいえ** | −0.067 / −0.369 / −0.327 / −0.812 ← フラストレーションの影響 |
| 4×4 | シリンダー | はい | +0.802 / +0.898 / +0.987 / +0.991 |
| 4×4 | トーラス | はい | **+0.963 / +0.835 / +0.985 / +0.993** |

つまり**符号反転を起こしていたのは対称性破れではなくフラストレーション**であり、周期境界そのものではない。対称性破れの効果は相関の符号ではなく、**上の飽和比 $\lvert\Delta\rvert/(2D_A)$ に現れる** — そちらは閉形式で完全に記述できる。

### 段階1のまとめ: 距離が $\Delta$ を決めるのはどの観測量か

結果1–5 はすべて **ZZ onsite**(単一 Pauli 列、台=2量子ビット)で議論した。ここで全観測量に広げ、**段階1の主張がどこまで成り立つかの境界**を確定させる。

まず論理を整理する。利得法則(元論文 式(4))は $G$ を $\Delta$ で決めており、**距離は法則に登場しない**。したがって「利得は部分系の距離に依存するか」は

> **部分系の距離は $\Delta$ を決めるか**

という問いに完全に帰着する。結果1–5 はこれに答えていた。全観測量で測る(L=16/32 全サイト、対称性を尊重する prior のみ):

| 観測量 | 型 | 台 | $\lvert\Delta\rvert/(2D_A)$ 中央 | 飽和率 | $\lvert\Delta\rvert/(2\sqrt{1-F_A})$ 中央 |
|---|---|---|---|---|---|
| ZZ onsite | **単一 Pauli 列** | 2 | **1.0000** | 79% | 0.7761 |
| ZZ up-up $r=1$ | **単一 Pauli 列** | 2 | **1.0000** | 73% | 0.7831 |
| hop up $r=1$ | 2項の和 | 3 | 0.4972 | 0% | 0.3782 |
| 二重占有 | 4項の和 | 2 | 0.2500 | 0% | 0.1979 |
| SzSz $r=1$ | 4項の和 | 4 | 0.0611 | 0% | 0.0380 |
| $n$ | 3項の和 | 2 | 0.0118 | 0% | 0.0105 |
| $S^z$ | 2項の和 | 2 | 0.0000 | 0% | 0.0000 |

**飽和するのは単一 Pauli 列だけである。** 和の観測量では上界が 2倍から 85倍緩む。理由は準備4b の符号パターン一致で説明できる: 和 $O=\sum_ic_iP_i$ では各項の寄与が打ち消し合うので、 $O$ の「符号パターン」が $X$ のそれと揃いようがない。

いくつかは閉じた形で分かる:

- **二重占有がちょうど $1/4$ になる理由**: $n_\uparrow n_\downarrow=(I-Z_a-Z_b+Z_aZ_b)/4$ で、半充填では $\langle Z_a\rangle=\langle Z_b\rangle=0$ が $\rho$ でも $\sigma$ でも成り立つので $\Delta(\text{二重占有})=\Delta_{ZZ}/4$ 。 $D_A=\lvert\Delta_{ZZ}\rvert/2$ と合わせて比はちょうど $1/4$ 。
- **$S^z$ がちょうど $0$ になる理由**: 対称性を尊重する prior では $\Delta(S^z)=0$ が厳密(§2g)。距離は有限なので比は $0$ 。

**これは枠組みの境界と一致している。** 利得法則そのものが単一 Pauli 列でのみ厳密なので(和の観測量では交差項が残る)、距離が $\Delta$ を決めるのも同じ範囲に限られる。

#### 段階1の結論

**利得は部分系のトレース距離に依存する。ただし正確には次の形である。**

```math
G=G(\Delta),\qquad
\lvert\Delta\rvert\le 2D_A\ \text{(常に)},\qquad
\lvert\Delta\rvert=2D_A\ \text{(単一 Pauli 列 + 半充填 + }r\le1/4)
```

- **常に成り立つこと**: $D_A$ は台の上の全観測量に対する $\lvert\Delta\rvert$ の**上界**(準備4b 理由1、双対ノルム)
- **厳密になる条件**: 単一 Pauli 列、半充填、 $r=\lvert\Delta(S^z)\rvert/\lvert\Delta_P\rvert\le1/4$ 。外れると $\min(1,2/(1+4r))$ で連続的に緩む(結果5、24点で最大誤差 0.0022)
- **忠実度は同じ役割を果たせない**: 上界としても緩く(0.78 対 1.0000)、次数が違う(2次 対 1次、準備4b 理由3)

### 段階2: 有限のデータで prior を選べるか(数値実験)

### 誤りが起こる理由 — 「大きさ」だけでは「向き」が分からない

段階2で「距離と忠実度は、データを無限に増やしても順位相関 0.786 で頭打ちになる」という結果が出た。ここまで「距離が対称性の破れに食われる」と書いてきたが、これは説明として粗い。**具体的な数で書き下すと、理由は一行で終わる。** そして新しい失敗様式を予言し、それが当たる。

#### まず、日常のたとえ

「駅から5 km 歩いた」と言われたとき、**北にどれだけ進んだか**は分かるだろうか。分からない。真北に歩けば 5 km、真東に歩けば 0 km で、その間のどこでもありうる。**「5 km」は距離であって、向きの情報を含んでいない。**

本節の2つの量はちょうどこの関係にある:

| | たとえ | 本節 |
|---|---|---|
| 分かっているもの | 歩いた距離 5 km | トレース距離 $D_A$ |
| 知りたいもの | 北に何 km 進んだか | 観測量の誤差 $\Delta_P$ |
| 言えること | $0$ 〜 $5$ km のどこか | $0\le\lvert\Delta_P\rvert\le2D_A$ |

上界 $\lvert\Delta_P\rvert\le2D_A$ (準備3)は「北に進んだ距離は総移動距離を超えない」と言っているだけである。**距離が向きを教えてくれないのは、当たり前のことだった。**

#### 準備: サイト1つの状態は「4つの数」で表せる

抽象的な話にしないために、具体的な数で見ていく。まずその「4つの数」が何なのかを説明する。

**(a) サイト1つに起こりうることは4通りしかない。** Hubbard 模型の1サイトには上向き電子と下向き電子が入りうるが、Pauli の排他律により**同じスピンは1個まで**である。したがって起こりうる配置は:

| 配置 | 記号 | 電子数 |
|---|---|---|
| 空 | $\lvert0\rangle$ | 0 |
| 上向き1個 | $\lvert\uparrow\rangle$ | 1 |
| 下向き1個 | $\lvert\downarrow\rangle$ | 1 |
| 二重占有 | $\lvert\uparrow\downarrow\rangle$ | 2 |

の**4通り**である。

**(b) そのサイトだけを見るとき、言えるのは各配置の確率である。** 鎖の残りを見ないことにする(= 縮約する、準備4d)と、このサイトについて言えるのは「空である確率」「↑ である確率」…の4つだけになる。合計は当然 1 である。これが縮約密度行列 $\rho_A$ の対角成分である。

> **なぜ確率4つだけで済むのか(対角になる理由)。** 一般には異なる配置の「重ね合わせ」を表す非対角成分もありうる。しかし全体の電子数と $S^z$ が確定している状態では、たとえば $\lvert0\rangle$ と $\lvert\uparrow\rangle$ の重ね合わせは残らない。このサイトの電子が1個増えれば鎖の残りが1個減るので、環境側が「どちらだったか」を覚えており、干渉が消えるからである。本節で扱う状態はすべてこれに当てはまるので、4つの確率で完全に決まる。

**(c) 実データ。** L=16、 $U=4$ 半充填、site 2 の真の状態(参照は DMRG $\chi=256$ ):

| | 空 | ↑ | ↓ | 二重占有 |
|---|---|---|---|---|
| $\rho_A$ | 0.099246 | 0.400754 | 0.400754 | 0.099246 |

物理的に読める。 $U=4$ は斥力が運動エネルギーより強いので**二重占有は損**で、確率は 0.099 しかない。ほとんど(0.400754 + 0.400754 = 0.80)は1個だけ入った状態で、↑ と ↓ が完全に対等である(これがスピン対称性)。空も 0.099 で、二重占有と同じ値である(これが半充填の粒子正孔対称性)。**Mott 絶縁体の姿がそのまま出ている。**

#### 誤差 $X$ とは何か、なぜ合計が 0 になるのか

prior $\sigma_A$ も同じ4つの数で表せる。その差を誤差と呼ぶ:

```math
X=\rho_A-\sigma_A\qquad(\text{4つの数})
```

$\chi_p=4$ の MPS prior で実際に引き算すると:

| | 空 | ↑ | ↓ | 二重占有 | 合計 |
|---|---|---|---|---|---|
| $\rho_A$ (真) | 0.099246 | 0.400754 | 0.400754 | 0.099246 | 1 |
| $\sigma_A$ (prior) | 0.090232 | 0.409768 | 0.409768 | 0.090232 | 1 |
| **$X$ (誤差)** | **+0.009014** | **−0.009014** | **−0.009014** | **+0.009014** | **0** |

**合計が 0 になるのは、どちらも確率で合計が 1 だからである**( $1-1=0$ )。物理的には確率の保存で、**prior が二重占有を少なめに見積もったなら、その分をどこか別の配置に置いているはずだ**という当たり前のことである。実際この prior は二重占有と空を 0.009 少なく、その分を ↑ と ↓ に 0.009 ずつ多く置いている。

**誤差は必ず「どこかから、どこかへ」という形をしている。** この見方が後で決定的になる。

#### 観測量とは「4つの配置に数を割り当てるもの」

次に観測量の側を用意する。**観測量とは、4つの配置それぞれに数を割り当てる規則**である。そして期待値は、その数を確率で重みづけした平均である:

```math
\langle O\rangle=\sum_{i\in\{空,\uparrow,\downarrow,二重\}} O_i\,\rho_i
```

本節に出てくる観測量を並べる:

| 観測量 | 空 | ↑ | ↓ | 二重占有 | $\langle O\rangle_\rho$ |
|---|---|---|---|---|---|
| 二重占有 $n_\uparrow n_\downarrow$ | 0 | 0 | 0 | **1** | 0.099246 |
| 電子数 $n$ | 0 | 1 | 1 | **2** | 1.000000 |
| $S^z$ | 0 | $+\tfrac12$ | $-\tfrac12$ | 0 | 0.000000 |
| **$Z\otimes Z$** | **+1** | **−1** | **−1** | **+1** | **−0.603016** |

たとえば二重占有の期待値は $0\cdot0.099+0\cdot0.401+0\cdot0.401+1\cdot0.099=0.099246$ で、素直に「二重占有である確率」になる。 $\langle n\rangle=1$ はちょうど半充填、 $\langle S^z\rangle=0$ は ↑ と ↓ が対等であることを表している。

#### $Z\otimes Z$ の符号 $(+,-,-,+)$ はどこから来るのか

これが分かりにくいところなので丁寧に述べる。ランダム測定の枠組みは量子ビットで書かれているので、**電子のモード1つを量子ビット1つに対応させる**(Jordan–Wigner 変換、§0)。サイト1つには上向きモードと下向きモードがあるので**量子ビット2つ**になり、それぞれ

```math
\lvert0\rangle_{\text{qubit}}=\text{そのモードは空き},\qquad
\lvert1\rangle_{\text{qubit}}=\text{そのモードは占有}
```

と読む。Pauli 行列 $Z$ は $Z\lvert0\rangle=+\lvert0\rangle$ 、 $Z\lvert1\rangle=-\lvert1\rangle$ なので、**空きなら $+1$ 、占有なら $-1$** を返す。そこで4つの配置について $Z_a$ (上向きモード)と $Z_b$ (下向きモード)の値を書き出すと:

| 配置 | 上向きモード | $Z_a$ | 下向きモード | $Z_b$ | $Z_a Z_b$ |
|---|---|---|---|---|---|
| 空 | 空き | $+1$ | 空き | $+1$ | **$+1$** |
| ↑ | 占有 | $-1$ | 空き | $+1$ | **$-1$** |
| ↓ | 空き | $+1$ | 占有 | $-1$ | **$-1$** |
| 二重占有 | 占有 | $-1$ | 占有 | $-1$ | **$+1$** |

**これが $(+1,-1,-1,+1)$ の出どころである。** 意味も読める: $Z_aZ_b$ は**2つのモードの状態が一致しているか**を測っている( $+1$ = 両方空きか両方占有、 $-1$ = 片方だけ占有)。

さらに $Z_a=1-2n_\uparrow$ 、 $Z_b=1-2n_\downarrow$ を掛け合わせると

```math
Z_aZ_b=1-2n+4\,n_\uparrow n_\downarrow
```

半充填では $\langle n\rangle=1$ なので $\langle Z_aZ_b\rangle=4\langle n_\uparrow n_\downarrow\rangle-1$ 、実データで検算すると $4\times0.099246-1=-0.603016$ で表の値と一致する。**つまり $ZZ$ は二重占有の言い換えにすぎない。** 「 $ZZ$ を測る」とは「二重占有を測る」ことであり、これが本節を通じて $ZZ$ を主役に据えている理由である。

#### 作り方の違い(1): $\Delta$ は「符号つきで足す」

$\Delta$ は、同じ加重平均を $\rho$ と $\sigma$ でとった差である:

```math
\Delta_{ZZ}=\langle ZZ\rangle_\rho-\langle ZZ\rangle_\sigma
=\sum_i (ZZ)_i\,\rho_i-\sum_i (ZZ)_i\,\sigma_i
=\sum_i (ZZ)_i\,X_i
```

つまり**誤差 $X$ に $ZZ$ の符号を掛けて足す**。 $\chi_p=4$ で1項ずつ書くと:

```math
\Delta_{ZZ}=\underbrace{(+1)(+0.009014)}_{空}
+\underbrace{(-1)(-0.009014)}_{\uparrow}
+\underbrace{(-1)(-0.009014)}_{\downarrow}
+\underbrace{(+1)(+0.009014)}_{二重}
=+0.036056
```

この prior では4項すべてが $+$ で揃っている。**誤差の符号 $(+,-,-,+)$ が $ZZ$ の符号 $(+,-,-,+)$ とぴったり同じだからである。**

#### 作り方の違い(2): $D_A$ は「動かすべき確率の量」

トレース距離は絶対値で足して半分にする:

```math
D_A=\tfrac12\sum_i\lvert X_i\rvert
```

**なぜ絶対値なのか。** トレース距離が答えたい問いは「2つの状態はどれくらい見分けられるか」(準備2、準備4b 理由2)である。どの配置での食い違いも、向きに関係なく見分けやすさに寄与するので、すべて正で数える。

**なぜ $\tfrac12$ なのか。** $X$ の合計は 0 なので、**正の部分の総和と負の部分の総和は必ず等しい**。したがって $\sum_i\lvert X_i\rvert$ は同じ量を2回数えている(出ていく分と入ってくる分)。半分にすると

> $D_A$ = **prior の確率分布を真の分布に直すために、動かさなければならない確率の量**

という意味になる。 $\chi_p=4$ では、空と二重占有に $+0.009014$ ずつ($+$ 側で合計 $0.018028$)、↑ と ↓ に $-0.009014$ ずつ($-$ 側で合計 $-0.018028$)なので、**0.018028 だけ確率を動かせばよい**。実際 $D_A=\tfrac12(0.009014\times4)=0.018028$ である。

#### 決定的な違い: $ZZ$ は ↑ と ↓ を区別しない

ここが本題である。 $ZZ$ の割り当てをもう一度見る:

| 配置 | 空 | ↑ | ↓ | 二重占有 |
|---|---|---|---|---|
| $ZZ$ の値 | $+1$ | **$-1$** | **$-1$** | $+1$ |

**↑ と ↓ に同じ $-1$ が割り当てられている。** これは当然で、 $ZZ$ が測っているのは二重占有(= 電子が2個か0個か1個か)であって、1個のときにそれが上向きか下向きかには何の関心もないからである。

したがって:

> **↑ と ↓ の間で確率を移すだけの誤差は、 $ZZ$ にはまったく見えない。**

なぜなら移した分は $(-1)\times(-t)+(-1)\times(+t)=0$ と厳密に打ち消し合うからである。ところが $D_A$ は絶対値で足すので、この移動を**丸ごと数えてしまう**。

**これが「片方は打ち消し合いを許し、片方は許さない」の意味である。**

#### UHF の誤差を2つに分ける

UHF はまさにこの状況にいる。同じ site の UHF prior:

| | 空 | ↑ | ↓ | 二重占有 |
|---|---|---|---|---|
| $\sigma_A$ (UHF) | 0.104691 | **0.776464** | **0.014154** | 0.104691 |
| **$X$ (誤差)** | −0.005445 | **−0.375710** | **+0.386600** | −0.005445 |

UHF は「このサイトのスピンは上向きだ」と決めつけている(↑ が 0.776、↓ が 0.014)。真の状態は上下対等(どちらも 0.401)なので、誤差の大半は **↓ から ↑ へ確率を 0.38 も動かしてしまった分**である。

そこで誤差を「↑↔↓ の移動」と「残り」に厳密に分解する:

| | 空 | ↑ | ↓ | 二重占有 | $ZZ$ の誤差 | 大きさ $\tfrac12\sum\lvert\cdot\rvert$ |
|---|---|---|---|---|---|---|
| **↑↔↓ の移動** | 0 | −0.381155 | +0.381155 | 0 | **0.000000** | **0.381155** |
| **残り** | −0.005445 | +0.005445 | +0.005445 | −0.005445 | **−0.021780** | 0.010890 |
| 合計( $=X$ ) | −0.005445 | −0.375710 | +0.386600 | −0.005445 | −0.021780 | 0.386600 |

**移動部分の $ZZ$ 誤差は厳密にゼロである。** $ZZ$ から見れば、UHF がスピンの向きをどれだけ間違えていても関係ない。 $\Delta_{ZZ}=-0.021780$ は全部「残り」から来ている。

一方 $D_A$ から見ると:

```math
D_A=0.386600\ \text{のうち}\ \mathbf{0.381155\ (98.6\%)}\ \text{が}\ ZZ\ \text{には見えない成分}
```

**距離の 98.6% が、測りたい観測量とは無関係な誤差である。** これが $D_A$ が $\Delta$ の35倍を主張し、利得を 48.57 対 0.61 と80倍も過小評価する理由である。

> **一言でまとめると。** UHF が間違えているのは「**スピンが上か下か**」で、 $ZZ$ が測っているのは「**電子が何個いるか**」である。別の量なので $ZZ$ は間違いに気づかない。ところがトレース距離は「どんな食い違いも食い違い」として数えるので、両方を等しく計上してしまう。**距離には「どの観測量を測りたいのか」という情報が入っていない**からである。

#### 同じ距離でも $\Delta$ は自由に動く

念のため、 $D_A$ を $0.100$ に固定したまま $\Delta$ が動くことを見ておく:

| $X=($ 空, ↑, ↓, 二重 $)$ | $D_A$ | $\Delta_{ZZ}$ | 比 |
|---|---|---|---|
| $(+0.050,\ -0.050,\ -0.050,\ +0.050)$ | 0.100 | 0.200 | **1.000** |
| $(+0.025,\ +0.050,\ -0.100,\ +0.025)$ | 0.100 | 0.100 | 0.500 |
| $(\ \ 0.000,\ +0.100,\ -0.100,\ \ \ 0.000)$ | 0.100 | **0.000** | **0.000** |

**距離が同じ 0.100 でも、 $\Delta$ は 0.200 から 0 まで何でもありうる。** 最後の行は「スピンの向きだけを間違えていて、二重占有は完全に正しい」prior で、 $ZZ$ の誤差はゼロなのに距離は 0.100 ある。UHF はこれに近い状況にいる。

#### では結果1ではなぜ一致したのか

飽和は**距離の性質ではなかった**。半充填では次の3つの拘束がかかる:

1. 確率の合計が 1 → $X$ の合計は 0
2. スピン対称( $\langle S^z\rangle=0$ )→ ↑ と ↓ の値が等しい
3. 粒子正孔対称(半充填)→ 空 と 二重占有 の値が等しい

これで4つの数のうち**自由なのは1つだけ**になり、 $X$ は必ず $(u,-u,-u,u)$ の形をとる。これは $ZZ$ の符号 $(+,-,-,+)$ とぴったり同じ向きなので、打ち消し合いようがない。

> **つまり「誤差の向きが1通りしかない」ように拘束されていたから一致していた。** 拘束が外れれば向きは自由になり、一致は失われる。UHF は拘束2を破り、次に見るようにドーピングは拘束3を破る。

#### 角度で言い直す

「向きが揃っているか」は角度で測れる。2つのベクトルの向きの近さを表す量が

```math
\cos\theta=\frac{\text{2つのベクトルの内積}}{\text{それぞれの長さの積}}
```

で、 $\cos\theta=1$ なら**同じ向き**、 $\cos\theta=0$ なら**直角(全く別の方向)**である。誤差 $X$ と観測量 $ZZ$ の間で測ると:

| prior | $\cos\theta$ | 角度 $\theta$ | $\lvert\Delta\rvert/(2D_A)$ | 真の $G$ | $D_A$ からの予測 |
|---|---|---|---|---|---|
| χ_p=2 〜 χ_p=32 | **1.0000** | **0.00°** | 1.0000 | — | 正しい |
| UHF-sym | **1.0000** | **0.00°** | 1.0000 | 48.57 | 48.57 |
| **UHF** | **0.0202** | **88.84°** | 0.0282 | **48.57** | **0.61** |

**UHF の誤差は、測りたい観測量からほぼ直角の方向を向いている。** 距離は角度を見ないので、この「関係ない方向の誤差」を「観測量の誤差」として数え上げてしまう。80倍の過小評価はここから出ている。

#### 汚染される向きは2つある — まとめの式

4つの数のうち自由なのは3つ(合計が0という拘束が1つ)なので、誤差の向きは3方向に分けられる:

| 方向 | 意味 | いつ開くか |
|---|---|---|
| $ZZ$ 方向 | 二重占有のずれ = **知りたい誤差** | — |
| **スピン方向** | ↑ と ↓ の非対称 | prior が**スピン対称性を破る**とき(UHF) |
| **粒子数方向** | 空 と 二重占有 の非対称 | **ドープ**したとき(粒子正孔対称性が破れる) |

汚染の強さを、知りたい誤差との比で測る:

```math
\sigma=\frac{4\lvert\Delta(S^z)\rvert}{\lvert\Delta_{ZZ}\rvert}\ \ (\text{スピン方向}),
\qquad
m=\frac{2\lvert\Delta(n)\rvert}{\lvert\Delta_{ZZ}\rvert}\ \ (\text{粒子数方向})
```

すると比は完全に決まる:

```math
\boxed{\ \frac{\lvert\Delta_{ZZ}\rvert}{2D_A}=\frac{2}{\max(1,m)+\max(1,\sigma)}\ }
```

$\max(1,\cdot)$ の意味は素直である。**汚染が知りたい誤差より小さいうちは何も起きず( $1$ のまま)、追い越して初めて効き始める。** 両方とも小さければ $2/(1+1)=1$ 、つまり飽和する。結果5で見つけた $\min(1,2/(1+4r))$ は、この式の $m=0$ の場合である。

全588点(2ドーピング × 7 prior × 全サイト)で検定する:

| ドープ | prior | $m$ | $\sigma$ | 実測 | 式の予測 | 誤差 |
|---|---|---|---|---|---|---|
| 0 | χ_p=4 | 0.000 | 0.000 | 1.0000 | 1.0000 | 3.1e−15 |
| 0 | **UHF** | 0.000 | **197.9** | **0.0101** | **0.0101** | 7.6e−17 |
| 0 | UHF-sym | 0.000 | 0.000 | 1.0000 | 1.0000 | 6.0e−14 |
| 1/8 | χ_p=8 | 0.649 | 0.297 | 1.0000 | 1.0000 | 5.6e−12 |
| 1/8 | **χ_p=16** | **1.097** | 0.893 | **0.8509** | **0.8509** | 3.1e−08 |
| 1/8 | **χ_p=32** | **1.395** | 0.674 | **0.7794** | **0.7794** | 9.9e−10 |

**全588点で最大誤差 $3.1\times10^{-8}$ 、中央値は機械精度である。**

#### 予言と検証: ドープすれば、対称性を破らなくても壊れる

この見方は**対称性の破れとは無関係な失敗**を予言する。半充填では粒子正孔対称性が「空 と 二重占有 の確率が等しい」を強制するので $m=0$ だった。**ドープすると電子の数が変わるのでこれが崩れ、 $m$ が開く。** したがって**スピン対称性をきちんと保っている MPS prior でも、ドープすれば飽和が壊れるはず**である。

| ドーピング | prior | $\lvert\Delta\rvert/(2D_A)$ 中央 | 飽和率 |
|---|---|---|---|
| 0(半充填) | χ_p=4 〜 χ_p=32 | 1.0000 | **100%** |
| **1/8** | χ_p=4 | 1.0000 | 67% |
| **1/8** | χ_p=8 | 1.0000 | 81% |
| **1/8** | χ_p=16 | **0.8509** | **36%** |
| **1/8** | χ_p=32 | **0.7794** | **31%** |

機構も直接見える。粒子数方向の誤差は半充填では**厳密にゼロ**なのに、ドープで開く:

| ドーピング | prior | $\lvert\Delta(n)\rvert$ | $\lvert\Delta(ZZ)\rvert$ |
|---|---|---|---|
| 0 | χ_p=4 | $3.7\times10^{-10}$ | $1.5\times10^{-1}$ |
| 1/8 | χ_p=4 | $1.2\times10^{-2}$ | $8.6\times10^{-2}$ |

**予言が当たった。** 対称性の破れとは別の機構なので、「距離は関係ない方向の誤差まで数える」という見方が正しいことの**独立な確認**になっている。

#### なぜ「prior を良くするほど予測が悪くなる」のか

$m$ と $\sigma$ の**分母が $\lvert\Delta_{ZZ}\rvert$ である**ことが効く。 $\chi_p$ を上げると知りたい方向の誤差 $\lvert\Delta_{ZZ}\rvert$ は小さくなるが、粒子数方向・スピン方向の誤差は同じ速さでは減らない。**分子が残ったまま分母だけ小さくなるので、比は上がる:**

```
ドープ δ=1/8:   χ_p=8 → m=0.649     χ_p=16 → m=1.097     χ_p=32 → m=1.395
```

結果5でトーラス上の MPS prior に見たのと同じ現象で、そこでは $\sigma$ が、ここでは $m$ が上がっている。**prior を精密にするほど、残った誤差は「観測量に対して斜め」になっていく。**

#### なぜ選定という文脈で致命的になるのか

3つ重なる。

**(1) 系統的である。** $m$ と $\sigma$ は prior の性質であって、測定データの量とは無関係である。だから測定を増やしても順位相関は 0.786 で止まる(段階2)。

**(2) 最も安い prior を狙い撃ちにする。** これが偶然でないことが重要である。**平均場が対称性を破るのは、それが局所的な物理を正しく捉えるための手段だからである** — Slater 行列式(平均場の波動関数)は「各サイトに局所モーメントがあるが全体としては一重項」という状態を表せない。そこで UHF はスピン対称性を破ることで局所的な正しさを買う。つまり**「安くて局所観測量に効く prior」と「対称性を破る prior」は同じものを指しており、距離ベースの判定はそこを狙い撃ちで棄却する。**

**(3) 中央値が隠す。** 選定は $\arg\max$ 、つまり**裾に敏感な操作**である。ところが誤差の中央値で評価すると、7つのうち6つが当たっているので 1.2% に見えてしまう。**平均的な精度で評価している限り、この失敗は見えない。** 段階2で決定問題として測るまで気づかなかったのはこのためである。

#### 対処できるか

- **スピン方向( $\sigma$ )は消せる。** 群平均(§2j)を当てれば $\Delta(S^z)\to0$ になり、コストは0である。表のとおり UHF-sym は正しい予測を与える。**距離ベースの診断を使うなら、群平均は前処理として必須である。**
- **粒子数方向( $m$ )は消せない。** 粒子数は物理量であって、平均を取って消すべき「破れ」ではない。**ドープ系では距離ベースの診断は原理的に使えない。**
- したがって結局、**選定には $\Delta$ を直接測るのが正しい**。 $\Delta$ は「知りたい1方向への成分」そのものなので、そもそも角度の問題が生じない。

#### 段階2の結論

**prior の選定には $\Delta$ を直接推定する。距離や忠実度を経由してはいけない。**

理由は3つあり、いずれも準備4e・4f で見た通りである:

1. **$\hat\Delta$ が最も安い** — Pauli 期待値ひとつ、線形、不偏(準備4e)
2. **$\hat D_A$ 、 $\hat F_A$ は正に偏る** — ノルムなのでノイズが足し込まれ、prior が良いほど相対的に悪化(準備4f)
3. **そして本質的に、両者は系統的に誤る** — 対称性を破る安い prior を、それが実際に働くときに棄却する(上の結果1)

**では段階1の結果に実用上の意味はないのか。** ある。ただし選定の道具としてではない:

- **最悪値の証明書**: $D_A$ は台の上の**全観測量**に対する $\lvert\Delta\rvert$ の上界である。個別の観測量では $\Delta$ に負けるが、「この台のどんな観測量でも利得は $X$ 以上」という保証は $D_A$ にしか作れない
- **prior クラスの事前判定**: $r\le1/4$ の分子 $\Delta(S^z)$ は prior 側だけで計算でき、測定が要らない。**破れているなら群平均を当てる**(§2j、コスト0)という処方は、距離を測らずに実行できる
- **説明**: なぜ UHF が効いて χ_p=2 が効かないのかを、 $r$ という1つの変数で説明する(結果5)

### 結論

**仮説「局所観測量には部分系の忠実度が効く」は正しい。ただし2つの条件が付く。**

| 条件 | 満たすとき | 満たさないとき |
|---|---|---|
| **部分系を観測量の台そのものにする** | 単一Pauli列で上界が飽和(半充填の86%) | 台より大きく取ると10〜20倍緩く見える |
| **prior が $\rho$ の対称性を尊重する**、定量的には $r=\lvert\Delta(S^z)\rvert/\lvert\Delta_P\rvert\le 1/4$ | 相関 0.74–0.999、 $D_{\text{台}}=\lvert\Delta\rvert/2$ が恒等式 | 距離が対称性破れに食われ、比は $\min(1,2/(1+4r))$ に落ちる(24点で最大誤差 0.0022) |

> **最初の報告(「部分系の忠実度でも決まらない」)は誤りだった。** 決まらないように見えたのは私の測り方のせいで、(i) 台より大きい部分系を使い、(ii) prior を横断して相関を取った、の2点である。両方を直すと仮説は支持される。
>
> **§2 の主張は損なわれない。** 「 $\Delta$ が利得を決める」ことは変わらない。新しく分かったのは「**その $\Delta$ は、対称性を尊重する prior に限れば、台のトレース距離から読める**」という追加の構造である。大域忠実度が使えないのは変わらず、使えるのは**台まで絞ったとき**だけである。
>
> **実務上の使い方**(手順2が $\rho_A$ を要求する点について、前提と限界を**準備4e**で訂正した。実験対象そのものには使えない):
> 1. prior が $\rho$ の対称性を尊重しているか確認する。破っていれば先に群平均を当てる(§2j、測定コストゼロ)
> 2. 測りたい観測量の**台だけ**に縮約した $\rho_A,\sigma_A$ を作る
> 3. $D_{\rm tr}(\rho_A,\sigma_A)$ を1回計算すれば、単一Pauli列なら $\lvert\Delta\rvert=2D_{\rm tr}$ が(半充填では)厳密に得られる
>
> これで**観測量ごとに $\Delta$ を計算し直す必要がなくなる** — ただし台が同じ観測量に限る。
