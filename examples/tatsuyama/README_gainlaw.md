## 結論

**288点すべてで法則と一致した。** 実測 / 法則の比は中央値ちょうど $1.0000$ 、範囲 $[0.905, 1.101]$ 、 $\lvert$ 比 $-1\rvert$ の95パーセンタイルが $0.059$ である。分散比を反復3000回で推定したときの統計誤差が約 $0.037$ なので、**ずれは統計誤差の範囲**である。15%以上外れた点はゼロだった。

これで §10 の全結果 — 大域忠実度が2万倍崩れても利得が動かないこと、1次元では平均場が MPS に追いつかないこと — が、**法則の当てはめではなく実際の測定過程に基づく**ものとして裏付けられた。

---

## 方法: $\langle P\rangle$ だけでシャドウ測定を厳密に模擬できる

128量子ビットの状態を扱う必要はない。**単一 Pauli 列に限れば、必要なのは $\langle P\rangle$ ひとつである。**

固有値 $\pm1$ の Pauli 列 $P=\bigotimes_{q\in A}P_q$ を局所ランダム測定で推定するとき、設定 $u$ での推定値は

```math
X(b,u)=3^{\lvert A\rvert}\Bigl(\prod_{q\in A}s_q\Bigr)\mathbf 1[\text{基底が }A\text{ 上で全一致}]
```

である(§0.5 の導出)。ここで積 $\prod_q s_q$ は $\pm1$ しか取らず、基底が一致した設定では**その期待値がちょうど $\langle P\rangle$** になる。設定内の $n_m$ ショットは独立同分布なので、

> **基底一致時のショットは「平均 $\langle P\rangle$ の $\pm1$ ベルヌーイ試行」に完全に等しい。**

したがって $\langle P\rangle_\rho$ と $\langle P\rangle_\sigma$ さえあれば、標準シャドウと CRM シャドウの推定値を厳密にサンプリングできる。ED も縮約密度行列も要らない。統合表が持っている `true` と `Delta` だけで足りる。

この単純化は**単一 Pauli 列だからこそ成り立つ**。和の観測量では各項の相関が効くので、この方法は使えない(そもそも利得法則自体が単一 Pauli 列でのみ厳密である)。

### 検証範囲

| 項目 | 値 |
|---|---|
| 系 | 1D OBC $L=16, 32, 64$(32 / 64 / **128量子ビット**) |
| $U$ | 2, 4, 8, 12 |
| prior | $\chi_p=2, 8, 32$ と UHF |
| 観測量 | ZZ onsite, ZZ up-up nb(利得法則が厳密な2種) |
| $n_m$ | 1, 10, 100 |
| 測定設定数 | $n_u=400$ |
| 反復 | 3000 |

$3\times4\times4\times2\times3=288$ 点。参照 $\rho$ はすべてエネルギー分散で厳密性を確認済みの状態である。

## 結果

### 128量子ビットでの一致( $n_m=100$ )

| $U$ | 観測量 | prior | $G$(法則) | $G$(実測) | 比 |
|---|---|---|---|---|---|
| 4 | ZZ onsite | χ_p=2 | 2.18 | 2.18 | 1.002 |
| 4 | ZZ onsite | χ_p=32 | 50.74 | 49.71 | 0.980 |
| 4 | ZZ onsite | **UHF** | **50.33** | **50.94** | **1.012** |
| 8 | ZZ onsite | χ_p=8 | 238.00 | 248.30 | 1.043 |
| 8 | ZZ onsite | **UHF** | **192.06** | **191.11** | **0.995** |
| 8 | ZZ up-up | UHF | 1.43 | 1.44 | 1.009 |
| 12 | ZZ onsite | χ_p=32 | 559.01 | 542.06 | 0.970 |
| 12 | ZZ onsite | **UHF** | **472.33** | **482.35** | **1.021** |
| 12 | ZZ up-up | χ_p=32 | 35.07 | 36.04 | 1.028 |

利得が $1.00$ から $559$ まで**2.7桁**にわたる範囲で、比はすべて $0.95$– $1.04$ に収まっている。

### 全288点

```
実測 / 法則:  中央値 1.0000   範囲 [0.905, 1.101]
|比 − 1| の 95 パーセンタイル: 0.059
統計誤差(反復3000回の分散比): 約 0.037
15% 以上ずれた点: 0 / 288
```

**中央値がちょうど 1.0000 である**ことが重要で、系統的な偏りがない。ばらつきの 0.059 は統計誤差 0.037 と同程度で、反復回数を増やせば縮む種類のものである。

### 損の側でも一致する

利得法則は $G<1$(CRM が標準シャドウに負ける)場合も予言する。 $U=8$ 、 $L=64$ の ZZ up-up で UHF は法則値 $1.43$ に対し実測 $1.44$ 、 $U=12$ では $1.38$ 対 $1.38$ である。**得の側だけでなく、損に近い側でも当たっている。**

χ_p=2 の ZZ up-up が全ての $U$ ・ $L$ で法則値 $1.00$ ちょうど・実測も $1.00$ になるのは、この prior が隣接サイト間の相関を全く持たない( $\Delta=\lvert\langle P\rangle\rvert$ 、すなわち $\varepsilon=1$ )ためで、§10 で見た損益分岐点の実例である。

## この検証で確定したこと

1. **利得法則は128量子ビットでも成り立つ。** §1 の検証は8量子ビット1系だったので、16倍の系サイズ・4つの $U$ ・4種の prior に広がった。
2. **§10 の結論は法則の当てはめの産物ではない。** 「大域忠実度が2万倍崩れても利得は2%しか動かない」「1次元では $L$ を8倍にしても平均場は MPS に追いつかない」といった結果は、実際の測定過程からも同じように出る。
3. **単一 Pauli 列の局所観測量なら、系サイズに関わらず $\langle P\rangle$ ひとつで測定を模擬できる。** これは検証の道具としてだけでなく、実験計画(必要なショット数の見積もり)にもそのまま使える。

## 残っている検証

**和の観測量。** 利得法則は単一 Pauli 列でのみ厳密なので、二重占有・SzSz・SxSx などについては §10 でも $G$ を `n/a` にしている。これらの実測利得を得るには各項の相関を含めた完全な RDM が要り、この方法では模擬できない。§2b では実測しているので、そちらとの接続が残っている。

**2次元。** ここは1次元のみである。 $W\ge4$ では厳密な $\rho$ 自体が作れない(§10)ので、DMRG 参照での確認になる。
