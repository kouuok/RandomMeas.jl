## この文書で分かること

- §10 の総当たりで報告した利得 $G$ は、すべて式から計算した値で、測定を模擬して数えた値ではない。この文書では、その式の値と、測定の過程を実際に模擬して得た値が一致することを、16〜128量子ビットの 288 点で確かめる。
- 288 点すべてで、両者の差は模擬の統計誤差の範囲に収まった。
- なぜ 128量子ビットの状態を直接扱わずに模擬できるのかも、途中を省かずに説明する。

## 前提: この文書の「利得の式」は何か

**利得の式は新しい法則ではない。** 元論文(Vermersch ら, PRX Quantum **5**, 010352 (2024))は、1つのパウリ文字列を CRM シャドウで推定したときの分散を厳密な等式で与えている(arXiv 版の付録 B.1 の式(25)、PRX Quantum 版の付録 C.1 の式(C7))。この研究の「利得の式」は、その分散を「標準の古典シャドウ」と「CRM シャドウ」の2つについて書き、比を取ったものである([README_crm_paper.md](README_crm_paper.md))。

したがって、この文書が確かめるのは式そのものの正しさではない。確かめるのは次の2点である。

1. §10 の表の数値が、式に正しい値を入れて計算されていること(実装の確認)。
2. 式が前提としている測定の手順(基底を選び、ショットを測り、平均する)を模擬すると、式どおりの分散比が実際に出ること。

## 1. 記号と利得の式

| 記号 | 意味 |
|---|---|
| $P$ | 推定したいパウリ文字列。固有値は $\pm1$ |
| $A$ 、 $\lvert A\rvert$ | $P$ が恒等でない量子ビットの集合(台)と、その個数 |
| $\rho$ | 測定する状態(この研究では DMRG または厳密対角化で作った基底状態) |
| $\sigma$ | prior(古典計算で作った近似状態) |
| $x=\langle P\rangle_\rho$ | 真の値 |
| $y=\langle P\rangle_\sigma$ | prior の値 |
| $\Delta=x-y$ | prior の外れ |
| $n_u$ | 測定の設定(ランダムに選んだ基底の組)の数 |
| $n_m$ | 1つの設定で測るショット数 |

1つの設定について、標準の推定量と CRM の推定量の分散は(元論文の式(25) [PRX: (C7)])

```math
n_u\,\mathrm{Var}[\text{標準}]=(3^{\lvert A\rvert}-1)\,x^2+\frac{3^{\lvert A\rvert}(1-x^2)}{n_m},\qquad
n_u\,\mathrm{Var}[\text{CRM}]=(3^{\lvert A\rvert}-1)\,\Delta^2+\frac{3^{\lvert A\rvert}(1-x^2)}{n_m}
```

である。利得はこの比で、

```math
G=\frac{\mathrm{Var}[\text{標準}]}{\mathrm{Var}[\text{CRM}]}=\frac{(3^{\lvert A\rvert}-1)x^2+v_s}{(3^{\lvert A\rvert}-1)\Delta^2+v_s},\qquad v_s=\frac{3^{\lvert A\rvert}(1-x^2)}{n_m}
```

となる。 $n_u$ は分子と分母に同じように掛かるので、比では消える。

## 2. 方法: なぜ $\langle P\rangle$ だけで測定を模擬できるのか

128量子ビットの状態から測定結果を直接サンプリングするのは重い。しかし**単一のパウリ文字列に限れば、測定の過程の統計は $x=\langle P\rangle_\rho$ という1つの数だけで決まる**。以下、その理由を順に述べる。

### 2.1 1つの設定での推定値

ランダム測定では、各量子ビット $q$ について基底 $b_q\in\{X,Y,Z\}$ を独立に等確率で選び、その基底で測って結果 $s_q\in\{\pm1\}$ を得る。パウリ文字列 $P=\bigotimes_{q\in A}P_q$ の、1回の測定からの推定値は(§0.5 の導出)

```math
X=3^{\lvert A\rvert}\Bigl(\prod_{q\in A}s_q\Bigr)\,\mathbf 1\bigl[\text{すべての }q\in A\text{ で }b_q=P_q\bigr]
```

である。基底が台の上で1つでも外れていれば $0$ を返し、全部当たっていれば $\pm3^{\lvert A\rvert}$ を返す。

### 2.2 この推定値の統計に要るもの

推定値の確率分布を決めるものを、1つずつ確かめる。

1. **基底が当たる確率。** 台の各量子ビットで当たる確率は $1/3$ で、量子ビットごとに独立に選ぶので、全部当たる確率は $3^{-\lvert A\rvert}$ である。これは状態によらない。
2. **当たったときの $\prod_q s_q$ の分布。** 基底が台の上で全部 $P$ の各因子と一致していれば、台の上での測定は $P$ の固有基底での測定そのものである。したがって積 $\prod_q s_q$ は $P$ の固有値 $\pm1$ のどちらかで、その平均は $\langle P\rangle_\rho=x$ である。 $\pm1$ しか取らない確率変数は平均だけで分布が決まる(+1 の確率が $(1+x)/2$ )。
3. **台の外の量子ビット。** 推定値の式に現れないので、どう測られても推定値に影響しない。
4. **同じ設定の中の $n_m$ ショット。** 状態 $\rho$ を毎回用意し直して測るので、互いに独立で同じ分布に従う。

以上から、**基底が当たった設定のショットは「 $+1$ が確率 $(1+x)/2$ で出る独立な試行」と統計的に同じ**である。状態のほかの情報(縮約密度行列など)は一切要らない。

CRM の推定値は、同じ設定で prior から計算した値 $3^{\lvert A\rvert}\,\mathbf 1[\text{一致}]\,y$ を引き、 $y$ を足し戻したものである。これも $x$ と $y$ だけで決まる。

したがって、統合表 [crm_edfid_all.tsv](crm_edfid_all.tsv) が各点で持っている真の値(`true`)と外れ(`Delta`)だけから、標準と CRM の推定値を厳密な分布で何度でも作れる。

### 2.3 和の観測量では使えない理由

二重占有のように複数のパウリ項の和で書かれる観測量では、同じ設定で同時に当たる2つの項の値の積が推定値の分散に入る。その平均は $\langle P_kP_l\rangle$ で、各項の $\langle P_k\rangle$ だけからは決まらない。そのため上の方法では模擬できない。ただし分散そのものは $\langle P_kP_l\rangle$ と項ごとの外れ $\Delta_k$ から厳密に書ける([crm_pauli_sum_variance.py](crm_pauli_sum_variance.py)、[crm_exact_gain.jl](crm_exact_gain.jl))。

### 2.4 何を比べたか

各点について、 $n_u=400$ 設定 × $n_m$ ショットの実験を 3000 回繰り返し、標準と CRM の推定値の標本分散を求め、その比を「実測の $G$ 」とした。これを 1 節の式の $G$ (「式の $G$ 」)と比べる。

### 2.5 調べた範囲

| 項目 | 値 |
|---|---|
| 系 | 1次元、開放端、 $L=16, 32, 64$ サイト(32 / 64 / 128 量子ビット) |
| $U$ | 2, 4, 8, 12 |
| prior | 切断 MPS( $\chi_p=2, 8, 32$ )と UHF |
| 観測量 | オンサイト ZZ、隣接 $Z_\uparrow Z_\uparrow$ (どちらも単一のパウリ文字列) |
| $n_m$ | 1, 10, 100 |
| 設定の数 | $n_u=400$ |
| 繰り返し | 3000 回 |

点の数は $3\,(L)\times4\,(U)\times4\,(\text{prior})\times2\,(\text{観測量})\times3\,(n_m)=288$ である。参照状態 $\rho$ は、どれもエネルギーの分散 $\langle H^2\rangle-\langle H\rangle^2$ で基底状態であることを確かめたものである。

### 2.6 統計誤差の目安

標本分散は、繰り返し回数 $n$ が大きいとき、相対的な揺らぎ(対数での標準偏差)がおよそ $\sqrt{2/(n-1)}$ である。分散の比はそれを2つ割るので、2つが独立なら対数での標準偏差は $\sqrt{4/(n-1)}$ になる。 $n=3000$ では

```math
\sqrt{\frac{4}{2999}}\approx0.037
```

である。比が 1 から 0.037 程度ずれるのは統計の揺らぎとして当然で、 $2\times0.037\approx0.07$ を超えるずれが 288 点のうち 5% 程度あってもおかしくない。

## 3. 結果

### 3.1 128量子ビットでの一致( $n_m=100$ )

| $U$ | 観測量 | prior | $G$ (式) | $G$ (実測) | 実測 / 式 |
|---|---|---|---|---|---|
| 4 | オンサイト ZZ | $\chi_p=2$ | 2.18 | 2.18 | 1.002 |
| 4 | オンサイト ZZ | $\chi_p=32$ | 50.74 | 49.71 | 0.980 |
| 4 | オンサイト ZZ | **UHF** | **50.33** | **50.94** | **1.012** |
| 8 | オンサイト ZZ | $\chi_p=8$ | 238.00 | 248.30 | 1.043 |
| 8 | オンサイト ZZ | **UHF** | **192.06** | **191.11** | **0.995** |
| 8 | 隣接 $Z_\uparrow Z_\uparrow$ | UHF | 1.43 | 1.44 | 1.009 |
| 12 | オンサイト ZZ | $\chi_p=32$ | 559.01 | 542.06 | 0.970 |
| 12 | オンサイト ZZ | **UHF** | **472.33** | **482.35** | **1.021** |
| 12 | 隣接 $Z_\uparrow Z_\uparrow$ | $\chi_p=32$ | 35.07 | 36.04 | 1.028 |

**表の読み方**: 各行が1つの点(系の長さ $L=64$ 、つまり 128量子ビット)で、式の $G$ と実測の $G$ を並べた。利得は 1.00 から 559 まで約 2.7 桁にわたるが、比はすべて 0.97〜1.05 に収まる。最も外れた 1.043 も、2.6 節の統計誤差の目安の 2 倍程度である。

### 3.2 全288点

```
実測 / 式:  中央値 1.0000   範囲 [0.905, 1.101]
|比 − 1| の 95 パーセンタイル: 0.059
統計誤差の目安(繰り返し 3000 回): 約 0.037
15% 以上ずれた点: 0 / 288
```

- **中央値がちょうど 1.0000** である。式と実測の間に、どちらか一方に偏ったずれ(実装の誤りがあれば現れるはずのもの)がないことを示している。
- ばらつき(95 パーセンタイルで 0.059)は、統計誤差の目安 0.037 と同じ程度である。繰り返しを増やせば小さくなる種類のずれである。
- 範囲の端 0.905 と 1.101 は、目安の約 2.7 倍である。288 点の中の最大のずれとしては不自然ではない。

### 3.3 損をする側でも一致する

利得の式は、 $G<1$ (CRM が標準のシャドウより悪い)場合も予言する。 $L=64$ の隣接 $Z_\uparrow Z_\uparrow$ で、UHF prior は $U=8$ で式 1.43 に対し実測 1.44、 $U=12$ で 1.38 対 1.38 だった。得をする側だけでなく、損得の境目に近い側でも式どおりである。

$\chi_p=2$ の切断 MPS では、隣接 $Z_\uparrow Z_\uparrow$ の $G$ がすべての $U$ と $L$ で式も実測もちょうど 1.00 になる。理由は次のとおりである。

1. $\chi_p=2$ の prior は、隣のサイトの間の相関を持たず、この観測量の値を 0 と予言する( $y=0$ )。
2. すると外れは $\Delta=x-0=x$ で、 $\Delta^2=x^2$ になる。
3. 1 節の式で分子と分母が等しくなり、 $G=1$ となる。

これは、prior の外れが真の値と同じ大きさ( $\lvert\Delta\rvert=\lvert x\rvert$ 、元論文 II.C 節の損得の境目)のときの実例である。

## 4. この検証で確定したこと

1. **式の値と、測定の過程を模擬した値は、128量子ビットまで一致する。** 以前の確認(§1)は 8 量子ビットの 1 つの系だけだったが、系の大きさで 16 倍、4 つの $U$ 、4 種類の prior に広がった。
2. **§10 の結論は、式を当てはめたことによる見かけのものではない。** 「大域的な忠実度が 2 万分の 1 になっても利得は 2% しか動かない」「1次元では $L$ を 8 倍にしても平均場は MPS に追いつかない」といった結果は、測定を模擬しても同じように出る。
3. **単一のパウリ文字列の局所観測量なら、系の大きさによらず $\langle P\rangle$ ひとつで測定を模擬できる。** これは検証の道具になるだけでなく、実験で必要なショット数を見積もるのにもそのまま使える。

## 5. 残っている検証

- **和の観測量。** 単一のパウリ文字列の式はそのままでは使えないので、§10 では二重占有・ $S^zS^z$ ・ $S^xS^x$ などの $G$ を `n/a` にしている。2026年10月に、和の観測量の厳密な分散の式(同時に測れる項の組の $\langle P_kP_l\rangle$ と、項ごとの外れ $\Delta_k$ で決まる)を実装し、1次元の掃引ではモンテカルロの模擬と一致することを確かめた([README_experiments.md](README_experiments.md) §3)。§10 の表への適用はまだである。
- **2次元。** ここでは1次元だけを調べた。幅 $W\ge4$ の 2 次元では厳密な基底状態を作れない(§10)ので、確認は DMRG の参照状態で行うことになる。
