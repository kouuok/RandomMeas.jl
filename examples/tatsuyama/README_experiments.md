## 2b. サイト分解: 利得は鎖の「どこでも」生き残るか(1D鎖 L=8–128)

スクリプト: [crm_site_resolved.jl](crm_site_resolved.jl), 解析 [crm_site_resolved_plot.jl](crm_site_resolved_plot.jl) / 図: [crm_site_resolved.png](crm_site_resolved.png) / データ: [crm_site_resolved_results.tsv](crm_site_resolved_results.tsv)

§2の結論は**鎖中央の観測量だけ**で得たものだった。開放端鎖では中央がエンタングルメント最大＝切断priorが最も苦しい場所なので「中央で効くなら全域で効く」は一見もっともらしいが、実際にサイト依存性を測るまでは仮説にすぎない。ここでは全サイトについて測る。

### この実験は何を測るのか(全体像)

一言でいうと、**「鎖の各サイトで局所観測量を測ったとき、CRMがどれだけ得をするか」を全サイト・全prior品質・全系サイズについて総当たりで測る**実験である。§2 は鎖中央の1点だけを見ていたので、そこを面的に広げる。

具体的には、下の3重ループを回して各点で利得 $G$ を求める:

```
for 系サイズ L ∈ {8,16,32,64,128},  ドーピング δ ∈ {0, 1/8}:
    参照状態 ρ を DMRG で作る                      ← 「実験装置」を1つ用意
    prior σ を ρ の χ 切断で 5 種類作る             ← 近似の良さのダイヤル
    for サイト i = 1..L:
        i の周りの観測量 7 個を用意
        その台を覆う「窓」から測定をシミュレート     ← ここが計算の本体
        for prior σ ∈ 5 種類:
            標準シャドウと CRM の分散を比べて G を得る
```

外側2ループが $5\times2=10$ 通り、サイトが最大128、観測量7個、prior 5種類で、**合計 17,210 点**の $G$ が得られる。

### セットアップ(各要素の意味と選んだ理由)

**1. 参照状態 ρ — 「実験装置」の代わり**

1次元ハバード鎖(サイト数 $L$、量子ビット数 $2L$)の基底状態を DMRG(ボンド次元 $\chi_{\rm exp}=256$)で作り、これを**測定対象の量子状態**とみなす。実機の代わりに古典計算した状態を測る「擬似実験」である。

> **なぜ ρ が厳密な基底状態でなくてよいのか**: この研究が主張するのは「**固定された状態 ρ に対する推定分散の比**」であって、ρ が真の基底状態かどうかは主張に入らない。 $\chi_{\rm exp}=256$ で切れていても、その状態を「実験で用意された状態」と定義すれば議論は自己無撞着に閉じる。 $L=128$ で $\chi=256$ は明らかに未収束だが、それでも構わないのはこのためである(物理量そのものを議論する §2e では別途収束を確認している)。

- $U=4$、 $t=1$、 $\mu=U/2$。 $U=4$ は1次元ハバード模型の中間結合領域で、電荷はMottギャップで凍り、スピンは gapless という典型的な設定。
- **境界条件は開放端(OBC)**。ホッピングは $i=1,\dots,L-1$ のみで、サイト $L$ と $1$ を結ぶボンドはない。**この選択が本節の結果を左右する** — 周期境界なら並進対称性から全サイトが等価になり、サイト依存性は定義上存在しない。下記の帰無検定(§2b末尾)で実際にそうなることを確認した。
- **ドーピング** $\delta=0$(半充填、 $L$個の電子)と $\delta=1/8$($L(1-\delta)$個)の2通り。粒子数はDMRGの量子数保存セクターで固定するので、初期積状態から電子を等間隔に $\delta L$ 個抜くことで指定する。 $\delta=1/8$ を入れたのは、**半充填の開放端鎖はほぼ一様なのでサイト依存性を問う意味が薄い**からである。ホールを入れると電荷分布が空間的に不均一になり、「場所によって prior の良し悪しが違うのか」という問いが初めて意味を持つ。

**2. prior σ — 「近似の良さ」を連続的に振るダイヤル**

$\rho$ そのものをボンド次元 $\chi_p \in \lbrace2,4,8,16,32\rbrace$ に切断した MPS を prior とする。 $\chi_p$ が小さいほど粗い近似である。

> **なぜ ρ の切断を prior に使うのか**: prior の品質を**1つのつまみ**で単調に変えられるからである。UHF のような別種の prior だと「良い/悪い」の2値しか作れないが、切断なら $\chi_p=2$(忠実度 $10^{-17}$)から $\chi_p=32$(ほぼ厳密)まで滑らかにたどれる。これにより「どの品質から利得が出るか」という閾値そのものを測れる。

さらに **6番目の prior として $\sigma=\rho$(完全prior)** を加える。これは $\Delta=0$ なので、その分散は**ショットノイズ床そのもの**である。標準シャドウの分散との比を取れば、**利得の天井 $G_{\max}$ を経験的に測定**したことになる。

> **なぜ $G_{\max}$ を実測する必要があるのか**: 単一 Pauli 列なら $G_{\max}=1+n_m(3^{|A|}-1)\langle P\rangle^2/[3^{|A|}(1-\langle P\rangle^2)]$ という閉形式があるが、二重占有や $S^zS^z$ のような**多項観測量には閉形式がない**。同じサンプルに完全priorを当てるだけで天井が測れるので、 $G/G_{\max}$ による2レジーム診断(§0.6)を全観測量に適用できるようになる。

**3. 観測量 — 各サイトで7個**

サイト $i$ について、
- **オンサイト量**: 電子数 $n(i)$、局所磁化 $S^z(i)$、二重占有 $D(i)$、 $\langle Z_{i\uparrow}Z_{i\downarrow}\rangle$
- **ボンド量**(サイト $i$ と $i+1$): $\langle Z_{i\uparrow}Z_{i+1\uparrow}\rangle$、 $S^zS^z$、ホッピング

を測る。 $n$ と $S^z$ は1量子ビットのPauli($|A|=1$)の線形結合、他は $|A|=2$ または $|A|=3$ である。**単一Pauli列(onsite ZZ、ZZ up-up)と多項観測量(残り)を混ぜている**のは、前者では理論式と直接照合でき、後者では $G_{\max}$ の実測が要ることを対比するためである。

**4. 測定プロトコルと統計**

- $n_u=50$ 設定 × $n_m=100$ ショット(1点あたり5000ショット)
- これを **n_repeat=1000 回**独立に繰り返し、1000個の推定値のばらつきから分散を求める
- 分散比には **bootstrap 信頼区間**(600リサンプル、16/84パーセンタイル)を付ける

> **なぜ n_repeat=1000 も要るのか**: 分散比の相対誤差は約 $2\sqrt{2/n_{\rm repeat}}$ で、n_repeat=100 なら±20%、1000 なら±6%である。この実験の主張は「損をするサイトが**あるか/ないか**」という境界($G=1$ 付近)の判定なので、 $G=0.9$ と $G=1.1$ を区別できる精度が要る。bootstrap CI を付けたのも同じ理由で、「有意に損」を **$G$ の上側84%点が0.9未満**と定義して数える。

**5. 計算技法 — 窓RDMサンプリング(この実験を可能にした鍵)**

観測量の台はサイト $i$ 周りの高々4量子ビットに収まる。そこで**その窓の縮約密度行列 $\rho_w$($16\times16$)を厳密に構成し、そこから直接サンプルする**。

MPSの直交中心を窓の左端 $q_1$ に置くと、 $q_1$ より左は左正準・右は右正準になるので**左右の環境がともに恒等**になり、
```math
\rho_w[s,s'] = \sum_{l,r} A[l,s,r]\,A^*[l,s',r]
```
が窓のMPSブロックだけから厳密に求まる(近似ではない)。観測量の期待値も同じ $\rho_w$ から $\mathrm{Tr}[\rho_w M]$ で取れる。

> **なぜこれが決定的だったか**: §2 で使った逐次MPSサンプリングはコストがボンド次元 $\chi$ に依存し、鎖中央では**1サイトあたり約250秒**($\chi=128$)かかった。 $L=128$ では walltime を超える。窓RDM方式は $16\times16$ の行列から引くだけなので **$\chi$ に一切依存せず約1秒/サイト**、およそ250倍速い。 $L=128$(256量子ビット)まで到達できたのはこの一点による。
>
> さらに、窓の列を $q_1$ 昇順に並べて**直交中心を左から右へ一方向に掃く**ことで、中心の移動をサイトごとにやり直さずに済ませている(やり直すと $L$ に対して二次のコストになる)。
>
> 正しさは ED の周辺分布との照合で確認済み: $\max|\Delta p| = 3\times10^{-15}$(機械精度)。

**6. 検証(スクリプト内 assert)**

L=4 の密行列 ED と突き合わせ、(i) DMRG エネルギーの一致(1e-14)、(ii) **全サイトの全観測量**の期待値一致(6e-15)、(iii) ホッピングのJW符号規約の一致、(iv) 窓RDM と ED 周辺分布の一致(3e-15)、(v) サンプラーの経験分布と Born 確率の一致(全変動距離が統計限界内)を確認する。さらにドープ系については、粒子数セクターが意図通りか、窓RDMから計算した観測量が転送行列の値と一致するか(8e-16)を独立に検証している。

### 何を出力するのか

各点 (L, δ, サイト, χ_p, 観測量) について次を記録する — [crm_site_resolved_results.tsv](crm_site_resolved_results.tsv) の各列:

| 列 | 意味 |
|---|---|
| `true` | 真値 $\langle P\rangle_\rho$(窓RDMから厳密) |
| `Delta` | prior の局所誤差 $\Delta=\langle P\rangle_\rho-\langle P\rangle_\sigma$ |
| `prior_fid` | prior のグローバル忠実度 $\vert\langle\sigma\vert\rho\rangle\vert^2$(比較用) |
| `G_emp` | 経験利得 $\mathrm{Var}[\text{標準}]/\mathrm{Var}[\text{CRM}]$ |
| `G_lo`, `G_hi` | その bootstrap 信頼区間(16/84パーセンタイル) |
| `G_max` | 完全prior で実測した利得の天井 |
| `G_theo` | 理論値(単一Pauli列のみ。多項観測量では NaN) |
| `S_bond` | その観測量の台にあたるボンドのエンタングルメントエントロピー |

`S_bond` を記録しているのは、当初の作業仮説「prior誤差はエンタングルメントが大きい場所ほど大きい」を検定するためである(結果は下記(5)の通り**否定された**)。

### 結果

**(1) 主張は全サイトで成立する — ただし prior 品質の閾値がある**

χ_p ≥ 4 では、**全 L・両ドーピングで「有意に損なサイト」がゼロ**(bootstrap上限 $G_{\text{hi}} < 0.9$ を「有意に損」と定義):

| L | δ | χ_p | prior忠実度 F | 全サイト最小G | 中央値G | 有意に損なサイト |
|---|---|---|---|---|---|---|
| 128 | 0 | 4 | **1.35e-4** | **1.00** | 8.5 | 0 / 893 |
| 128 | 0 | 8 | 3.18e-1 | 1.00 | 26.2 | 0 / 893 |
| 128 | 1/8 | 4 | **1.91e-6** | 0.89 | 4.7 | 0 / 893 |
| 128 | 1/8 | 8 | 8.01e-3 | 1.24 | 16.1 | 0 / 893 |
| 128 | 0 | **2** | 4.67e-10 | **0.70** | 1.4 | **51 / 893 (5.7%)** |
| 128 | 1/8 | **2** | **1.16e-17** | **0.14** | 1.4 | **166 / 893 (18.6%)** |

**表の読み方**: 上4行が「良いprior($\chi_p\ge4$)」、下2行が「粗いprior($\chi_p=2$)」の場合。**prior忠実度 F** は $10^{-4}$〜 $10^{-17}$ と天文学的に小さい(priorは状態全体としては完全に的外れ)。それでも「**全サイト最小G**」(893サイト中で最も成績の悪いサイトの利得)が $\chi_p\ge4$ では 1.0 前後を保ち、「**有意に損なサイト**」(bootstrap上限が0.9未満、つまり統計的に確実にCRMが損をしているサイト)が**ゼロ**である。一方 $\chi_p=2$ の粗いpriorでは最小Gが0.14まで落ち、損なサイトが最大18.6%現れる — これが実験6(最適係数CRM)の必要性の直接的証拠になる。
**(1b) 機構を正しい変数で見る — 崩壊するのは $F$ 、効くのは $\varepsilon$**

上の表は「忠実度が $10^{-17}$ でも利得が残る」という形で主張を述べているが、なぜそうなるのかは $F$ を見ていても分からない。利得法則に入るのは**観測量ごとの相対誤差** $\varepsilon=\lvert\Delta/\langle P\rangle\rvert$ だけである。これは窓の縮約密度行列から厳密に計算できる(Monte Carlo 不要)ので、 $L$ 依存を直接測れる。

**χ_p=8 を固定して $L$ を 8→128 と振ったときの三者の振る舞い**(全サイト中央値):

| | L=8 | L=16 | L=32 | L=64 | L=128 | L=8→128 |
|---|---|---|---|---|---|---|
| **$F$** (半充填) | 0.991 | 0.953 | 0.842 | 0.639 | 0.318 | **1/3.1** |
| **$F$** (δ=1/8) | 0.965 | 0.797 | 0.473 | 0.132 | 0.0080 | **1/120** |
| **$\varepsilon$** (半充填) | 5.1e−3 | 9.1e−3 | 1.2e−2 | 1.2e−2 | 1.2e−2 | 2.4倍 |
| **$\varepsilon$** (δ=1/8) | 2.5e−2 | 5.4e−2 | 7.1e−2 | 8.4e−2 | 9.3e−2 | 3.8倍 |
| **$G$** (半充填) | 48.7 | 40.0 | 33.4 | 30.0 | 29.1 | 1/1.7 |
| **$G$** (δ=1/8) | 22.4 | 20.1 | 19.4 | 18.8 | 18.2 | 1/1.2 |

**ドープ系では $F$ が120分の1に崩壊する間に、 $\varepsilon$ は3.8倍しか悪化せず、 $G$ は1.2分の1にしか落ちない。** これがこの節の主張の中身である。 $F$ は全サイトの誤差の積なので指数的に死ぬが、 $\varepsilon$ は**その観測量の周辺の縮約密度行列の誤差**だけで決まるので、 $L$ にほとんど依存しない。

同時に、 $\varepsilon$ が**完全に一定ではない**ことも見える(半充填 2.4倍、ドープ 3.8倍)。これは §2b(7) で扱う「ドープすると電荷セクターが gapless になり $\Delta$ の $L$ 非依存性が破れる」現象を、利得を決める変数そのもので見たものである。

**$\chi_p$ 依存も $\varepsilon$ で見る必要がある**( $L=128$ 、全サイト中央値):

| δ | χ_p | $F$ | $\varepsilon$ | $G$ | $G/G_{\max}>0.9$ の割合 | 感度 |
|---|---|---|---|---|---|---|
| 0 | 2 | 4.7e−10 | 8.2e−1 | 2.12 | 0% | 1.79 |
| 0 | 4 | 1.4e−4 | 2.9e−1 | 9.42 | 6% | 0.559 |
| 0 | 8 | 3.2e−1 | 1.2e−2 | 29.07 | **100%** | 0.003 |
| 0 | 16 | 8.2e−1 | 4.1e−3 | 29.50 | **100%** | 0.001 |
| 0 | 32 | 9.6e−1 | 1.1e−3 | 29.56 | **100%** | 0.000 |
| 1/8 | 8 | 8.0e−3 | 9.3e−2 | 16.12 | 56% | 0.044 |
| 1/8 | 32 | 6.8e−1 | 6.2e−3 | 19.10 | **100%** | 0.000 |

**半充填の $\chi_p\ge8$ では、 $\varepsilon$ が12倍改善しても $G$ は 29.07 → 29.56 で動かない**(全点が天井、感度 0.003 → 0.000)。§0.5b で述べたとおり、この領域の $G$ は prior ではなく $n_m=100$ の天井を測っている。**この表の $\chi_p\ge8$ の列を prior の比較に使ってはいけない。** ドープ系の $\chi_p=8$ は 56% が天井なので部分的に情報を持つ。

**(2) 中央だけを見ていたら見落としていた事実: 悪いpriorではサイトによってCRMが「損」になる**

χ_p=2 のドープ系では最悪 **G = 0.039**(標準シャドウより分散が25倍悪い)。損なサイトの割合は δ=1/8 で 19–32%、half-filling では **L≥64 で初めて出現**(L=64: 3.4%, L=128: 5.7%)。つまり固定χの粗いpriorは、局所観測量に対してすら L とともに相対的に劣化しうる。これは実験6の**最適係数CRM($G\ge1$ を保証)がなぜ必要かの、最も直接的な証拠**である。

**(3) サイト依存の形: L非依存のバルク平坦部 + 端の増強**

G(i) は鎖の内部で**L に依存しない平坦部**を持ち(L=32,64,128 が同一のプラトーに乗る)、端の数サイトだけが増強される。端/中央比は L に依らずほぼ一定:

| 観測量 | 端/中央比 (χ_p=8, δ=0) | 端/中央比 (χ_p=8, δ=1/8) |
|---|---|---|
| onsite ZZ | 1.39–1.58 | 2.21–2.85 |
| 二重占有 | 1.26–1.43 | 1.66–1.98 |
| SzSz r=1 | 1.89–2.91 | 2.41–3.66 |
| ZZ up-up r=1 | 2.08–3.55 | 2.43–3.77 |

**(4) 2レジーム診断はサイトに沿ってほぼ一様**

χ_p ≥ 8 では中央値 $G/G_{\max} = 1.00$(全サイトでショットノイズ律速)、χ_p=4 で 0.33、χ_p=2 で 0.076(Δ律速)。**レジームの切り替わりはサイトではなく prior 品質で決まり**、この系では χ_p ≈ 8 が境界。

**(4b) 帰無検定: サイト依存性は本当に開放端の効果か**

(2)(3)の説明が正しければ、**周期境界条件(PBC)にすると並進対称性から全サイトが等価になり、サイト依存性は完全に消えるはず**である。消えなければ説明が誤りということになるので、これは反証可能な予言である。同じ $L$・同じ $U=4$ で境界条件だけを変えて $\langle P\rangle(i)$ を測った([crm_pbc_check.jl](crm_pbc_check.jl))。 $G_{\max}$ は $\langle P\rangle$ だけの関数なので、Monte Carlo は不要で DMRG と窓RDMだけで判定できる。

| | $\langle P\rangle$ の変動係数 | $G_{\max}$ の最大/最小 |
|---|---|---|
| L=16 OBC | 0.3310 | **16.76** |
| **L=16 PBC** | **0.0000** | **1.00** |
| L=32 OBC | 0.2525 | **16.12** |
| **L=32 PBC** | **0.0015** | **1.01** |

ボンド観測量 $\langle Z_{i\uparrow}Z_{i+1\uparrow}\rangle$ の先頭8ボンドを並べると一目瞭然である:

```
L=32 OBC:  -0.8237  -0.3277  -0.6724  -0.3820  -0.6338  -0.4061  -0.6153  -0.4195
L=32 PBC:  -0.5143  -0.5170  -0.5143  -0.5161  -0.5144  -0.5157  -0.5145  -0.5156
```

**OBC の交替が PBC では完全に消え、全ボンドが同じ値になる。** 変動係数は 0.2525 → 0.0015 と **168分の1**、 $G_{\max}$ の最大/最小比は 16.1 → 1.01 になった(PBC に残る 0.0015 は物理ではなく、周期ボンドが実効的にボンド次元を二乗するため MPS にとって不利な PBC での DMRG 収束誤差である)。

さらに **PBC のバルク値 $-0.514$ は OBC の交替値のちょうど中間にある**。OBC の $\langle P\rangle(i)$ が「バルク値のまわりに立った定在波」であるという §2c の描像そのものである。

> **この検定が示すこと**: §2b の「端の増強」も §2c の「周期2の振動」も、**すべて開放端があることの帰結**であり、境界条件を変えれば消える。逆にいえば、**周期境界の系ではサイト分解に意味がなく、鎖中央1点を測れば十分**である。§2 が中央1点で済ませていたのは、PBC なら正しい省略だったことになる — OBC を使っている限りは正しくなかった、というのが本節の出発点であった。

**(4c) 「実際に知りたいのはPBCでは?」への回答 — PBCでも主張は成立し、むしろ強化される**

(4b)はサイト依存性がOBC固有であることを示したが、では**主張そのもの(「χ_p≥4なら損をしない」)はPBCでも成り立つのか**。これは自明ではない。PBCは同じ $L$ でもエンタングルメントが約2倍($S=(c/3)\ln L$ 対 $(c/6)\ln L$)なので、**同じ $\chi_p$ の prior はPBCの方が悪い**はずだからである。同じ $L$・同じ $U=4$ で境界条件だけ変えて比較した([crm_pbc_gain.jl](crm_pbc_gain.jl))。

**予測どおり prior は悪くなる**(L=32):

| | $S_c$ | F(χ_p=8) | F(χ_p=32) | **1−F(χ_p=32)** |
|---|---|---|---|---|
| OBC | 1.0815 | 0.8418 | 0.9985 | 0.0015 |
| **PBC** | **2.2788** | 0.3965 | 0.8255 | **0.1745** |

$S_c$ の比 2.11 は $c/3$ 対 $c/6$ の予想比2と整合する。 $\chi_p=32$ の prior は PBC で **116倍悪い**(1−F で比較)。ところが利得は変わらない:

| L=32, ZZ onsite, $\chi_p=32$ | 忠実度 | **利得 $G$** | 天井 |
|---|---|---|---|
| OBC | F=0.9985 | **47.61** | 47.60 |
| PBC | F=0.8255 | **47.67** | 47.54 |

**損をする観測量は OBC/PBC どちらでも、全 $\chi_p$・全観測量でゼロ**($\min G=1.000$)。 $\chi_p\ge8$ での $G/G_{\max}$ の中央値は OBC 1.000、PBC 0.984–0.988 で、どちらも天井に貼り付いている。

> **この比較が局所性の最も強い実証である理由**: これまでの実証は「同じ系を大きくする($L$ を変える)」ものだった。今回は**ハミルトニアン自体を変えて**(境界条件を変えて)グローバル忠実度を2桁悪化させている。それでも局所観測量の利得が変わらないということは、**同じ系の拡大ではなく、異なる状態どうしの比較で局所性が確認された**ことを意味する。 $\Delta$ が「その観測量の周辺の縮約密度行列の誤差だけで決まる」という主張の、最も直接的な形である。
>
> **実務的な含意**: デジタル量子シミュレーションでPBCを選ぶ場合(有限サイズ効果を減らすために合理的な選択である)でも、CRMの利得は同じように得られる。ただし**サイト分解には意味がなくなる**((4b))ので、1サイト測れば十分になる。

**(5) 当初の作業仮説は外れた**: 「prior誤差 Δ(i) はエンタングルメント S(i) が大きい場所ほど大きい」と予想したが、corr(|Δ|, S) は **+0.03〜+0.28 と弱い**。median|Δ| は**サイトにはほとんど依存しない**。

> **重要な訂正(L 依存について)**: 当初「median|Δ| は L にも依存しない(χ_p=2 で L=8: 0.098 → L=128: 0.100)」と書いたが、これは **χ_p=2 でのみ成立**する。観測量を固定して χ_p ごとに見ると:
>
> | χ_p | 2 | 4 | 8 | 16 | 32 |
> |---|---|---|---|---|---|
> | Δ の L128/L8 比 | 1.02 | 4.97 | 0.99 | 12.4 | **184** |
>
> χ_p=2 では Δ が既に飽和しているため平坦に見えるだけで、**細かい prior では L とともに大きく増加する**。単一の χ_p での比較は信用できない(§2e の教訓も参照)。それでも利得の主張が成立する理由は次項で説明する。

**(5b) では、なぜ利得は L に対して平坦なのか — 2レジームで説明できる**

観測量を ZZ onsite に固定し、 $\varepsilon=\Delta/|\langle P\rangle|$ と $G/G_{\max}$ を追うと機構がはっきりする(半充填):

| χ_p | G(L=8) | G(L=128) | ε(L=8) | ε(L=128) | G/G_max (L=128) | レジーム |
|---|---|---|---|---|---|---|
| 2 | 2.27 | 2.18 | 0.65 | 0.67 | 0.043 | **Δ律速・飽和** |
| **4** | **40.5** | **9.84** | 0.058 | 0.29 | 0.194 | **Δ律速・遷移** |
| 8 | 50.5 | 50.9 | 2.7e-3 | 2.8e-3 | 1.000 | ショットノイズ律速 |
| 16 | 50.4 | 50.9 | 2.4e-4 | 2.9e-3 | 0.999 | ショットノイズ律速 |
| 32 | 50.4 | 50.8 | 2.4e-6 | 4.5e-4 | 1.000 | ショットノイズ律速 |

**「利得が L に平坦」が成立するのは両端だけ**である:

- **χ_p ≥ 8**: Δ は L とともに増えるが、 $\varepsilon$ が $3\times10^{-3}$ 以下に留まりショットノイズ床のはるか下にある。したがって $G=G_{\max}$ に貼り付き、**L にも prior 品質にも一切依存しない**。忠実度が $10^{-17}$ でも無関係なのはこのためである。
- **χ_p = 2**: $\varepsilon\approx0.67$ で飽和済み。これ以上悪くなりようがないので平坦。
- **χ_p = 4(中間)**: ここだけ $G$ が **40.5 → 9.84 と4倍劣化する**。 $\varepsilon$ が $0.058\to0.29$ と成長し、Δ律速の領域を横切るためである。

したがって正しい主張は「利得は L に依存しない」ではなく、**「ショットノイズ律速でいられる限り利得は L に依存せず、Δ律速の遷移領域でのみ L とともに劣化する」**である。それでも χ_p=4 の $G=9.84$ は 1 を大きく上回るので、(1) の運用上の結論(損なサイトゼロ)は変わらない。

> **方法論上の教訓**: 以前の表は観測量をまたいで $G$ の中央値を取っていたため、この4倍の劣化が隠れていた。 $G_{\max}$ が桁で違う観測量を混ぜて中央値を取ってはいけない。

**(6) $\langle P\rangle=0$ の観測量には利得が存在しない**: half-filling の n(i), Sz(i) は粒子空孔/スピン対称性から $\langle Z\rangle=0$ なので $G_{\max}=1$、実測も $G \equiv 1.00$。ドープすると $\langle Z\rangle\neq0$ となり $G_{\max}\approx2.3$ に上がる。

**(7) 重要な限界: ドープすると Δ の L 非依存性が破れる**

(5)の「 $\Delta$ は L に依存しない」は **half-filling でのみ厳密**である。δ=1/8 では **全観測量で** median|Δ| が L とともに増加する(χ_p=8, ZZ onsite: 5.8e-3 → 1.8e-2 → 2.5e-2 → 3.0e-2 → **3.4e-2**、L=8→128)。結果として $G/G_{\max}$ も単調に低下する:

| $G/G_{\max}$ (χ_p=8, δ=1/8) | L=8 | L=16 | L=32 | L=64 | L=128 |
|---|---|---|---|---|---|
| n | 0.997 | 0.996 | 0.992 | 0.991 | 0.987 |
| 二重占有 | 0.999 | 0.963 | 0.955 | 0.938 | 0.914 |
| ZZ onsite | 0.995 | 0.959 | 0.938 | 0.919 | 0.885 |
| ZZ up-up r=1 | 0.949 | 0.908 | 0.867 | 0.830 | 0.793 |
| **hop up r=1** | 0.960 | 0.879 | 0.787 | 0.741 | **0.719** |

対照的に half-filling では全て 0.95–1.00 でほぼ平坦。物理的な理由は明快で、**半充填ハバード鎖は電荷がMottギャップで凍結しているが、ドープすると電荷セクターが gapless(朝永-Luttinger液体)になる**ためである。gapless セクターではエンタングルメントが $\sim\frac{c}{3}\log L$ で増えるので、固定χのpriorが捉えられる割合が L とともに落ちる。増加が $\log L$ 的で緩やかなことも整合的である。

**したがって局所性の主張はこう精密化される**: 「 $\Delta$ が L 非依存」は**ギャップのある系で厳密**、gapless な系では**対数的にのみ破れる**。ホッピングの劣化が最速なのはJW弦のせいではなく(half-fillingのホッピングは平坦)、電流揺らぎが gapless な電荷セクターに最も強く結合するためと考えられる。

## 2c. なぜボンド観測量の利得は「1本おき」に振動するのか

(データは §2b と同じ計算 — $t=1$ の一様鎖、 $U=4$、 $\mu=U/2$ — を別の切り口で見たものである。)上表で最も目を引くのは、オンサイト量が滑らかなのに**ボンド量は隣り合うボンドで G が5〜17倍違う**ことである(ZZ up-up: 186.6 → 11.1 → 79.7 → 15.8 …)。これは4段階で完全に説明でき、CRMの利得法則が実際にどう働くかの良い教材にもなっている。数式を伴う詳細版は[自習用チュートリアル](paper/crm_tutorial.pdf)§16に書いた。

> **この節の説明は帰無検定で確認済み**: 周期境界条件にすると振動は完全に消え、全ボンドが同じ値になる(§2b(4b))。 $\langle P\rangle$ の変動係数は 0.25 → 0.0015、 $G_{\max}$ の最大/最小比は 16.1 → 1.01。以下で述べる「開放端が原因」という説明は、この意味で反証可能な形で検証されている。

### 第1段階: 開放端は周期2の定在波を作る(Friedel振動)

無限鎖なら並進対称性からどのボンドも等価で、 $\langle P\rangle$ は場所に依らない。端があるとこの対称性が破れる。金属に不純物を1個入れると波数 $2k_F$ の電子密度の定在波(Friedel振動)が立つのと同じことが起きる。半充填ハバード鎖では電荷はMottギャップで凍結しているが、**スピンは gapless**(超交換で得られるHeisenberg鎖と同じ普遍類)で、支配的な相関はスタッガード成分 $2k_F=\pi$。波長 $2\pi/\pi = 2$、つまり**周期2の定在波**が端から立ち上がる。

### 第2段階: ボンド量では「強い/弱い」の交替として現れる

なぜボンド量にだけ強く出るのか。直感的な理由は**端のサイトは隣が1つしかない**ことである。バルクのサイトは左右2本のボンドにシングレットを組む能力を分け合わねばならないが、端のサイトは1本に全部注げる。結果として第1ボンドがほぼ完全なシングレット(ダイマー)になり、そのしわ寄せで第2ボンドが弱くなり、第3ボンドが再び強くなり…と交替が内側へ伝わる。

測定量で確認できる。半充填では $\langle n_{i\uparrow}\rangle = 1/2$ なので $Z_q = 1-2n_q$ より

```math
\langle Z_{i\uparrow}Z_{i+1\uparrow}\rangle = 1 - 2\langle n_{i\uparrow}\rangle - 2\langle n_{i+1\uparrow}\rangle + 4\langle n_{i\uparrow}n_{i+1\uparrow}\rangle = -1 + 4\langle n_{i\uparrow}n_{i+1\uparrow}\rangle
```

完全なシングレット $(|{\uparrow\downarrow}\rangle-|{\downarrow\uparrow}\rangle)/\sqrt2$ では $n_{i\uparrow}n_{i+1\uparrow}$ が常に0なので $\langle P\rangle = -1$。相関がなければ $\langle n_\uparrow n_\uparrow\rangle = 1/4$ で $\langle P\rangle = 0$。実測は端のボンドで $\langle P\rangle = -0.823$($\langle n_\uparrow n_\uparrow\rangle = 0.044$)、バルクで $-0.51$ 前後 — **端のボンドがバルクよりはるかにシングレットに近い**という描像を裏づける。

### 第3段階: 振幅は端からの距離 x に対し $x^{-1/2}$ で減衰する(定量確認)

端の効果なら内側へ行くほど収まるはずである。L=128 で交替振幅 $`A(x) = \frac12(|\langle P\rangle|_{強} - |\langle P\rangle|_{弱})`$ を測ると:

| 端からの距離 x | 1 | 3 | 7 | 15 | 31 | 63(中央) |
|---|---|---|---|---|---|---|
| $A(x)$ | 0.2470 | 0.1430 | 0.0922 | 0.0614 | 0.0426 | 0.0347 |
| $A(x)\sqrt{x}$ | 0.247 | 0.248 | 0.244 | 0.238 | 0.237 | 0.275 |
| G(強)/G(弱) | 15.7 | 5.1 | 3.0 | 2.1 | 1.6 | 1.6 |

$A(x)\sqrt{x}$ が $x\le31$($x \lesssim L/4$)で4%以内の一定値になる。すなわち $A(x)\propto x^{-1/2}$ で、**gapless スピン鎖のボンド秩序 Friedel 振動について知られている指数と一致する**(中央での16%の上振れは両端からの寄与が重なるため)。第1段階の説明の定量的裏づけであると同時に、DMRGが正しく収束していることの独立なチェックにもなっている。

**バルク値との整合。** 周期境界で測ったバルク値は $\langle P\rangle=-0.514$ である(§2b(4b))。開放端での交替値 $-0.824, -0.328, -0.672, -0.382, \dots$ はこの値の**まわりを振動**しており、端から離れるにつれてこの値に収束する。 $A(x)$ を「バルク値からのずれの振幅」と定義したことと、それが $x^{-1/2}$ で減衰することが、これで整合的に読める。

### 第4段階: なぜ $\langle P\rangle$ の2.5倍差が G の17倍差になるのか

ここが利得法則の効くところである。この系では prior が十分良く(χ_p≥8)、全点で $G\approx G_{\max}$ なので飽和則をそのまま使える。 $|A|=2$, $n_m=100$ で

```math
G_{\max} = 1 + n_m\frac{(3^2-1)\langle P\rangle^2}{3^2(1-\langle P\rangle^2)} = 1 + \frac{800}{9}\cdot\frac{\langle P\rangle^2}{1-\langle P\rangle^2}
```

肝心なのは $G_{\max}$ が $\langle P\rangle^2$ ではなく **$\langle P\rangle^2/(1-\langle P\rangle^2)$ に比例する**ことで、この関数は $|\langle P\rangle|\to1$ で**発散する**:

| | $\langle P\rangle$ | $\langle P\rangle^2/(1-\langle P\rangle^2)$ | $G_{\max}$(理論) | G(実測) |
|---|---|---|---|---|
| 強ボンド(端) | −0.823 | 0.677/0.323 = 2.09 | 187 | 186.6 |
| 弱ボンド(その隣) | −0.329 | 0.108/0.892 = 0.121 | 11.8 | 11.1 |
| **比** | **2.5** | **17.3** | **15.8** | **16.8** |

**$\langle P\rangle$ のたかだか2.5倍の違いが、G の16倍の違いに増幅された**。

なぜ二重に効くのかは分子と分母を別々に見ればわかる。分子 $\langle P\rangle^2$ は「基底が当たるか外れるかで生じる設定間揺らぎ」＝**CRMが打ち消せる量**で、 $|\langle P\rangle|$ が大きいほど大きい。分母の $1-\langle P\rangle^2$ はショットノイズ、すなわち**どうやっても打ち消せない床**で、 $|\langle P\rangle|$ が大きいほど**小さい**(射影測定の結果が決定的に近づくため)。打ち消せる量が増えると同時に打ち消せない量が減るので、比は $|\langle P\rangle|$ に対して急激に変化する。

### この例から読み取るべきこと

1. **この振動は prior の良し悪しとは無関係**。χ_p≥8 では全サイトで $G/G_{\max} = 1.00$(どこもショットノイズ律速)で、 $\Delta$ はサイトによらずほぼ一定だった。変わっているのは**観測量自身の物理** $\langle P\rangle(i)$ であって、priorの性能ではない。
2. **§2b の「端の増強」と同じ現象**。端の増強はFriedel振動の $x\to0$ 極限にすぎず、同じ機構が鎖の内部でも周期2で効いていた。
3. 実務的には、**どのボンドを測るかで必要ショット数が一桁変わる**。測定計画を立てる際は観測量の種類だけでなく**系のどこか**まで含めて $\langle P\rangle$ を見積もる必要がある。これは§0の「利得は観測量ごとに $\Delta$ と $\langle P\rangle$ で決まる」を「観測量ごと・場所ごと」に精密化したものである。

### 解釈

**主張は生き残り、かつ精密化された**。「グローバル忠実度が $10^{-17}$ まで崩壊しても局所観測量の利得は残る」は、鎖中央の偶然ではなく **256量子ビット系の全サイトで成立する**。その実体は結果(5)にある: 局所prior誤差 $\Delta(i)$ が**サイトにも系のサイズにも依存しない**からで、 $\Delta$ が観測量周辺の縮約密度行列の誤差だけで決まるという主張の直接的な確認になっている。

一方でサイト分解は、中央だけを見ていては**原理的に見えない**二つの事実を出した。第一に、**利得は鎖に沿って一様ではない**(端で1.3–3.6倍高い)。これは prior の品質差ではなく — χ_p≥8 では全サイトで $G/G_{\max}=1$、つまりどこもショットノイズ律速である — **観測量自身の $\langle P\rangle(i)$ が開放端由来の Friedel 振動で変化し、天井 $G_{\max}$ を動かしている**ためである。§0で述べた「利得を支配するのは相対誤差 $\varepsilon=\Delta/\langle P\rangle$、 $|\langle P\rangle|$ は天井を決める」という描像が、同一の系の内部で場所を変えるだけで確認できた形になっている。

第二に、**「CRMは常に得」ではない**。χ_p=2 という粗いpriorでは、ドープ系のサイトの2〜3割で有意に損をし、最悪で25倍悪化する(損の**有無**は $n_m$ に依存しないが、粗い prior に $n_m=100$ を当てているぶん**深さ**は誇張されている — §0.5b)。中央のサイトだけを見ていた §2 ではこの領域に一度も触れていなかった。実用上の含意は明快で、**粗いpriorを使うなら最適係数CRM(実験6)を併用すべき**である。またこの「損」がドープ系に集中する点は、§9で得た「安いpriorが破綻するのはドープ系の電荷テクスチャ」という相図と整合する。

## 2d. 損の領域は「損をしないCRM」で直せるか(最適係数の検証)

スクリプト: [crm_site_beta.jl](crm_site_beta.jl) / [.pbs](crm_site_beta.pbs) / データ: [crm_site_beta_results.tsv](crm_site_beta_results.tsv)

§2b で、χ_p=2 の粗い prior を使うと**ドープ鎖の3割のサイトで CRM が有意に損をする**(最悪 G=0.037、標準シャドウの27倍悪い)ことが分かった。実験6の最適係数CRMは理論上 G≥1 を保証するが、係数 β を同じ設定から推定する以上、有限標本ノイズが修復分を食い潰さない保証はない。**この損の領域で実際に試したことは一度もなかった**ので、ここで検証する。

### セットアップ

- 系: L=16/64、 $t=1$、U=4、δ ∈ {0, 1/8}、χ_p ∈ {2,4,8,16,32}、 $n_m=100$、n_repeat=500、bootstrap 600
- $n_u \in \lbrace50, 100, 200\rbrace$ を**入れ子**(先頭50/100/200設定)で切り出すので、1回のサンプリングで済む
- 各設定 $u$ について $m_\rho(u)$(実験側ショット平均)と $Y(u)=E[X_\sigma|u]$(prior側厳密)を保持し、**6つの推定量を同一データで比較**:

| 推定量 | 定義 |
|---|---|
| 標準 | $\bar m_\rho$ |
| CRM(β=1) | $\bar m_\rho - (\bar Y - \mathrm{Tr}[O\sigma])$ |
| 素朴β | $\bar m_\rho - \hat\beta(\bar Y - \mathrm{Tr}[O\sigma])$, $\hat\beta = \widehat{\mathrm{Cov}}/\widehat{\mathrm{Var}}(Y)$ |
| 縮小β | $\hat\beta \cdot r^2/(r^2+1/n_u)$ で 0 方向に縮小 |
| 標本分割 | 前半で $\hat\beta$ を推定し後半に適用(交差適用) |
| **厳密Var** | 分母に**解析的な** $\mathrm{Var}(Y)$ を使う(下記) |
| **分割×厳密Var** | 上記2つの併用 |

**重要な指標上の注意**: $G$ は分散比なので**バイアスを見ない**。プラグイン $\hat\beta$ は同一データで係数を推定するため原理的にバイアスを持つので、**MSE比**(= (Var+bias²)_標準 / (Var+bias²)_CRM)と**バイアス/標準偏差**も併記する。分散比だけで比較するとプラグイン推定量を不当に有利に評価してしまう。

### 結果

**(1) 損は直る。ただし必要な設定数がある**

L=64, δ=1/8, χ_p=2(445点)での有意に損なサイト数:

| 推定量 | n_u=50 | n_u=200 | n_u=200 の min G |
|---|---|---|---|
| CRM(β=1) | **134/445** | **134/445** | 0.037 |
| 素朴β | 16/445 | **0/445** | 0.950 |
| 縮小β | 13/445 | **0/445** | 0.952 |
| 標本分割 | 66/445 | **0/445** | 0.937 |
| **厳密Var** | **0/445** | **0/445** | 0.967 |
| 分割×厳密Var | 8/445 | **0/445** | 0.937 |

**n_u ≥ 200 なら全ての最適β系が損を完全に消す**。n_u=50 では厳密Var版だけが損ゼロ。

**(2) プラグイン β̂ の破綻を同定した**

n_u=50 で残った病的な点は **52点すべてが二重占有、すべて χ_p=2**。β の中央値は 0.48–0.67 と正常なのに標準偏差が 185–6480 という裾の重い分布になっていた。原因は数値に出ている: ⟨P⟩ = 0.0995 に対し Δ = 0.0995、つまり **⟨P⟩_σ = 0.0000** — χ_p=2 の prior は本質的に Néel 積状態でダブロンを含まないため二重占有をゼロと予言し、**Var(Y)=0 の 0/0 割り算**になる。r² による縮小が効かないのも当然で、分子分母が同じノイズに駆動されるため標本 r² は偽の高値を出す。

**解決**: $Y(u) = \sum_t c_t\mathbf 1[\text{基底一致}]3^{|A_t|}\langle P_t\rangle_\sigma$ であり、基底は既知の一様分布($\Pr[\text{項}t\text{が一致}] = 3^{-|A_t|}$、 $\Pr[t,t'$ 同時 $] = 3^{-|A_t\cup A_{t'}|}$、重なりでPauli指定が矛盾すれば0)なので、**Var(Y) は prior だけから閉形式で計算できる**。標本推定をやめれば発散は起きない。40万サンプルの経験分散と 0.5% 以内で一致することを確認済み。

これは**元のCRM推定器を直したときと同じ原理の再適用**である(§1: prior側は有限ショットでサンプルせず厳密に計算する)。

**(3) しかし MSE で測ると推奨が変わる**

L=64, δ=1/8, n_u=200 の中央値 MSE比:

| 推定量 | χ_p=2 | χ_p=4 | χ_p=8 | χ_p=32 | max&#124;bias&#124;/sd |
|---|---|---|---|---|---|
| CRM(β=1) | 1.00 | 4.32 | 16.68 | 19.44 | 0.13 |
| **素朴β** | 1.01 | **17.46** | **18.60** | 18.60 | 0.59 |
| 縮小β | 1.01 | 17.49 | 18.61 | 18.61 | 0.58 |
| 標本分割 | 1.01 | 16.69 | 17.95 | 18.02 | 0.14 |
| 厳密Var | 1.02 | 5.94 | 6.73 | 6.78 | **0.78** |
| 分割×厳密Var | 1.01 | 4.60 | 5.17 | 5.29 | 0.12 |

**厳密Var版は「絶対に損をしない」代わりに、典型的な利得が3分の1になる**。分散比だけ見ていると厳密Var版が優れて見えるが、MSE で見ると素朴βが最良である。したがって実務的な推奨は:

- **$n_u \ge 200$ が取れるなら素朴な(または縮小) $\hat\beta$** — MSE最良かつ損ゼロ
- **$n_u$ が小さいなら厳密Var版** — 利得は3分の1だが損が絶対に出ない
- バイアスが問題になる用途(系統誤差を厳密に管理したい場合)は標本分割版(バイアス 0.12–0.15σ、MSE は素朴βとほぼ同等)

**(4) priorフリー性の再確認と、その限界**

χ_p を変えても $G_\beta$ が**小数点2桁まで不変**になる観測量がある。これはノート§3.7の「一致インジケータによるpriorフリー制御変量」が働いているためで、単一Pauli列では $Y \propto \langle P\rangle_\sigma$ が $\hat\beta(\bar Y - \mathrm{Tr}[O\sigma])$ の中で約分され、**推定量が prior に一切依存しなくなる**。

| 観測量 (site=5) | χ_p=2 → 32 の $G_\beta$ | prior依存 |
|---|---|---|
| ZZ onsite(単一Pauli列) | 13.27 → 13.27 | なし(完全にprior-free) |
| ZZ up-up r=1 | 14.39 → 14.39 | なし |
| n, hop(係数対称な2項) | 3.54 → 3.54 | なし |
| **二重占有**(4項) | **1.28 → 12.5 → 16.8** | **あり** |
| **SzSz r=1**(4項) | **1.00 → 5.3 → 15.3** | **あり** |

つまり「粗い prior でも最適βなら利得が出る」の実体は、**単一Pauli列では prior を捨てた推定量に切り替わっている**ということである。忠実度 $10^{-17}$ の prior でも $G\approx15$ が出るのは、prior をうまく使っているのではなく使っていないからで、この点は§2b の「利得はprior誤差で決まる」という主張と矛盾しない(β=1 の CRM に限った話である)。

**限界も明確になった**。χ_p=2, δ=1/8 での観測量別 MSE比:

| 観測量 | CRM(β=1) | 素朴β | 天井 $G_{\max}$ |
|---|---|---|---|
| ZZ onsite | 0.60(損) | **20.68** | 21.90 |
| ZZ up-up r=1 | 1.00 | **18.98** | 19.95 |
| 二重占有 | 0.97 | **15.40** | 21.13 |
| SzSz r=1 | 1.00 | 1.00 | 15.25 |
| hop up r=1 | 1.00 | 1.00 | 35.74 |
| n, Sz | 1.00 | 0.99 | 2.31, 1.96 |

ZZ系は**忠実度 $10^{-17}$ の prior で天井の94–95%に到達する**一方、SzSz とホッピングは天井が高い(15.3, 35.7)のに**最適βでも何も得られない**。理由は同じ Var(Y)=0 で、χ_p=2 の prior はホッピング振幅を厳密にゼロと予言するため $Y\equiv0$ となり、制御変量として使える情報が存在しない。つまり:

- **Var(Y)=0**: 制御変量が原理的に存在しない → β=0 に落ちて標準シャドウに戻る(損もしないが得もしない)
- **Var(Y) が小さいが非ゼロ**: プラグイン $\hat\beta$ が不安定 → 厳密 Var(Y) で解消

### 解釈

§2b が出した「CRMは常に得ではない」という否定的結果に対して、**実務的な解答が得られた**: 設定数を $n_u\ge200$ 取り、係数をプラグイン推定すれば、この研究で調べた範囲では損は一つも残らない。同時に、分散比という指標の落とし穴(バイアスを見ない)と、プラグイン推定の失敗モード(Var(Y)=0)と、その原理的な解決(prior側は解析的に計算する)が明らかになった。最後の点は、この研究の出発点だった推定器のバグ修正とまったく同じ発想であり、**「prior側で標本推定に頼らない」という設計原則が推定量の各所で繰り返し効く**ことを示している。

## 2e. 局所性はどこまで成り立つか — 必要ボンド次元 $\chi^\ast(L)$ で測る

スクリプト: [crm_gap_scaling.jl](crm_gap_scaling.jl)(第1版)、[crm_chistar.jl](crm_chistar.jl)(**再設計版**) / 収束診断 [crm_gap_conv2.jl](crm_gap_conv2.jl) / 図: [crm_gap_scaling.png](crm_gap_scaling.png) / データ: [crm_chistar_fixed.tsv](crm_chistar_fixed.tsv)

§2b(5)で「 $\Delta$ の L 非依存性は粗い prior でしか成り立たない」ことが分かった。では**局所性はどこで破れるのか**。仮説は「gapless なセクターがあると、固定 $\chi$ の prior が捉えられる割合が L とともに落ちる」である。

### 第1版は失敗した — そして失敗の理由が重要だった

最初は「固定 $\chi_p$ での相対誤差 $\varepsilon$ の L 依存」を測った。結果は**χ_p に対して頑健でなかった**: 同じ系(U=4 半充填)で $\varepsilon(L{=}128)/\varepsilon(L{=}32)$ が $\chi_p=4,8,16,32$ に対し 1.08, 1.20, 1.03, 9.18 と桁で変わり、χ で平均すると全配置が 1.8–3.1倍に潰れて gapped/gapless の区別が消えた。

**原因**: $|\Delta|(\chi)$ は**単調ではない**。偶然の打ち消しでくぼみができる(U=4 半充填 L=64 では χ=8 が χ=16 より7倍良い)。単調でない量の、しかも比を取れば、どの χ で切るかで答えが変わるのは当然である。

> **方法論上の教訓**: 単一の χ での比較を信用してはいけない。同じ罠で一度、「U=8 半充填の異常」という存在しない現象を報告しかけた(U=8/U=4 の $|\Delta|$ 比は χ=4,8,16,32 で 0.43, **7.31**, 0.21, 0.55 — 7.31倍は χ=8 だけのアーティファクト)。

### 再設計: 「目標精度に必要な χ」を測る

指標を逆にする。固定 χ での誤差ではなく、

```math
\chi^*(\varepsilon_{\rm target}, L) \equiv \min\{\chi : \varepsilon(\chi') < \varepsilon_{\rm target}\ \text{が全ての}\ \chi'\ge\chi\ \text{で成立}\}
```

を測る。「最後に閾値を上から横切った点」を取るので**非単調性に影響されず、定義上 L について単調**になる。しかも「この精度が欲しいならχはいくつ必要か」という実務的な問いに直接答える量である。

- 系: $t=1$、U ∈ {1,2,4,8} の half-filling と U ∈ {4,8} の δ=1/8、L = 16/32/64/128、χ ∈ {2,…,256} の14点掃引(U=0 の自由フェルミオンも $t=1$ で含む)
- Δ は窓RDMから厳密に計算できるので **Monte Carlo 不要**(DMRG と RDM 縮約のみ)
- 中央ボンドエントロピーから中心電荷 $c$ を**独立に**読む(gapless なら $S_c=(c/6)\ln L+$ const)

> **実装上の注意**: $\chi$ が DMRG の maxlinkdim を超える点は「切断が厳密($\varepsilon=0$)」なので目標を満たすものとして扱う必要がある。ここを「未測定=失敗」と扱うと、**ボンド次元が小さくて済む強結合の系ほど $\chi^\ast$ が大きく出る**という逆転が生じる(最初この扱いを誤り、U=8 半充填だけ $\chi^\ast>256$ という異常が出た)。

### 設計上の反省(第1版で判明、修正済み)

1. **絶対誤差ではなく相対誤差を使うべきだった**。U=0 では χ_p=8 が自由フェルミオン基底状態をほぼ厳密に表現でき $\Delta=3\times10^{-11}$ になるため、比が10⁶倍になるのは物理ではなく基準値の問題である。自分たちで確立した「利得を支配するのは相対誤差」を、この実験の指標選びに適用できていなかった。
2. **U=8 で nsweeps=16 では DMRG が収束していなかった**。 $S_c$ が L=64→128 で減少するという異常で気づいた(c=1 なら +0.116 のはず)。30スイープで解消し、増分 0.107 と予言値 0.1155 がほぼ一致。χ=512 にしても変わらないのでスイープ数が原因だった。**強結合では必ず収束確認をすること**。

### 結果

$\chi^\ast(\varepsilon<10^{-2})$ の L 依存(観測量5種):

| 配置 | χ*(L=16) | χ*(L=128) | 比(幾何平均) | 指数 $p$ | $c$(独立測定) |
|---|---|---|---|---|---|
| U=4 half(電荷gapped) | 10.0 | **15.1** | **1.52** | 0.200 | 0.92 |
| U=8 half(強くgapped) | 8.9 | **15.1** | **1.70** | 0.255 | 0.91 |
| U=2 half(ギャップ極小) | 13.9 | 24.8 | 1.78 | 0.278 | 0.99 |
| U=1 half(ξ_c が巨大) | 16.4 | 35.5 | 2.17 | 0.372 | 1.53 |
| U=4 δ=1/8(電荷gapless) | 13.5 | **30.9** | **2.30** | 0.400 | 1.64 |
| U=8 δ=1/8(電荷gapless) | 12.4 | **32.8** | **2.64** | 0.467 | 1.66 |

**指標を変えただけで、第1版で消えていた区別がはっきり出た。**

1. **ギャップのある系は飽和する**。U=4 半充填では χ* が L=32 以降 16 のまま動かない(観測量5種すべて)。 $L$ を4倍にしても必要な prior の質は変わらない — これが「局所性」の最も直接的な形である。
2. **gapless な系は増え続ける**。ドープ系では χ* が L=16 の 12–14 から L=128 の 31–33 へ、 $\chi^\ast\propto L^{p}$($p\approx0.40$– $0.47$)で増加する。
3. **増加指数 $p$ は中心電荷 $c$ と corr = +0.95 で相関する**。 $c$ はエントロピーから**独立に**測った量なので、これは「gapless セクターの数が prior の必要品質を決める」という仮説の直接的な確認である。

$S\sim(c/6)\ln L$ から $\chi\sim e^{S}=L^{c/6}$ が期待されるが、実測の $p$ は $c/6$ の平均 1.55 倍である。**観測量を固定精度で当てることは、エントロピーを再現することより厳しい要求**なので、この向きのずれは自然である(ただし比例係数の由来は未解明)。

### 解釈

**局所性には明確な適用条件がある**: 「同じ prior 品質で系を大きくできる」のは**ギャップのある系に限る**。gapless なセクターがあると必要な χ は $L^{c/6}$ 程度で増え続ける。ただし増加は**代数的で緩やか**であり、L を8倍にしても χ* は2〜3倍にしかならない。実用上は「ドープ系では L に応じて prior の χ を少しずつ上げる必要があるが、指数的な破綻ではない」と読める。

この節はもう一つ、**実験設計そのものについての教訓**を残した。第1版と再設計版は同じ物理・同じデータ生成過程を測っており、違うのは**何を指標にしたか**だけである。非単調な量の比を取ると結論が消え、単調になるよう定義し直すと corr=0.95 の関係が現れる。**指標が単調で well-defined かを先に確認すべき**である。

## 3. ショット配分と相図(U・ドーピング依存)

スクリプト: [crm_param_sweep.jl](crm_param_sweep.jl) / 図: [crm_param_sweep.png](crm_param_sweep.png)

### セットアップ

- 実験A(配分): L=8、 $t=1$、U=4で $n_m \in \lbrace1,3,10,30,100,300,1000\rbrace$($n_u=50$固定、n_repeat=400/100/nm≥1000は50)。 **$n_m=1$ は標準的な古典シャドウの設定そのもの**で、当初この掃引から抜けていたので追加した(§0.5b)。
- 実験B(相図): L=16で U ∈ {1,4,8}(half-filling)+ U=4ドープ(16サイトに電子14個、 $n=7/8$)。χ_exp=96、n_repeat=60。

> **この掃引は総ショット数を固定していない。** $n_u=50$ を固定して $n_m$ を振るので、総ショット数 $n_u n_m$ 自体が $50$ から $50{,}000$ まで1000倍変わる。したがってここで $n_m$ とともに $G$ が伸びるのは「配分を良くした」結果ではない。**配分そのものの問題**( $B=n_u n_m$ を固定して $n_m$ を振る)は §0.5b で別に測った。

**なぜ $n_u$ を固定して $n_m$ だけを振るのか。** 利得法則の分母・分子に共通して入る $v_s=3^{|A|}(1-\langle P\rangle^2)/n_m$ だけが $n_m$ に依存し、 $n_u$ は約分されて $G$ に現れない(§1の導出)。したがって **$n_m$ は「打ち消せない床の高さ」を動かす唯一のつまみ**である。 $n_m$ を大きくすると床が下がり、 $\Delta\to0$ の極限で

```math
G_{\max}(n_m) = 1 + n_m\,\frac{(3^{|A|}-1)\langle P\rangle^2}{3^{|A|}(1-\langle P\rangle^2)}
```

と **$n_m$ に線形**で伸びる(飽和則)。実験Aはこの直線を実測で引く。 $n_u$ を変えても $G$ は変わらないはずなので振る必要がない — ただし $n_u$ は推定値そのものの分散($1/n_u$ 倍)を決めるので、 $n_u=50$ は「 $G$ の測定精度」を確保するための固定値である。

**なぜ相図を $U$ とドーピングで切るのか。** 利得を決める2つの入力 $\langle P\rangle$ と $\Delta$ は、どちらも物理領域で大きく変わる。 $U$ を変えると観測量の期待値 $\langle P\rangle$ が変わり(＝天井 $G_{\max}$ が動く)、ドーピングを変えると基底状態のエンタングルメントが変わって同じ $\chi$ の切断priorの誤差 $\Delta$ が変わる。**この2つを別々に動かせるのが $U$ とドーピングという2つのつまみ**であり、実験Bはこの平面上で $G$ を測る。

### 結果

- **A**: 飽和則(Gの上限が $n_m$に線形)を理論曲線ごと確認。掃引は $n_m=1$ から始まる(245点)。ただし**「利得 $G$ の最大化」と「分散の最小化」は別物**である(下記の注意)。

  **$n_m=1$ での実測**(ZZ onsite、 $\langle P\rangle=-0.600$ 、 $n_u=50$ 、n_repeat=400):

  | χ_p | 2 | 4 | 8 | 32 |
  |---|---|---|---|---|
  | $G$(実測) | 1.36 | 1.60 | 1.60 | 1.60 |
  | $G$(理論) | 1.23 | 1.50 | 1.50 | 1.50 |

  **prior を $\chi_p=4$ より良くしても $G$ は 1.60 で止まる。** 上限 $1/(1-\langle P\rangle^2)=1.56$ に対応しており、 $n_m=1$ では利得が prior の質ではなく観測量だけで決まることの直接確認である(§0.5b)。

> **注意: 利得を最大化する配分は、誤差を最小化する配分ではない。**
> 総ショット数 $B=n_u n_m$ を固定すると
> $$\mathrm{Var}[\text{CRM}] = \frac{1}{B}\Bigl[(3^{|A|}-1)\Delta^2 n_m + 3^{|A|}(1-\langle P\rangle^2)\Bigr]$$
> となり、 **$n_m$ に単調増加**する(標準シャドウも同様)。すなわち固定予算では $n_m=1$(設定を最大限多く)が分散最小である。一方 $G$ は比なので $n_m$ とともに増える。数値例($|A|=2$, $\langle P\rangle=0.6$, $\Delta=0.05$, $B=5000$):
>
> | $n_m$ | 1 | 10 | 100 | 1000 |
> |---|---|---|---|---|
> | $B\cdot\mathrm{Var}$[CRM] | **5.78** | 5.96 | 7.76 | 25.8 |
> | $G$ | 1.49 | 5.80 | 37.9 | 112 |
>
> **この表は数値例だが、実測でも確認済みである** — §0.5b で総ショット数を固定して配分だけを振ると、CRM 側の誤差はほぼ不変のまま標準シャドウだけが20倍悪化した。実務的に正しい読み方は次の2点である。(i) $n_m$ が**ショットノイズ支配の閾値** $n_m^\ast = 3^{|A|}(1-\langle P\rangle^2)/[(3^{|A|}-1)\Delta^2]$(この例では288)以下なら、 $n_m$ を増やしても分散はほとんど悪化せず $G$ だけが大きく伸びる — つまり**ほぼタダで利得が買える**。(ii) 閾値を超えると分散が線形に悪化する。したがって「設定を絞れ」という指針ではなく、**「 $n_m \lesssim n_m^\ast$ の範囲なら設定数を減らして構わない」**が正しい。実機で測定基底の切り替えコストが高い場合(=大きな $n_m$ を強いられる場合)にCRMの価値が最も高くなる、という形で効いてくる。

- **B**(χ=8 priorでのG):

| 領域 | prior忠実度 | onsite ZZ | 二重占有 | ホッピング |
|---|---|---|---|---|
| U=1(弱結合) | 0.81 | 2.8 | 2.1 | **45.8** |
| U=4 | 0.95 | 44.2 | 22.5 | 23.8 |
| U=8(Mott) | 0.98 | **466.7** | 160.5 | 9.5 |
| U=4 doped | 0.80 | 15.6 | 18.7 | 43.4 |

**表の読み方**: 行が物理的な領域(相互作用の強さとドーピング)、列が観測量ごとの**利得 $G$**($\chi_p=8$ の切断MPS priorを使用)。太字は各行で最も得をする観測量。**利得の分布が物理を反映している**のが要点: 弱結合($U=1$、電子が動き回る金属的な状態)では運動エネルギー(ホッピング)の期待値が大きいのでそこで得をし、強結合($U=8$、電子が各サイトに凍りつくMott状態)では密度・スピン型が主役になり onsite ZZ で $G=467$ に達する。2列目のprior忠実度は、 $U=1$ やドープ系でエンタングルメントが大きく同じ $\chi$ でも近似が苦しくなることを示す。

### なぜこの数字になるのか(表の各行の物理)

表の数字は理論式と物理から順に説明できる。天井は $G_{\max}\propto\langle P\rangle^2/(1-\langle P\rangle^2)$ で決まるので、まず各領域で $\langle P\rangle$ がどうなるかを見ればよい。

**$U=8$ の onsite ZZ が $G=467$ と突出する理由。** onsite ZZ は二重占有の一次関数 $\langle Z_\uparrow Z_\downarrow\rangle = -1+4\langle D\rangle$ である(§0.3の $Z_q=1-2n_q$ から2行で出る)。強結合では二重占有が $\langle D\rangle\sim(t/U)^2$ と抑制されるので $\langle P\rangle\to-1$ に近づく。ところが $\langle P\rangle^2/(1-\langle P\rangle^2)$ は $|\langle P\rangle|\to1$ で**発散する**。 $U=8$ では $\langle D\rangle\approx0.03$ すなわち $\langle P\rangle\approx-0.88$ で、 $0.774/0.226=3.4$ となり天井が非常に高くなる。 $U=4$ なら $\langle D\rangle\approx0.09$、 $\langle P\rangle\approx-0.64$ で $0.41/0.59=0.69$ — 同じ観測量でも天井が5倍違う。

**$U=1$ でホッピングが $G=45.8$ と最大になる理由。** 弱結合では電子が動き回るので運動エネルギーの期待値 $|\langle c^\dagger c+\mathrm{h.c.}\rangle|$ が大きい。逆に $U=8$ の Mott 状態では電子が各サイトに凍りついてホッピング振幅が $\sim t/U$ に抑制され、 $\langle P\rangle$ が小さくなって天井が下がる($G=9.5$)。**同じ観測量の利得が $U$ で5倍変わるのは、prior の質ではなく観測量自身の大きさが変わるため**である。

**prior忠実度の列が $U=1$ とドープ系で下がる($0.81, 0.80$)理由。** 弱結合では電荷の自由度が凍らず、ドープ系ではホールが動き回るので、どちらも基底状態のエンタングルメントが大きい。同じ $\chi=8$ で切断したときに捨てる重みが増え、忠実度が下がる。**これは $\Delta$ を大きくする方向に働く**ので、天井が高くても実際の $G$ が伸びない要因になる。

### 解釈

利得の観測量マップは物理を反映する。弱結合(金属的)では運動エネルギーが大きな期待値を持ち(=利得の天井が高い)、強結合(Mott)では密度・スピンが主役になる。ただし**天井が高いことと実際に利得が出ることは別**で、実際の $G$ を決めるのはその観測量に対するpriorの相対誤差 $\Delta/\langle P\rangle$ である(この点は§0の統計プロトコル末尾と[観測量解説](paper/crm_observables.pdf)§10.1で詳述)。またU=1やドープ系では基底状態のエンタングルメントが大きく、同じχの切断priorの忠実度が下がる(0.81, 0.80)ことも見える。**「どの物理領域で・どの観測量に・どれだけ得か」が理論式と2つの入力($\langle P\rangle, \Delta$)から読める**、というのがこの実験の要点。

## 4. 2Dシリンダー: タダの平均場priorはMPS priorに代われるか(W=4、64量子ビット)

スクリプト: [crm_2d_cylinder.jl](crm_2d_cylinder.jl), [crm_2d_symuhf.jl](crm_2d_symuhf.jl) / 図: [crm_2d_cylinder.png](crm_2d_cylinder.png), [crm_2d_symuhf.png](crm_2d_symuhf.png), 清書 [crm_fig3_priors2d.png](crm_fig3_priors2d.png)

### セットアップ

- 系: 4×8シリンダー(y方向周期・x方向開放)、64量子ビット、 $t=1$(軸方向・円周方向とも同一、異方性なし)、U ∈ {4, 8}、half-filling。スネーク順にJW。ρ=DMRG χ=192。
- prior:
  - **UHF**: Néel初期値からの自己無撞着共線平均場(副格子磁化 m=0.34/0.45)。Slater行列式なので相関行列 $C=\Phi\Phi^\dagger$ から**Wickの定理で** $\langle Z\rangle, \langle ZZ\rangle, \langle\text{hop}\rangle$ が閉形式になり、**MPS表現が一切不要・コスト $O(N^3)$**。
  - **UHF-sym**(対称性回復): スピン回転で平均した混合状態 $\bar\sigma = \int d\Omega R|{\rm UHF}\rangle\langle{\rm UHF}|R^\dagger$。回転後も一般化Slater行列式なので、フル $2n\times2n$相関行列 $C(\theta)$ に対する同じWick式で厳密計算(共線秩序のz軸対称性により極角の1次元求積・64点)。**CRMのpriorは $\langle P\rangle_\sigma$ しか要らないので混合状態でも使える**ことの実例。
  - 比較対象: ρのχ切断MPS(χ ∈ {8,16,32,64})。
- 観測量: 中央サイト周りの onsite ZZ / ZZ(y隣・y距離2・x隣) / 二重占有 / SzSz(y,x) / yボンドホッピング。窓10量子ビット。 $n_u=50, n_m=100$、n_repeat=50。UHF系とMPS系は**同一の測定データ**で後処理だけ変えて比較。
- 検証: 4×2シリンダー(16量子ビット、χ=256でMPS表現が厳密)でエネルギー・全Wick式をDMRGと機械精度(~1e-13)で照合。一般化Wickはθ=0で共線と一致(1e-16)、U=0一重項で回転平均不変(1e-16)。

### 結果

前提の確認として、2DではMPS priorが急劣化する(U=4: χ=8で F=0.055。1D L=16の同じχは0.95)。**同じ $\chi=8$ でも1Dと2Dで忠実度が17倍違うのは、蛇行順で1次元に並べた2D系では切り口が幅 $W$ の1列を横切るため、必要なボンド次元が $\chi\sim e^{cW}$ と幅に対して指数的になるためである**(§8で定量化)。つまり2Dは「MPS priorが高価になる領域」であり、**タダの平均場priorが代われるかを問う意味がある唯一の場所**でもある。そのうえで:

| U=4 | G(UHF) | G(UHF-sym) | G(χ=16) | G(χ=64) |
|---|---|---|---|---|
| onsite ZZ | **44.0** | 44.0 | 13.9 | 44.5 |
| 二重占有 | 6.6 | 3.4 | 10.5 | 34.2 |
| ホッピング | **11.8** | 11.8 | 15.4 | 15.4 |
| ZZ x隣 | 0.83 | **8.69** | 5.8 | 8.6 |
| SzSz x | 0.81 | **6.11** | 3.9 | 6.9 |

**表の読み方**: 行が観測量、列が**priorの種類**。左2つ(UHF, UHF-sym)は $O(N^3)$ で作れる**タダの平均場prior**、右2つ($\chi=16,64$)は**高価なMPS prior**(DMRGを回して切断する)。数字は利得 $G$ で、**タダのpriorが高価なMPSに匹敵しているか**を見る表である。上3行(オンサイト量・運動項)では UHF が $\chi=64$ に並ぶ一方、下2行(サイト間スピン相関)では素のUHFが $G<1$(損)に落ち、対称性回復した UHF-sym がそれを $\chi=64$ 相当まで救っている。
(U=8ではさらに顕著: onsite ZZ で UHF G=241 vs χ=64 の 243)

- **オンサイト量と運動項ではタダのUHFがχ=32–64のMPS priorと同等**。
- **サイト間スピン相関では素のUHFは失敗**(G≤3、時に<1): 凍結したNéel秩序は量子揺らぎを含まず $|\langle S^zS^z\rangle|$ を過大評価する($\Delta\approx0.2{-}0.4$)。
- **対称性回復UHFが弱点を全て修復**: 回転不変な観測量(onsite・hop・docc)は厳密に不変のまま(理論予言と一致)、スピン相関はχ=16–64 MPS相当まで改善。
- 唯一の退行: 二重占有 6.6→3.4。演算子はSU(2)不変で観測量全体のΔは両priorで同一なのにGが変わる — **多項観測量の利得は「項ごとのΔ」に依存**し、χ=192の参照状態自体がNéel対称性を破っているため、項ごとの $\langle Z_q\rangle$ は共線UHFの方が合う。

### 解釈

2Dはこの手法の本命の適用先で、結論は「**幅広な系では、DMRGを回さなくてもWickで書ける平均場が測定効率化のpriorとして十分機能する**」。対称性回復の成功は、(i) 混合状態priorという概念的拡張が実際に役立つこと、(ii) priorの誤差の物理的起源(凍結秩序)を特定すれば安価に直せることを示す。二重占有の退行は一見バグに見えるが、「priorの対称性は実験状態の対称性(破れの程度)に合わせるべき」「priorは古典後処理なので観測量ごとに使い分ければよい(追加測定ゼロ)」という2つの実務指針に変換できる。

## 4b. 2Dサイト分解: 安価なpriorはどこで破綻するか

スクリプト: [crm_2d_site.jl](crm_2d_site.jl) / [.pbs](crm_2d_site.pbs)、解析 [crm_2d_site_plot.jl](crm_2d_site_plot.jl) / 図: [crm_2d_site.png](crm_2d_site.png)

§9 は「安いpriorが破綻するのはドープ系の電荷テクスチャ」を示唆したが、**どこで**破綻するかの空間地図はなかった。1Dのサイト分解(§2b)で $\Delta(i)$ がほぼ一様だったのと対照的なはずである。窓RDMサンプリングはスネーク順で窓が連続なら2Dでもそのまま使えるので、これを地図にする。

### セットアップ

- W=4×Lx=8 シリンダー(64量子ビット)、 $t=1$(軸方向・円周方向とも同一、異方性なし)、U ∈ {4,8}、half-filling と 1/8ドープ。ρ=DMRG χ=512
- prior: UHF平均場、χ切断MPS(χ_p ∈ {8,32})、完全prior
- 各サイトで n, Sz, 二重占有, onsite ZZ と、スネーク順で隣接するサイトとの ZZ・SzSz
- Δ は窓RDMから厳密に計算(Monte Carlo不要)。利得 G も同じ窓からサンプル

### 結果

**(1) 安いpriorだけが空間的に大きく不均一**

相対誤差のサイト間変動(max/min):

| 系 | 観測量 | χ_p=8 | χ_p=32 | **UHF** |
|---|---|---|---|---|
| U=8 half | ZZ onsite | 2.9 | 3.8 | **1.4** |
| U=8 half | 二重占有 | 2.3 | 3.0 | **1.8** |
| U=8 δ=1/8 | ZZ onsite | 411 | 19.1 | **9.9** |
| U=8 δ=1/8 | 二重占有 | 55.9 | 7.8 | **19.8** |
| U=8 δ=1/8 | SzSz 隣接 | 16.3 | 11.2 | **52.9** |

半充填では UHF の空間変動は小さい(1.4–3.0倍)が、**ドープすると一桁に跳ね上がる**(9.9–52.9倍)。図の地図を見ると、UHF の誤差は**列 x にのみ依存する縞構造**を示す(ドープで生じる電荷変調が x 方向にのみ立つため)のに対し、切断MPS priorの誤差はまだら模様で系統的な構造を持たない。

**(2) UHF の誤差は局所ホール密度で予測できる**

$\ln\varepsilon_{\rm UHF}$ と局所密度の相関:

| 系 | 観測量 | corr(lnε, \|n−1\|) 真の密度 | corr(lnε, \|n−1\|) UHF予言密度 |
|---|---|---|---|
| U=8 δ=1/8 | ZZ onsite | **+0.87** | +0.61 |
| U=8 δ=1/8 | 二重占有 | **+0.83** | +0.29 |
| U=4 δ=1/8 | ZZ onsite | +0.50 | +0.69 |
| U=4 δ=1/8 | 二重占有 | **+0.98** | +0.64 |
| U=8 δ=1/8 | SzSz 隣接 | +0.14 | −0.48 |

**安いpriorは、ホールがある場所でちょうど破綻する**。§9 の定性的な示唆が、相関係数 0.83–0.98 という定量的な形で確認された。

### 解釈

**自己診断は可能だが限定的**、というのがこの実験の実務的な結論である。真の密度を使えば UHF の破綻箇所は 0.83–0.98 の相関で予測できるが、実際に手元にあるのは UHF が自分で予言する密度である。それを使うと相関は 0.29–0.69 に落ちる。理由は明快で、**UHF の密度プロファイル自体が真の値と corr 0.42–0.55 でしか一致しない** — つまり「安いpriorが最も間違える量(電荷テクスチャ)」が「安いpriorがどこで間違えるかを教えてくれる量」でもある、という circular な状況になっている。

それでもオンサイト量については正の相関が残る(0.29–0.69)ので、**「UHF が予言するホール密度が高い領域では CRM の利得を割り引いて見積もる、あるいは最適係数版に切り替える」という実務的な指針は成立する**。一方サイト間スピン相関では相関が負になり、この指標は使えない(UHFのスピン相関の失敗は電荷テクスチャとは別機構であり、§4b の対称性回復UHFが対処する問題である)。

## 5. matchgate(フェルミオンGauss)シャドウ: JW弦問題と、CRMの適用範囲

スクリプト: [crm_matchgate.jl](crm_matchgate.jl), [crm_matchgate_nm.jl](crm_matchgate_nm.jl) / 図: [crm_matchgate.png](crm_matchgate.png)

### セットアップ

- 系: W=4×Lx=2 シリンダー(8サイト、16量子ビット)、 $t=1$(異方性なし)。**x方向ボンドがJW上で $|A|=9$の弦付きになる最小の2D系**で、 $2^{16}$次元の密ベクトルにより測定を厳密シミュレーションできる。ρ=DMRG基底状態を密ベクトル化。U ∈ {4,8}。

**なぜ $|A|=9$ になるのか(この節の出発点)。** スネーク順でJW変換すると、同じ列内の $y$ 方向の隣は量子ビット順でも隣接するが、 $x$ 方向の隣は**列を1つまたぐので $W$ サイト分($=2W$ 量子ビット)離れる**。JW変換のホッピング項 $c^\dagger_a c_b+\mathrm{h.c.} = (X_a Z\cdots Z X_b + Y_a Z\cdots Z Y_b)/2$ は、その間の全量子ビットに $Z$ の「弦」を引きずるので、台は両端の2個＋間の $2W-1$ 個 $=2W+1$ 個になる。 $W=4$ なら $|A|=2\cdot4+1=9$ である。これが2Dで古典シャドウが破綻する構造的な理由で、 $W$ を増やすと**指数的に**測れなくなる。
- matchgateシャドウ: Haar一様な $Q\in SO(2n)$($n=16$モード、QR分解で生成)を隣接Givens回転列(=Z回転とXX回転のゲート列、約500個)に分解して状態に適用し、占有数基底で測定。推定量はMajorana単項式ごとに $X_S(b) = \lambda_{2k}^{-1}\sum_{S'}\det(Q[S,S'])\langle b|\Gamma_{S'}|b\rangle$、チャネル係数 $\lambda_{2k} = \binom{n}{k}/\binom{2n}{2k}$。

**なぜこれで弦問題が消えるのか。** Pauliシャドウは「各量子ビットを独立に X/Y/Z のどれで測るか」を選ぶので、観測量の台が長いほど全一致が起きにくくなる — 台の**空間的な長さ**がそのまま難しさになる。matchgateシャドウはランダムな**Gauss(フェルミオン線形)変換** $Q\in SO(2n)$ をかけてから測るので、効くのは観測量が Majorana 演算子の**何次式か**だけである。ホッピングは $c^\dagger_ac_b+\mathrm{h.c.}$ という**2次**の量なので、 $a$ と $b$ が空間的にどれだけ離れていても同じ次数であり、 $y$ ボンドと $x$ ボンドが同じ難しさになる。 $\lambda_{2k}=\binom{n}{k}/\binom{2n}{2k}$ はこの「 $2k$ 次の Majorana 単項式」に対する測定チャネルの固有値で、Pauliシャドウの $3^{-|A|}$ に相当する逆チャネル係数である。 **$k$(次数)だけに依存し、空間的な広がりに依存しない**のが要点。
- **CRMのprior側(UHF)はPfaffianで厳密**: 回転後の2点関数 $K' = Q^T K Q$ の部分Pfaffianで $E[X_\sigma|u]$ が閉形式になる(Slater priorとmatchgate測定の構造的な相性)。
- 観測量: yボンドhop($|A|=3$相当)、**xボンドhop(Pauliでは $|A|=9$)**、二重占有、SzSz、全エネルギー(運動項+U×二重占有)。 $n_u=50, n_m=100$、n_repeat=40。Pauliシャドウ(±CRM)と同一予算で比較。
- 検証: ゲート列が $U\gamma_\mu U^\dagger = \sum_\nu Q_{\mu\nu}\gamma_\nu$ を実現(1e-15)、Majorana展開係数=密行列(1e-10; この検証が実装中の符号ミスを2件検出した)、推定量の不偏性(統計)、Pfaffian=全数和(1e-8)、エネルギー真値=DMRGの $E_0+\mu N$(1e-6)。

### 結果

| 推定誤差(U=4) | Pauli標準 | Pauli+CRM | MG標準 | MG+CRM |
|---|---|---|---|---|
| hop yボンド | 0.211 | 0.052 | 0.098 | 0.096 |
| hop **xボンド** | **測定不能** | prior値を返すだけ | **0.095** | 0.076 |
| 全エネルギー | 11.5 | 0.88(要注意) | **0.87** | 1.01 |

**表の読み方**: 数字は $G$ ではなく**推定値の標準誤差**(小さいほど良い)。列は測定方式の4通り: Pauli標準/Pauli+CRM/matchgate標準(MG)/matchgate+CRM。要点は2行目で、 $x$ 方向ボンドはJW弦のため $|A|=9$ となり、Pauliシャドウでは基底が一致する確率が $3^{-9}\approx1/2$万で**5000設定で一度もサンプルされず測定不能**(CRMを付けてもpriorの値をそのまま返すだけ)。matchgateなら同じ予算で $y$ ボンドと同等の精度で測れる。3行目の全エネルギーはPauli標準の11.5に対しMGが0.87と**約13分の1**。
- xボンドのPauli基底一致確率は $3^{-9}\approx1/2$万で、5000設定では**一度もサンプルされない**(推定値恒等0)。matchgateでは演算子の"次数"(2次Majorana)だけが効くので、xボンドもyボンドと同精度。全エネルギーの誤差はPauli標準の約13分の1。
- **Pauli+CRMの隠れバイアス**: 測定されない項のCRM推定はpriorの値をそのまま返すため、誤差0.88に見えて平均が−5.35と真値−5.95からズレる(UHFのxボンド誤差ぶん)。有限予算では実質バイアス推定量。
- **CRMはmatchgateにはほぼ効かない**: G≈0.5–1.6。 $n_m$ を3000まで増やしても(ショットノイズ床をほぼ消しても)エネルギーで最大~1.9倍、最適βでも~1.5–2.6倍止まり。

### 解釈

PauliシャドウのCRM利得の源泉は「基底一致/不一致」がつくる巨大な設定間揺らぎだが、Haar的なGauss回転は**自己平均的**で、priorが打ち消すべき揺らぎがそもそも小さい。

**「自己平均的」の意味を具体的に。** Pauli測定では、ある設定 $u$ は観測量 $P$ にとって「当たり」($3^{|A|}$ 倍の値を返す)か「外れ」(厳密に0)かの**二値**である。この当たり外れが設定間分散 $V_u=(3^{|A|}-1)\langle P\rangle^2$ を生み、CRMはこれを打ち消す。一方 Gauss 回転 $Q$ は全モードを混ぜるので、**どの設定もすべての2次観測量を少しずつ測る** — 「一度も当たらない」ことがなく、設定ごとの値のばらつきが最初から小さい。打ち消すべき $V_u$ が小さければ、それを $\Delta^2$ に減らしても得るものが少ない。実際 $n_m$ を3000まで増やしてショットノイズ床をほぼ消しても $G$ は最大 $\sim1.9$ 止まりで、これは「 $v_s$ が小さいからではなく $V_u$ が小さいから」であることを示している。つまり **CRMの価値は測定アンサンブルに依存する**: 「JW弦問題はmatchgateで解く、ランダムPauliデータの分散はCRMで削る」— 両者は同じ問題の別のボトルネックに対する道具であり、「matchgate×CRMで二重の得」という単純な加算は成立しない。この切り分け自体が論文の独立した貢献になる(そして「priorに合わせて測定アンサンブルの局所性を設計する」という理論課題を開く)。

## 6. 最適係数CRMと多prior回帰: 「損をしないCRM」

スクリプト: [crm_optimal_beta.jl](crm_optimal_beta.jl) / 図: [crm_optbeta.png](crm_optbeta.png)

### セットアップ

- 系: W=4×Lx=8 シリンダー(64量子ビット)、 $t=1$(軸方向・円周方向とも同一、異方性なし)、U ∈ {4,8}、half-filling。§4(`crm_2d_symuhf.jl`)と**同一系・同一seed**なので、測定データもそのまま同じものを後処理している。

CRMは統計学の**制御変量法**のβ=1特殊例と見なせる:

```math
\hat o(\beta) = \bar m_\rho - \beta\,(\bar Y_\sigma - \mathrm{Tr}[O\sigma]), \qquad Y_\sigma(u)=E[X_\sigma|u]
```

**なぜ $\beta^\ast$ がこの形で、なぜ $G=1/(1-\mathrm{corr}^2)$ になるのか。** $\bar Y_\sigma$ の期待値は $\mathrm{Tr}[O\sigma]$ なので、 $\hat o(\beta)$ は**任意の $\beta$ で不偏**である($\beta$ を選ぶ自由度が丸ごと使える)。分散は

```math
\mathrm{Var}[\hat o(\beta)] = \mathrm{Var}(\bar m_\rho) - 2\beta\,\mathrm{Cov}(\bar m_\rho,\bar Y) + \beta^2\mathrm{Var}(\bar Y)
```

と $\beta$ の2次式なので、頂点 $\beta^\ast = \mathrm{Cov}/\mathrm{Var}(Y)$ で最小になり、その最小値は $\mathrm{Var}(\bar m_\rho)(1-\mathrm{corr}^2)$ である。標準シャドウは $\beta=0$ の場合なので、比を取ると $G=1/(1-\mathrm{corr}^2)\ge1$ が出る。**2次式の頂点を取るだけなので、priorがどれほど悪くても標準シャドウより悪くなりようがない** — これが「損をしない」の中身である。通常のCRMは $\beta=1$ に固定した特殊例で、頂点から外れていれば損をしうる。

最適係数 $\beta^\ast$ は真の共分散を要するので、実際には**同じ $n_u=50$設定のデータからプラグイン推定**する。複数prior $\lbrace Y_i\rbrace$ は回帰(擬似逆行列で退化も自動処理)に一般化。実験4と同一の系・同一乱数シード(=同一測定データ)で、prior {UHF, UHF-sym, χ8, χ32}、多prior集合 {UHF+UHF-sym}(タダのみ)と{全4つ}を比較。n_repeat=50。

### 結果と解釈

- **保険が効く**: β=1で損をしていた全ケースが修復(U=8のUHFで ZZ y2: 0.70→14.0、ZZ x隣: 1.1→18.6)。達成Gは理論 $1/(1-\mathrm{corr}^2)$ とy=xで一致し、プラグインによるバイアスは検出限界以下。
- **理論的副産物**: 単一Pauli列では $Y_p = \mathbf{1}[\text{一致}]\cdot3^{|A|}\langle P\rangle_{\sigma_p}$ がpriorごとにスカラー倍しか違わず、βに吸収される → 最適β利得は**prior非依存**。系として「一致インジケータを制御変量にし係数をデータから学習する」**priorフリーの自己校正推定器**が存在する。
- **β=1との使い分け**: priorが優秀ならβ=1が勝つ(onsite ZZ: 241 vs 141)。**理由**: $\beta^\ast$ を推定するには $\mathrm{Cov}$ と $\mathrm{Var}(Y)$ を $n_u$ 個の設定から測る必要があり、その推定誤差は $O(1/\sqrt{n_u})$ 残る。真の最適値が $\beta^\ast\approx1$ のときは、 $\beta=1$ と決め打ちする方が**推定ノイズをゼロにできる分だけ有利**になる。この不利は基底一致が稀な観測量ほど大きく、ホッピング($|A|=3$ なので一致率 $3^{-3}=1/27$、50設定なら平均2設定しか当たらない)で特に厳しい。**「信頼できるpriorはβ=1、不確かなpriorは最適βで保険」**という使い分けになる。なお §2d で、この推定ノイズが $\mathrm{Var}(Y)\to0$ のときに発散という形で牙をむくことが判明した。
- **多prior回帰**: 二重占有でタダのprior2つの回帰が G=98(U=8)— 単独(15.9/6.3)を桁で超え、χ=32 MPS(101)と同等。回帰が「共線UHFの対称性破れ情報」と「回転平均の揺らぎ情報」を観測量ごとに最適配合した結果で、**MPSなしでMPS級**に到達。

## 7. 正直なベースライン: 貪欲derandomizationとの比較(多観測量同時推定)

スクリプト: [crm_derand_benchmark.jl](crm_derand_benchmark.jl) / データ: [crm_derand_results.tsv](crm_derand_results.tsv)

### セットアップ

「単一観測量なら該当基底の直接測定が最強では?」という(正しい)批判に答えるため、**同一総ショット数**(50設定×100ショット)で多数の観測量を同時推定する誤差を比較。1D L=16(窓18量子ビット)、 $t=1$、 $U=4$、prior=χ32切断(F=0.9998)。

- セットA(構造化): 物理観測量23個(二重占有×7、SzSz×6、hop×6、距離別ZZ×4)= ユニークPauli列60本。
- セットB(非構造): 窓内のランダムな2–3局所Pauli列150本。
- 手法: ランダムシャドウ / +CRM / **貪欲derandomization**(HKP型: 命中回数に指数減衰重みを付けたカバレッジ最大化で50設定の基底を決定論的に構築)。

**derandomization とは何か、なぜ強いのか。** ランダムシャドウは基底をサイコロで決めるので、ある観測量が「一度も当たらない」ことが起きうる。derandomization はこれを**決定論的に**置き換える: 測りたいPauli列のリストが事前に分かっているなら、「どの列が何回カバーされたか」を数えながら、まだ手薄な列を優先して次の設定の基底を貪欲に決めればよい(命中回数に指数減衰重みを付けるのは、既に十分測れた列に予算を回さないため)。結果として全60列を確実にカバーできる。

**逆チャネル係数 $3^{|A|}$ が不要になる点が本質的である。** ランダムシャドウでは「 $3^{-|A|}$ の確率でしか当たらない」ことを補正するために、当たったときの値を $3^{|A|}$ 倍する。この増幅が分散をそのまま $3^{|A|}$ 倍にする。derandomization では狙った列を確実に当てるので補正が要らず、**素直な標本平均**で済む。すなわちシャドウの分散の主要因そのものを回避しており、固定リストに対して強いのは当然である。この節は「それでもシャドウ+CRMを使う理由があるか」を正直に測ることが目的である。

### 結果

| 誤差(中央値/最悪値) | shadow標準 | shadow+CRM | 貪欲derand |
|---|---|---|---|
| セットA(構造化23個) | 0.059 / 0.351 | 0.012 / 0.054 | **0.0085 / 0.028** |
| セットB(ランダム150個) | 0.058 / 0.208 | 0.057 / **0.096** | **0.044 / 0.067** |

### 解釈

- **既知の固定リストにはderandomizationが最強**(全60列をカバーし、命中率1・係数増幅なしで測るため)。これは隠さず認める。
- ただし**CRMはシャドウの不利をほぼ帳消しにする**(構造化セットで中央値4.8倍改善、derandとの残差1.5倍)うえ、シャドウ+CRMは**測定後に任意の観測量を選べる**(derandはリストの事前確定が必須)。
- 非構造セットではCRMの中央値利得は消えるが、**最悪誤差は半減**する。**理由は利得法則から直接読める**: ランダムに選んだ2–3局所Pauli列の期待値はほとんどが $\langle P\rangle\approx0$ で、打ち消すべき設定間揺らぎ $(3^{|A|}-1)\langle P\rangle^2$ 自体がゼロに近い(=天井 $G_{\max}\approx1$)。中央値の観測量には**そもそも改善の余地がない**。一方で誤差バジェットを支配するのは $|\langle P\rangle|$ が大きい少数の列であり、そこは天井が高いのでCRMが効く。**CRMは「効く場所だけを自動的に狙い撃つ」**わけで、最悪誤差が半減するのはその帰結である。
- 決定論的設定には(揺らぎがないので)CRMの原理自体が適用不能 — CRMとderandは**相補的**で、「priorで測定計画も設計する」統合(prior-informed derandomization)が次の理論課題。

## 8. スケールアップ: W=6シリンダー(96量子ビット、クラスター計算)

スクリプト: [crm_2d_w6.jl](crm_2d_w6.jl) + [crm_2d_w6.pbs](crm_2d_w6.pbs) / 図: [crm_2d_w6.png](crm_2d_w6.png)

### セットアップ

- 系: 6×8シリンダー(48サイト、96量子ビット)、 $t=1$(異方性なし)、U ∈ {4,8}。ρ=DMRG χ=512(14スイープ)。prior: UHF / UHF-sym / χ切断 {8,16,32,64,128}。 $n_u=40, n_m=100$、n_repeat=30。
- 実行: 研究室クラスター(clara)のPBSジョブ(U別に2本、各16コア・約40分)。パラメータは環境変数(UVAL/CHI_EXP/NU/NM/NREP等)で外から与えるスモークテスト対応の設計。
- 検証で2つ問題を発見・解決: (i) 6×2検証系はU=0のフェルミ準位が縮退し基底状態が非一意 → 副格子ポテンシャルでギャップを開けRHF厳密の閉殻に変更。(ii) CDW自由フェルミオンのDMRG収束が遅い(40スイープ/χ=400で7e-5)ため、検証の許容値は「符号バグならO(0.1)ずれる」検出目的に合わせ5e-4に設定(巻き付きボンドの符号は独立診断で正しさを確認)。

### 結果

- **MPS priorの崩壊が加速**(U=4): χ=8の忠実度 0.055(W=4)→**0.018**、χ=32: 0.57→**0.22**、χ=128でも0.74。
- **UHFは持ちこたえる**: U=4のonsite ZZで G(UHF)=19.2 ≈ G(χ=32)=18.2、二重占有で G(UHF)=14.3 > G(χ=16)=11.8。U=8のonsite ZZで G(UHF)=157 > G(χ=32)=96。
- **W=4からの逆転**: 共線UHFがサイト間スピン相関でも機能し(ZZ x隣 0.83→7.7)、UHF-sym(4.5)を上回る。

### なぜ幅を増やすとMPSだけが苦しくなるのか

**面積則から。** MPSは鎖を1本の線に並べて左右に切る表現なので、切り口をまたぐエンタングルメントを表すのに必要なボンド次元は $\chi\sim e^{S}$($S$ は切り口のエンタングルメントエントロピー)である。2次元系を蛇行順で1次元に並べると、**切り口は幅 $W$ の1列を横切る**ので $S\propto W$(面積則)、したがって

```math
\chi \sim e^{cW}
```

と**幅に対して指数的**に必要χが増える。実測でも $\chi=8$ の忠実度が $W=4$ の 0.055 から $W=6$ の 0.018 へ落ち、 $\chi=32$ でも 0.57→0.22 と悪化している。

**一方 UHF は幅に鈍感である。** UHF prior が必要とするのは相関行列 $C=\Phi\Phi^\dagger$ の対角化と Wick の定理による期待値だけで、コストはサイト数 $N$ の3乗、すなわち $O(N^3)=O((L_xW)^3)$ である。 **$W$ に対して多項式**にしか増えない。したがって $W$ を増やすほど両者の差が開く。

### 解釈

幅Wを増やすと、面積則により同じ忠実度に必要なχが指数的に増える一方、UHFのコストは $O(N^3)$のまま — **「タダのpriorの相対優位は、まさにMPSが苦しくなる領域で拡大する」**という主張3の最も強い実証。逆転現象の原因は参照状態側にある: 96量子ビットに対しχ=512は未収束で、参照自体がW=4のときより強くNéel対称性を破っており、凍結共線秩序が項ごとの構造に合う。これは欠陥ではなく教訓の再確認 — 有限χの参照(や実験の状態)がどれだけ対称性を破っているかで最適priorは変わるので、**観測量ごとのprior選択と最適β(実験6)が実務上の保険**になる。

## 9. ドープ系: ストライプと「安いpriorの相図」の境界(W=4/W=6、クラスター計算)

スクリプト: [crm_2d_doped.jl](crm_2d_doped.jl), [crm_2d_w6_doped.jl](crm_2d_w6_doped.jl) / データ: `crm_2d_doped_results_U8.tsv`, `crm_2d_w6_doped_results_U*.tsv`, ログ [crm_dope_U8.log](crm_dope_U8.log), [crm_dope_U4.log](crm_dope_U4.log)

### セットアップ

- 系: 1/8ホールドープのシリンダー2種 — W=4×8(64量子ビット、4ホール、電子28個)と W=6×8(96量子ビット、6ホール、電子42個)。 $t=1$(異方性なし)、U ∈ {8, 4}、μ=0(粒子数はDMRGの量子数で固定)。ρ=DMRG χ=512(14スイープ)。

**なぜドープ系が最も苦しいのか。** half-filling の Mott 絶縁体では電荷の自由度が Mott ギャップで凍っており、動けるのはスピンだけである。ホールを入れるとこの凍結が解け、**電荷セクターも gapless になる**。gapless なセクターが1つ増えると、エンタングルメントの対数的な増大に寄与する中心電荷が $c=1$ から $c=2$ へ上がり(§2e で実測)、同じ $\chi$ での切断誤差が大きくなる。加えて、ホールが自発的にストライプ(電荷の川)を作るため**状態が空間的に不均一**になり、一様な秩序を仮定する平均場priorにとっても難しくなる。DMRG・切断prior・平均場priorの三者が同時に苦しくなる領域である。
- **UHFは複数初期値の競争**: Néel / ストライプ(反位相ドメイン+ホールの川を仕込む)/ 乱数 の3初期値から自己無撞着解(最大2000反復)を求め、最低エネルギー解を採用。列ごとの平均密度とスタッガード磁化のプロファイルをログに出力する。
- 観測量: これまでのセットに**サイト分解密度**(電荷変調=ストライプ秩序パラメータの直接測定)を2点追加。W=6では観測窓の中心列を環境変数X0で選べるようにし、**壁の上(x=4)とAFドメイン内(x=2)を別ジョブで比較**。
- 測定: $n_u=40, n_m=100$、n_repeat=25。クラスター(PBS、16コア)でU別に並列実行、各約1時間。

### 結果

**(a) UHFは「正しい形」のストライプを自発的に見つける。** W=6・U=8ではストライプ初期値が勝ち(E=−26.901 vs Néel −26.846)、x=4–5にホールの川(n=0.59)、壁を挟んで反強磁性が反位相反転する教科書的なbond-centeredストライプに収束。W=4ではNéel初期値からも自発的にホールポケット+反位相列(x=6)の非一様解へ流れる。

**(b) W=4ドープ(U=8): half-fillingと逆転し、対称性回復が必須になる。**

| U=8, W=4 doped | G(UHF共線) | G(UHF-sym) | G(χ=16) | G(χ=64) |
|---|---|---|---|---|
| ZZ y隣 | 0.60 | **12.0** | 4.5 | 13.8 |
| 二重占有 | 1.0 | **21.3** | 35.5 | 70.9 |
| SzSz y | 0.69 | **10.5** | 7.9 | 25.3 |

**表の読み方**: ドープ系(1/8ホールドープ)での利得。half-fillingの表(実験4)と比べると**優劣が逆転**しているのが要点で、そこでは素のUHFが強かったオンサイト量以外の観測量で、ここでは UHF が $G<1$(損)に落ち、**UHF-sym(対称性回復)が救っている**。ドープにより静的な磁気秩序が溶けて状態がより「対称的」になるため、凍った秩序を持つ共線UHFよりも回転平均したpriorの方が合う。
**なぜ逆転するのか。** 対称性回復priorが有利か不利かは、**参照状態 $\rho$ 自身がどれだけ対称性を破っているか**で決まる。共線UHFはスピンをz軸に凍らせた「対称性を最大限破った」状態で、回転平均UHFはそれをスピン回転で均した「対称的な」状態である。half-filling の W=6 では、χ=512 が96量子ビットに対して未収束なため参照状態自体が強く対称性を破っており、凍った共線UHFの方が合う。ドープすると静的な磁気秩序が溶けて参照状態がより対称的になるので、今度は回転平均priorの方が合う(共線UHFは Δ≈0.44–0.56 と大きく外す)。**priorの対称性は「正しい」ものを選ぶのではなく、参照状態の破れ具合に合わせるもの**である、という §4 の教訓が両側から確認された形になる。half-filling W=6(参照がより対称性破れ→共線が勝つ)と正反対で、「priorの対称性は状態の破れの程度に合わせる」則が両側から確認された。

**(c) W=6ドープ(U=8): 破綻は電荷テクスチャに局在する。** 観測窓の場所を変えた比較:

| U=8, W=6 doped | 壁の上(x=4) | ドメイン内(x=2) |
|---|---|---|
| ZZ y隣: UHF-sym | 0.8 | **9.2** |
| ZZ x隣: UHF-sym | 1.2 | **7.1** |
| SzSz y: UHF-sym | 1.2 | **9.5** |
| サイト密度: UHF系 | 0.1–2.6 | 0.1–1.9 |
| 運動ボンド(全prior) | ≈6 | ≈6 |

**表の読み方**: 同じ系・同じpriorで、**観測量を測る場所だけを変えた**比較。「壁の上」はストライプのドメイン壁(電荷の川)の上、「ドメイン内」は反強磁性が揃った領域の中。スピン相関(上3行)はドメイン内なら UHF-sym で救えるが壁の上では全滅、**サイト密度**(ストライプ秩序パラメータそのもの)は場所によらず平均場では歯が立たない($G\approx0.1$)。つまり平均場priorの破綻は「電荷テクスチャの不一致」に局在している。
- ドメイン内ではUHF-symがスピン相関をχ=16–32 MPS相当(Δ≈0.01–0.03)まで救う。
- 壁の上では全平均場priorが失敗(onsite ZZでΔ=−0.57): **平均場は秩序振幅を過大評価する**という古典的な失敗モードで、鋭すぎる電荷の川が、揺らぎで軟化したDMRG参照のストライプと合わない。
- **サイト密度(ストライプ秩序パラメータそのもの)は場所によらず平均場では無理**(UHFは密度0.99 vs 真値0.83など、ホールの広がりを外す)。MPS χ≥32が必要。
- U=4ドープはさらに厳しい: UHFはほぼ常磁性(m=0.08–0.09)に潰れ、χ=8 MPSの忠実度は4e-4(W=6)まで崩壊。運動ボンドだけはどのpriorでも常に容易(G≈6–23)。

### 解釈 — 「安いpriorの相図」の完成

| 領域 | 有効な安いprior |
|---|---|
| half-filling(任意の幅) | 共線UHF(W=6でG=157) |
| ドープ強結合・スピンセクター(ドメイン内) | 対称性回復UHF |
| ドープ系の電荷テクスチャ・壁近傍 | **平均場の限界** — χ≥32 MPS または平均場超のprior(Gutzwiller/DMET的)が必要 |
| 運動項 | どこでも何でも可 |

破綻の場所が「電荷テクスチャの不一致」に局在していると特定できたことが重要で、次に作るべきprior(電荷分布だけDMRG/実験値に合わせた拘束付き平均場など)の設計指針になる。どの領域でも最適βCRM(§6)が「損はしない」保険として下支えする。なお本実験ではスモークテストが実装バグを2件(TSVのU間上書き、X0ノブの検証格子への漏れ)検出しており、クラスター投入前の小規模実行の重要性も実務的教訓。
