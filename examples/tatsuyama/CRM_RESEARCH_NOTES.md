## 0. 要旨 — 論文の主張の骨子 (main claims)

1. **利得法則**: 局所Pauli観測量 $P$($|A|$量子ビットに台を持つ)に対する CRM (common randomized measurements) の分散削減率は閉形式

   $$G \;=\; \frac{(3^{|A|}-1)\,\langle P\rangle^2 \;+\; v_s}{(3^{|A|}-1)\,\Delta^2 \;+\; v_s}, \qquad
   \Delta \equiv \langle P\rangle_\rho - \langle P\rangle_\sigma, \quad
   v_s = \frac{3^{|A|}(1-\langle P\rangle^2)}{n_m}$$

   **記号の定義**

   | 記号 | 定義 |
   |---|---|
   | $P$ | 推定したい局所Pauli演算子(Pauli列)。例: $Z_1Z_2$ |
   | $A$ | $P$ の**台** — 恒等演算子でないPauliが載る量子ビットの集合。$\lvert A\rvert$ はその個数 |
   | $\rho$ | 実験状態(本研究では擬似実験としてDMRGで作った参照状態) |
   | $\sigma$ | **prior** — 古典計算で作った $\rho$ の近似(切断MPS、UHF平均場など) |
   | $\langle P\rangle$ | 実験状態での期待値 $\langle P\rangle_\rho=\mathrm{Tr}[P\rho]$。添字を省いたものは常に $\rho$ 側 |
   | $\langle P\rangle_\sigma$ | prior での期待値 $\mathrm{Tr}[P\sigma]$ |
   | $\Delta$ | **priorの局所誤差** $\langle P\rangle_\rho-\langle P\rangle_\sigma$ — その観測量について prior がどれだけ外しているか |
   | $n_m$ | 1つの測定設定あたりのショット数 |
   | $n_u$ | 測定設定(ランダム基底の選び方)の数。標準・CRM双方の分散が $1/n_u$ に比例するので、比である $G$ には現れない |
   | $v_s$ | **ショットノイズ床** — 有限ショットに由来し、priorでは打ち消せない分散 |
   | $3^{\lvert A\rvert}$ | 逆測定チャネルの増幅率。基底が $A$ 上で全一致する確率が $3^{-\lvert A\rvert}$、一致時の推定値が $3^{\lvert A\rvert}(\pm1)$ |
   | $G$ | **利得** $=\mathrm{Var}[\text{標準シャドウ}]/\mathrm{Var}[\text{CRM}]$。$G>1$ で得、$G<1$ で損 |

   **式の読み方**: 分子の $(3^{\lvert A\rvert}-1)\langle P\rangle^2$ は「ランダムに選んだ基底が当たるか外れるか」による**設定間の揺らぎ**で、CRMが打ち消す対象である。分母ではこれが $\Delta^2$ に置き換わる — priorが当たっていれば($\Delta\to0$)この揺らぎは消える。$v_s$ は分子・分母の**両方に同じ形で入る**ので決して打ち消せない床であり、$\Delta\to0$ でも $G$ は $1+(3^{\lvert A\rvert}-1)\langle P\rangle^2/v_s$ で頭打ちになる。


   で与えられ、数値的に **G ≈ 0.005 から ≈ 1000 まで約5桁**にわたり検証された(Fig 1)。利得を決めるのは prior のグローバル忠実度ではなく、**その観測量に対する prior の局所誤差 Δ** である。より正確には、利得を支配するのは**相対誤差 $\varepsilon=\Delta/\langle P\rangle$** であり($v_s\to0$ で $G\to1/\varepsilon^2$、$\langle P\rangle$ のスケールは消える)、$|\langle P\rangle|$ の大きさ自体は「利得の天井」を上げるだけである(§2.2)。

2. **局所性**: グローバル忠実度が系サイズとともに指数的に崩壊しても($L=32$ 鎖で $F=0.007$)、局所観測量の利得は **L に依存せず生き残る**(G ≈ 12–57、Fig 2a)。忠実度推定そのものは局所Pauliシャドウでは量子ビット数に対し指数的に破綻するため、大きい系では局所観測量への適用が本筋である。

   この主張は鎖中央だけでなく **L=128(256量子ビット)の全サイト**で検証済み(§3.2b): χ_p≥4 の prior なら、忠実度が $10^{-17}$ まで落ちても損をするサイトは一つもない。その実体は、**$\Delta$ がサイトに依存せず、かつ $\varepsilon=\Delta/\ev{P}$ がショットノイズ床のはるか下に留まる**ことである($\Delta$ 自体は細かい prior では L とともに増えるが、$G=G_{\max}$ に貼り付いている限り無関係)。ただし**χ_p=2 の粗いpriorではドープ系のサイトの2〜3割で有意に損をする(最悪25倍悪化)**ため、「CRMは常に得」ではなく、粗いpriorには主張5の最適係数CRMが必要になる。

3. **2Dでの安価な prior**: 2Dシリンダーでは切断MPS prior が急激に劣化する(χ=8 で F=0.055)一方、$O(N^3)$ で構成できる **UHF平均場 prior がオンサイト観測量で χ=32–64 のMPS prior に匹敵**する(U=8 のオンサイトZZで G=241 vs χ=64 の 243)。UHFの弱点(サイト間スピン相関)は**スピン回転平均による対称性回復**で修復され、全観測量で概ね χ=16 MPS 相当になる(Fig 3)。

4. **混合状態prior と観測量ごとのprior選択**: CRMのpriorは推定量に $\langle P\rangle_\sigma$ としてしか入らないため、(i) **混合状態でもpriorにできる**(回転平均UHFはその実例)、(ii) **priorは古典後処理なので、同一の測定データに対し観測量ごとに最適なpriorを選べる**。いずれも追加測定コストゼロ。

5. **最適係数CRM(損をしないCRM)**: §3.2b で見つけた損の領域($n_u\ge200$ で 134/445 サイト → 0/445)で実証済み(§3.2d)。CRMは制御変量法のβ=1特殊例であり、係数を同一データから $\hat\beta = \widehat{\mathrm{Cov}}(m_\rho,Y)/\widehat{\mathrm{Var}}(Y)$ とプラグイン推定すると理論利得 $G=1/(1-\mathrm{corr}^2)\ge 1$ で**priorがどれほど悪くても漸近的に損をしない**(β=1で G<1 だった全ケースが修復、達成Gは理論とy=x一致)。複数priorは回帰に一般化され、**タダのprior集合 {UHF, UHF-sym} の回帰だけで χ=32 MPS prior 相当**に達する例(二重占有)もある(§3.7)。

6. **CRMの価値は測定アンサンブル依存**: matchgateシャドウはJW弦問題を解消し2Dの全エネルギー測定を可能にする(誤差13分の1)が、Gauss回転アンサンブルは自己平均的で、CRMの利得はショット豊富極限でも~2倍に留まる(§3.5)。また既知の固定観測量リストには貪欲derandomizationが最強で、CRMはシャドウの柔軟性(事後選択)を保ったままその差をほぼ埋める(§3.8)。CRM・matchgate・derandomizationは同じ問題の**異なるボトルネックへの相補的な道具**である。

7. **安いpriorの相図**: 平均場系priorの有効領域は「秩序が強く(ほぼ)一様な状態」— half-fillingは任意の幅で共線UHF、ドープ強結合のスピンセクターはドメイン内で対称性回復UHFが機能する。**破綻は広幅ドープ系の電荷テクスチャ(ストライプの形)に局在**し、そこではχ≥32のMPSか平均場超のpriorが必要(§3.9–3.10)。運動項はどの領域でも平均場で十分。

## 1. 背景と問い

CRM [Vermersch et al., PRX Quantum 5, 010352 (2024)] は、実験状態 ρ の古典近似 σ (prior) を用意し、同じランダムユニタリ u を σ に古典計算で適用して差分推定

$$\hat o_{\rm CRM} = \overline{X_\rho(u) - X_\sigma(u)} + \mathrm{Tr}[O\sigma]$$

を行うことで、ランダム測定(古典シャドウ)の分散を削減する手法である。原論文は汎用のMPS priorを扱うが、フェルミオン系(ハバード模型)への適用では次の問いが残っていた:

- **Q1**: HF/CISDなど量子化学の標準近似は prior としてどこまで使えるか。大きい系では近似精度(グローバル忠実度)が指数的に落ちるが、それでも手法に意味はあるか。
- **Q2**: MPSが高くつく2D系で、安価な平均場 prior は χ制限MPS prior に代われるか。

本研究の答え: **利得はグローバル忠実度ではなく観測量ごとの局所誤差 Δ で決まる**(主張1)。したがって Q1 は「局所観測量に対しては意味がある」(主張2)、Q2 は「オンサイト量では代われる。対称性回復すれば概ね全観測量で代われる」(主張3)。

### 2.0 模型パラメータ(ホッピング $t$ の確認)

全実験でハバード模型

$$H = -t\sum_{\langle ij\rangle\sigma}(c^\dagger_{i\sigma}c_{j\sigma}+\mathrm{h.c.}) + U\sum_i n_{i\uparrow}n_{i\downarrow} - \mu\sum_{i\sigma}n_{i\sigma}$$

を用いる。**ホッピングは §3.1 の8量子ビットED系を除きすべての計算で $t=1$**(エネルギーの単位)である。全スクリプトを走査して確認した結果:

| $t$ | 該当スクリプト |
|---|---|
| **$t_L=1$(結合3本)/ $t_S=0.5$(結合1本)** | `crm_gain_verification.jl` のみ |
| $t=1$ | 上記以外のすべて(`crm_mps_scaling`, `crm_site_resolved`, `crm_site_beta`, `crm_site_median`, `crm_1d_hf`, `crm_ed_reference`, `crm_ed_pbc`, `crm_pbc_check`, `crm_pbc_gain`, `crm_gap_scaling`, `crm_gap_conv`, `crm_gap_conv2`, `crm_chistar`, `crm_sensitivity`, `crm_sensitivity2`, `crm_param_sweep`, `crm_optimal_beta`, `crm_derand_benchmark`, `crm_matchgate`, `crm_matchgate_nm`, `crm_2d_cylinder`, `crm_2d_symuhf`, `crm_2d_site`, `crm_2d_w6`, `crm_2d_doped`, `crm_2d_w6_doped`, `crm_chain_common` の検証系) |

**唯一の例外の中身**: `crm_gain_verification.jl` は4サイトリングで、結合 $1\text{--}2,\ 3\text{--}4,\ 4\text{--}1$ が $t_L=1$、$2\text{--}3$ の1本だけが $t_S=0.5$ である(コードの `edges_L`/`edges_S`)。**1本だけを弱めた形であって、強弱を交互に並べる本来の二量体化ではない**(README でこの点の記述を修正済み)。目的は並進対称性を壊して ED 基底状態の縮退を避けること — 縮退があると基底状態が一意に定まらず、「すべてを厳密に検算する」という本節の役割が成立しない。

**2次元シリンダーは等方的**: 軸($x$)方向と円周($y$)方向のホッピングを区別していない(`hubbard_cyl_mpo` が `cyl_edges` の全辺に同じ $t$ を使う)。次近接ホッピング $t'$ は全実験で導入していない。

### 2.1 CRM推定器と prior 側の厳密化

各ランダム設定 u (ランダムPauli基底、X/Y/Z を各量子ビット独立に選択) で実験状態から $n_m$ ショットを取得し、観測量ごとにスナップショット推定値 $X(b,u)$ を平均する。CRMではさらに prior 側の条件付き期待値 $E[X_\sigma|u]$ を引く。

**先行実装の問題点**(`CRM_Hubbard.ipynb` 系列): prior側も $n_m$ ショットのサンプリングで推定していた。分散分解

- 標準シャドウ: $\mathrm{Var} = V_u^{(\rho)} + V_s^{(\rho)}/n_m$
- 旧CRM実装: $\mathrm{Var} = V_u^{(\rho-\sigma)} + \bigl(V_s^{(\rho)}+V_s^{(\sigma)}\bigr)/n_m$

より、prior側サンプリングは独立ノイズ $V_s^{(\sigma)}/n_m$ を**上乗せ**し、ショットノイズ支配領域ではCRMを必ず悪化させる(`crm_fidelity_comparison.png` で CRM が標準に負けていた原因)。**修正**: prior側は厳密に計算する。局所Pauliに対しては

$$E[X_\sigma|u] \;=\; \sum_t c_t\,\mathbf{1}[\text{基底一致}]\,3^{|A_t|}\,\langle P_t\rangle_\sigma$$

という閉形式で、必要なのは項ごとの $\langle P_t\rangle_\sigma$ のみ(u毎の追加コストゼロ)。`crm_gain_verification.jl` で旧/新実装を同一データで比較し、修正の効果を確認済み。

### 2.2 分散の閉形式理論

**原論文の枠組みからの導出**(論文§2.3に詳述。ここでは骨子のみ)

*出発点(原論文)*: 設定 $u=\bigotimes_q u_q$($u_q$ は X/Y/Z 基底への回転)で測定してビット列 $b$ を得たとき、逆チャネルを通したスナップショット

$$\hat\rho(b,u) = \bigotimes_q \bigl(3\,u_q^\dagger|b_q\rangle\langle b_q|u_q - I\bigr), \qquad E[\hat\rho]=\rho$$

が $\rho$ の不偏推定量になる。観測量の推定値は $X(b,u)=\mathrm{Tr}[O\hat\rho(b,u)]$。

*ステップ1: 局所Pauli列に対する閉形式*。$P=\bigotimes_{q\in A}\sigma^{a_q}_q$ とすると、$\mathrm{Tr}[\sigma^a]=0$ より各因子は $3\,\mathrm{Tr}[\sigma^{a_q}u_q^\dagger|b_q\rangle\langle b_q|u_q]$ になる。測定基底 $\beta_q$ が $a_q$ と一致すれば $3s_q$($s_q=\pm1$ は測定結果)、不一致なら 0。よって

$$X(b,u) = 3^{|A|}\Bigl(\prod_{q\in A}s_q\Bigr)\mathbf 1[\text{基底が }A\text{ 上で全一致}]$$

で、一致確率は各量子ビット独立に 1/3 なので $3^{-|A|}$。

*ステップ2: 全分散の公式*。一致時 $E[\prod s_q]=\langle P\rangle$、$\prod s_q\in\{\pm1\}$ より $\mathrm{Var}(\prod s_q)=1-\langle P\rangle^2$。したがって条件付き期待値は $E[X|u]=3^{|A|}\mathbf 1[\text{一致}]\langle P\rangle$ で、$u$ 平均は $3^{|A|}\cdot3^{-|A|}\langle P\rangle=\langle P\rangle$(不偏)。$\mathrm{Var}(X)=\mathrm{Var}_u(E[X|u])+E_u[\mathrm{Var}(X|u)]$ の2項は

- ユニタリ揺らぎ: $V_u = 3^{2|A|}\langle P\rangle^2\cdot3^{-|A|}-\langle P\rangle^2 = (3^{|A|}-1)\langle P\rangle^2$
- 条件付きショットノイズ: $E_u[\mathrm{Var}(X|u)] = 3^{-|A|}\cdot3^{2|A|}(1-\langle P\rangle^2) = 3^{|A|}(1-\langle P\rangle^2)$

*ステップ3: CRMは第1項だけを置き換える*。同一の $u$ で prior 側の条件付き期待値 $Y(u)=3^{|A|}\mathbf 1[\text{一致}]\langle P\rangle_\sigma$ を引く。これは **$u$ が決まれば確定値**(サンプルしない)なので:

- $E[Z|u]=3^{|A|}\mathbf 1[\text{一致}]\Delta$ より、同じ計算で $V_u^{\rm CRM}=(3^{|A|}-1)\Delta^2$
- $Y(u)$ が確定値なので条件付き分散は不変 → ショットノイズはそのまま残る

$n_u$ 設定・各 $n_m$ ショットで平均すると

$$\mathrm{Var}[\text{標準}] = \frac{1}{n_u}\Bigl[(3^{|A|}-1)\langle P\rangle^2 + \frac{3^{|A|}(1-\langle P\rangle^2)}{n_m}\Bigr],\qquad
\mathrm{Var}[\text{CRM}] = \frac{1}{n_u}\Bigl[(3^{|A|}-1)\Delta^2 + \frac{3^{|A|}(1-\langle P\rangle^2)}{n_m}\Bigr]$$

比を取ると $1/n_u$ が約分されて要旨の $G$ 式になる。

*系(§2.1の修正の意味)*: もし $Y(u)$ を $\sigma$ からの $n_m$ ショットで**推定**すると、$\bar X_\rho(u)$ と独立なので条件付き分散が加算され、ショットノイズ床が

$$\frac{3^{|A|}(1-\langle P\rangle_\rho^2) + 3^{|A|}(1-\langle P\rangle_\sigma^2)}{n_m} \approx 2\times$$

とほぼ2倍になる。$\Delta$ がどれほど小さくてもショットノイズ支配域では $G<1$ になり、CRMが標準に負ける。これが先行実装の不可解な挙動の正体だった。

ここから要旨の $G$ 式と、**飽和則** $G_{\max}(n_m) = 1 + n_m\,\frac{(3^{|A|}-1)\langle P\rangle^2}{3^{|A|}(1-\langle P\rangle^2)}$ (Δ→0 の上限、$n_m$ に線形) が従う。**CRMは「少ない設定 × 多ショット」の予算配分で最大化される**(Fig 2b)。

**2つの律速レジームと診断法**(査読者の自然な疑問「$|\langle P\rangle|$ が大きいと $\Delta$ も比例して大きくなり比は変わらないのでは?」への回答): 信号項 $S=(3^{|A|}-1)\langle P\rangle^2$ とショット床 $v_s$ の比 $g\equiv S/v_s$、相対誤差 $\varepsilon=\Delta/\langle P\rangle$ を使うと
$$G = \frac{g+1}{\varepsilon^2 g + 1}$$
と書ける。したがって (i) $v_s\to0$($n_m\to\infty$)では $G\to1/\varepsilon^2$ で**$\langle P\rangle$ のスケールは完全に消える**(疑問は正しい)。(ii) 有限 $n_m$ では $v_s$ が $\langle P\rangle^2$ に比例しないためスケール不変性が破れ、$g$(すなわち $|\langle P\rangle|$)が大きいほど**天井**が高い。(iii) 実データでは $\Delta$ は $\langle P\rangle$ に比例せず、$\mathrm{corr}(|\langle P\rangle|,|\Delta|)=+0.28$(211点)、同一priorでも相対誤差は観測量ごとに1.5%〜124%。反例: 二重占有は $|\langle P\rangle|=0.053$ で G=16、ZZ y隣は $|\langle P\rangle|=0.508$ で G=2.2。**Δ が支配因子**。

実務的な**診断法**: 得られた $G$ を天井 $G_{\max}$ と比較する。
- $G\approx G_{\max}$(例: W=4 U=8 のonsite ZZ、理論141 vs 天井145)→ **ショットノイズ律速**。priorをこれ以上良くしても無駄、$n_m$ を増やすべき。
- $G\ll G_{\max}$(例: ZZ y隣、2.2 vs 32)→ **Δ律速**。prior改善(対称性回復・多prior回帰)に余地。

この診断は結果表の読み方を変える: 表中の各 $G$ は「priorの質」と「測定予算」のどちらが効いているかを $G/G_{\max}$ で判定できる。

注意(2Dで発見): 多項観測量(例: 二重占有 $=\tfrac14(I - Z_\uparrow - Z_\downarrow + Z_\uparrow Z_\downarrow)$)の利得は**合計Δだけでなく項ごとのΔ**に依存する。参照状態が対称性を破っている場合、対称化priorは合計Δ不変でも項ごとΔが悪化しうる(§3.5)。

### 2.3 数値実験パイプライン

- **実験状態 ρ**: DMRG基底状態(ITensorMPS、`Fermion` サイト + QN保存でJW符号は自動処理)。厳密基底状態である必要はなく「固定された参照実験」であればよい。
- **prior σ**: (i) ρ の切断MPS(χをpriorの品質ダイヤルに使う)、(ii) UHF平均場(Wick)、(iii) 回転平均UHF(混合状態、一般化Wick)。
- **測定シミュレーション**: right-canonical MPSからの逐次完全サンプリング $O(N\chi^2)$/サンプル。
- **窓サンプリング**(高速化・本研究で導入): 観測量の台が載る連続窓 $[q_1,q_2]$ のみサンプルする。直交中心を $q_1$ に置くと左環境は恒等になり、左Schmidt指標 $l$ を回転に依存しない分布 $p(l)=\mathrm{diag}(\sum_b C[b]C[b]^\dagger)$ から先に引いて $v_0=e_l$ から通常の逐次サンプリングをすればよい。**コストが窓幅のみに依存し系サイズ L に依存しない**。
- **BLAS**: 小さいgemvはスレッド化が逆効果(実測で~10倍劣化)。サンプリングは1スレッド、DMRGのみ4スレッド。

### 2.4 平均場 prior の Wick 閉形式(2Dの鍵)

Slater行列式 prior は相関行列 $C_{qq'}=\langle c_q^\dagger c_{q'}\rangle$ だけで局所Pauli期待値が閉形式になる:

$$\langle Z_q\rangle = 1-2C_{qq}, \qquad
\langle Z_aZ_b\rangle = 1-2C_{aa}-2C_{bb}+4(C_{aa}C_{bb}-C_{ab}C_{ba}),$$
$$\langle(XZX+YZY)/2\rangle_{\rm JW隣接} = 2\,\mathrm{Re}\,C_{ab}.$$

→ **MPS化不要、どのサイズでも $O(N^3)$**。さらにスピン回転平均(対称性回復)は、回転後も一般化Slater行列式なので $C(\theta)=U(\theta)\,C\,U(\theta)^\dagger$ に対する同じWick式で計算でき、共線秩序ではz軸周り回転不変性により**極角の1次元求積**に落ちる。混合状態だがCRM priorには $\langle P\rangle_{\bar\sigma}$ しか要らないので問題ない。

### 2.6 matchgateシャドウの定式化(結果は§3.5)

測定アンサンブルはフェルミオンGaussユニタリ $U_Q$($Q\in SO(2n)$ Haar、$U_Q^\dagger\gamma_\mu U_Q = \sum_\nu Q_{\mu\nu}\gamma_\nu$)+占有数測定。実装は $Q$ をQR分解で生成し、隣接Givens回転列に分解して各回転をJW表現のゲート($\gamma_{2j-1}\gamma_{2j}=iZ_j$ → Z回転、$\gamma_{2j}\gamma_{2j+1}=iX_jX_{j+1}$ → XX回転)として状態に適用する。次数 $2k$ のMajorana単項式 $\Gamma_S$ のスナップショット推定量は

$$X_S(b) = \lambda_{2k}^{-1}\sum_{S'\text{対角}}\det(Q[S,S'])\,\langle b|\Gamma_{S'}|b\rangle,\qquad \lambda_{2k}=\binom{n}{k}\Big/\binom{2n}{2k},\qquad \langle b|\Gamma_T|b\rangle = i^{|T|}\prod_{j\in T}(1-2b_j)$$

**CRMのprior側はPfaffianで厳密**: Slater(一般にGauss)状態の2点関数 $K_{\mu\nu}=\langle\gamma_\mu\gamma_\nu\rangle$ は回転後 $K'=Q^TKQ$ となり、$E[X_S|u]=\lambda^{-1}\sum_{S'}\det(Q[S,S'])\,\mathrm{Pf}(K'[S'])$。UHF priorとmatchgate測定は構造的に相性が良い(ただし§3.5の通りCRM利得自体は小さい)。符号・順序の規約はすべて8モード密行列で機械精度検証(この検証が実装中の符号ミス2件を検出)。

### 2.7 制御変量法としての一般化(結果は§3.7)

CRMは制御変量法のβ=1特殊例: $\hat o(\beta) = \bar m_\rho - \beta(\bar Y_\sigma - \mathrm{Tr}[O\sigma])$、$Y_\sigma(u)=E[X_\sigma|u]$。最適係数 $\beta^*=\mathrm{Cov}(m_\rho,Y)/\mathrm{Var}(Y)$ をプラグイン推定すれば $G=1/(1-\mathrm{corr}^2)\ge1$(漸近的に損をしない)。複数prior $\{Y_i\}$ は回帰 $\beta = \Sigma_{YY}^{+}\,c_{Y\rho}$ に一般化(擬似逆行列でpriorの冗長性も自動処理)。注意点: (i) $\hat\beta$ の推定ノイズにより優秀なpriorにはβ=1が勝つ(特に基底一致が稀な観測量)。(ii) 決定論的測定(derandomization)には揺らぎがなく適用不能。

### 3.2a 局所性は独立に構成した prior でも成り立つか — HF prior (`crm_1d_hf_results.tsv`)

§3.2 の prior は $\rho$ の $\chi$ 切断で、構成上 $\rho$ の対称性を受け継ぐ。実務で使う HF は独立に構成されるため質的に違う失敗をしうる。1DではUHFが構造的に誤る(nesting により任意の $U>0$ で Néel、$m=0.39$。真の1D基底状態は長距離秩序なし)。L=8/16/32、半充填とδ=1/8、全サイトで測定。

1. **素のUHFは3〜4割のサイトで損をする**(半充填: 20/49, 42/105, 73/217)。§3.2 の切断MPS($\chi_p\ge4$ で損ゼロ)と対照的。
2. **ただし損は構造的かつ $L$ 非依存**: $n$, $S^z$ で $G=0.02$–$0.03$ が $L=8,16,32$ で完全に一定。半充填では $\ev{Z_q}=0$ が厳密(天井=1、得る余地ゼロ)なのにUHFが対称性を破って $\Delta\neq0$ を作るため(§3.1の機構)。**「$L$ 依存しない」という意味では局所性は成立しており、$L$ 非依存の値が1を下回りうるだけである**。
3. **対称性回復で半充填の損は完全消滅**(0/49, 0/105, 0/217)。ドープでも 2/49, 5/105, 13/217 と素のUHFの1/7。
4. **効く観測量では $\chi=32$ MPS と同等**: onsite ZZ で UHF=48.6 対 天井49.9(**97%**)、$\chi=32$=49.9。2Dの主張(§3.6)の1次元版。
5. **単一Pauli項の回転不変性の数値確認**: onsite ZZ は UHF=UHFsym=48.57 と小数点まで一致。一方**二重占有は 1.16→27.40**。$\ev{Z_uZ_d}$ と $n_u+n_d$ は不変だが**個々の $\ev{Z_u}$ は不変でない**ためで、多項観測量の利得が項ごとの $\Delta$ に依存する(§3.5)ことの帰結。
6. **UHFとUHF-symの優劣が $L$ で交差**: スピン相関で UHF は 37.4→13.2→7.94 と劣化、UHF-sym は 4.93→6.42→7.45 と改善し L=32 で交差。「priorの対称性は参照状態の破れ具合に合わせる」規則の $L$ 版。

**論文上の位置づけ**: 主張2に「独立に構成した prior でも $L$ 非依存性は成り立つ」を追加でき、同時に「損をしないためには prior の対称性が参照と合っている必要がある」という**別条件**を切り分けられる。切断MPS priorだけでは対称性不一致の失敗モードが原理的に起きないので、この検証には HF が必要だった。

### 3.2a2 参照状態を厳密対角化にしても結論は変わらない (`crm_ed_reference_results.tsv`)

**査読で必ず出る疑い**: 参照 $\rho$ が DMRG の切断MPSで、prior もその切断だから「同じMPS族の中での比較」になって有利では、というもの。$\rho$ を**ED基底状態**に置き換えて直接消した。

**手法**: 粒子数セクター内で行列を保持しない Lanczos(完全再直交化・thick restart、自前実装。KrylovKit不使用)。量子ビット占有基底で張るので JW 符号は「間のモード」の占有だけで決まる(up: $(-1)^{n_{2i}}$、dn: $(-1)^{n_{2i+1}}$)。全 $2^{2L}$ に展開して窓RDMは reshape で厳密に取得。

**到達規模**: L=14(28量子ビット、セクター次元 $1.18\times10^7$、全ベクトル4.29 GB、Lanczos 202秒)。$L=16$ は全ベクトル69 GBで本実装では不可(セクター表現のまま窓RDMを取る書き換えなら届く可能性)。

**結果**:
1. DMRG(χ=256)は $L\le14$ で実質厳密($|\Delta E|\sim10^{-9}$、局所観測量の最大差 $\sim4\times10^{-9}$)。
2. **全2,688点で $|G_{\rm ED}-G_{\rm DMRG}|=0$**(浮動小数点で厳密にゼロ)。窓RDMが $10^{-9}$ しか違わないので同じ乱数種で**測定ビット列が一つも変わらず**、推定値列が完全に同一になるため。
3. 損をするサイト数も同一(χ切断は0、素のUHFは約4割、UHF-symは0)。

**限界を明示すること**: 検証が及ぶのは $L\le14$ のみ。§3.2 は L=32 まで、§3.2b は L=128 まで扱っており、そこでは ED による直接確認ができない。ただし「$L\le14$ で DMRG の切断が局所観測量に $10^{-9}$ しか効かない」ことと、§3.2e で「局所観測量には $\chi^*\approx16$ で足りる」ことが分かっているので、大きい $L$ でも局所観測量に関しては同じ結論が期待できる。

**この節の弱点と、それを埋める §3.2a3**: 上の結果 2 は一見強いが、**OBC では $L\le14$ の DMRG がそもそも事実上厳密**だったので、「切断が効いていないことを確認した」に近い。切断が実際に効く状況での再検証が必要で、それが §3.2a3(PBC 版)である。

### 3.2a3 同じ検証を周期境界条件で — 切断が本当に効く領域 (`crm_ed_pbc_results.tsv`)

**狙い**: §3.2a2 に歯を持たせる。PBC は MPS に二重に不利 — (i) $S_c=(c/3)\ln L$ で OBC の約2倍、(ii) JW 順序で巻き付きホッピングが長距離項になる。同じ $L$ でも DMRG の切断が桁違いに強く効くので、「$\rho$ が切断MPSであること」の影響を測れる。

**ボンド次元は ED には無関係**: よくある懸念(PBC はボンド次元が跳ね上がる)は DMRG 側だけの話。ED は疎行列 Lanczos なのでセクター次元も計算量も変わらず、**到達限界は §3.2a2 と同じ L=14**。増えるのは JW 文字列の長さだけ。巻き付き符号は「厳密に間にあるモード」のパリティ:
- up $1\leftrightarrow L$(モード $1$ と $2L-1$): $(-1)^{n_\uparrow(2..L-1)+n_\downarrow(1..L-1)}$
- dn $1\leftrightarrow L$(モード $2$ と $2L$): $(-1)^{n_\uparrow(2..L)+n_\downarrow(2..L-1)}$

**符号の妥当性検証**: 巻き付き符号は間違えても「それらしい」値が出るので、ITensor の `OpSum`(JW を内部処理する独立経路)の DMRG と突き合わせた。L=4/6 の PBC で $|\Delta E|<2\times10^{-14}$。

**結果**:
1. **狙いどおり切断が効いた**: $L\ge12$ の PBC で $\chi$ が上限 1024 に張り付く。$L=14$ PBC は $|\Delta E|=2.8\times10^{-7}$、局所観測量の ED-DMRG 差 $3.1\times10^{-7}$ で、**OBC の 676倍**。$S_c$ は 1.18→2.02。prior 忠実度も $\chi_p=8$ で 0.964→0.659。
2. **それでも利得はほぼ変わらない**が、**厳密ゼロではなくなる**。3シード×全点(比較 10,416 点)で、$L\le12$ と $L=14$ OBC は全て $|\Delta G|=0$。$L=14$ PBC のみ seed 1 で 16点、seed 2 で 8点ずれた。最大 $|\Delta G|=1.5\times10^{-2}$($G\simeq23.5$、相対 $6.5\times10^{-4}$)。**同じ点のブートストラップ1σ幅は 1.89 なので、参照状態の違いは統計誤差の 1/123**。
   - → **§3.2a2 の「全点で厳密ゼロ」は一般的主張としては強すぎた。** 本節で正しい形に直した。
3. **機構を推測から実測に**: サンプラーが使うのは各基底での測定確率なので、$3^4=81$ 通りの基底×全窓で $\max|\Delta p|$ と max TV を測り、総抽選数×max TV を「ビット反転回数の期待値の上限」とした。上限は 0.0027(L=8 PBC)〜8.20(L=14 PBC)で、**ずれが起きる境目を正しく囲む**(上限 $\le0.018$ の5ケースは反転せず、8.20 で初めて反転)。L=12 PBC(上限 1.14)が反転しなかったのは、この上限が全基底での最大 TV を使う保守的評価だから。
   - ずれた24点は 3つの (seed, サイト) × 8 prior に分解され、各組で変わったのは "SzSz r=1" のみ。1ユニットで1ビット反転した場合に期待される形(`estimate_obs` は台の Pauli が基底と一致するときしか寄与しない)。**ただしこれはパターンからの推論で、反転ユニット数を直接数えてはいない。**
4. **境界条件に依存する結論が1つ**: 損の判定(CI上端<0.9)で、$\chi_p=2$ は OBC では 0/49〜0/91 だが **PBC では 4/49, 6/77, 7/91(約8%)で損**。$\chi_p\ge4$ は PBC でも 0。→ **実務的な下限は $\chi_p\ge4$**。UHF は3–4割で損、UHF-sym で 0 という構造は境界条件によらない。
5. **サイト依存性は PBC で大きく減るが消えない**: ボンド観測量の max/min は OBC 19–22 → PBC 3–5。§3.2c で Friedel 振動に帰した部分が境界を取ると実際に消える確認。**残る 2–5倍は物理ではなく prior 由来** — $\langle P\rangle_\rho$ は並進対称でも、$\sigma=\mathrm{truncate}(\psi,\chi_p)$ は並進対称でない(切断誤差は JW 鎖の中央で最大)ので $\Delta$ に位置依存性が残る。§3.2b の null test($\langle P\rangle$ の依存性は PBC で完全に消える)と混同しないこと。
6. **副産物として §3.2 の主軸の別実例**: prior 忠実度が 0.964→0.659 と大きく落ちても、利得の低下はせいぜい2倍。「大域忠実度が崩れても局所的な利得は生き残る」の境界条件を変えた実例になっている。

**限界**: ここでも $L\le14$。ただし本節は $L$ を上げる代わりに**切断の強さ**の側から同じ疑いに答えている($L$ を上げたときに増えるのも結局は切断の強さなので、無関係な代替ではない)。

### 3.2b 局所性のサイト分解 — L=128 (256量子ビット) 全サイト (`crm_site_resolved.png`)

§3.2 は鎖中央の観測量のみ。全サイト×7観測量×5 prior×2ドーピング(δ=0, 1/8)×L=8–128 の 17,210 点に拡張した(`crm_site_resolved.jl`, $n_u=50, n_m=100$, n_repeat=1000, bootstrap CI 600)。

技術的な前提として、観測量の台が4量子ビットに収まることを使い**窓の縮約密度行列を厳密に構成してサンプル**する方式に変えた(直交中心を窓左端に置けば左右環境が恒等になる)。コストがボンド次元に依存しなくなり、逐次MPSサンプリングの約250秒/サイト(χ=128)が約1秒/サイトになる。これが L=128 を可能にした。ED周辺分布と $\max|\Delta p|=3\times10^{-15}$。

同時に、**完全prior($\sigma=\rho$)を同じサンプルに適用して利得の天井 $G_{\max}$ を経験的に測る**手法を導入した。閉形式のない多項観測量にも2レジーム診断 $G/G_{\max}$ が使えるようになる。

**主結果**:

| L | δ | χ_p | prior忠実度 | 全サイト最小G | 中央値G | 有意に損なサイト($G_{\rm hi}<0.9$) |
|---|---|---|---|---|---|---|
| 128 | 0 | 4 | **1.35e-4** | **1.00** | 8.5 | 0 / 893 |
| 128 | 1/8 | 4 | **1.91e-6** | 0.89 | 4.7 | 0 / 893 |
| 128 | 0 | 2 | 4.67e-10 | 0.70 | 1.4 | 51 / 893 |
| 128 | 1/8 | 2 | **1.16e-17** | **0.039** | 1.4 | 166 / 893 |

1. **χ_p ≥ 4 なら全L・両ドーピングで損なサイトはゼロ**。忠実度 $10^{-17}$ でも局所利得は全サイトで生きる。§3.2の主張が中央の偶然でないことが確定した。
2. **利得は一様ではない**: 端の数サイトで 1.3–3.6 倍高く、内部は **L非依存の平坦部**(L=32/64/128 が同一プラトー)。
3. **その原因は prior 品質ではない**: χ_p≥8 では全サイトで $G/G_{\max}=1.00$(どこもショットノイズ律速)。端の増強は観測量自身の $\langle P\rangle(i)$ が開放端由来のFriedel振動で変わり**天井 $G_{\max}$ が動く**ためで、§2.2の2レジーム描像が同一系の内部で場所を変えるだけで確認できた。
4. **作業仮説は外れた**: 「$\Delta(i)$ はエンタングルメント $S(i)$ が大きい場所ほど大きい」と予想したが corr(|Δ|,S) は +0.03〜+0.28 と弱い。median|Δ| は**サイトにはほぼ依存しない**。

   **ただし L 依存については訂正が必要**: 「L にも依存しない」は χ_p=2 でのみ成立する。ZZ onsite の Δ の L128/L8 比は χ_p=2,4,8,16,32 でそれぞれ 1.02, 4.97, 0.99, 12.4, **184** であり、粗い prior で飽和しているから平坦に見えるだけである。

4b. **では、なぜ利得は L に平坦なのか — 2レジームで説明できる**(観測量を ZZ onsite に固定、半充填):

| χ_p | G(L=8) | G(L=128) | ε(L=8) | ε(L=128) | G/G_max(L=128) | レジーム |
|---|---|---|---|---|---|---|
| 2 | 2.27 | 2.18 | 0.65 | 0.67 | 0.043 | Δ律速・飽和 |
| **4** | **40.5** | **9.84** | 0.058 | 0.29 | 0.194 | **Δ律速・遷移** |
| 8 | 50.5 | 50.9 | 2.7e-3 | 2.8e-3 | 1.000 | ショットノイズ律速 |
| 32 | 50.4 | 50.8 | 2.4e-6 | 4.5e-4 | 1.000 | ショットノイズ律速 |

   「利得が L に平坦」が成立するのは両端だけである。χ_p≥8 では Δ が増えても $\varepsilon\le3\times10^{-3}$ でショットノイズ床のはるか下にあるため $G=G_{\max}$ に貼り付き、**L にも prior 品質にも一切依存しない**(忠実度 $10^{-17}$ が無関係なのはこのため)。χ_p=2 は飽和済み。**χ_p=4 の中間領域だけ $G$ が 40.5→9.84 と4倍劣化する**。

   したがって正しい主張は「利得は L に依存しない」ではなく、**「ショットノイズ律速でいられる限り利得は L に依存せず、Δ律速の遷移領域でのみ劣化する」**である。運用上の結論(χ_p≥4 で損なサイトゼロ)は変わらない。

   **方法論上の教訓**: 以前は観測量をまたいで $G$ の中央値を取っていたため、この4倍の劣化が隠れていた。$G_{\max}$ が桁で違う観測量を混ぜて中央値を取ってはいけない。
5. **$\langle P\rangle=0$ には利得が存在しない**: half-filling の $n(i), S_z(i)$ は対称性から $\langle Z\rangle=0$ ⇒ $G_{\max}=1$、実測 $G\equiv1.00$。ドープすると $G_{\max}\approx2.3$。
6. **重要な限界 — Δ の L 非依存性は gapped 系でのみ成立**: δ=1/8 では**全観測量で** median|Δ| が L とともに増加(χ_p=8 の ZZ onsite: 5.8e-3→3.4e-2, L=8→128)し、$G/G_{\max}$ も単調低下する(ZZ onsite 0.995→0.885、ホッピング 0.960→0.719)。half-filling では全て平坦(0.95–1.00)。物理的理由は**ドープにより電荷セクターが gapless(Luttinger液体)になり、エンタングルメントが $\sim(c/3)\log L$ で増える**ため、固定χ priorの捉える割合が落ちること。増加が対数的で緩やかなことも整合的。したがって主張2は「$\Delta$ の L 非依存性は**ギャップのある系で厳密**、gapless系では**対数的にのみ破れる**」と精密化される。ホッピングが最速なのはJW弦ではなく(half-fillingのホッピングは平坦 0.997→0.986)、電流揺らぎが gapless 電荷セクターに最も強く結合するためと考えられる。

**論文にとって最も重要な含意**: χ_p=2 のドープ系では2〜3割のサイトで**有意に損をし、最悪25倍悪化する**。中央のサイトだけを見ていた §3.2 はこの領域に一度も触れていなかった。これは**最適係数CRM(§3.7, $G\ge1$ 保証)がなぜ必要かの最も直接的な証拠**であり、「CRMは常に得」という誤読を防ぐために本文に明示すべき。損がドープ系に集中する点は §3.10 の相図(安いpriorの破綻は電荷テクスチャに局在)と整合する。

### 3.2c ボンド観測量の利得の周期2振動 — Friedel振動による $G_{\max}$ の変調 (`crm_site_median.png`)

サイト×観測量ごとの利得中央値(`crm_site_median.jl`、χ_p で集約、1,743組)を取ると、**オンサイト量の利得は鎖に沿って滑らかなのに、ボンド量は隣り合うボンドで5〜17倍違う**($L=16$ の $Z_\uparrow Z_\uparrow$: 186.6, 11.1, 79.7, 15.8, …)。サイト方向の変動係数で観測量は2群に分かれる: オンサイト 0.10–0.29 / ボンド 0.24–0.58。

機構は完全に同定できた(詳細は README §2c、数式版は `paper/crm_tutorial.tex` §16):

1. **開放端がスタッガード($2k_F=\pi$、周期2)の定在波を誘起する**。半充填ハバード鎖は電荷はMottギャップで凍結だがスピンはgapless(Heisenberg普遍類)なので、端が支配的なスタッガード成分をピン留めする。
2. ボンド量では「強い/弱い」の交替になる。端のサイトは隣が1つなのでその1本にシングレットを集中でき、第1ボンドがほぼダイマー化する($\ev{Z_\uparrow Z_\uparrow}=-0.823$、$\ev{n_\uparrow n_\uparrow}=0.044$、完全シングレットなら $-1$)。
3. **振幅は端からの距離に対し $A(x)\propto x^{-1/2}$**。$L=128$ で $A(x)\sqrt x = 0.247, 0.248, 0.244, 0.238, 0.237$($x=1,3,7,15,31$、4%以内)、中央のみ両端の寄与が重なり16%上振れ。**gapless スピン鎖のボンド秩序 Friedel 振動の既知の指数と一致**し、DMRG収束の独立なチェックにもなる。
4. **$\ev{P}$ の2.5倍差が $G$ の17倍差に増幅される理由**は $G_{\max}\propto \ev{P}^2/(1-\ev{P}^2)$ が $|\ev{P}|\to1$ で発散すること。強ボンド $0.677/0.323=2.09$ vs 弱ボンド $0.108/0.892=0.121$(比17.3)→ $G_{\max}=187$ vs $11.8$(実測 186.6 / 11.1)。分子は「CRMが打ち消せる設定間揺らぎ」、分母は「打ち消せないショットノイズ床」で、$|\ev{P}|$ が大きいと前者が増え後者が減るため二重に効く。

**帰無検定(査読対策として重要)**: 周期境界条件にすると振動は完全に消える — $\langle P\rangle$ の変動係数が 0.25→0.0015、$G_{\max}$ の最大/最小比が 16.1→1.01(L=32、`crm_pbc_check.jl`)。PBC のバルク値 $-0.514$ は OBC の交替値のちょうど中間にあり、「バルク値のまわりに立った定在波」という描像と整合する。**説明を反証可能な形で検証した**ことになるので本文に入れる。系として「周期境界の系ではサイト分解に意味がなく中央1点で十分」も言える。

**論文上の位置づけ**: (i) §3.2b の「端の増強」はこのFriedel振動の $x\to0$ 極限であり、両者は同一現象である。(ii) $G/G_{\max}=1.00$ かつ $\Delta$ が一様なので、振動は**prior性能ではなく観測量自身の物理**に由来する — 2レジーム診断(§2.2)が「利得のばらつきの原因が prior 側か観測量側か」を切り分けた実例として使える。(iii) 実務的含意として、**測定計画は「どの観測量か」だけでなく「系のどこか」まで含めて $\ev{P}$ を見積もる必要がある**(端の1本と隣の1本で必要ショット数が一桁違う)。この点は prior-informed derandomization(§5項1)の設計変数にもなる。


### 3.2d 損の領域での最適係数CRM — 6推定量の比較 (`crm_site_beta_results.tsv`)

§3.2b の否定的結果(χ_p=2 のドープ鎖で3割のサイトが有意に損)に対し、§3.7 の最適係数CRMを**その領域で初めて試した**。L=16/64, δ∈{0,1/8}, χ_p∈{2,…,32}, $n_u\in\{50,100,200\}$(入れ子), n_repeat=500。

**指標上の必須の注意**: $G$ は分散比なのでバイアスを見ない。プラグイン $\hat\beta$ は同一データで係数を推定するため原理的にバイアスを持つので、**MSE比とバイアス/標準偏差を併記**しないとプラグイン推定量を不当に有利に評価する。

1. **損は消える**: L=64, δ=1/8, χ_p=2 で CRM(β=1) は 134/445 サイトで損(min G=0.037)。$n_u\ge200$ なら**全ての最適β系が 0/445**。
2. **プラグイン $\hat\beta$ の失敗モードを同定**: $n_u=50$ で残る52点はすべて二重占有・χ_p=2。χ_p=2 の prior はダブロンを含まないので $\langle D\rangle_\sigma=0$ が厳密、すなわち **Var(Y)=0 の 0/0**。β中央値は正常(0.48–0.67)だが標準偏差が 185–6480 という裾の重い分布になる。$r^2$ 縮小は効かない(分子分母が同じノイズに駆動され標本 $r^2$ が偽の高値を出す)。
3. **解決 — Var(Y) は解析的に計算できる**: $Y(u)=\sum_t c_t\mathbf 1[\text{一致}]3^{|A_t|}\ev{P_t}_\sigma$ で基底分布は既知($\Pr[t] = 3^{-|A_t|}$, $\Pr[t\wedge t']=3^{-|A_t\cup A_{t'}|}$、重なりで矛盾すれば0)なので閉形式。経験分散と0.5%以内で一致を確認。**元のCRM推定器の修正(prior側を厳密に)とまったく同じ原理**。
4. **ただし MSE で見ると推奨が変わる**(L=64, δ=1/8, n_u=200 の中央値MSE比):

| 推定量 | χ_p=4 | χ_p=8 | max\|bias\|/sd | n_u=50 の損 |
|---|---|---|---|---|
| CRM(β=1) | 4.32 | 16.68 | 0.13 | 134/445 |
| **素朴β** | **17.46** | **18.60** | 0.59 | 16/445 |
| 縮小β | 17.49 | 18.61 | 0.58 | 13/445 |
| 標本分割 | 16.69 | 17.95 | 0.14 | 66/445 |
| 厳密Var | 5.94 | 6.73 | 0.78 | **0/445** |
| 分割×厳密Var | 4.60 | 5.17 | 0.12 | 8/445 |

厳密Var版は「絶対に損をしない」代わりに典型利得が1/3になる。**実務推奨: $n_u\ge200$ なら素朴/縮小 $\hat\beta$、$n_u$ が小さいなら厳密Var版、バイアス管理が要るなら標本分割版**。

5. **priorフリー性の定量化と限界**: 単一Pauli列では $\hat\beta(\bar Y-\Tr[O\sigma])$ の中で $\ev{P}_\sigma$ が約分され、$G_\beta$ が χ_p に対し**小数点2桁まで不変**になる(ZZ onsite 13.27、ZZ up-up 14.39)。多項観測量(二重占有・SzSz)では prior 依存が残る(1.28→16.8)。忠実度 $10^{-17}$ の prior でも ZZ系は**天井の94–95%**に到達する。
   一方 **SzSz とホッピングは天井が高い(15.3, 35.7)のに最適βでも 1.00 のまま**。χ_p=2 の prior はホッピング振幅を厳密に0と予言するので $Y\equiv0$、制御変量が原理的に存在しない。整理すると: **Var(Y)=0 ⇒ β=0 に落ちて標準に戻る(損も得もなし)/ Var(Y) 小さいが非ゼロ ⇒ プラグインが不安定、厳密Varで解消**。

**論文上の位置づけ**: 主張5(損をしないCRM)に、(i) 損の領域での実証、(ii) 必要な $n_u$、(iii) プラグインの失敗モードとその解析的解決、(iv) 分散比ではなくMSEで評価すべきという方法論的注意、を追加できる。特に (iv) は査読で必ず突かれる点であり、先回りして提示すべき。


### 3.2e Δ の L 依存は「ギャップの有無」で決まるか — 部分的にしか決まらない (`crm_gap_scaling.png`)

§3.2b の限界(ドープすると Δ の L 非依存性が破れる)を、U を振って直接検証した。U ∈ {0,1,2,4,8} の half-filling と U ∈ {4,8} の δ=1/8、L=8–128、χ_p ∈ {4,…,32}。Δ は窓RDMから厳密に計算できるので **Monte Carlo 不要**(DMRGとRDM縮約のみ)。あわせて中央ボンドエントロピー $S_c(L)$ から中心電荷を読み、ギャップ構造を独立に同定する。

**設計上の反省が2つあった(どちらも修正済み)**:
1. 当初 median|Δ| を指標にしたが、U=0 では χ_p=8 が自由フェルミオン基底状態をほぼ厳密に表現でき Δ=3e-11 になるため比が 10⁶ 倍になる。**相対誤差 ε=Δ/⟨P⟩ を使うべき**だった — 自分たちで確立した「利得を支配するのは相対誤差」を指標選びに適用できていなかった。
2. U=8 で nsweeps=16 では DMRG が収束せず、$S_c$ が L=64→128 で**減少**するという異常が出た。30スイープで解消(χ=512 にしても変わらないのでスイープ数が原因)。**強結合では必ず収束確認をすること**。

**確認できたこと**:

| U=2 half | 0.99 | 1.15e-2 | 8.38e-2 | 4.85 |
| **U=4 half** | **0.92** | 2.7e-3 | 2.8e-3 | **1.20(平坦)** |
| U=8 half | 0.91 | 2.7e-4 | 1.41e-2 | 1.64 |

1. **中心電荷の読み出しは機能する**: c≈0.9(Mott、電荷gapped・スピンgapless)→ c≈1.6–1.7(ドープ/金属、→2)のクロスオーバーを再現。U=1(1.53)→U=2(0.99) の推移は、電荷相関長 $\xi_c\sim e^{2\pi t/U}$ が L を下回る点に対応する。
2. **ドープ系と弱結合(U=1,2)では ε が L とともに増加**、**U=4 半充填では平坦**。ここまでは予言どおり。

**確認できなかったこと(未解決)**: **U=8 半充填も同じ c≈0.91 なのに ε が増加する**(×1.64)。しかもこれは収束不足ではない(スイープ45・χ=512 でも ε=1.411e-2 で完全に安定)。

さらに、当然の候補である2つの説明が**どちらも否定された**(L=64 で確認):

|---|---|---|---|
| 中央エントロピー $S_c$ | 1.214 | 1.002 | U=8 |

**作業仮説**: 強結合では二重占有 $\ev{D}\sim(t/U)^2$ 自体が小さく、**仮想的な電荷ゆらぎ(＝Schmidt 重みの小さい成分)が担っている**。したがって「重みの99.3%を保つ切断」でも、その0.7%に住む量は大きく壊れる。$\ev{Z_\uparrow Z_\downarrow} = -1+4\ev{D}$ なので ZZ onsite もこれを継承する。

### 3.3 測定予算配分 — Fig 2b

飽和則 $G_{\max}\propto n_m$ を nm=10–1000 で検証(理論曲線と一致)。

**重要な注意(過去の記述を訂正)**: 「$n_u$ を絞り $n_m$ を厚くせよ」と書いていたが、これは**利得 $G$ の最大化であって分散の最小化ではない**。総ショット数 $B=n_u n_m$ を固定すると
$$\Var[\text{CRM}] = \frac{1}{B}\bigl[(3^{|A|}-1)\Delta^2 n_m + 3^{|A|}(1-\ev{P}^2)\bigr]$$
で $n_m$ に単調増加する(標準も同様)ので、固定予算では $n_m=1$ が分散最小である。$G$ は比なので $n_m$ とともに増えるが、両者は別物。

正しい実務指針は: (i) $n_m$ が閾値 $n_m^\ast=3^{|A|}(1-\ev{P}^2)/[(3^{|A|}-1)\Delta^2]$ 以下なら分散はほとんど悪化せず $G$ だけ伸びる(ほぼタダで利得が買える)、(ii) 閾値を超えると分散が線形に悪化する。したがって「設定を絞れ」ではなく「$n_m\lesssim n_m^\ast$ なら設定数を減らして構わない」。実機で基底切り替えコストが高く大きな $n_m$ を強いられる場合にCRMの価値が最大になる、という形で効く。**査読で必ず突かれる点なので本文で明示すること。**

### 3.5 matchgateシャドウ: JW弦問題の解消とCRMの効果範囲 (`crm_matchgate.png`)

4×2シリンダー(16量子ビット、密ベクトルで厳密シミュレーション)で、ランダムPauliシャドウとmatchgate(フェルミオンGauss)シャドウを同一測定予算($n_u{=}50, n_m{=}100$)で比較:

| 推定誤差(U=4) | Pauli標準 | Pauli+CRM | **MG標準** | MG+CRM |
|---|---|---|---|---|
| hop y-bond | 0.211 | 0.052 | 0.098 | 0.096 |
| hop **x-bond** (JW弦 \|A\|=9) | **測定不能**(全設定で不一致、推定恒等0) | prior値を返すだけ | **0.095** | 0.076 |
| エネルギー全体 | 11.5 | 0.88(ただし下記) | **0.87** | 1.01 |

- **matchgateはJW弦問題を実際に解消**: x-bondがy-bondと同じ精度で測れる(演算子の台によらず2次Majorana)。エネルギー全体の誤差はPauli標準の**約13分の1**。
- **注意(Pauli+CRMの隠れバイアス)**: Pauli+CRMのエネルギー誤差0.88は一見良いが、一度も測定されないx-bond項のCRM推定は「priorの値そのもの」を返すため、UHFのx-bond誤差ぶん(約0.6)**バイアスする**(平均 −5.35 vs 真値 −5.95)。有限予算では実質バイアス推定量。
- **CRMはmatchgateにはほぼ効かない**: nm=100でG_MG ≈ 0.5–1.6。nm掃引(30–3000, `crm_matchgate_nm.tsv`)でも、ショット豊富極限でβ=1利得はエネルギーで最大~1.9倍、個別観測量は≈1に留まる(最適βで~1.5–2.6倍)。Pauliの利得源は「基底一致/不一致」による巨大な設定間揺らぎだが、Haar的Gauss回転は自己平均的で打ち消すべき揺らぎ自体が小さい。**CRMの価値はアンサンブル依存**という重要な知見(アンサンブル設計=方向性の理論課題につながる)。
- 検証: ゲート列とSO(2n)回転の対応(1e-15)、Majorana展開(1e-10)、推定量の不偏性(統計)、Pfaffian古典側=全数和(1e-8)、エネルギー真値=DMRG E0+μN(1e-6)。

### 3.6 2D: 安価な prior は MPS に代われるか — Fig 3 (`crm_fig3_priors2d.png`)

W=4×8 シリンダー(64量子ビット、half-filling、参照=DMRG χ=192):

- **前提の確認**: MPS prior は2Dで急劣化(U=4: χ=8 で F=0.055。1D L=16 の同χは 0.95)。
- **UHF (Néel, O(N³))**: オンサイトZZで G=44 (U=4) / **241** (U=8, χ=64の243と同等)、運動ボンドで G≈9–12。ただしサイト間スピン相関は凍結秩序の過大評価で失敗(G≤3、時に<1)。
- **対称性回復UHF(回転平均、混合状態prior)**: サイト間スピン相関を**全て修復**(U=4: ZZ x隣 0.83→8.69 でχ=64の8.57と同等、SzSz x 0.81→6.11、他同様)。オンサイト・運動項は回転不変で厳密に不変(理論予言通り)。全体として **χ=16 MPS 相当を O(N³)+1次元求積で達成**。
- **退行が1つ**: 二重占有 6.6→3.4 (U=4)。演算子はSU(2)不変で合計Δは両priorで同一だが、**χ=192のDMRG参照自体がNéel対称性を破っており**、項ごとの $\langle Z_q\rangle$ は共線UHFの方が合う。→ 項ごとΔの効果(§2.2注意)の実証例であり、「priorの対称性を実験状態の対称性に合わせる」「観測量ごとにpriorを選ぶ」という設計指針につながる。

### 3.6b 2Dサイト分解: 安価な prior が破綻する場所の地図 (`crm_2d_site.png`)

§3.10 の「安いpriorが破綻するのはドープ系の電荷テクスチャ」を空間地図にした。W=4×8シリンダー(64量子ビット)、U∈{4,8}、半充填と1/8ドープ、prior = UHF / χ切断MPS(8,32)。窓RDMサンプリングはスネーク順で窓が連続なら2Dでもそのまま使える。

1. **安いpriorだけが空間的に大きく不均一**: 相対誤差のサイト間変動(max/min)は、半充填では UHF 1.4–3.0倍だが、**ドープすると 9.9–52.9倍**に跳ね上がる。誤差は列 x にのみ依存する縞構造を示す(電荷変調が x 方向にのみ立つため)。対照的に切断MPS priorの誤差はまだら模様で系統的構造を持たない。
2. **UHF の誤差は局所ホール密度で予測できる**: corr(ln ε, |n−1|) = **+0.83〜+0.98**(オンサイト量、ドープ系)。§3.10 の定性的示唆が定量化された。
3. **ただし自己診断は限定的**: 実務で使えるのは UHF が自分で予言する密度だが、それでは相関が 0.29–0.69 に落ちる。**UHF の密度プロファイル自体が真の値と corr 0.42–0.55 でしか一致しない**ためで、「安いpriorが最も間違える量(電荷テクスチャ)」が「どこで間違えるかを教えてくれる量」でもあるという circular な状況になっている。サイト間スピン相関では相関が負になり、この指標は使えない(そちらは対称性回復UHFが対処する別機構)。

**論文上の位置づけ**: 主張7(安いpriorの相図)に空間分解能を与える。特に (2) は「prior自身から難しさの指標を作る」方向(§5 項2の損の事前予測)の具体的な足がかりになり、(3) はその限界を正直に示す。


### 3.7 最適係数CRMと多prior回帰 — `crm_optbeta.png`

CRM推定量を制御変量法の一般形 $\hat o(\beta) = \bar m_\rho - \beta(\bar Y_\sigma - \mathrm{Tr}[O\sigma])$ に拡張し、βを同一データからプラグイン推定($n_u{=}50$ 設定から共分散を推定)。W=4×8シリンダーで検証(既存runと同一seed=同一測定データ):

- **保険としての最適β**: β=1 で損をしていた全ケースが修復される。U=8のUHF priorで ZZ y2: 0.70→**13.95**、ZZ x1: 1.14→**18.59**、SzSz x: 1.02→**15.06**。達成利得は理論 $1/(1-\mathrm{corr}^2)$ と y=x で一致。プラグインバイアスは検出限界以下(全法・全観測量で |mean−true|/SE ≤ 2.6)。
- **単一Pauli列では最適βの利得がprior非依存になる**(理論的必然): $Y_p(u) = \mathbf{1}[\text{基底一致}]\cdot 3^{|A|}\langle P\rangle_{\sigma_p}$ はpriorごとにスカラー倍しか違わず、その定数はβに吸収される。系として、**単一Pauli列にはpriorなしの「一致インジケータ制御変量」($Y=\mathbf{1}[\text{match}]$、係数はデータから学習)が定義できる** — self-calibrating shadow ともいうべき推定器で、prior構築コストゼロ。
- **β=1 と最適βのトレードオフ**: priorが優秀な場合はβ=1が勝つ(U=8 ZZ onsite: 241 vs 141; hop y-bond: 9.3 vs 3.2)。原因は $\hat\beta$ の推定ノイズで、特に基底一致が稀な観測量(hop, |A|=3, 一致率1/27 → 50設定中約2回)で顕著。**「信頼できるpriorはβ=1、不確かなpriorは最適β」**という運用指針が定量化された。
- **多prior回帰**: 二重占有で multi(free: UHF+UHF-sym)=**98**(U=8)。単一のタダprior(UHF 15.9 / UHF-sym 6.3)を桁で超え、χ=32 MPS prior(101)とほぼ同等。**MPSを一切使わずにMPS級の利得**に到達。priorが冗長な場合(純Pauli列)は擬似逆行列で自動的に単一prior相当へ退化。

### 3.8 多観測量同時推定: vs 貪欲derandomization (`crm_derand_results.tsv`)

1D鎖 L=16(窓18量子ビット)、同一総ショット数(50設定×100ショット)で、多数の観測量を同時推定する誤差を比較(prior=χ32切断MPS, F=0.9998):

| セット | shadow標準 (中央値/最悪) | shadow+CRM | 貪欲derand |
|---|---|---|---|
| A: 構造化23個(docc/SzSz/hop/ZZ) | 0.059 / 0.351 | 0.012 / 0.054 | **0.0085 / 0.028** |
| B: ランダム2-3局所 150個 | 0.058 / 0.208 | 0.057 / **0.096** | **0.044 / 0.067** |

- 既知の固定リストには**derandomizationが最強**(貪欲カバレッジで全列命中、逆チャネル係数 $3^{|A|}$ が不要なため)。これは正直に認める。
- ただし**CRMはシャドウの不利をほぼ解消**する: 構造化セットで中央値 4.8倍改善、derandとの残差は1.5倍。非構造セットでは中央値の利得は消える($\langle P\rangle\approx0$ の列に打ち消すべき揺らぎがない)が、**最悪誤差は半減**する(CRMは $|\langle P\rangle|$ が大きい=最も誤差の大きい観測量を自動的に狙い撃つ)。
- 決定論的設定にはCRMの利得原理が適用できない(揺らぎがないので打ち消す対象がない)ことも確認 — CRMとderandomizationは**相補的**であり、「priorで測定計画自体を設計する」方向(prior-informed derandomization)が次の理論課題。

### 3.9 W=6シリンダー (96量子ビット, クラスター計算) — `crm_2d_w6.png`

主張3を「MPSが本当に苦しむ幅」で検証(6×8シリンダー、参照=DMRG χ=512、PBSジョブ2本×約40分):

- **MPS priorの崩壊が加速**(U=4): χ=8の忠実度 0.055(W=4)→**0.018**、χ=32: 0.57→**0.22**、χ=128でも0.74。同じχで買える忠実度が幅とともに急落する。
- **UHFは持ちこたえる**: U=4のオンサイトZZで G(UHF)=19.2 ≈ G(χ=32)=18.2、二重占有では G(UHF)=14.3 > G(χ=16)=11.8。U=8ではオンサイトZZで G(UHF)=157 > G(χ=32)=96。**タダのpriorの相対優位はWとともに拡大**(同等のMPS priorのコストが指数的に上がるため) — 論文の主張3をより強い形で裏付ける。
- **意外な逆転**: W=6では共線UHFがサイト間スピン相関でも機能し(ZZ x隣 G=7.7、W=4では0.83)、**UHF-symの方が悪い**(4.5)。原因はχ=512参照自体が(サイズに対して未収束のため)W=4参照より強くNéel対称性を破っており、凍結共線秩序が項ごとの構造に合うため。「priorの対称性は実験状態の対称性(破れの程度)に合わせる」という§3.5-3.7の教訓の再確認であり、有限χ参照への依存性として正直に記載する(観測量ごとのprior選択・最適βがこの不確実性への実務的な保険になる)。

### 3.10 ドープ系 (1/8 hole doping, W=4×8) — `crm_dope_U8.log` / `crm_dope_U4.log`

U=8とU=4、電子28個(4ホール)、参照=DMRG χ=512。UHFは複数初期値から最低エネルギー解を採用。**Néel初期値からでも自発的にストライプ的な解**(x=5–7にホールの川、x=6で反位相、列分解プロファイルをログに出力)に流れる。

| U=8 doped | G(UHF) | G(UHF-sym) | G(χ=16) | G(χ=64) | prior忠実度: χ=8/χ=128 |
|---|---|---|---|---|---|
| onsite ZZ | 27.8 | 27.8 | 43.2 | 70.5 | 0.026 / 0.91 |
| ZZ y隣 | 0.60 | **12.0** | 4.5 | 13.8 | |
| DoubleOcc | 1.0 | **21.3** | 35.5 | 70.9 | |

- **half-fillingとの逆転**: 共線UHFはサイト間スピン相関で大失敗(Δ≈0.44–0.56)、**回転平均UHF-symが救う**(χ=16–32相当)。ドープ状態は静的秩序が壊れてより対称的・量子揺らぎ的なので、対称化priorが合う — 「priorの対称性を状態の(破れの)対称性に合わせる」則のドープ側の実例。
- **密度(ストライプ秩序パラメータ)はどのpriorも苦手**(UHFはG≪1: ホールの川の位置・形が参照と合わずΔ=±0.07–0.14)。最適β(§3.7)で保険をかけるべき典型例。
- **U=4 doped(相関金属)は安いpriorの限界**: UHFはほぼ常磁性(m=0.078)に潰れ、onsite ZZすら G=0.81。MPSもχ=8で忠実度0.0016と崩壊し、χ≥32が必要。例外は運動項(G(UHF)=8.6 ≈ χ=128)。**「安いpriorの相図」**: 強結合(Mott/ストライプ)では機能、中間結合ドープ金属では平均場を超えるprior(Gutzwiller等)が必要 — 今後の課題の物理的動機付け。

**W=6ドープ(96量子ビット、6ホール、`crm_2d_w6_doped_results_U*.tsv`)**: UHFは複数初期値の比較で**教科書的なbond-centered反位相ストライプ**(x=4–5にホールの川 n=0.59、壁を挟んでm_stagが符号反転)を自発的に選ぶ。しかし観測窓(中心列=壁の上)では**UHF/UHF-symともに崩れる**(U=8: onsite ZZ G=0.90、Δ=−0.57): UHFのストライプは電荷変調が強すぎ・壁が鋭すぎ、揺らぎで軟化したDMRG参照のストライプと局所構造が合わない(平均場が秩序振幅を過大評価する古典的な失敗モード)。MPSはχ≥32が必要(χ=32でG≈4–38、ただしW=6でのχ=32は既に安くない)。U=4ドープはさらに厳しく(χ=8忠実度4e-4)、χ=128でようやく実用域。**運動ボンドだけはどのpriorでも常に機能**(G≈6–23)。→ 「安いpriorの相図」の境界が確定: 秩序が強く一様な領域(half-filling全域、W=4ドープの対称化UHF)では機能し、**強い量子揺らぎを伴う非一様テクスチャ(広幅ドープのストライプ)で破れる**。**壁上/ドメイン内の位置依存性(X0=2ジョブ、`crm_2d_w6_doped_results_U8p0_x2.tsv`)**: 観測窓をAFドメイン内(x=2)に移すと、(i) **UHF-symがスピン相関を再び救う**(ZZ y隣 G=9.2、x隣 7.1、SzSz y 9.5 — Δ≈0.01–0.03でχ=16–32 MPS相当。W=4ドープと同じ構図)、(ii) 共線UHFはドメイン内でも失敗(Δ≈0.3–0.8)、(iii) **サイト密度は場所によらず平均場では無理**(G≈0.1、Δ≈0.13–0.16: UHFのストライプは電荷変調が鋭すぎ、DMRG参照はホールをドメイン側まで広げている)。まとめると平均場priorの破綻は「電荷テクスチャの不一致」に局在しており、スピンセクターはドメイン内なら対称性回復で救える。運動ボンドは常に容易(G≈6)。

## 4. 論文化に向けて

### 新規性の整理

1. 局所Pauli観測量に対するCRM利得の閉形式と、その大規模数値検証(原論文は忠実度中心・変分バウンド)
2. 「利得=priorの局所誤差」原理による、グローバル忠実度崩壊下での利得残存の実証。**256量子ビット系の全サイト**で検証し、$\Delta(i)$ がサイト・系サイズにほぼ非依存であることを直接示した(§3.2b)。同時に**利得が負になる領域(粗いprior×ドープ系)をサイト分解で同定**し、項5の最適係数CRMの必要性を実証的に基礎づけた
3. Wick閉形式による**MPS不要の平均場prior**(サイズ非依存コスト)と、2DでのMPS priorとの定量比較
4. **混合状態prior**の導入と対称性回復UHFによる弱点修復
5. 最適係数・多prior回帰CRM: 「損をしない」保証、priorなしの一致インジケータ制御変量、タダのprior回帰でMPS級利得(§3.7)
6. 利得の2レジーム(Δ律速 / ショットノイズ律速)の切り分けと $G/G_{\max}$ による診断法 — 「priorを改善すべきか、ショットを増やすべきか」を観測量ごとに判定できる(§2.2)
7. 窓サンプリングと**窓RDMサンプリング**(副産物、シミュレーション手法): 後者はコストがボンド次元に依存せず、局所観測量のシャドウ実験を 256量子ビット・全サイトで回せる

### 境界条件の選択(査読で問われる可能性が高い)

1D鎖はOBC、2Dシリンダーは $y$ のみ周期。**PBCにしない理由**: (i) 実験系(冷却原子・イオン・超伝導量子ビット)はすべて端のある有限系であり、測定コストの問いは実機についての問いである、(ii) PBCは実効ボンド次元を二乗するので $L=128$・$\chi=256$ が不可能(PBC検定は $\chi=512$ で $L=32$ が限界だった)、(iii) 2Dのシリンダー幾何はDMRGの標準で、ストライプが立ちやすいという物理上の利点もある。

**OBCはPBCと別物ではない**: OBCの値は「PBCのバルク値 + 端の変調」である($G_{\max}$ が OBC最小50.2 / PBC 51.0 / OBC最大94.4、L=32 の onsite ZZ)。

**主張そのものはPBCでも成立し、むしろ強化される**(`crm_pbc_gain.jl`): PBCは同じ $L$ でエンタングルメントが約2倍($S_c$ 1.08→2.28、L=32、$c/3$ 対 $c/6$ の予想比2と整合)、$\chi_p=32$ の prior は 1−F で **116倍悪い**(0.0015→0.1745)。それでも $G$ は変わらず(ZZ onsite 47.61 vs 47.67)、損をする観測量は両BC・全 $\chi_p$ でゼロ、$\chi_p\ge8$ の $G/G_{\max}$ は 1.000 / 0.984–0.988。**これまでの実証は「同じ系を大きくする」ものだったが、これはハミルトニアン自体を変えてグローバル忠実度を2桁悪化させた比較であり、局所性の最も直接的な実証になる**。論文の主張2の証拠として Fig 2 に併記する価値がある。

**依存関係を明示すること**: §3.2b(サイト依存性)と§3.2c(周期2振動)は**OBCに全面的に依存**し、PBCでは定義上消えて§3.2に還元される。一方、利得法則・2レジーム診断・$\chi^*(L)$ と中心電荷の対応・最適係数CRM・2Dのprior比較は境界条件に依存しない。なお中心電荷フィットはOBCの式 $S_c=(c/6)\ln L$ を使っており整合している(PBCなら $c/3$)。

### 想定される査読コメントと対応

- **「単一の局所観測量なら該当基底の直接測定が最強では」** → その通りで、多観測量同時推定ベンチマーク(§3.8, `crm_derand_results.tsv`)で定量化済み。既知の固定観測量リストに対しては貪欲derandomizationが最強(構造化23個: 中央値誤差0.0085)。ただし (i) CRMはシャドウの弱点をほぼ埋め(0.059→0.012、derandとの差1.5倍)、(ii) 非構造150個ではその差は1.3倍まで縮み、(iii) シャドウ+CRMは測定後に任意の観測量を選べる柔軟性(derandはリスト事前確定が必須)を保つ。「リスト既知→derand、事後選択・多目的→シャドウ+CRM」という守備範囲の明確化として論文に書く。
- **「参照状態(χ=192)は収束していない」** → 手法の主張は「固定参照に対する推定分散」なので自己無撞着。ただし物理量の議論をする場合はχ収束を確認する。参照の対称性破れの定量化(⟨Z_q⟩ρの出力)も追加すべき(**要追加**)。
- **「JW弦のせいで2Dの横ボンド運動項が測れない」** → 事実であり、§3.5でmatchgateシャドウにより解消できることを実証済み(x-bondがy-bondと同精度、エネルギー誤差13分の1)。あわせて「CRMの利得はアンサンブル依存(Pauliで大、matchgateでは小)」という効果範囲の切り分けも提示できる。
- **「忠実度でのCRMの意味は」** → 小さい系では有効(L=8でG≈15)だが、局所シャドウの忠実度推定自体が指数的に破綻するため主戦場ではない、と明示する。
- **「期待値 $|\langle P\rangle|$ が大きい観測量が得なのは自明ではないか(Δも比例するので比は不変)」** → 鋭い指摘であり、$v_s\to0$ 極限では実際に $G\to1/\varepsilon^2$ でスケール不変。回答は §2.2 の通り2点: (i) 有限 $n_m$ ではショット床がスケール不変性を破り天井が $|\langle P\rangle|$ とともに上がる、(ii) 実データで $\Delta$ と $\langle P\rangle$ は事実上無相関(+0.28)で、相対誤差は観測量ごとに1.5%〜124%とばらつく。論文では利得を**相対誤差 $\varepsilon$ と $g=S/v_s$ の2変数**で提示し、$G/G_{\max}$ の診断表を添える。
- **「中央のサイト1点で局所性を語るのは弱い」** → §3.2b で L=8–128 の全サイト(17,210点)に拡張済み。χ_p≥4 では損なサイトがゼロである一方、χ_p=2 のドープ系では2〜3割のサイトが有意に損をすることも同時に報告する。**都合の悪い領域を自分から出しておく**のが査読対応として最も強い。
- **統計**: 分散比のエラーバー(n_repeat=50–200によるブートストラップCI)を最終図には付けること(**要追加**。ただし §3.2b では n_repeat=1000 + bootstrap 600 で全点にCIを付与済みで、実装はそこから流用できる)。なお最大利得の点(理論141に対し実測241)は n_repeat=50 で 1σ≈28% のため約2.4σ高い外れ値であり、CI を付ければこの解釈も明示できる。

## 5. 今後の課題

1. ~~多観測量ベンチマーク~~ → **実施済み**(§3.8)。残り: prior-informed derandomization(priorを測定計画の設計に使う統合)
2. 分散比のブートストラップCI付き最終図(あわせて $G$ vs $G_{\max}$ 診断図 = Fig 5 を作成)
2b. **測定予算の最適配分**: 診断法(§2.2)を使い、観測量集合が与えられたとき「prior改善に計算資源を割く」か「$n_m$ を増やす」かを定量的に決める枠組み。$G/G_{\max}$ が1に近い観測量が多ければ後者が有利で、これは prior-informed derandomization(項1)とも接続する
3. 参照状態の対称性破れの定量化と、対称性を破らない参照(SU(2) DMRG or 大χ)での再確認
4. ~~ドープ2Dシリンダー(ストライプUHF prior)~~ → **実施済み**(§3.10、W=4/W=6+窓位置比較)。残り: 電荷テクスチャを捉える中間コストprior(電荷分布を拘束した平均場、Gutzwiller/DMET的)
5. ~~matchgateシャドウ × CRM~~ → **実施済み**(§3.5)。残り: (a) matchgateでCRM利得が現れうる大 n_m 領域の掃引とmatchgate版分散理論の導出、(b) 相関状態に対するmatchgateシャドウの大規模シミュレーション法(現状は16量子ビット密ベクトルが上限)
6. 忠実度CRMのprior側厳密化(χ²-MPO縮約 $q_\sigma^T W q_\sigma$)— 現状は安価な過剰サンプリングで代用
7. QSE行列要素($H_{ij}, S_{ij}$)へのCRM適用(ブランチ名 `qse-debug` の元テーマとの接続)
8. **§3.2b が新たに開いた課題**:
   - (a) **「損」の事前予測**: 損の条件は $\varepsilon=\Delta/\langle P\rangle>1$ だが $\Delta$ は真値を知らないと測れない。priorを2つ用意して差から $\Delta$ を上から見積もる方法と、最適係数CRMを常時使う方法のどちらが実務的かを決める
   - (b) **サイト分解の2D版**: 1Dでは $\Delta(i)$ がほぼ一様だったが、2Dドープ系ではストライプ壁とドメイン内部で prior 品質が大きく違う(§3.10)。同じサイト分解を W=4/6 に適用すれば「安いpriorが破綻する場所」の空間地図が得られる。窓RDMサンプリングは2Dでも(スネーク順で窓が連続なら)そのまま使える
   - (c) **gapped/gapless 仮説の直接検証**: §3.2b(6)の「$\Delta$ の L 非依存性は gapped 系でのみ成立」を、U=0(全セクターgapless)/ U=4,8 half-filling(電荷gapped)/ U=4 δ=1/8(電荷gapless)で median|Δ|(L) を測って確かめる。gapped なら定数、gapless なら $\log L$。**局所性の主張に適用条件を与える**ので論文の主張2の記述を確定させるために必要
