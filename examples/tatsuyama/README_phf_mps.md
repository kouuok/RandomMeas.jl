## この文書の要点

1. UHF-sym は UHF が勝手に選んだスピンの向きを消すが、残る相関は古典的なネール状態のもので、**量子的な一重項の相関が足りない**([README_uhfsym.md](README_uhfsym.md) 5.2)。これを直せそうな prior を2種類計算し、UHF・UHF-sym と同じ表で比べた。
   - **スピン射影 HF(PHF)**: 回した UHF を量子的に重ね合わせ、全スピン 0 の成分だけを取り出したもの。
   - **低い結合次元の MPS**: 厳密な状態を結合次元 $\chi$ に切り詰めた**切断 MPS**と、結合次元を $\chi$ に制限した DMRG の基底状態である**変分 MPS**。
2. **PHF の効果は系の大きさ $L$ に反比例して消える。** 射影は、UHF の2つの副格子の大きなスピンを一重項に組み直すだけである。そのため副格子が違う2サイトの相関が**距離によらず一律に** $2m/L$ だけ強まり( $m$ は UHF の磁化)、エネルギーは系全体で $2mJ$ しか下がらない( $J=4t^2/U$ )。 $U=12$ 、 $L=64$ では、隣の結合の $L\,\Delta\langle\mathbf S\cdot\mathbf S\rangle$ が予測 $-0.972$ に対して実測 $-0.963$ 、エネルギーが予測 $-0.324$ に対して実測 $-0.316$ だった。 $L=64$ では真の値との差の 11%、相関エネルギーの 8% しか埋まらず、CRM の利得の改善も 24 サイト以上の系では UHF-sym の 1.1〜1.8 倍にとどまる。射影してから軌道を最適化(VAP)しても変わらない。
3. **切断 MPS( $\chi=4$ )は、スピン相関はほぼ正確だが、電荷のゆらぎを捨てる。** $L=64$ でも隣の $\langle\mathbf S\cdot\mathbf S\rangle$ は真の値との差が 3% で、隣接 $Z_\uparrow Z_\uparrow$ の利得は 29(PHF の2倍)。一方、中央の二重占有は真の値 0.0178 に対して 0.0000 になり、エネルギーは UHF より悪く、オンサイト ZZ の利得は 151 と UHF(465)を下回る。 $\chi=8$ で両方がそろい、ほぼすべての観測量で HF 系の prior と同等以上になる。ただし**厳密な状態がないと作れない**ので、実際に使える prior ではなく「 $\chi$ で表せる prior の上限の目安」である。
4. **変分 MPS はその逆で、電荷のゆらぎとエネルギーは $\chi=4$ で正確だが、UHF と同じくスピンの向きを選ぶ。** 相関エネルギーの 78〜88% を $L$ によらず取り戻し、オンサイト ZZ の利得は 553、ブロックの電荷の偶奇 $P_{16}$ は 668 で、どちらもほぼ天井に届く。ところが中央サイトの $\lvert\langle S^z\rangle\rvert$ が約 0.30 あり、単一サイト $Z_\uparrow$ では 20 系すべてで損をする。二重占有を4項の和で測ると利得は 4.75(UHF-sym は 123)、遠くのスピン相関でも損をする。 $\chi=16$ にすると $U\ge8$ の1次元開放端では対称性が戻るが、周期境界と2次元では破れたままだった。
5. **2つの MPS の違いは、各結合で使える少ない状態を何に使うかで決まる**(4)。中央の結合を量子数ごとに Schmidt 分解すると、切断 MPS( $\chi=4$ )は重みの大きいスピンの成分だけを上下対称に残し、電荷がゆらいだ成分(厳密な状態では重み 1.7%)を捨てていた。変分 MPS( $\chi=4$ )は、電荷がゆらいだ成分を残してその重み(1.8%)を正しく再現する代わりに、スピンの成分を一方の向きだけにしていた。PHF はどちらも作らず、系全体の回転の対称性を1つ回復するだけである。
6. **実用上**: 数十〜数百量子ビットの系で PHF を使う意味はない。変分 MPS は電荷の量には最良の prior だが、スピンの量ではその対称性の破れを別に取り除く必要がある(UHF-sym と同じ回転平均が使えるはずだが、この文書では試していない)。

## 1. 何を確かめたか

### 1.1 UHF-sym に残る誤差

UHF-sym は UHF をあらゆるスピンの向きに回して平均した prior で、UHF が勝手に選んだ向きの情報だけを消す([README_uhfsym.md](README_uhfsym.md))。回転で変わらない量( $\langle\mathbf S_i\cdot\mathbf S_j\rangle$ など)は UHF の値のままなので、UHF の相関そのものの不足は直らない。1次元 $L=64$ 、 $U=12$ の中央の結合では:

- 隣の $\langle\mathbf S_i\cdot\mathbf S_j\rangle$ は UHF(= UHF-sym)で $-0.247$ 、真の値は $-0.383$ である。差の $-0.136$ は、隣り合うスピンが上下を入れ替えながら一重項を作る**量子的なゆらぎ**の分で、1枚の Slater 行列式にはこれがない。
- UHF は長距離秩序を持つので、離れた対でも相関が一定の大きさで残る(副格子が違う対で $-0.236$ 、同じ対で $+0.236$ )。真の相関は距離とともに減衰するので、UHF-sym は $r\ge4$ から損をする([README_eigenstate.md](README_eigenstate.md) 4.3)。

### 1.2 利得は prior の外れで決まる

単一のパウリ文字列 $P$ (台の量子ビット数 $\lvert A\rvert$ )を $n_m=100$ 回ずつ測るとき、CRM の利得は

```math
G=\frac{Kx^2+v_s}{K\Delta^2+v_s},\qquad K=3^{\lvert A\rvert}-1,\quad v_s=\frac{3^{\lvert A\rvert}(1-x^2)}{n_m},\quad \Delta=x-y
```

である( $x=\langle P\rangle_\rho$ は真の値、 $y=\langle P\rangle_\sigma$ は prior の値)。prior が完全なら $\Delta=0$ で天井 $G_{\max}=1+Kx^2/v_s$ に届き、 $\lvert\Delta\rvert>\lvert x\rvert$ なら $G<1$ で損をする。和の観測量では、項ごとの外れがそれぞれ効く([README_observables.md](README_observables.md) 5.1)。以下で「prior が正確」とは、この $\Delta$ が小さいことである。

### 1.3 比べた prior

| prior | 作り方 | 厳密な状態が要るか | スピン回転の対称性 | 計算の手間 |
|---|---|---|---|---|
| UHF | 平均場の自己無撞着計算 | 要らない | 破る | 行列の対角化の反復 |
| UHF-sym | UHF をあらゆる向きに回して確率的に混ぜる | 要らない | 保つ | UHF と同じ |
| **PHF** | 回した UHF を量子的に重ね合わせ、全スピン 0 を取り出す | 要らない | 保つ | 回転角の積分点(64 点)の数だけ UHF の計算を繰り返す |
| **切断 MPS** | 厳密な状態を結合次元 $\chi$ に切り詰める | **要る** | 保つ(厳密な状態から受け継ぐ) | 厳密な状態を作る手間そのもの |
| **変分 MPS** | 結合次元を $\chi$ に制限した DMRG | 要らない | 破ることがある | スイープ1回が $N\chi^3$ に比例 |

比べる系は、これまでの統合表と同じ**厳密な 80 系**(1次元の開放端 $L=8$ 〜 $64$ と周期境界 $L=8$ 〜 $16$ 、2次元の $W=2$ と $W=4$ の 12 サイト以下、それぞれ $U=2,4,8,12$ の半充填)で、観測量は中央のサイトと結合のものである。距離依存とブロックの偶奇は1次元 $L=64$ の開放端で調べた。

## 2. 計算方法

### 2.1 スピン射影 HF(PHF)

UHF の行列式 $\lvert\Phi\rangle$ は全スピンの $z$ 成分が 0 である。このような状態を全スピン 0 に射影するには、 $z$ 軸から傾ける角 $\beta$ についての積分だけでよい:

```math
\hat P\lvert\Phi\rangle=\frac12\int_0^\pi\sin\beta\;e^{-i\beta S_y}\lvert\Phi\rangle\,d\beta
```

(一般の射影は3つのオイラー角の積分だが、 $z$ 軸まわりの回転は $S^z=0$ の状態を変えないので、残るのは $\beta$ だけになる。)回転で変わらない観測量 $O$ は $\hat P$ と交換し、 $\hat P^2=\hat P$ なので、期待値は1本の積分の比になる:

```math
\langle O\rangle_{\rm PHF}=\frac{\langle\Phi\rvert O\hat P\lvert\Phi\rangle}{\langle\Phi\rvert\hat P\lvert\Phi\rangle}=\frac{\int_0^\pi\sin\beta\,\langle\Phi\rvert O\,e^{-i\beta S_y}\lvert\Phi\rangle\,d\beta}{\int_0^\pi\sin\beta\,\langle\Phi\rvert e^{-i\beta S_y}\lvert\Phi\rangle\,d\beta}
```

- **回した行列式との行列要素**: $e^{-i\beta S_y}\lvert\Phi\rangle$ も、上向きと下向きの軌道を混ぜた Slater 行列式である。2つの行列式の重なり $\langle\Phi\vert\Phi_\beta\rangle$ は軌道の重なり行列の行列式で、 $\langle\Phi\rvert O\lvert\Phi_\beta\rangle/\langle\Phi\vert\Phi_\beta\rangle$ は「遷移密度行列」を使った一般化 Wick の定理で求まる。パウリの $Z$ 文字列はモードの偶奇の積なので、遷移密度行列の小行列の行列式1つで計算できる。
- **求積**: $\cos\beta$ についての Gauss–Legendre 求積(64 点)。 $L=64$ でも 48 点で 10 桁まで収束している。
- **回転で変わる観測量**: 例えば $Z_{i\uparrow}Z_{j\uparrow}$ 。全スピン 0 の状態では、回転で変わらない部分しか期待値に効かないので、その部分に置き換える( $Z_{i\uparrow}Z_{j\uparrow}\to\langle c_ic_j\rangle+\tfrac43\langle\mathbf S_i\cdot\mathbf S_j\rangle$ 、 $Z_{i\uparrow}\to1-n_i$ 。[README_uhfsym.md](README_uhfsym.md) 3.4 の表と同じ)。
- **2つの作り方**: **PAV**(変分してから射影)は UHF の軌道をそのまま射影する。**VAP**(射影してから変分)は、射影したエネルギーが最小になるように軌道を最適化する(7章)。
- **検証**: 小さい系( $L=6$ 、 $U=4$ と $L=8$ 、 $U=2,8$ )で、UHF をフォック空間の状態ベクトルにして $\mathbf S^2$ の固有値 0 の空間へ厳密に射影した値と、7つの量(単一サイト $Z_\uparrow$ 、オンサイト ZZ、隣と距離2の $Z_\uparrow Z_\uparrow$ 、電荷の偶奇の2点相関と3サイトのブロック、ホッピング)が $4\times10^{-15}$ 以内で一致した([crm_phf_check.py](crm_phf_check.py))。

### 2.2 低い結合次元の MPS

**局所基底と結合次元**: 各サイトは ITensor の Electron 基底( $\lvert0\rangle,\lvert{\uparrow}\rangle,\lvert{\downarrow}\rangle,\lvert{\uparrow\downarrow}\rangle$ 、JW 変換で2量子ビット)で、MPS は上向きと下向きの電子数をそれぞれ保存する。結合の状態は「左半分の電子数 $N_L$ と $2S^z_L$ 」の量子数のブロックに分かれ、 $\chi$ はそのブロックの次元の合計である。

**切断 MPS**: 厳密な基底状態を左端に正準化し、左から順に各結合で特異値の大きい $\chi$ 個だけを残し、規格化する([README.md](README.md) の「切断MPS」と同じ)。80 系の中央の値は統合表 [crm_edfid_all.tsv](crm_edfid_all.tsv)、距離依存は [crm_eigcorr_pairs.tsv](crm_eigcorr_pairs.tsv)、ブロックの偶奇は `crm_eigparity_*.tsv` にあったものを使い、エネルギーだけを新しく計算した。

**変分 MPS**: 結合次元の上限を $\chi$ にした DMRG を 60 スイープ回す(ノイズ項を $10^{-4}$ から段階的に 0 まで下げる)。**低い $\chi$ の DMRG は局所解に落ちやすい**ので、Néel の積状態1つと乱数の MPS(16 サイト以下で3つ、24 サイト以上で5つ)から始め、エネルギーが一番低いものを採った。出発点ごとのエネルギーの幅は1サイトあたり中央値で $9\times10^{-3}$ ( $\chi=4$ )、 $1\times10^{-4}$ ( $\chi=8$ )、 $2\times10^{-4}$ ( $\chi=16$ )あり、最良の値に $10^{-6}$ 以内で届いた出発点は中央値で2〜3個だった。つまり「一番低いもの」も真の最適解だという保証はない。これは実際に低い $\chi$ の DMRG を prior に使うときにも同じように起こる。

**検証**:

- 新しく作り直した切断 MPS の中央の値は統合表と一致した(420 値)。差の最大は $L=64$ 、 $U=12$ の $3.4\times10^{-5}$ で、他の系は $1.2\times10^{-7}$ 以下である。この系は、統合表の厳密な状態と、ここで使った保存済みの状態を別々の DMRG で作っている(エネルギー分散はどちらも $2\times10^{-10}$ 程度)。 $L$ が大きく $J=4t^2/U$ が小さいこの系は励起のエネルギーが最も小さく、同じ分散でも状態の違いが大きく残りやすいので、その違いが切り詰めた状態の値に出たと考えられる。いずれにしても、 prior どうしの差(表の値の違い)よりずっと小さい。
- 厳密なエネルギーは統合表と $7\times10^{-11}$ で一致した。
- 変分 MPS では、相関行列から組んだ値と MPO で直接求めた値が $10^{-12}$ で一致し、厳密なエネルギーを下回ったものはなかった。

### 2.3 $\chi=2$ は使えない

$\chi=2$ では、どちらの MPS も UHF よりずっと高いエネルギーにしかならない。切断 MPS はすべての系で $E=0$ ちょうどで、二重占有も隣の相関も 0 になる。変分 MPS も Néel の積状態から始めると $E=0$ のまま動かず、乱数の出発点を含めた最良の値でも、3.3 の1次元の系( $U\ge4$ )で相関エネルギーの回収率は $-420$ 〜 $-206$ %だった。理由は結合の量子数のブロックにある。

1次元 $L=64$ 、 $U=12$ の厳密な状態を中央の結合で Schmidt 分解すると、重みは次のように分かれる([crm_mps_lowchi_sectors.log](crm_mps_lowchi_sectors.log)):

| 結合を横切る状態の種類 | $(N_L,\ 2S^z_L)$ | 重み |
|---|---|---|
| 電子が結合を横切っていない(スピンの成分) | $(32,0)$ | 83.0% |
| 同上、左半分のスピンが1つ反転 | $(32,\pm2)$ | 7.6% ずつ |
| 電子が1つ結合を横切った(電荷がゆらいだ成分) | $(31,\pm1)$ 、 $(33,\pm1)$ | 0.43% ずつ(合計 1.7%) |

Hubbard 模型の強結合でのエネルギーは、ほぼすべてが**電子が隣へ仮想的に跳んで戻る過程(超交換)**から来る。この過程では結合をまたいで電子数が1つ変わるので、結合に電荷がゆらいだ成分がなければ、その結合のエネルギーは 0 になる。4章で見るとおり、1つの向きのネール配置の超交換を表すだけでも、電子が横切っていない成分・右へ跳んだ成分・左へ跳んだ成分・スピンが入れ替わった成分の4つのブロックを使う。 $\chi=2$ ではブロックを2つしか持てないので、この過程をほとんど表せない。表は $\chi=4$ から載せる。

| $L$ | 真 | UHF(= UHF-sym) | PHF | 切断 $\chi=4$ | 切断 $\chi=8$ | 変分 $\chi=4$ | 変分 $\chi=8$ | 変分 $\chi=16$ |

| 8 | $-0.291$ | $-0.247$ | $-0.364$ (265%) | $-0.296$ (111%) | $-0.291$ (101%) | $-0.361$ (259%) | $-0.273$ (60%) | $-0.291$ (100%) |
| 16 | $-0.333$ | $-0.247$ | $-0.306$ (69%) | $-0.340$ (107%) | $-0.334$ (100%) | $-0.406$ (184%) | $-0.294$ (55%) | $-0.333$ (99%) |

- **PHF** の埋まる割合は $L=8$ の 265%(行き過ぎ)から $L=64$ の 11% まで、系の大きさで大きく変わる(3.2)。

### 3.2 PHF の効果が $1/L$ で消える理由 — 回転子の描像

**描像**: 反強磁性の UHF 解は、副格子 A のスピンがすべて上、B がすべて下を向いた状態に近い。そこで、副格子ごとのスピンの和 $\mathbf S_A=\sum_{i\in A}\mathbf S_i$ 、 $\mathbf S_B=\sum_{j\in B}\mathbf S_j$ を、それぞれ長さ $S=Nm/2$ の**1つの大きなスピン**とみなす( $N$ はサイト数、 $N/2$ は副格子のサイト数、 $m$ は UHF の各サイトの磁化)。UHF は $\mathbf S_A$ が $+z$ 、 $\mathbf S_B$ が $-z$ を向いた積の状態で、

```math
\langle\mathbf S_A\cdot\mathbf S_B\rangle_{\rm UHF}\approx-S^2
```

である。この近似では UHF は $\mathbf S_A^2$ と $\mathbf S_B^2$ の固有状態(大きさ $S$ )で、 $\mathbf S_A^2$ 、 $\mathbf S_B^2$ は $\mathbf S_{\rm tot}^2$ と交換するので、全スピン 0 に射影しても副格子のスピンの大きさは $S$ のまま変わらない。一方、全スピン 0 の状態では角運動量の合成から

```math
\langle\mathbf S_A\cdot\mathbf S_B\rangle_{S_{\rm tot}=0}=\frac{S_{\rm tot}(S_{\rm tot}+1)-S_A(S_A+1)-S_B(S_B+1)}{2}=-S(S+1)
```

となる。**射影で変わるのは $\langle\mathbf S_A\cdot\mathbf S_B\rangle$ の $-S$ だけ**で、同じ副格子の相関の和 $\langle\mathbf S_A^2\rangle$ は変わらない。 $\mathbf S_A\cdot\mathbf S_B=\sum_{i\in A,\,j\in B}\mathbf S_i\cdot\mathbf S_j$ には $(N/2)^2$ 個の対があり、大きなスピンの中の構造は射影で変わらないので、この変化は全部の対に均等に配られる:

```math
\Delta\langle\mathbf S_i\cdot\mathbf S_j\rangle\approx\frac{-S}{(N/2)^2}=-\frac{2m}{N}\quad(\text{副格子が違う対、距離によらない}),\qquad\Delta\langle\mathbf S_i\cdot\mathbf S_j\rangle\approx0\quad(\text{同じ副格子の対})
```

エネルギーは、強結合で Hubbard 模型を Heisenberg 模型 $J\sum_{\langle ij\rangle}\mathbf S_i\cdot\mathbf S_j$ ( $J=4t^2/U$ )とみなすと、隣の結合(約 $N$ 本、すべて副格子が違う対)の変化の和で

```math
E_{\rm PHF}-E_{\rm UHF}\approx J\times N\times\left(-\frac{2m}{N}\right)=-2mJ
```

になり、**系の大きさによらない一定量**である。

**実測との比較**( $L=64$ の開放端、UHF の中央サイトの磁化 $m$ を使った予測):

| $U$ | $m$ | 予測 $-2m$ | 実測 $L\,\Delta SS$ 、 $r=1$ | $r=3$ | $r=2$ (予測 0) | 予測 $-2mJ$ | 実測 $E_{\rm PHF}-E_{\rm UHF}$ |
|---|---|---|---|---|---|---|---|
| 4 | 0.385 | $-0.769$ | $-0.689$ | $-0.441$ | $-0.157$ | $-0.769$ | $-0.696$ |
| 8 | 0.469 | $-0.939$ | $-0.917$ | $-0.818$ | $-0.055$ | $-0.469$ | $-0.453$ |
| 12 | 0.486 | $-0.972$ | $-0.963$ | $-0.915$ | $-0.026$ | $-0.324$ | $-0.316$ |

( $\Delta SS$ は PHF − UHF の $\langle\mathbf S_i\cdot\mathbf S_j\rangle$ で、 $r$ は中央のサイトからの距離。エネルギーは系全体の差。)

$U\ge8$ では予測がよく合う。副格子が違う対( $r=1,3$ )は距離によらずほぼ $-2m/L$ だけ強まり、同じ副格子の対( $r=2$ )はほとんど変わらない。 $L$ を変えても、隣の結合の $L\,\Delta SS$ は $U=12$ で $-0.937$ ( $L=8$ )、 $-0.953$ (16)、 $-0.960$ (32)、 $-0.963$ (64)と $-2m=-0.972$ に近づく。 $U=4$ では磁化が小さく電荷のゆらぎも大きいので、「硬い大きなスピン」の近似も Heisenberg 模型への置き換えも粗くなり、ずれが大きい。

**なぜ真の値に届かないか**: UHF のように向きを決めた解から出発すると、真の状態との違いは2つに分けて考えられる。1つは系全体の向きの回転(Anderson の「状態の塔」に当たる部分)で、もう1つは各結合に広がった量子的なゆらぎ(スピン波)である。**PHF が回復するのは前者だけ**で、そのエネルギーは系全体で $O(1)$ 、1結合あたりでは $1/L$ である。一方、真の値との差 $-0.136$ ( $L=64$ )は後者の分で、結合1本ごとに $O(1)$ あり、系が大きくなっても減らない( $U=12$ の開放端で $L=16$ 、32、64 のとき $-0.087$ 、 $-0.116$ 、 $-0.136$ )。したがって、埋まる割合は $L$ とともに 0 に向かう。小さい系では逆に、 $2m/L$ が必要な補正より大きくなって行き過ぎる( $L=8$ で必要なのは $-0.044$ 、射影は $-0.117$ )。

**別の見方**: 向きが角度 $\beta$ だけ違う2つの UHF の重なりは、およそ $\cos(\beta/2)^N$ で、系が大きくなるとわずかに向きが違うだけでほぼ直交する。ほぼ直交した状態を量子的に重ね合わせても、局所的な量には干渉がほとんど効かず、確率的に混ぜた UHF-sym とほぼ同じになる。

### 3.3 エネルギー: 相関エネルギーの回収率

UHF から厳密な値までの相関エネルギーのうち、各 prior が取り戻した割合( $U=4$ 、8、12 の範囲。負は UHF より悪い)。

| 系 | PHF | 切断 $\chi=4$ | 切断 $\chi=8$ | 変分 $\chi=4$ | 変分 $\chi=8$ | 変分 $\chi=16$ |
|---|---|---|---|---|---|---|
| 1次元開放端 $L=8$ | 55〜57% | $-8$ 〜 0% | 97〜99% | 78〜85% | 98〜99% | 100% |
| 1次元開放端 $L=16$ | 31〜36% | $-64$ 〜 $-36$ % | 93〜97% | 79〜87% | 97〜99% | 99〜100% |
| 1次元開放端 $L=64$ | **8〜10%** | $-162$ 〜 $-78$ % | 85〜91% | **80〜88%** | 96〜99% | 99〜100% |
| 1次元周期 $L=16$ | 33〜39% | $-222$ 〜 $-160$ % | $-13$ 〜 52% | 55〜71% | 73〜83% | 84〜90% |

- **変分 MPS の回収率は $L$ によらない。** エネルギーは結合ごとの項の和で、MPS は各結合の量子的な相関を局所的に持つからである。PHF の回収率が $L$ とともに下がるのと対照的である。

## 4. 結果2: 2つの MPS は少ない状態を何に使っているか

3章の違いの原因を直接見るため、1次元 $L=64$ の中央の結合で、MPS の Schmidt 係数を量子数 $(N_L,\ 2S^z_L)$ ごとに分けた([crm_mps_lowchi_sectors.jl](crm_mps_lowchi_sectors.jl))。

$U=12$ :

| 状態 | 電荷がゆらいだ成分の重み | 残した状態の数(量子数ごと) |
|---|---|---|
| 厳密 | 1.72% | $(32,0)$ 65、 $(32,\pm2)$ 46 ずつ、 $(31,\pm1)$ と $(33,\pm1)$ 36 ずつ、ほか |
| 切断 $\chi=4$ | **0%** | $(32,0)$ 2、 $(32,+2)$ 1、 $(32,-2)$ 1 |
| 切断 $\chi=8$ | 1.70% | 上の4つ + $(31,\pm1)$ と $(33,\pm1)$ 1 ずつ |
| 変分 $\chi=4$ | 1.77% | $(32,0)$ 1、 $(32,-2)$ 1、 $(31,-1)$ 1、 $(33,-1)$ 1 |
| 変分 $\chi=8$ | 1.81% | $(32,-2)$ の重み 15.2% に対して $(32,+2)$ は 0.3%(上下が非対称) |
| 変分 $\chi=16$ | 1.67% | $(32,0)$ 4、 $(32,\pm2)$ 2 ずつ、 $(31,\pm1)$ と $(33,\pm1)$ 2 ずつ(上下対称) |

$U=4$ では厳密な状態の電荷の成分が 11.4% に増えるが、切断 $\chi=4$ は同じく 0%、変分 $\chi=4$ は 11.0% だった。

**切断 MPS は「重みの大きい順」に残す。** 厳密な状態では電荷の成分が1つのブロックあたり 0.43% しかなく、特異値の大きい順に4つだけ残すと、実際にすべてスピンの成分になって電荷の成分がちょうどなくなった。残ったスピンの成分は $+2$ と $-2$ を対称に含むので、**スピン回転の対称性は保たれ、隣のスピン相関は正確**になる(3.1)。しかし電子が結合を横切れないので、超交換のエネルギーも二重占有も失われる。

**変分 MPS は「エネルギーを下げる順」に残す。** 電荷の成分は重みこそ 1.7% しかないが、エネルギーのほぼすべてを担うので、変分 MPS はこれを必ず残す。変分 $\chi=4$ が残した4つの状態は、中央のサイト 32 が上向き、33 が下向きのネール配置から出発する過程にちょうど対応する:

- $(31,-1)$ : サイト 32 の上向き電子が右へ跳んだ状態(左半分の電子が1つ減り、上向きが1つ減る)
- $(33,-1)$ : サイト 33 の下向き電子が左へ跳んだ状態
- $(32,-2)$ : 跳んで戻った結果、2つのスピンが入れ替わった状態

一重項には、逆向きの配置(32 が下向き、33 が上向き)から出発する過程 $(31,+1)$ 、 $(33,+1)$ 、 $(32,+2)$ も同じ重みで必要だが、 $\chi=4$ ではそれを持つ余裕がない。**変分 MPS は「向きを1つに決めたネール配置に、その向きの超交換の過程だけを着せた状態」を選び、スピンの向きを決めることでスピンの絡み合いを節約している。** これが対称性の破れの正体である。

この破れは、中央サイトの $\lvert\langle S^z\rangle\rvert$ にそのまま現れる( $U=12$ 、変分 MPS。切断 MPS はすべての系で 0):

| 系 | $\chi=4$ | $\chi=8$ | $\chi=16$ |
|---|---|---|---|
| 1次元開放端 $L=8$ | 0.284 | 0.005 | 0.000 |
| 1次元開放端 $L=16$ | 0.297 | 0.053 | 0.000 |
| 1次元開放端 $L=32$ | 0.297 | 0.165 | 0.000 |
| 1次元開放端 $L=64$ | 0.297 | 0.178 | 0.000 |
| 1次元周期 $L=16$ | 0.297 | 0.053 | 0.206 |
| 2次元 $W=2$ 開放端 $L=6$ | 0.346 | 0.396 | 0.135 |
| 2次元 $W=4$ 開放端 $L=3$ | 0.179 | 0.442 | 0.426 |
| (参考)UHF | 0.486 | | |

- $\chi=4$ は1次元のすべての系で約 0.3 の磁化を持つ。UHF(0.486)より小さいのは、量子的なゆらぎを一部持っているためである。2次元 $W=4$ では $\chi=4$ で 0.13〜0.18 と小さいが、 $\chi=8$ で 0.44 に増える。
- $\chi=8$ は短い鎖では対称に近いが、鎖が長くなると磁化が育つ(0.005 → 0.178)。長い鎖では、対称な状態が必要とする絡み合いが $\chi=8$ に入りきらないためである。
- $\chi=16$ は1次元開放端では $L=64$ まで対称になる。ただしこれは $U\ge8$ の場合で、相関の長い $U=4$ では $L=24$ 、32、48、64 のとき磁化 0.016、0.029、0.054、0.071 と、鎖が長くなるにつれて破れ始める。周期境界(実質的に $\chi^2$ が要る)と2次元(1本の鎖に並べると遠い結合が生まれる)では $U=12$ でも破れたままで、 $W=4$ では $\langle S^xS^x\rangle\approx0$ と、ほとんど UHF と同じ古典的なネール状態になっている。

### 5.3 向きを持つ量(単一サイト $Z_\uparrow$ )

真の値が 0 なので天井は 1 で、**得をすることはできず、損をしないことだけが問題**になる。スピン回転の対称性を保つ prior(UHF-sym、PHF、切断 MPS)は値が 0 になって利得 1 に戻る。変分 MPS は磁化を持つので、UHF と同じく損をする。 $U=12$ では、 $\chi=4$ で 20 系すべて(利得 0.03〜0.19)、 $\chi=16$ でも1次元開放端以外の 11 系すべて(0.02〜0.71)で損をし、利得 1 に戻るのは対称になった1次元開放端の9系だけである。

| $L=16$ 、 $U=4$ | 0.355 / 0.364 | 0.384 / 0.394 | 13.7 / 13.9 |
| $L=16$ 、 $U=12$ | 0.306 / 0.306 | 0.486 / 0.486 | 21.6 / 21.6 |

VAP では、射影したエネルギーを軌道(上向きと下向きの電子数は同じ)について L-BFGS で最小化した。各系で UHF と、磁化を弱めた UHF( $U/2$ で解いた軌道)の2つから出発し、低い方を採った。 $L=8$ 、 $U=8$ で確かめると、UHF から出発した最適化は勾配 $10^{-8}$ まで収束しており、ランダムな4つの初期点からはもっと高いエネルギーの極小にしか届かなかった。

最適化した軌道は UHF の軌道とほとんど変わらない(磁化の変化は 0.02 以下)。3.2 の描像で考えると理由がわかる。VAP が最小化するのは「平均場のエネルギー + 射影の得 $-2mJ$ 」である。UHF は平均場のエネルギーの極小なので、磁化を $\delta m$ だけ変えると平均場のエネルギーは系全体で $N\,\delta m^2$ の程度悪くなる。一方、射影の得は $2J\,\delta m$ しか変わらない。つりあう $\delta m$ は $1/N$ の程度で、大きな系では軌道はほとんど動かない( $L=8$ 、 $U=4$ でだけ 0.384 → 0.403 と目に見えて動く)。**射影の仕方を変えても、系の大きさとともに効果が消えるという結論は変わらない。**

## 8. まとめ: どの prior をどの観測量に使うか

| 観測量の種類 | 最も良かった prior | 避けるべき prior | 理由 |
|---|---|---|---|
| 電荷の量(オンサイト ZZ、ブロックの電荷の偶奇) | 変分 MPS( $\chi=4$ から天井) | 切断 MPS の低い $\chi$ | 電荷のゆらぎを持つかどうか(4章) |
| 隣のスピン相関 | 対称な MPS(切断 $\chi\ge4$ 、 $U\ge8$ の1次元開放端での変分 $\chi=16$ ) | UHF、向きを選んだ変分 MPS | 一重項の相関を持ち、向きを選ばない |
| 向きを持つ量、それを含む和 | 対称な prior(UHF-sym、PHF、対称な MPS) | UHF、向きを選んだ変分 MPS | 真の値が 0 なので、磁化がそのまま外れになる |
| 遠くの相関 | 相関が減衰する prior(対称な MPS) | 長距離秩序を持つ prior(UHF 系、低い $\chi$ の変分 MPS) | 減衰する真の相関に対する過信 |

**実用上の結論**:

1. **数十〜数百量子ビットでは PHF を使う意味はない。** 射影は系全体の回転を1つ回復するだけで、その効果は $1/L$ で消える(3.2)。十数サイト以下では隣接スピン相関の利得が UHF-sym の約2倍になるが、行き過ぎることがある。
2. **UHF-sym で直せない古典的な相関の不足は、結合ごとの量子的な相関を持つ MPS なら直せる。** 切断 MPS が示すとおり、 $\chi=8$ で表せる状態の中に、ほぼすべての観測量で HF 系と同等以上の prior がある(隣接スピン相関は2倍以上、下回るのは $U=4$ のオンサイト ZZ の 49.5 対 50.3 だけ)。
3. **ただし実際に作れる変分 MPS は、低い $\chi$ でスピンの向きを選ぶ。** 電荷の量には最良だが、スピンの量では UHF と同じ種類の損をする。対称性を戻せる大きさの $\chi$ ( $U\ge8$ の1次元開放端なら $L=64$ まで $\chi=16$ )を使うか、UHF-sym と同じように変分 MPS をスピンの向きについて平均することが考えられる。後者は、 $Z_{i\uparrow}Z_{j\uparrow}\to\langle c_ic_j\rangle+\tfrac43\langle\mathbf S_i\cdot\mathbf S_j\rangle$ などの置き換えで計算できるはずだが、まだ試していない。

## 9. 限界

- 24 サイト以上の系は1次元だけである。2次元は 12 サイト( $W=4$ 、 $L=3$ )までで、そこでは変分 MPS が $\chi=16$ でも対称性を破っていた。大きな2次元系で必要な $\chi$ はわかっていない。
- 切断 MPS は厳密な状態から作るので、実際の prior としては使えない。変分 MPS との差は、「 $\chi$ が同じでも、作り方で prior の性質が逆になる」ことを示すための比較である。
- 変分 MPS は4〜6個の出発点から最良のものを採っただけで、真の最適解である保証はない(2.2)。別の出発点で別の局所解に落ちれば、特に対称性の破れ方と、その結果の利得が変わりうる。
- 利得は中央のサイトと結合、距離依存は $L=64$ の1系で調べた。境界の近くや、ドープした系は調べていない。
- PHF はスピンの射影だけで、並進などほかの対称性の射影は試していない。回転子の描像は $U\ge8$ で定量的に合うが、 $U=4$ では粗い。
